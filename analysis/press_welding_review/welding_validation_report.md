# 용접 추가 검증: 실제 집계 정답과 문맥 경계 제거

2026-09-23. 비교 대상이 ② 용접과 ③ 프레스로 좁혀진 뒤, 용접의 가능성을 실제 집계 정답과 수정한 합성 실험으로 추가 확인했다. 이 문서의 수치는 아래 코드로 새로 실행한 결과다. 기존 Claude 코드나 데이터는 수정하지 않았다.

## 판단

**용접에서 센서를 추가하면 실제 불량수 추정이 좋아진다는 증거를 이번 실험에서는 확보하지 못했다. 반면 Claude의 국소 문맥 합성 실험 결과는 경계 혼입을 제거해도 거의 유지된다.** 따라서 기존 합성 성과를 구현상 문제로 일괄 무효화하는 판단은 부당하다. 남은 핵심 약점은 실제 건별 품질 정답의 부재, 반복 센서 구간, 소수 집계 정답과 실제 집계 기준선 대비 개선 부재다.

이 결과가 가능한 모든 용접 모델의 실패를 증명하지는 않는다. 특히 센서 Ridge와 단순 평균의 MAE 차이는 0.037건으로 작다. 그러나 모델·특징·임계값을 계속 바꾸며 8일에 맞추는 것만으로 새로운 일반화 근거가 생기지는 않는다.

## 1. 실제 불량 집계: 엄격한 날짜 제외 평가

원본 `result` 시트의 날짜별 불량 개수를 합산했다. 정답은 8일, 총 39건이며, 개별 용접의 정답은 만들지 않았다. 3/27은 정답이 없으므로 평가에서 제외했다. 매회 다른 7일만으로 스케일러와 모델을 학습하고 제외한 1일의 불량수를 추정했다. 당일 센서 전체를 사용하므로 **하루가 끝난 뒤 불량수 추정**이며, 생산 전 예측이나 건별 검사 우선순위 성능이 아니다.

모델은 결과를 보기 전에 `Ridge(alpha=10)`로 고정했다. 센서 변수는 가압력·전류·전압·통전시간 각각의 일별 평균과 표준편차 8개다. 생산량만, 센서만, 생산량과 센서 결합을 전부 보고하며 유리한 단일 변수를 사후 선택하지 않았다. 음수 예측은 0으로 제한했다.

| 모델 | 실제 불량수 MAE | RMSE | 단순 일평균보다 오차가 작은 날짜 |
|---|---:|---:|---:|
| 다른 7일 불량수 단순 평균 | **1.536** | **1.846** | — |
| 다른 7일 불량률 × 그날 생산량 | 2.190 | 2.582 | 3/8 |
| 생산량만 Ridge | 1.623 | 1.932 | 4/8 |
| 센서 8개 요약 Ridge | 1.572 | 2.049 | 3/8 |
| 생산량과 센서 Ridge | 1.700 | 2.181 | 2/8 |

Claude 보고서의 기존 비교대상인 생산량 비례 기준선보다 **불량수 단순 일평균이 더 강한 기준선**이었다. Ridge 3종은 생산량 비례 기준선은 이기지만 단순 평균은 못 이겼다. 이 결과를 보고 센서 모델을 유효하다고 선언하면 약한 기준선만 선택한 해석이 된다.

다만 8일의 센서 구간에 반복이 있어 날짜가 서로 완전히 독립이라는 보장도 없다. 현재 정답으로 수행한 소규모 탐색이며, 독립 확증 성능이나 통계적 유의성을 주장하지 않는다. 엄격한 날짜별 학습 분리를 했다는 사실이 원천 데이터의 독립성을 회복시키지는 않는다.

## 2. 합성 주입: 같은 평가 정답으로 문맥 경계 제거

Claude `1162c1d`의 `find_copies`, `make_folds`, 주입 함수, 모델과 시드 7~11을 사용했다. 27행 반복 구간의 최초 출현을 남긴 대표 2,177행을 5개 구간으로 나눴다. 이는 생성 이력상 진짜 원본이나 2,177개의 독립 제품을 입증하는 표현이 아니다.

기존 방식과 수정 방식은 같은 위치·유형·크기의 평가 주입을 공유한다. 수정 방식은 같은 날짜 안에서 보류 구간 경계 양옆 25행의 학습 관측을 제외한 뒤 모델을 적합했다. 임계값 보정도 남은 학습행에서만 한다. 학습·평가 주입 난수는 기존 방식과 동일하게 먼저 생성하므로, 학습행 제거가 평가 정답을 바꾸지 않는다. 모델은 Ctx(raw)와 IsolationForest의 물리 특징 버전 두 가지다.

| 폴드 | 평가 행 | 기존 학습 행 | 경계 제외 행 | 수정 학습 행 | 보류 구간을 과거 문맥으로 쓰는 학습 행: 전 → 후 |
|---|---:|---:|---:|---:|---:|
| 0 | 436 | 1,741 | 25 | 1,716 | 25 → 0 |
| 1 | 435 | 1,742 | 50 | 1,692 | 25 → 0 |
| 2 | 436 | 1,741 | 50 | 1,691 | 25 → 0 |
| 3 | 435 | 1,742 | 50 | 1,692 | 25 → 0 |
| 4 | 435 | 1,742 | 25 | 1,717 | 0 → 0 |

| 주입 설정 | 모델 | 기존 합성 F1 | 경계 제외 합성 F1: 평균 ± 시드 표준편차 |
|---|---|---:|---:|
| 3% | Ctx(raw) | 0.305 | **0.300 ± 0.034** |
| 3% | IF 물리 | 0.272 | 0.220 ± 0.088 |
| 0.5% | Ctx(raw) | 0.052 | 0.056 ± 0.019 |
| 0.5% | IF 물리 | 0.167 | **0.212 ± 0.157** |

Ctx의 3% 결과는 경계를 제거해도 거의 유지됐다. 고가압력 밖의 F1도 0.484에서 0.474로 바뀌었다. 따라서 이 모델의 합성 성과가 경계 혼입 때문에 만들어졌다고 해석할 근거는 없다. IF의 변동에는 학습·보정 표본 자체가 바뀐 효과도 포함되므로, 전후 차이를 모두 누수 제거 효과로 해석하지 않는다.

0.5% 설정은 반올림 때문에 폴드마다 양성 2건, **시드당 총 10건**이다. 5개 시드도 같은 2,177개 원행에 재주입한 것이므로 독립 공장이나 생산일 5개가 아니다. 경계 제외 후 0.5%에서 Ctx는 평균 정밀도 0.030·재현율 0.460·1,000건당 경보 71.6건, IF 물리는 0.197·0.300·11.9건이다. 후자는 시드 간 F1 표준편차가 0.157로 크다. 이 수치는 전부 가정한 합성 이탈에 대한 것이며 실제 불량 정밀도·재현율이 아니다.

남은 한계도 있다. 임계값 보정은 별도 원천 검증 제품이 아닌 학습 원행의 합성 변형에서 이루어진다. 미변형 행의 양품 여부도 실측으로 확인된 것은 아니다. 제공한 AP는 원 보고서와 비교를 위해 서로 다른 폴드 모델의 점수를 합쳐 계산했으며, 별도로 교정된 공통 점수 척도로 해석하지 않는다.

## 3. 주제 판단에 주는 의미

용접을 선택한다면 방어 가능한 목표는 **반복 데이터와 운전 상태 변화를 고려한 공정 이상 경보 및 검사 우선순위 제안**이다. 물리 특징은 설명 자료로 활용할 수 있지만, 이번 결과로 안정 공정조건의 품질 보장이나 실제 결함 유형 판별을 주장할 수 없다. 고가압력 구간에서 판단을 보류하면 판정 커버리지와 해당 구간의 검사 비용도 함께 보여야 한다.

용접의 우선순위를 높일 근거는 대회원본과 연결된 추가 품질 정답, 또는 추가 독립 생산일에서 사전에 고정한 집계 모델이 단순 평균을 개선하는 결과다. 기존 합성 수치의 재현과 경계 제거 후 유지 자체는 긍정적인 구현 검증이지만 그 근거를 대신하지 못한다. 프레스와 비교할 때는 서로 다른 정답에 대한 F1 숫자를 직접 비교하지 말고, 실제로 평가 가능한 목표와 정답 단위가 과제 요구에 얼마나 부합하는지 따져야 한다.

## 재현과 산출물

```sh
PYTHONDONTWRITEBYTECODE=1 /opt/anaconda3/bin/python analysis/press_welding_review/welding_validation_audit.py --claude-code /tmp/kai-claude-review.XP9eUV/claude/code
```

다른 환경에서는 `--claude-code`에 해당 Claude 브랜치의 `claude/code` 경로를 지정한다. 원본 XLSX 위치가 다르면 `--xlsx`로 지정한다. 실라벨 집계만 재현하려면 `--daily-only`를 사용한다.

- `welding_validation_audit.py`: 사전 고정한 집계 모델과 경계 제외 실험.
- `welding_daily_features.csv`, `welding_daily_lodo_predictions.csv`, `welding_daily_lodo_metrics.csv`: 날짜별 입력, 보류일 예측, 전체 비교 결과.
- `welding_injection_fold_counts.csv`, `welding_injection_fold_results.csv`: 폴드 표본 수, 시드별 임계값·TP·FP·FN·TN.
- `welding_injection_seed_metrics.csv`, `welding_injection_metrics.csv`: 시드별 성능과 평균·표준편차, 경보량.
- `welding_validation_summary.json`: 입력 파일·원 코드 SHA-256, 라이브러리 버전, 실험 설정과 결과.
