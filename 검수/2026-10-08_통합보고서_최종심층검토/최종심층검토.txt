2. 종합 판단

이 보고서는 데이터 진단, 오류 조건 분석, 사후 비교의 공개, 재현 자료 구성에 강점이 있다. 핵심 성능 수치와 추가 실험 표에서 이번 검산으로 확인한 계산 불일치는 없었다. 형식적 누수, 단일 사건, 겹치는 분할, 규칙이 성능을 올리는 구조, 강한 기준선의 장점까지 적은 것은 평가상 긍정적이다.

그러나 연구의 증거 범위는 좁다. 같은 정상 세션과 한 이상 사건을 반복 분석한 결과이며, 모델 설계 전에 전체 이상 자료를 이미 본 상태다. 실험 수·해시 잠금·기록 부트스트랩을 늘려도 독립 고장 사건 검증을 대신할 수 없다. 따라서 현재 자료가 뒷받침하는 성과는 다음과 같다.

  “제공된 자료에서 전류 파형을 이용한 이상 구분이 효과적이었고, 수집 공백과 고부하 정상 오경보에 맞춘 두 단계 경보를 구현했다. 추가 통합 후보는 정의한 합성 진동 잡음·충격에서 감시 범위를 넓혔다.”

새 설비·새 고장에 대한 일반화, 실제 고장 전 선행 경보, 현장 고장확률의 정확성, 장기 운전의 경보 예산 충족은 아직 입증되지 않았다. 보고서가 이 한계를 대부분 이미 공개하고 있으므로 ‘한계를 숨겼다’고 평가하는 것은 부당하다. 남은 문제는 일부 요약·운영 문장의 단정이 본문의 제한 조건보다 강하다는 점이다.

제출 가치가 있는 분석 보고서다. 다만 ‘현장 적용이 검증된 범용 예지보전 시스템’으로 평가할 근거는 부족하다. 다른 참가작을 동일하게 직접 평가하지 않았으므로 순위·수상 가능성·확정적인 예상 점수는 부여하지 않는다.

3. 확인된 수치와 강점

공식 test 이상은 분할별 324행이다. 독립 재계산 결과:

모델                         A: TP / FP / FN / F1             B: TP / FP / FN / F1
v2                           302 / 0 / 22 / 0.964856230        308 / 3 / 16 / 0.970078740
1단계 v2+R1                  324 / 0 / 0 / 1.000000000         324 / 3 / 0 / 0.995391705
2단계 v2+R1+R2               324 / 0 / 0 / 1.000000000         324 / 0 / 0 / 1.000000000

2단계만 울리고 1단계가 울리지 않은 행은 A·B 모두 0이다.

2.8절의 전체 600행·21기록 기준 결과도 동봉 기준표와 맞는다.
  - v2: F1 A 0.961938 / B 0.970990, 미탐 44 / 31행.
  - 통합 후보: F1 A 0.968186 / B 0.974490, 미탐 37 / 27행.
  - 실제 사건에서 추가로 잡은 행은 A 7행, B 4행이다. A·B는 같은 이상 사건을 공유한다.
  - 진동 단독 VD3: 이상 16/21기록 탐지, F1 0.679739 / 0.657718.
  - 합성 진동 잡음 강도 1: 통합 후보 57.4% / 68.0%.
  - 합성 진동 충격 강도 4: 통합 후보 92.1% / 98.6%.

실질적인 강점은 다음과 같다.

가. 데이터 이해가 모델과 연결되어 있다.
초당 10회, 최대 50행 기록, 정상과 이상의 날짜·형식 차이, 단일 사건, 운전 상태 변화가 전처리·평가·경보 규칙에 연결된다. 물리적 해석이 불가능한 부분도 진단 매트릭스에서 구분한다. 일반적인 전처리 목록에 그치지 않는다.

나. 비교의 불리한 결과도 공개한다.
보완 LSTM은 v2와 F1이 비슷하고, 특징 맞춤 5NN은 실제 F1이 비슷하면서 일부 정상 오경보가 더 적다. max|z|+R1+R2도 이번 사건에서는 매우 높은 성능을 낸다. 따라서 ‘새 알고리즘이라 우월하다’는 주장 대신 파형 특징·경보 상태 유지·운영 규칙의 기여를 설명할 수 있다.

다. R1과 R2의 역할·비용을 나눴다.
R1이 초기 미탐을 줄이는 동시에 오경보를 이어 붙일 수 있고, R2가 진동 단독 탐지를 희생한다는 점까지 수치로 보여 준다. 2.7절에서 단순 기준선에도 R1을 붙인 것은 타당한 대조다. R1은 미래를 보고 과거를 채우는 point-adjust와 같지는 않지만, 이어진 한 사건에서 비슷한 점수 이득을 얻는다는 설명도 적절하다.

라. 2.8절의 개선 범위를 비교적 정확하게 한정했다.
주입 시작 전 표본 보존, 개발·평가 seed 분리, 같은 보정 예산, 새 주입 가족, 후보 순위의 불안정성, 결합으로 떨어지는 일부 탐지율을 공개했다. 합성 시험의 의미는 있다. 독립 실제 고장으로의 일반화와는 다른 증거다.

마. 재현 자료가 구체적이다.
학습 캐시 없이 재현한 기록, 배포 ZIP과 실행 ZIP의 파일 동일성 기록, 해시 검사, 예측 파일, 부분 실행, 설치 없는 확인 도구가 있다. 이번에 직접 수행한 배포물 검사도 통과했다. 다만 재현은 ‘같은 계산이 나온다’를 확인하며 ‘설계가 일반화된다’를 확인하지는 않는다.

4. 제출 전 우선 수정할 사항

4-1. 이상 확률의 성능은 test 정답 비율을 이용한 조건부 평가다.
위치: 2.5절, 원고 300행, 검토 PDF 16~17쪽.
근거 코드: claude/code/press/tvt/08_probability.py 42~46행.

코드는 test 정답의 평균 y.mean()으로 pi_file을 구하고, 이 값을 실제 확률 변환에 넣는다. 따라서 단조 회귀의 적합은 valid만 사용했더라도 최종 평가 확률 전체가 test 정답과 독립적으로 생성된 것은 아니다.

보고서의 ‘test 행은 보정에 쓰지 않았다’는 문장은 회귀 적합 범위만 뜻한다면 맞지만, 독자가 최종 확률 계산에도 test 라벨을 전혀 쓰지 않았다고 읽을 수 있다. 보고서가 test 비율 사용 사실을 바로 뒤에서 밝히므로 은폐로 볼 사안은 아니다. 해석을 더 정확히 해야 한다.

같은 예측 CSV에서 다시 계산한 Brier:
  - test 비율 사전: A 0.004558 / B 0.003806.
  - 사전 1% 고정: A 0.018249 / B 0.012454.

두 값은 다른 사전을 적용한 확률을 같은 파일의 라벨로 채점한 결과다. 이 차이를 그대로 현장 성능 저하율로 해석해서도 안 된다. 파일의 이상 비율 자체가 현장의 1% 가정과 다르기 때문이다. 참고로 정상·이상별 평균 제곱오차에 99%·1% 가중치를 주면 사전 1% 출력의 Brier는 약 0.002510 / 0.002588이지만, 이것도 이 단일 사건의 조건부 분포가 유지된다는 가정 아래 재가중한 값이다. 새로운 현장 검증이 아니다.

권고 문안:
  “단조 회귀는 valid 자료만으로 적합했다. 표의 Brier·ECE는 test 파일의 실제 이상 비율을 알고 있다는 조건에서 사전을 맞춘 사후 평가값이며, 미지 현장의 확률 보정 성능을 뜻하지 않는다. 운영 표시 확률은 별도로 고정한 사전 1%를 사용한다.”

추가로 55% 표시 상한은 n+1에서 우도비를 자르는 표시 정책이다. 55%가 실제 고장확률의 통계적 상한·하한이라는 뜻이 아님을 본문에도 명확히 적는 편이 좋다. 경보 F1은 확률 층과 독립이므로 이 지적은 공식 경보 성능 수치를 무효화하지 않는다.

4-2. ‘시간당 6건 기준 안’의 해석 범위가 인용문헌보다 넓다.
위치: 2.5절 299행, 4.3절 630·633~640행, PDF 36쪽.

E3의 0건/38.6406분에서 포아송 양측 95% 상한 5.72799건/시간을 계산하는 산술은 맞다. 그러나 이를 운영 기준 충족 근거로 쓰기에는 조건이 다르다.

보고서가 인용한 exida 문헌의 Table 1은 ‘최소 30일 자료’를 전제로 한다. 시간당 약 6건은 운전 담당 지점 전체에 표시되는 경보의 평균 목표이고, 최대 관리 가능 수준은 약 12건으로 구분한다. 펌프 한 대의 정상 오경보만으로 전체 경보량 기준 충족을 판단할 수 없다. 실제 이상 경보와 다른 설비 경보도 담당자의 작업량에 포함된다.

더구나 E3는 창마다 학습·보정을 바꾼 결과를 합쳤고, R2 설계에 참고했던 같은 날의 자료를 재사용했다. 일정 사건률의 독립 포아송 과정이라는 가정과 사후 선택 문제를 넘어서지 못한다.

권고 문안:
  “E3의 짧은 재생 자료에서 계산한 참고 상한은 5.7건/시간으로, 문헌의 평균 목표 약 6건/시간과 비슷한 수준이다. 다만 문헌은 최소 30일의 운영 지점 전체 경보량을 기준으로 하므로 이번 결과로 현장 기준 충족을 판정하지 않는다.”

원문: https://www.exida.com/articles/ALARM-MANAGEMENT-AND-ISA-18-A-JOURNEY-NOT-A-DESTINATION.pdf
확인 위치: 인쇄 8쪽, Table 1. 기준 전체를 현재 ISA 표준의 인증 기준이라고 단정하지 않고, 보고서가 직접 인용한 문헌의 조건을 확인했다.

4-3. 교대당 34건은 경보량의 임시 기준이며, 진동형 고장의 대응 기준을 대신하기 어렵다.
위치: 4장 첫머리 560행, 4.2절 578행, 4.3절 629·640행, PDF 31·35~36쪽.

34건은 E3에서 관측한 2건/38.6분의 사건률을 고정해, 8시간에 34건 이상 날 포아송 확률이 4.65%가 되도록 정한 값이다. 산술은 맞다. 그러나 사건률을 2건만으로 추정한 불확실성을 포함한 미래 예측확률은 아니다.

자료 안에서도 B test의 정상 사건률은 시간당 7.457건이다. 이 사건률이 8시간 유지된다고 가정해 같은 포아송 식을 적용하면 34건 이상 발생할 확률은 약 99.9879%다. 이는 실제 미래에서 그 확률이 관측되었다는 뜻이 아니라, 보고서 안의 다른 관측률만 적용해도 34건의 의미가 달라짐을 보여 주는 민감도 계산이다. 본문의 41·74·94건 범위 공개는 좋은 점이지만, 4장 첫머리의 ‘34건 이상 쌓일 때만’은 지나치게 단정적이다.

더 근본적인 문제는 빈도와 심각도가 다르다는 것이다. 60초 안의 경보를 한 사건으로 묶으므로, 진동형 이상이 계속 이어지면 사건 수는 작게 유지될 수 있다. 심한 이상 한 건이 34건 조건을 충족하지 않는다는 이유로 점검 대상에서 빠질 수 있다. 1단계 화면에 남겨 둔다는 사실만으로 R2의 진동 고장 미탐 비용이 해소되지는 않는다.

권고:
  - 34건을 ‘도입 첫 달의 경보량 모니터링용 임시 시작값’으로 일관되게 표시한다.
  - ‘34건 이상일 때만’이라는 배타적인 조치 조건을 없앤다.
  - 진동 보완 경로의 지속시간·반복 기록·강도에 따른 별도 검토 조건을 제안으로 분리한다. 검증되지 않은 수치 임계값을 새로 발명하지 않는다.
  - 통합 후보는 점수 체계가 다르므로 34건을 그대로 적용하지 않는다는 629행의 원칙을 유지한다.

4-4. 11/11 탐지의 ‘95% 하한 76.2%’는 독립 고장 탐지율의 하한이 아니다.
위치: 2.5절 298행, PDF 16쪽.

0.05^(1/11)=0.7616이므로 단측 이항 하한 계산 자체는 맞다. 문제는 11개가 서로 독립적인 고장 사건이 아니라 한 사건의 연속 기록이라는 점이다. R1 때문에 기록별 탐지 여부가 더욱 강하게 연결된다. 다른 절에서 단일 사건 한계를 밝힌 것과 별개로, 이 숫자 바로 옆에 독립 가정이 없으면 모집단 고장 탐지율의 보장처럼 읽힐 수 있다.

권고: 이 하한을 빼거나 다음처럼 쓴다.
  “기록을 독립 시행으로 가정한 형식적 이항 하한은 76.2%지만, 실제로는 한 사건의 연속 기록이므로 새로운 고장 사건의 탐지율 하한으로 해석할 수 없다.”

정상 오경보 이항 상한·포아송 상한도 짧은 같은 세션, 의존성, R2 사후 설계가 포함된 참고 계산이라는 제한이 필요하다. 기존 블록 부트스트랩의 ‘같은 사건 안’이라는 제한은 이미 적절하게 적혀 있다.

4-5. 핵심 문장을 관측 범위 안으로 제한할 필요가 있다.
위치: 요약 16~20행, 1.5절 107행, 2.6절 319행, 3장 477·481행.

‘고장의 흔적은 전류 파형에 남고 오경보는 진동에서 생긴다’, ‘고장 여부는 전류 파형이 가른다’는 문장이 반복된다. 이 데이터에서는 강한 구분 신호지만, 원인은 고장·운전 조건·계측/수집 차이 가운데 확정하지 못했다는 본문의 판단과 함께 읽혀야 한다.

권고 문안:
  “제공된 자료에서는 이상 파일을 구분하는 핵심 신호가 전류 파형의 변화였고, 고부하 정상에서 발생한 v2 오경보는 주로 진동 크기 성분에 집중되었다.”

이는 성과를 없애는 수정이 아니다. 확인한 현상과 고장 원인에 대한 추론을 정확히 나누는 수정이다. 라벨에 대한 높은 탐지 성능 자체는 관측 결과로 남는다.

요약의 ‘고부하 9/53→1/53’에도 ‘B, valid+test, α 5%, 사후’를 붙이는 것이 좋다. 운영 α는 1%이고, 이 수치는 α 5%에서 오류 조건을 확대한 분석이다. 본문 3.2절은 이를 이미 정확히 밝히지만 요약은 조건을 생략한다.

4-6. 진폭 감소에 대한 3.6절 문장에 내부적인 충돌이 있다.
위치: 552~553행, PDF 30쪽.

552행은 파형을 유지하는 측판·끝면 마모가 ‘R2에 막혀 1단계 경보로만 나간다’고 쓴다. 바로 다음 553행과 E2는 진폭 감소를 모델이 거의 못 잡는다고 한다. 앞단 v2가 경보를 만들지 못한 경우에는 1단계에도 경보가 남지 않는다.

권고 문안:
  “파형이 유지되는 전류 진폭 감소형 마모는 앞단 v2가 경보를 만들지 못할 수 있다. 다른 크기 변화로 1단계 경보가 발생하더라도 전류 파형이 정상이면 R2가 2단계 승격을 보류할 수 있다. 전류 진폭 기준선 추세 감시는 별도로 검증해야 할 제안이다.”

5. 해석상 남지만 문장만으로 해결되지 않는 한계

5-1. 사전 잠금과 독립 검증은 다르다.
해시 잠금은 실행 이후 선택 변경을 탐지할 수 있지만 설계자가 이미 본 test 정보를 지우지 못한다. 원고 236행은 설계가 전체 이상 자료 열람 후였음을 분명히 밝힌다. ‘공식 성능’은 제출에서 대표로 쓰는 값이라는 뜻이지 독립 검증된 성능이라는 뜻은 아니다. ‘준-표본 밖’도 같은 날의 착안 기록을 제외한 재분석이므로 ‘착안 기록 제외 재평가’가 더 정확한 이름이다.

5-2. 새 통합 후보의 주된 기여는 합성 감시 범위다.
실제 사건의 개선은 이상 600행 중 A 7행·B 4행의 미탐 감소이고, 특징 맞춤 5NN과의 차이는 같은 사건 안 부트스트랩에서도 방향이 확정되지 않는다. 정상 오경보는 통합 후보 B 3/180, 5NN·Ridge 1/180이다. 실측 사건에서 일방적으로 우월한 모델이라고 할 수 없다.

반면 같은 주입 조건에서 전류 왜곡 감지를 유지하며 진동 잡음·충격 탐지를 크게 넓힌 점은 실험적 기여다. 정상 자료만으로 선택했다는 것은 실제 이상 라벨을 새로 사용하지 않았다는 뜻이며, 합성 가족과 강도에 대한 설계자의 선택이 없다는 뜻은 아니다. 가족 하나를 빼면 4번 중 2번 1위가 달라지고 한 경우 선택 후보가 9위가 된다는 결과가 이를 잘 보여 준다. 본문 2.8절의 현재 제한적 채택 결론을 유지하는 것이 적절하다.

5-3. 시간당 오류보다 수집 조건의 변화에 더 크게 흔들릴 수 있다.
2.8절에서 가정한 시각 흔들림의 최악 정상 경보율이 A 95.0%·B 97.2%이고, 겉보기 주파수 −0.1Hz에도 급증한다. 시각 흔들림은 실제 계측 오차를 측정한 결과가 아니라 가정한 재합성 시험이다. 따라서 현장에서도 정확히 그 비율이 날 것이라고 할 수는 없다. 다만 재보정·시각 동기화 없이 다른 설비에 바로 옮겨도 된다는 근거는 없다.

1.4절에서 전류가 교류 순시값이라는 판단도 음수가 존재한다는 이유만으로 확정되지는 않는다. 부호와 매우 높은 사인 적합도가 그 해석을 지지하나 센서 정의가 없는 만큼 ‘교류 순시값으로 해석했다’가 더 정확하다. 0.6Hz 앨리어싱·99/101ms 역산을 가설로 남긴 현재 처리는 적절하다.

5-4. Conformal α는 모든 현장 상태에서의 오경보 보장이 아니다.
기록 최대값으로 보정하는 설계는 반복 행 검정 문제를 고려한 선택이다. 그러나 보정 기록과 미래 기록의 교환 가능성, 기록 길이·운전 상태·센서 조건의 유사성이 필요하다. 정상 분포가 바뀌고 R1이 경보를 덧붙이면 최종 사건률을 α로 보장할 수 없다. 보고서는 R1 이후 보장 부재를 이미 밝힌다. 통합 후보의 ‘단일 경보 예산’도 동일한 명목 보정 절차라는 뜻으로 유지하고 현장 보장으로 확대하지 않아야 한다.

참고: Angelopoulos & Bates, A Gentle Introduction to Conformal Prediction and Distribution-Free Uncertainty Quantification, 특히 시계열 의존성·분포 변화의 제한.
https://arxiv.org/html/2107.07511v6

6. 구성과 전달력

보고서는 요약과 초반 표에서 제출 모델 1·2단계를 보여 주므로 독자가 최종 산출물을 찾을 수 있다. 다만 2.7절의 긴 대조, 2.8절의 새로운 후보, 4.3절의 Ridge 병행 권고와 통합 후보 시험 운영이 이어지면서 모델 선택 이야기가 여러 번 다시 시작된다. 표본 단위도 행·기록·사건, 11기록·21기록, α 1%·5%, test·valid+test로 바뀐다.

권고하는 편집은 다음과 같다.
  - ‘공식 1단계 / 사후 2단계 운영 규칙 / 연구용 통합 후보’의 세 역할을 한 작은 표로 고정한다. 모델 이름을 설명할 때마다 역할이 바뀌지 않게 한다.
  - 표 제목에 [자료 범위 / α / 평가 단위 / R1 유무]를 일관되게 쓴다.
  - 2.7절의 학습 탐색 세부, 전체 규칙 격자, 해시·AST·검증 로그 설명은 부록으로 옮길 수 있다. 본문에는 채택 근거와 결과의 한계를 남긴다.
  - 2.8절 표에서는 전체 21기록뿐 아니라 기존 뒤 11기록 수치를 가까이 배치해 F1 상승 폭을 오해하지 않도록 한다. 현재 420행의 설명은 맞지만 표 아래 문장에 숨어 있다.
  - 4.3절의 도입 시험 대상은 통합 후보 하나로 읽히도록 정리한다. Ridge 병행은 비교 기준이라는 629행의 결정을 앞 문단에도 맞춘다.
  - 6장의 본문은 실행 명령·검증 환경·직접 재현 범위·예외를 먼저 보여 주고, 나머지 파일 매핑은 부록으로 보낼 수 있다.

44쪽 미리보기의 선정한 11쪽에서 명백한 글자 겹침이나 잘림은 확인하지 못했다. 13·17·40쪽은 표와 설명이 매우 조밀하다. 이 결과는 한컴으로 다시 조립한 최종 PDF의 레이아웃 검사를 대신하지 않는다.

8. 제출 형식과 버전 일치

검토용 PDF는 첫머리와 바닥글에 ‘검토용, 한컴 양식 아님’이라고 적혀 있다. 통합 원고의 773행과 PDF 44쪽에는 필수 만족도 조사 화면이 ‘[제출 전 삽입]’ 상태다. 표지 서명과 정식 양식 조립도 이 PDF에서 완료되었다고 볼 수 없다. 공식 과제공개 문서는 결과보고서를 첨부 양식의 PDF로 제출하고 만족도 조사 완료 화면을 넣도록 요구한다. HWPX 자체를 제출해야 한다는 뜻은 아니다.

보고서 6장은 ‘북적북적_code_통합본.zip’을 기준으로 한다. main의 claude/submission/북적북적_code.zip은 별도 기존 버전이다. 확인한 두 ZIP의 파일 수는 기존 306개, 통합본 402개다. 통합 보고서와 기존 ZIP을 조합하면 2.8절·추가 감사·실행 설명이 일치하지 않는다. 제출에 사용하는 ZIP 이름뿐 아니라 위 SHA-256까지 확인하면 혼동을 줄일 수 있다.

통합본 README에는 원본 해시 검사와 브랜치에 따른 빌더 실행 조건이 적혀 있다. 이번 검토는 HWPX 빌더를 실행하지 않았으므로 조립 명령의 성공 여부를 보증하지 않는다. 현재 PDF는 내용 검토 근거로 유효하지만 최종 제출본으로 완결된 상태는 아니다.

9. 권고하는 최종 수정 순서

1) 2.5절 확률 평가를 ‘test 사전 비율을 알고 있다는 조건의 사후 평가’로 정확히 한정한다.
2) 4.3절의 ‘시간당 6건 기준 안’ 문장을 참고 비교로 바꾸고, 최소 30일·운영 지점 전체 경보라는 원문 조건을 적는다.
