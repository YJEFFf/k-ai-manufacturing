준용 결과보고서 검수 자료 — 2026-10-04

검수보고서.txt부터 읽으면 된다. 쪽수별 지적, 근거, 수정 예시와 기각한 과도한 지적을 담았다.
참고문헌_25건_대조표.csv에는 문헌별 실재 여부, 원문 확인 범위, 주장 지지 여부와 권장 서지 표기가 있다. Excel에서 한글이 보이도록 UTF-8 BOM으로 저장했다.
수치_독립검산.json은 원자료 집계, 제공된 성능표 258행의 산술 확인, 기록 단위 F1 비교 등의 결과다.
검수범위_및_파일해시.json은 검토한 보고서·코드 버전과 SHA-256을 기록한다.
verify_numbers.py는 해당 수치 확인을 다시 수행하는 Python 표준 라이브러리 스크립트다.

검토 대상
- 관련 자료/TalkFile_결과보고서_북적북적.hwpx.hwpx (한글 PDF 변환 기준 31쪽)
- GitHub claude/press-cases의 e436fa822da1420e8da8d493fb1265d1f65cefe3 커밋

이 자료는 위 버전의 검수 기록이다. 이후 수정된 보고서·코드에는 지적이 이미 해소됐을 수 있으므로 적용 전 버전을 확인한다. 원본 보고서와 분석 코드는 수정하지 않았다. 모든 모델의 재학습이나 모든 유료 문헌의 전체 원문 확인을 수행한 것은 아니며, 확인 범위는 보고서와 대조표에 표시했다.

수치 확인 재실행

저장소 루트에서 아래 순서로 실행한다. Python 3.10 이상을 사용한다. 원본 CSV 두 개는 데이터셋/3. 소성가공 예지보전 AI 데이터셋/에 있어야 한다. 검산 스크립트는 같은 깊이의 폴더에서 press_data_normal.csv와 outlier_data.csv를 찾는다.

git fetch origin claude/press-cases
git archive --format=zip --output=../review-source-e436fa8.zip e436fa822da1420e8da8d493fb1265d1f65cefe3 claude

Windows PowerShell에서 다음 명령으로 위 ZIP을 푼다. 같은 이름의 출력 폴더가 이미 있으면 새 폴더명을 정하고 --source에도 같은 이름을 사용한다.

Expand-Archive -LiteralPath ../review-source-e436fa8.zip -DestinationPath ../review-source-e436fa8

python "검수/2026-10-04_준용_결과보고서/verify_numbers.py" --repo . --source ../review-source-e436fa8 --out ../reaudit.json

reaudit.json을 수치_독립검산.json과 비교한다. 경로 표기는 실행 환경에 따라 달라질 수 있다. 스크립트는 원자료의 행·기록 수와 제공 산출물의 산식을 확인하며, 모델을 재학습하거나 누락된 예측 파일을 생성하지 않는다.

보고서 파일 경로는 저장소 루트 기준이다. source_sha256의 claude/ 해시는 위에 고정한 검토 커밋의 Git blob 원본 바이트 기준이다(git show 커밋:경로). Windows에서 파일을 꺼낼 때 줄바꿈이 바뀌면 로컬 파일의 해시는 달라질 수 있다. 개인 PC의 임시 폴더 없이도 해당 커밋으로 검토 범위를 추적할 수 있도록 정리했다.
