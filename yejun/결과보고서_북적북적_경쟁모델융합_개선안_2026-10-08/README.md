# 경쟁모델 융합 개선안 — Windows 실험 반영본

준용의 c898be2 원고 복사본에 정상 전용 결합 후보 선택과 사후 평가 결과를 반영했다. **기존 공식 제출본과 구분한 개선안**이다. 원본은 `claude/report/`에 있으며 `원본보관/final_v5.md`도 초기 Markdown 그대로다.

2.8절에 59개 후보와 별도 OR 4개 비교, 정상 전용으로 고정한 V2+VD3@1, A/B 실제 파일·인과적 주입·센서 조건 변화 결과를 추가했다. 전체 이상 21기록의 R1 없는 행 F1은 A 0.968186, B 0.974490이며 정상 오경보는 0/120·3/180기록이다. 진동 잡음·충격 탐지가 늘었지만 B 전류 왜곡·지속 증폭 탐지는 일부 낮아져 손실도 명시했다. 독립 사건 일반화나 전반적인 센서 강건성 개선을 주장하지 않는다.

첫 페이지 요약을 줄여 서명란까지 표시되도록 하고, 과도한 일반화 문구와 기존 감쇠 충격의 시작 전 변화 한계를 수정했다. 원래 그림 14개와 신규 그림15, 기존 양식으로 조립한 별도 HWPX/PDF가 이 폴더에 있다. HWPX/PDF는 Git 제외 대상이므로 다른 PC에서는 다시 조립한다.

실행 명령과 수치 근거는 [실험 README](../analysis/press_frontier_improvement_2026-10-08/README.md), 한컴 원고·표·캡션·페이지 검수는 [레이아웃 감사](../analysis/press_frontier_improvement_2026-10-08/outputs/report_layout_audit.json)에 있다. 표지 서명과 만족도 조사 캡처는 실제 제출 전 마무리 항목이다.
