# 결과보고서 개선본 — 통합 제출 ZIP 반영본

준용의 c898be2 원고 복사본에 정상 전용 결합 후보 선택과 사후 평가 결과를 반영했다. **기존 공식 제출본과 구분한 개선안**이다. 원본은 `claude/report/`에 있으며 `원본보관/final_v5.md`도 초기 Markdown 그대로다.

## 2.8절 사후 보완

- 정상 전용으로 고정한 통합 후보(v2 + 진동 차분 잔차, 코드 이름 V2+VD3@1)를 기록했다. 후보는 56개, 경로별 OR 4개는 참고 대조다.
- 실제 파일·인과적 주입·정상 조건 변화 결과를 넣었다. 전체 이상 21기록의 R1 없는 행 F1은 v2 0.962·0.971 → 통합 후보 0.968·0.974이고, 정상 오경보는 0/120·3/180기록으로 같다.
- 2026-10-08 보완(검수 b9ad5e9·재채점 c195d68 반영)에서 아래를 바꿨다.
  - 비교기 3행을 지웠다. 같은 조건의 특징 맞춤 5NN·3채널 Ridge 비교와 기록 블록 부트스트랩 구간을 추가했다. 5NN과는 F1로 갈리지 않고, 차이는 진동 잡음·충격 주입까지 잡는 감시 범위다.
  - 주입 가족 제외 시 선택 안정성(4회 중 2회 변경), 선택에 쓰지 않은 세 변화, 겉보기 전류 주파수 이동(−0.1Hz에서 정상 경보 급증), 보정 기록 오염 결과를 2.8·3.6·4.3절에 넣었다.
  - 4.3절 합성 열화 시험을 2.6절 E1·E1b 확장으로 다시 서술하고 문장을 새로 썼다. 5장 추가 기여는 단일 경보 예산으로 좁혔다.
  - 6장을 통합 제출 ZIP(`yejun/submission/press_integrated_2026-10-08/북적북적_code_통합본.zip`) 구성에 맞춰 다시 썼다. 파이썬 3.14, 실행 옵션, 예측 파일 위치, 새 환경 실행 결과, 동결 모델 평가 도구를 담았다.
  - 참고문헌 [30]·[31]을 추가했다.
  - 모의 재채점(review/regrade_b26115a) 뒤 채점자가 짚은 표현을 고쳤다: --extra-audits 필요, CD 후보 설명, 배포용 PROTOCOL·잠금 관계, environment_original.yml의 성격, 재생 검증 범위.
- 독립 사건 일반화나 전반적인 센서 강건성 개선을 주장하지 않는다.
