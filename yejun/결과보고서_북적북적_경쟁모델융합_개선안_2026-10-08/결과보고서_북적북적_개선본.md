# 표지

- 부문: 일반국민/대학(원)생 부문
- 프로젝트명: 설비 물리·데이터 결함 진단에 기반한 프레스 유압펌프 이상 조기 경보와 오경보 발생조건 분석
- 팀명: 북적북적 (팀장 허예준, 팀원 장준용)

## 내용요약

◦ 데이터 진단: 프레스 유압펌프의 이상 조기탐지와 정상 운전변화 오경보를 분석함. 저장 정밀도 차이만으로 행 F1 0.992가 나오는 누수를 정밀도 맞춤으로 제거함. 최대 5초의 단속 기록, 정상·이상의 날짜 차이, 단일 고장 사건이라는 제약을 명시함.
◦ 모델·성능: 정상 자료로 학습한 크기·전류 파형·동역학 모델 v2의 R1 없는 test 행 F1은 A 0.965·B 0.970임. 같은 특징을 넣은 5NN도 0.970·0.972로, 성능의 주된 근거는 특징에 있음. 사건 지속 규칙 R1을 더한 기존 잠금 모델은 1.000·0.995이나 단일 사건의 경보 유지 효과가 포함된 값임.
◦ 오류·적용 조건: 미탐은 기록 시작부에, 오경보는 고부하 정상의 크기 단독 경보에 몰림. 사후 추가한 R2 교차 확인은 고부하 오경보를 줄이지만 진동형 변화도 일부 보류함. 진동 단독 변화·진폭 감소·표본 시각 흔들림은 별도 점검이 필요함.
◦ 현장 활용: 진동 2·전류 1채널로 주의와 점검 요청을 나누고, 경보 근거별 점검 순서와 재보정 기준을 제시함. 합성 주입 결과는 가정한 신호 변화의 탐지 시험이며 실제 고장 전 선행 시간을 뜻하지 않음.
◦ 사후 보완: 정상 자료만으로 고정한 통합 후보(v2 + 진동 차분 잔차)는 같은 21기록에서 R1 없는 행 F1을 0.962·0.971에서 0.968·0.974로 올렸고 정상 오경보(0/120·3/180)는 같았음. 특징 맞춤 5NN과는 F1로 갈리지 않으며, 차이는 진동 잡음·충격 주입까지 잡는 감시 범위임(2.8절).
◦ 재현성: 제출 ZIP의 run_all.py로 기존 전처리·학습·예측·수치 대조(43항목)와 사후 보완 실험·검산을 실행함(추가 감사는 --extra-audits). 새 가상환경에서 단계별로 모두 통과함(6장).
◦ 한계: v2 특징과 R1·R2는 전체 자료를 본 뒤 설계함. A·B의 이상은 같은 사건이고 정상 평가 기록도 겹침. 정상 자료 안의 재분할이나 새 잠금은 독립 고장 검증을 대신하지 못하며, 다른 날짜·설비·사건의 추가 검증이 필요함.

# □ 제1장. 데이터 이해 및 진단〔15점〕

◦ 핵심 결과 한눈에(test, 같은 시간순 분할·같은 보정 α 1%, 행 단위)

| 모델 | 실시간 행 F1 A / B | † 행 AUROC A / B(문턱 무관) | 미탐 행 A / B | 오경보 행 A / B |
|---|---:|---:|---:|---:|
| MLP 오토인코더(베이스라인 F1 최고) | 0.498 / 0.498 | 0.801 / 0.770 | 216 / 216 | 2 / 2 |
| 5NN 거리(베이스라인 AUROC 최고) | 0.474 / 0.487 | 0.895 / 0.862 | 223 / 218 | 1 / 5 |
| max\|z\|(크기 성분만) | 0.404 / 0.428 | 0.862 / 0.818 | 242 / 235 | 0 / 3 |
| v1(크기 + 전류 파형) | 0.904 / 0.912 | 0.932 / 0.927 | 57 / 50 | 0 / 3 |
| 기반 모델 v2 | 0.965 / 0.970 | 0.975 / 0.974 | 22 / 16 | 0 / 3 |
| **v2 + R1 (잠금 모델, 공식 성능 = 1단계 "주의")** | **1.000 / 0.995** | 규칙(해당 없음) | **0 / 0** | **0 / 3** |
| v2 + R1 + R2 (2단계 "점검 요청", test 확인 후 추가) | 1.000 / 1.000 | 규칙(해당 없음) | 0 / 0 | 0 / 0 |

    * 공식 성능은 사전 잠금 모델(v2+R1)의 값이고, 2단계는 R2 교차 확인을 더해 늘 1단계 경보 안에 있다(2.5절). 1.000은 약 3분짜리 단일 고장 사건의 결과이며, valid부터 이어 돌리면 R1을 붙인 어느 모델이든 0.982~1.000이라(test 기록부터 따로 돌리면 IsolationForest+R1 0.612·0.609, v2+R1 1.000·0.995로 갈림) 기반 모델의 우열은 R1 없는 F1·AUROC 열로 읽는다. 이 우위의 원천은 전류 파형·동역학 특징이며, 같은 특징을 넣은 5NN에서도 재현된다(2.4·2.7절 †). 고부하 정상 오경보는 v2 단독(9/53, 분할 B α 5%)이 베이스라인(1~10/53)보다 낫지 않고 v2 경로에서 이를 줄인 것은 R2다(3.2절).
  - 오류 조건: v2의 미탐은 기록 시작 직후에, 오경보는 고부하 정상의 크기 성분 단독 경보에 몰렸다(학습에 없던 정숙 구간 90기록의 오경보는 10개 모델·α 1·3·5%를 합쳐 1행). R1은 test 미탐을 없앴고 R2는 그 경보 유형을 2단계로 올리지 않는 규칙으로 착안 자료 안에서 분할 B 고부하 오경보 기록을 9/53에서 1/53으로(α 5%) 줄였다(3.2~3.4절).
  - 현장·재현: 진동 2·전류 1채널만으로 두 단계 경보(주의 = 잠금 모델, 점검 요청 = R2 교차 확인을 더한 모델)와 경보 근거별 점검 순서·품질 조치를 낸다(4장). 명령 하나로 test 예측 파일·보고서 수치 대조까지 끝나고 새 가상환경에서 수치 43/43이 일치했다(6장).

## ◦ 1.1 과제와 출제 의도

- 다섯 과제 중 ③ "진동·전류 시계열 기반 프레스 유압펌프 이상 조기탐지 및 오경보 분석"을 골랐다. 가이드북[27]에 따르면 이 펌프가 고장 나면 수리비와 부품 수급 때문에 최대 2~3일 동안 공정이 멈춘다. 지금은 숙련 작업자가 작동 소음을 듣고 판단할 뿐이다.
- 과제문은 두 과업을 요구한다. ① 상부·하부 진동과 전류로 설비 이상을 조기에 탐지하는 모델을 만들고, ② 정상적인 운전변화를 이상으로 판단하는 오경보를 줄이며 미탐지·오경보 발생조건을 분석하는 일이다. ②는 가이드북(LSTM 오토인코더 실습)에 없던 요구다.
- 분석에 앞서 용어를 정했다.
  - 조기 탐지: 이상 상태에 들어선 뒤 첫 경보까지 걸린 시간(행·초). 고장 전 선행 시간은 데이터에 고장 직전 구간이 없어 검증할 수 없다(2.1절).
  - 오경보: 정상 기록에서 울린 경보. 행·기록 수로 세고 시간당 경보 사건 수로도 바꿔 본다(2.5절).
  - 정상 운전변화: 부하(전류 크기)와 진동 수준이 바뀌는 정상 운전 상태. 신호로 고·중·저부하와 정숙 구간을 나눴다(3.2절).

## ◦ 1.2 설비 구조: 파인블랭킹 프레스와 유압 계통

- 파인블랭킹은 판재를 V링으로 눌러 고정하고(V링력), 아래에서 역압으로 받친 채(역압) 펀치로 절단한다(블랭킹력). V링력과 역압은 유압 실린더로 걸며 가공은 펀치·가이드 판·다이를 따로 제어하는 3중 동작 유압 프레스에서 한다[12]. 이 설비는 유압펌프로 약 1000톤의 힘을 낸다(가이드북).
- 한 행정은 고속 접근 → 감속·감지 → 저속 블랭킹 → 고속 복귀로 나뉜다. 블랭킹 구간만 고압·저속이다[13].
- Shu 등이 분석한 12,000kN 유압 파인블랭킹 프레스의 압력원은 모터-펌프가 어큐뮬레이터를 채우다가 설정압에서 비례밸브로 기름을 탱크에 돌려보내는(언로딩) 구조다[13]. 이 설비도 그렇다면 모터 부하는 행정 단계와 충전·언로딩에 따라 수 초 단위로 오르내린다(추정). 실제 회로와 행정 속도는 자료에 없어 그림 1은 일반 구조로 그렸다.
- 펌프는 가이드북의 구조 그림(맞물린 두 기어)과 "기어 마모" 서술로 보아 외접 기어펌프로 보인다. 가이드북이 이 설비 펌프의 형식을 직접 적지는 않았다. 고압 기어펌프의 잇수는 보통 9~12개다[14].
- 센서는 모터-펌프 유닛 상부·하부의 진동센서 2개와 펌프 모터 전력선의 전류센서 1개다(과제문 표현은 "유압펌프 모터의 상부·하부 진동"). PLC가 초당 10회 수집한다.

## ◦ 1.3 기어펌프 고장의 물리와 센서 서명

- 가이드북은 노후화에 따른 펌프 내부 기어 마모를 고장 원인으로 든다. 마모되면 진동·소음이 커지고 출력 유압이 약해져 불량품이 나온다.
- 기어펌프 마모는 주로 기어 끝면과 측판(플로팅 부싱)에서 생긴다. 끝면 누설은 틈새의 세제곱에 비례하고 그만큼 토출 유량과 체적효율이 떨어진다. 가속수명시험에서 체적효율 70%까지 960~982시간이 걸렸다[15]. 마모는 수백 시간 단위로 진행되므로 2분 46초 안의 급변은 진행 중인 마모보다 이미 이상 상태인 펌프의 증상에 가깝다(추정).

| 고장 모드 | 진동·압력·유량 서명(문헌) | 모터 전류 서명(문헌) |
|---|---|---|
| 측판·끝면 마모(내부 누설) | 내부 누설·체적효율 저하, 압력 맥동 증가(압력 측정)[15] | 유압 일이 줄어 전류 감소(새것일 때 대비)[16] |
| 치면 마모·피팅 | 맞물림 주파수 주변 측대역(기어박스 연구, 적용은 가설)[17] | 부하 토크 변동 → 전류 위상 변조[18] |
| 캐비테이션·에어레이션 | 고음(캐비테이션)·불규칙한 소음(에어레이션)[19], 고주파 광대역(추정) | 불규칙한 부하 변동(추정) |
| 커플링 정렬 불량 | 회전 1X·2X, 커플링 양쪽 180° 위상[20] | 영향 작음 |
| 기초·체결 풀림(흔들림) | 발·베이스 사이 180° 위상[20] | 영향 작음 |

- 표의 서명은 대부분 수십 Hz~kHz 대역에 있다. 그래서 다음으로 10Hz 데이터가 무엇을 담을 수 있는지부터 따졌다.

- 의미 열은 가이드북 정의를 그대로 옮겼다. 가이드북은 진동·전류를 '유압펌프'의 값으로 적지만, 센서는 모터-펌프 유닛의 진동센서와 펌프 모터 전력선의 전류센서로 본다(1.2절).
- 가이드북은 AI2_Current를 '유압펌프 전류'로 적지만, 이 채널은 평균이 0 근처이고 값의 절반이 음수이므로 실효값이 아니라 펌프 모터 전류의 교류 순시값이다. 정상 전류는 기록마다 겉보기 0.600Hz 사인에 맞는다(30행 이상 360기록, R² 0.9941~0.9996).
- 이 0.600Hz는 60Hz 계열 파형이 10Hz 표본으로 접힌 결과로 보인다. 기본파를 뺀 잔차에 홀수 고조파가 정확히 3·5·7배 위치(1.8·3.0·4.2Hz)에 있고(배경의 2131·485·391배) 짝수 고조파는 거의 없다. 교류 모터 전류의 반파 대칭과 맞는다. 표본만으로는 진짜 0.6Hz 신호와 구별할 수 없어 접힘은 가설로 남긴다.
- 표본 간격이 정확히 100ms라면 전류 주파수는 59.4 또는 60.6Hz여야 하지만 한국 계통 주파수 허용 범위는 60±0.2Hz다[21]. 계통이 정확히 60Hz라면 실제 표본 간격은 101.0ms 또는 99.0ms(허용 범위를 넣으면 약 100.7~101.4ms 또는 98.7~99.3ms)다. 기록 안 타임스탬프 간격이 모두 정확히 100ms라 시각은 실측값이 아니라 계산값으로 보인다(추정). 77분 동안 겉보기 주파수가 0.00066Hz 안에서만 움직여 인버터 구동 가능성도 남으므로 표본 간격은 확정하지 않는다.
- 접힘 가설이 맞다면 적어도 전류 채널에는 충분한 안티앨리어싱 필터가 없다. 진동 채널은 필터 유무를 확인하지 못했다(없으면 5Hz 위 성분이 0~5Hz로 접혀 섞이고, 있으면 기록에 남지 않는다). 그래서 진동의 기록 안 표준편차(SD)는 관측 표본의 상대 변동 지표로 쓰고 원 진동의 절대 RMS로 읽지 않는다(필터가 없으면 SD가 RMS와 크게 다를 수 있다). 기록 길이와 SD는 뚜렷한 관계가 없어(Spearman 0.08·0.015) 길이가 다른 기록도 같은 지표로 비교한다. 진동 단위가 공개되지 않아 ISO 20816 진동 심각도 구역 판정은 할 수 없고 정상 기준 대비 상대 판정만 한다[22].
- 정상 하부 진동은 백색 잡음이 아니다. 1.79Hz 톤이 1~2Hz 대역에 몰려 에너지의 71%를 차지하고 톤 진폭은 부하를 따라 움직인다(전류 진폭과 Spearman 0.874). 하부 진동은 펌프 부하를 반영한다.
- 행은 최대 50행(5초) 길이의 "기록"으로 끊겨 들어온다. 기록 시작은 약 8.02초, 끝은 약 6.78초 주기에 묶여 있어 PLC가 표본을 최대 50개 모아 올리는 구조로 보인다(추정). 이 보고서는 기록을 분석 단위로 쓴다. 정상은 600기록, 이상은 21기록이다.

## ◦ 1.5 센서 관측 가능성: 초당 10회로 볼 수 있는 것

- 나이퀴스트 주파수는 5Hz라 1.3절 서명의 대부분(4극 모터라면 회전 1X 약 29Hz, 맞물림 약 260~350Hz, 캐비테이션 고주파)은 직접 볼 수 없다. 모터 극수와 펌프 잇수는 자료에 없어 가정값이다.
- 이 데이터에서 쓸 수 있는 정보는 10Hz로 남는 세 가지뿐이다. 기반 모델(2.3절)의 특징이 여기에 해당하는지는 설계 뒤에 점검했다.
  - 관측 진폭의 크기: 진동 크기(기록 안 SD, 상대 변동 지표)
  - 저주파 구조와 채널 관계: 자기상관, 대역 에너지 비율, 상·하부 상관과 위상
  - 전류 파형: 사인 적합. 부하 토크 변동은 전류를 위상 변조하고[18] 변조가 수 Hz 안이면 접혀도 사인의 일그러짐으로 남는다(추정)
- 맞물림 측대역, 베어링 결함 주파수, 1X 위상 같은 표준 진단은 이 데이터로 할 수 없다. 이 점은 3.5절 한계 표에 적었다.

## ◦ 1.7 전처리와 검증 전략

- 전처리
  - 정밀도 맞춤: 두 파일의 진동을 1e-4, 전류를 1.1920929 간격으로 같게 반올림해 형식 누수를 지운다.
  - 기록 분할: 이웃 행 간격이 0.1초를 벗어나면 새 기록으로 본다. 모든 창 계산은 기록 안에서만 한다.
  - 표준화와 성분 분포는 정상 학습(train) 자료로, 경보 문턱은 정상 검증(valid) 자료로 정한다. 라벨·날짜·파일명은 입력에서 뺀다.
- 검증 전략: 시간순 train/valid/test

| 구분 | 정상 분할 A | 정상 분할 B | 이상 21기록 | 쓰임 |
|---|---|---|---|---|
| train | 기록 0~359 | 0~299 | 사용 안 함 | 모델 학습 |
| valid | 360~479 | 300~419 | 앞 10기록 | 정상: 문턱 보정 / 이상: 모델 선택·확률 보정 |
| test | 480~599 | 420~599 | 뒤 11기록 | 최종 채점 |

  - valid 정상 기록의 오경보는 그 기록을 뺀 나머지로 문턱을 정해 잰다(leave-one-record-out). α 1%·valid 120기록이면 이 문턱이 '다른 119기록의 최댓값'이 되어 점수 모델의 valid 오경보는 구조적으로 1기록이다(α 3%는 3, 5%는 6). 그래서 valid F1의 모델 차이는 주로 이상 앞 10기록의 미탐에서 난다. 오경보 비교는 test와 3.2절에서 한다. 즉 잠금 선택은 같은 사건의 앞부분(이상 10기록)으로 한 것이고, test는 그 사건의 뒷부분이라 독립된 사건의 검증이 아니다.
  - valid에서 고른 결과와 규칙·성분별 test 판정 기준을 해시로 잠그고 잠금이 맞을 때만 test를 채점하도록 코드를 짰다. 규칙과 기반 모델은 전체 데이터를 본 뒤 정했으므로(2.3절) test 1.000을 새 고장에 대한 일반화 성능으로 내세우지 않는다. 해시 잠금은 선택 과정을 통제하는 장치다. 2.6절의 분할 변경·인공 주입·수집 조건 시험은 같은 자료 안의 민감도와 합성 조건에서의 동작 범위를 점검한 것이며, 독립 고장 사건의 일반화 검증은 아니다.
  - 채점은 행 단위다. 이상 구간에서 한 점만 맞혀도 구간 전체를 맞힌 것으로 치는 point-adjust 방식은 성능을 부풀리므로 쓰지 않았다[2].
  - 주 지표는 실시간 행 F1(valid A·B 평균, α 1%)이고 실시간 잠금 선택(v2+R1)도 이 값으로 했다. 기록 판정 F1(2.4절)은 정상·이상 기록에 같은 규칙을 쓰는 기록 분류 지표이며 기록 단위 판정 쪽 잠금 선택(v3 kNN)에만 썼다. 실시간 행 F1은 행이 연속 스트림으로 들어온다고 가정한 지표다. 1.4절 추정처럼 기록이 묶음으로 올라온다면 기록 판정 F1도 같은 지연의 운영 지표이므로 두 지표를 함께 보고한다(2.4절).
  - R1(2.3절)은 확인된 이상 기록에 이어지는 기록을 첫 행부터 경보로 채워, 사건이 하나로 이어진 이 데이터에서는 행 F1에서 point-adjust와 비슷한 이득을 본다. 미래 행을 쓰지 않고 전류 파형이 정상으로 확인되면 풀린다는 점이 다르다(2.6절 E1a′).
  - A·B는 이상 기록이 같고 A test 정상이 B test 정상에 들어 있어 독립된 두 확인이 아니다. A test 정상 120기록 중 83기록이 정숙 구간, 고부하는 7기록뿐이라 오경보가 낙관적이므로 고부하 오경보는 B test와 valid에서 읽는다.

- 추가 정상 전용 선택: 2.8절의 결합 후보는 기존 A·B 공통 정상 학습 범위 안에서만 선택했다. 선택용 정상 기록과 최종 보정·평가 기록을 구분하고, 새 해시 잠금 뒤 기존 이상을 사후 재평가했다. 이 절의 기존 모델 선택 이력과는 별도 절차다.

## ◦ 2.1 고장 모드 진단 매트릭스와 목표 설정

- ISO 13379-1의 고장 모드–증상 분석 틀[3]로, 1.3절의 고장 모드마다 이 데이터의 관찰과 맞는지 따졌다. 관찰은 다섯 가지다.
  - O1 전류 파형 붕괴: 이상 10행 이상 기록이 모두 사인 적합 R² 0.617 이하(정상 중앙 0.995)
  - O2 진동 크기 증가와 저주파화: 상부 SD 5.34배·하부 2.55배(20행 이상 기록 중앙값), 에너지가 0~1.4Hz로 이동
  - O3 상·하부 음의 상관: 이상 기록 상관 중앙값 −0.36, 우세 대역 위상차 크기 약 120°
  - O4 정상 부하 관계로 설명되지 않는 진동: 부하 효과를 지워도 정상 잔차에서 크게 벗어남(2.2절)
  - O5 전류 치우침: 이상 기록 |평균|/RMS 중앙값 0.60. 유도전동기 상전류에는 원래 직류 성분이 없다

- 결론: 세 센서로는 고장 종류를 가를 수 없다. 이상 상태는 뚜렷하지만 원인이 펌프 기계 고장인지, 운전 조건인지, 계측·수집 변화인지는 데이터로 분리할 수 없다.
- 고장 직전 패턴과 서서히 진행되는 열화도 이 데이터로는 볼 수 없다. 정상(7/12)과 이상(7/17) 사이 5일이 비어 있고 이상 파일은 첫 기록부터 이미 이상이며, 측정이 연속이 아니고 정상은 하루 77분뿐이다.
- 그래서 목표를 좁혔다. 고장 전 경보는 이 데이터로 검증할 수 없으므로 "고장 상태에 들어선 순간을 실시간으로 알리는 경보"를 만든다. 정상 운전 자료만으로 학습하고 정상과 다른 상태를 알린다.

## ◦ 2.3 모델 구성

- 모델 계열: v1(크기+파형), v2(v1에 초반 6행 파형 창과 동역학 성분을 더한 Press Guard), v3(기록 단위로 판정하는 기본형 B1·kNN과 부하 조건부 진동 성분)는 이 과제를 위해 먼저 만든 모델 계열이다. 이 보고서는 v2를 기반 모델로 쓰고 v1·v3는 같은 조건의 비교(2.4절)와 검증 틀(2.6절)에 쓴다.
- 기반 모델(v2, Press Guard): 정상 학습 자료만으로 0.1초마다 세 성분을 계산한다. 세 성분은 1.5절의 세 정보(관측 진폭의 크기, 채널 관계를 뺀 저주파 구조, 전류 파형)와 하나씩 대응한다(설계 뒤 점검).
  - 크기: 세 센서의 표준화 값 중 최댓값 → 관측 진폭의 크기(행마다 표준화한 순간 편차. 1.5절의 기록 안 진동 SD와는 다른 양이다)
  - 파형: 최근 6~8행 전류의 사인 적합 1−R² → 부하 토크 변동에 따른 전류 일그러짐
  - 동역학: 정상 전류로 학습한 AR(2)의 예측 오차 → 겉보기 0.6Hz 전류의 시간 구조
  - 각 성분을 정상 꼬리 확률의 −log10 척도로 바꿔 최댓값(가장 드문 성분)을 점수로 쓰고 valid 정상 기록의 최대 점수로 conformal 문턱을 정한다[4].
- 규칙 R1 사건 지속: 직전 기록(끝난 지 60초 안)이 확인된 이상이면, 새 기록은 첫 행부터 경보를 이어받는다. 확인된 이상은 자기 경보가 2행 이상이거나, 이어받은 경보가 기록 끝까지 풀리지 않은 기록이다. 새 기록의 전류 파형이 정상으로 확인되면(8행 이상, 사인 적합 R²가 정상 학습 기준 이상) 해제한다. 8행이 안 되는 기록에서는 해제되지 않는다.
  * 근거: 고장은 수집 공백(수 초) 사이에 사라지지 않는다. v2의 미탐은 기록 시작 직후에 몰려 있다. 산업 경보 관리로 보면 조건이 사라진 뒤에도 경보를 일정 기준까지 유지하는 OFF-delay·래치 계열이다[5]. 운전원 리셋 대신 전류 파형의 정상 확인으로 자동 해제한다는 점이 표준 래치와 다르다.
- 규칙 R2 교차 확인: 크기 성분(세 센서의 표준화 최댓값)만 문턱을 넘고 그 시점 전류 파형이 정상이면 경보를 보류한다(2단계 모델의 경보 없음. 두 단계 경보 체계에서는 이 경보가 1단계 "주의"로 남는다, 4.2절). 파형을 판단할 행(8행)이 아직 없으면 경보를 그대로 둔다.
  * 근거: 고부하 정상 구간에서는 크기만 커지고 전류 파형은 정상이다. 두 물리 채널(진동 크기, 전류 파형)이 함께 이상을 가리킬 때만 크기 경보를 내는 규칙으로, 과제 과업 ②의 정상 운전변화 오경보를 겨냥한다.

## ◦ 2.4 같은 조건의 모델 비교

- 모든 모델을 같은 분할, 같은 valid 보정(α 1%)으로 채점했다. 실시간은 행이 들어오는 순간, 기록 단위는 기록이 끝난 뒤 판정한다. 표의 기록 판정 F1은 그 판정을 기록의 모든 행에 펼쳐 센 값이라 긴 기록일수록 비중이 크다(기록 단위 모델의 잠금 선택에 쓴 정의, 1.7절). 기록 하나를 1개로 센 F1은 † 열에 따로 적었고, 두 정의에서 순위가 바뀌는 쌍도 있다(예: B의 v2와 v3 kNN).
- 같은 분할·같은 보정으로 견준 모델은 거리(5NN)·트리(IsolationForest)·복원(MLP·LSTM 오토인코더, 보완 LSTM 516개 변형)·예측(Ridge)·관리도(PCA·CUSUM·EWMA)·특징 기반(max|z|·v1·v2·v3, v2 특징을 넣은 5NN·IsolationForest)의 여섯 계열이다(일부 †, 2.7절).
- 모든 점수는 형식 누수를 지운 입력(1.6절)에서 쟀다. 남은 차이가 고장 때문인지 수집 조건 때문인지는 2.6절 E5에서 따로 본다.
- †는 test 채점 이후 추가한 행·열·문단이라 선택·잠금·2단계 규칙 추가에는 쓰지 않았다. 표준 기법·R1을 붙인 비교·보완 LSTM 같은 사후 대조의 상세는 2.7절에 모았다.
- 모델을 가른 세 기준(†): 기반 모델 v2는 잠금 전에 정했고(2.3절), 잠금 규칙은 valid 실시간 F1과 단순성 기준으로 v2+R1을 골랐으며, 2단계 승격 규칙(R2, v2+R1+R2)은 test를 본 뒤 더했다(2.5절). valid→test를 이어 돌리면 test 구간의 실제 사건에서 R1을 붙인 어느 앞단 모델이든 F1 0.982~1.000이어서(2.7절 R1 † 표) 이 사건으로는 모델을 가르지 못한다(이상 흐름을 test 기록부터 따로 돌려야 IsolationForest+R1 0.612·0.609, v2+R1 1.000·0.995로 갈린다). 아래는 기반 모델 선택을 test에서 ① R1 없는 탐지(실시간 행 F1, 문턱과 무관한 행 AUROC·PR-AUC) ② 인공 주입 탐지력(성분 절제) ③ 정상 오경보(운전 상태별, 3.2절)로 사후 점검한 결과다. 딥러닝은 가이드북 방식을 그대로 따른 모델에 더해 516개 변형 가운데 valid로 고른 보완 LSTM으로도 견줬고(2.7절), 예측 계열은 같은 기록 안 과거 5행으로 현재 값을 예측하는 Ridge 회귀의 오차로 견줬다(†).

  - ① 잠금 후보(베이스라인 5종·v1·v2) 가운데서는 문턱과 무관한 행 AUROC·PR-AUC도 v2가 가장 높다. 보완 LSTM은 실험 때 행 점수를 저장하지 않아 AUROC를 재지 못했고 실시간 F1은 v2와 같은 수준이다. 부트스트랩(2,000회)은 test 기록을 정상·이상 묶음 안에서 복원 추출했다. 그 95% 구간에서 v2와의 차이는 v1 대비 F1 A 0.038~0.103·B 0.034~0.101, AUROC A 0.017~0.079·B 0.019~0.082이고 베이스라인 5종 대비 F1 +0.32 이상·AUROC +0.036 이상이다(기록 독립 가정). 다만 이 구간은 문턱과 학습을 고정하고 기록을 서로 독립으로 뽑은 값이다. 이 때문에 같은 부하 구간에 이어진 정상 기록끼리의 상관과 한 사건의 이상 11기록끼리의 상관을 반영하지 않아 실제보다 좁을 수 있다. 정상은 연속 10기록, 이상은 연속 3기록 블록으로 다시 뽑아도(†) v2−v1 구간은 F1 A 0.030~0.096·B 0.027~0.092, AUROC A 0.020~0.070·B 0.019~0.075로 F1 구간은 조금 아래로 옮겨지고 AUROC 구간은 좁아져, 넓어지지 않은 채 모두 0을 넘었다. 분할 A·B는 이상 test 11기록이 같고 A의 정상 test 120기록이 B의 test 180기록에 들어 있어 독립된 반복도 아니다. 이상 11기록은 한 사건이므로 다른 사건으로 일반화할 수 있는지는 이 구간으로 말할 수 없다. 행 AUROC에서 창이 차지 않아 점수가 없는 행(MLP 오토인코더 기록 앞 4행, LSTM 오토인코더 앞 19행)은 가장 정상으로 두었다. v2·v1·max|z|·5NN·IsolationForest는 모든 행에 점수가 있다. PR-AUC의 무작위 기준선은 이상 행 비율(A 0.073·B 0.050)이다.
  - ③ 정상 오경보에서는 v2 단독(9/53)이 max|z|·v1(10/53)과 비슷하고 가이드북 LSTM 오토인코더(1/53)·5NN·MLP 오토인코더(6/53)보다 많다. v2 경로에서 고부하 오경보를 줄인 것은 앞단 모델이 아니라 R2다(9/53→1/53). R2는 앞단 모델과 무관하게 붙일 수 있다(2.7절 R1 † 표의 max|z|+R1+R2). 고부하 오경보가 적은 단독 모델(가이드북 LSTM 오토인코더 1/53, MLP 오토인코더 6/53)은 test 이상 행도 적게 잡는다(R1 없는 행 F1 0.24~0.50, ①행). 사후에 더한 Ridge(2/53, F1 0.877)와 v2 특징을 넣은 5NN(R2 없이 1/53, F1 0.970·0.972)은 예외라(아래 †), 고부하 오경보를 줄이면 탐지를 잃는다고 볼 근거는 없다.
  - † Ridge 예측 오차(사후 추가): 정상 train으로 각 센서의 현재 값을 같은 기록 안 과거 5행 × 3채널로 예측하고(과거 행이 적은 기록 앞부분은 짧은 lag 모델, 첫 행은 점수 없음) 세 센서 표준화 잔차의 최댓값을 점수로 썼다. 같은 분할·같은 보정에서 R1 없는 F1·AUROC는 베이스라인 5종보다 높고 v2보다 낮았다(점 추정, 구간 미산출). 전류 파형 주입은 대조 수준으로만 잡았지만 진동 단독 주입은 최대 95.7%(v2 35.0%)를 잡았고, 고부하 정상 오경보도 R2 없이 2/53이었다. 기록 안 직전 값으로 예측해 기록 내내 높은 진동은 잔차가 작고 갑자기 생긴 충격·잡음은 잔차가 커지기 때문으로 보인다(추정). 같은 이유로 기록 전체의 진동 수준 상승에는 둔할 수 있다. R1을 붙이면 v2+R1과 거의 같다(B 오경보 1행 대 v2+R1 3행, 이상 흐름을 test부터 따로 돌린 F1 0.998·0.997, 2.7절 R1 † 표). 두 모델은 서로 다른 이상을 잡으며, 1단계에 함께 쓰는 구성은 4.3절 †에서 사후로 계산했다.

IsolationForest에 넣으면 F1 0.867·0.864다. 따라서 v2가 원신호 베이스라인보다 앞선 몫은 주로 특징, 곧 이상 자료를 본 뒤 정하고 1.5절의 정보와 대응을 설계 뒤에 점검한 전류 파형·동역학 성분에서 오고, 이 특징은 학습기를 바꿔도(5NN) 유효하고, v2의 결합 방식(성분별 꼬리 점수의 최댓값)은 성능을 더하기보다 경보 근거를 성분별로 내는 데 쓰인다. 기록마다 최대 점수로 판정한 기록 단위 AUROC는 기록 안 시간 구조를 쓰는 모델(v2·v1·Ridge·특징 맞춤 5NN·IsolationForest)이 0.999~1.000이고 원신호 베이스라인은 0.676~0.984라, 기록이 묶음으로 올라온다면 기반 모델 사이 우열은 이 데이터로 가를 수 없다.

- 이 데이터는 쉽게 갈리는 편이다. 이상 자료를 본 뒤 만든 단순 규칙(최댓값 세 개만 학습)도 v2의 원 평가 방식에서 행 F1 0.890·0.900을 냈다(v2 개발 때 결과, 평가 방식이 달라 위 표와 비교하지 않음, 6장). 성능 차이는 주로 기록 시작 직후 행을 얼마나 빨리 잡느냐에서 난다.
- v3의 조건부 진동 성분(전류 크기에 따라 진동 정상 범위를 바꿈)은 A에서 조금 오르고 B에서 내려, 잠근 판정 기준(test A·B 평균 F1이 v2보다 높음)을 충족하지 못했다. 기록 단위 모델 중 잠금 규칙이 valid에서 고른 v3 kNN은 0.993이었지만 test에서 0.889~0.954로 내려갔다.
- 가이드북 LSTM 오토인코더는 자체 결과로 F1 74.76%, 오경보율 1.95%(계산값)를 보였다. 그 결과는 이상 라벨로 임곗값을 고르고 창이 수집 공백을 가로지르는 조건이라, 같은 조건에서 다시 잰 위 표의 0.289·0.238과 직접 비교하지 않는다.
- 딥러닝을 기반 모델로 고르지 않은 이유: 당시 근거는 아래 데이터 조건과 해석 가능성이다. 가이드북 방식 LSTM 오토인코더와 MLP 오토인코더는 같은 조건에서 test 실시간 행 F1이 낮았다(주 비교표). 다만 20행 창 LSTM 오토인코더는 기록 앞 19행을 판정하지 못해 test 이상 324행 중 177행(54.6%)을 처음부터 미탐으로 셌다(MLP 5행 창은 44행). 점수는 가이드북처럼 마지막 시점의 복원 오차를 썼다. 2.7절 사후 확인대로 이 F1 차이는 주로 설계에서 나와 근거로 삼지 않는다. 가이드북 방식 LSTM에 R1을 붙이면 test 0.998이지만 사건 앞부분을 포함한 valid 실시간 F1(0.918)은 v2+R1(0.997)보다 낮다(2.7절 R1 † 표). 이 데이터는 고장이 한 사건뿐이고 기록이 최대 50행(5초)으로 끊겨 긴 시계열을 학습할 연속 구간이 없으며, 초당 10회 표본이라 빠른 진동 정보가 없다(1.5절). 다변량 시계열 이상탐지 연구에서도 단순한 방법이 딥러닝과 비슷하거나 낫다는 결과가 보고됐다[9][10]. 그래서 F1 차이보다 이런 데이터 조건과 해석 가능성을 근거로 물리적으로 해석되는 성분과 규칙을 택했다.
- 사후 대조 요약(†, 2.7절): 기록 앞부분 처리와 점수 방식을 보완한 LSTM은 R1 없이 test 0.975·0.972로 v2와 같은 수준이지만 전류 파형 주입은 거의 놓친다. R1을 붙이면 어느 앞단 모델이든 test F1이 0.982~1.000이 되고, CUSUM·EWMA도 기록 경계에서 상태를 이어 가면 R1 수준이 된다. 교과서 한계를 쓴 PCA 관리도는 기록 단위 운영에 맞지 않았다. 표준 기법 표, R1을 붙인 비교, 보완 LSTM 상세는 2.7절에 모았다.

## ◦ 2.5 제출 모델: 잠금 모델과 두 단계 경보

- 선정 근거 한눈에
  - 기반 모델 v2: R1 없는 test 행 F1(0.965·0.970)과 문턱과 무관한 행 AUROC(0.975·0.974)가 베이스라인 5종·v1보다 높다(2.4절 †, 사후 점검).
  - R1 사건 지속: test 미탐 A 22·B 16행을 0으로 줄였다(3.4절).
  - R2 교차 확인: 2단계 기준으로 분할 B α 5% 고부하 정상 오경보 기록을 9/53에서 1/53으로 줄였고(착안 자료 안), 그 대가로 2단계의 진동 단독 주입 탐지율이 최대 23.7%p 낮아졌다(2.6절. 이 경보는 1단계로 남는다).
  - 제출 구조: 잠금 규칙이 고른 v2+R1(잠금 모델)을 공식 성능(test 1.000·0.995, 미탐 0행)으로 두고 그 경보를 1단계 "주의"로 낸다. R2 교차 확인을 더한 2단계 "점검 요청"(2단계 모델 v2+R1+R2)은 test를 본 뒤 더한 운영 권고안이다. 2단계 모델은 v2 경보에 R2를 먼저 적용하고 R1을 붙인다. R2는 R1에 들어가는 경보를 빼기만 하고, R1의 이어받기는 입력 경보가 적을수록 줄며 해제는 전류 R²로만 정하므로 2단계 경보는 늘 1단계 경보 안에 있다(제출 예측 파일에서도 2단계에만 울린 행 0).
- 기반 모델: v2는 잠금 전에 정한 기반 모델이며(2.3절), 잠금 후보 가운데 R1 없는 valid 실시간 F1도 v2 계열이 가장 높았다(0.963, 베이스라인 최고 0.644). test 채점 뒤의 사후 대조(2.4·2.7절 †)에서 보완 LSTM은 F1로는 같은 수준이었지만 전류 파형 주입·직류 이동·시각 흔들림에서 갈렸고, R1·R2를 붙인 max|z|도 2단계 모델과 비슷했다. 이 사후 결과는 선택에 쓰지 않았다. v2 성분의 몫은 R1 없는 탐지(test 행 AUROC max|z| 0.862·0.818 → v2 0.975·0.974. 같은 특징을 넣은 5NN과는 같은 수준, 2.4절 †), 사건 첫 기록 안의 미탐(valid A에서 max|z|+R1 2행 대 v2+R1 1행), 크기 성분이 구조상 볼 수 없는 약한 전류 파형 왜곡(2.4절 † 성분 절제)에서 보인다(모두 사후). v2는 이번 이상을 가장 잘 가른 신호(전류 파형)를 직접 보며 경보 근거를 성분별로 설명할 수 있다. 같은 특징을 넣은 5NN도 R1 없는 F1·AUROC가 v2와 같은 수준이어서(2.4절 †) 특징의 유효성은 학습기를 바꿔도 확인됐고, v2는 같은 성능에서 켜진 성분이 곧 4.2절 점검 순서로 이어지는 경보 근거를 낸다(보정 방식은 5NN과 같다).
- R2는 초기 탐색에서 v2의 정상 오경보가 고부하 정상의 크기 성분 단독 경보였다는 관찰에서 착안한 규칙이며(정의·경위 2.3절) 과업 ②의 정상 운전변화 오경보를 겨냥한다. 아래는 R2를 넣은 2단계 모델과 잠금 규칙의 선택이 갈린 과정이다.
- 잠금 대상 후보 가운데 valid 실시간 F1은 v2+R1+R2, 그리고 여기에 v3 조건부 성분을 더한 두 변형까지 세 모델이 0.998로 공동 1위였다(† 사후 비교 제외). v2+R1과의 차이는 valid에서 점수가 가장 높은 정상 기록(461)의 A 오경보 1행을 R2가 보류했는지뿐이었다.
- 미리 정한 잠금 규칙은 "valid 차이 0.002 이내면 더 단순한 모델"이라, 0.998 대신 0.997인 v2+R1을 골랐다. 단순성은 성분 수와 규칙 수를 더한 복잡도로 쟀다(v2+R1 4, v2+R1+R2 5).
- 잠금 규칙이 고른 모델은 v2+R1(test F1 A 1.000·B 0.9954)이고 이것을 공식 성능으로 둔다. v2+R1+R2는 test 결과를 확인한 뒤 2단계 승격 규칙으로 더했다.
- R2를 2단계 승격 규칙으로 더한 것은 과업 ②를 겨냥한 설계 판단이다. 판단의 출발은 초기 탐색에서 본 관찰, 곧 v2의 정상 오경보가 고부하 정상의 크기 성분 단독 경보였다는 점이다(2.3절). R2를 더한 뒤 사후 분석에서 R2는 이번 사건의 탐지를 그대로 둔 채(미탐은 R2 유무와 같음, 3.4절) 분할 B α 5% 고부하 오경보 기록을 9/53에서 1/53으로 줄였고(3.2절, 착안 때 본 자료 안의 확인), 그 대가로 진동 단독 주입 탐지율이 최대 23.7%p 낮아졌다(2.6절 E1b). 이 사후 결과는 R2를 더하는 판단에 쓰지 않았고 통계적 우위도 아니다. 잠금 규칙의 단순성 기준으로도 v2+R1이 맞다. 그래서 R2는 공식 성능에 넣지 않고 출동할 경보를 골라내는 2단계에만 쓴다.
- R2가 test에서 줄인 오경보 3행은 초기 탐색에서 이미 본 행이다. valid에서 v2+R1과 갈린 A 오경보 1행(기록 461)도 착안 때 본 기록이라, 이 행들로는 R2 효과를 표본 밖에서 확인할 수 없다. v2의 B test 오경보 3/180도 α 1% 설계 기대(1.49기록)와 통계적으로 구별되지 않는다(관측값 이상이 나올 확률 0.19). 준-표본 밖 확인(†): 착안 때 본 기록(303·423·461·570)과 앞뒤 1기록을 빼고 2.6절 E3의 시간순 5창(창마다 다시 학습·보정, 평가 정상 300기록 중 288기록)을 합쳐 다시 셌다. 평가 300기록은 분할 B valid+test와 같은 기록이라, 3.2절과 독립된 자료가 아니라 학습·보정 구간만 바꾼 재확인이다. α 5%에서 정상 오경보 기록은 v2 10 → v2+R2 2(차이의 블록 부트스트랩 95% 구간 1.4~4.2%p), 고부하 50기록에서는 7 → 0(7.5~21.0%p)이었다. α 3%에서는 4→1기록으로 구간(0~2.1%p)이 0을 포함했고, α 1%에서는 착안 기록을 빼면 v2 오경보가 0이라 비교할 것이 없다. 같은 날·같은 세션 안의 확인이므로 R2는 여전히 가설 규칙으로 두고 효과 크기는 주장하지 않는다. 도입 첫 달에 R2가 2단계로 올리지 않은 1단계 경보를 따로 기록해 표본 밖에서 잰다(4.3절).
- R1을 CUSUM·EWMA 대신 유지한 이유(사후 비교): 고장 뒤 정상 기록을 이어 붙인 가상 흐름에서 R1은 7행(0.7초) 만에 경보가 풀렸고 상태를 이어 가는 CUSUM은 11.4~12.2분 동안 경보가 이어졌다. R1의 해제는 고장 규모가 아니라 전류 파형의 정상 확인에 묶여 있다. EWMA는 0.2~0.3초로 더 빨리 풀렸지만 상태를 넘기는 힘이 점수 크기에 달려 약한 이상에서는 다음 기록까지 남지 않을 수 있다. CUSUM의 11.4~12.2분은 상한·리셋이 없는 표준형 기준이고 정상 확인 리셋을 붙이면 해제 부분은 R1과 같은 구조가 된다. F1로는 셋을 가를 수 없었다.
- α 민감도(2단계 모델, test B): α 1% 오경보 0행(F1 1.000), 3% 1행(0.998), 5% 9행(0.986). A는 세 수준 모두 1.000이다. 운영 α는 1%로 둔다.
- 첫 경보 지연(2단계 모델. 1단계는 2단계 경보를 모두 포함해 첫 경보가 같거나 빠르며, 이 사건에서는 같다): test 이상 11기록 모두 기록 첫 행(0.0초)에서 경보가 났다. test는 valid→test를 한 흐름으로 돌려 R1이 직전 이상 기록의 판정을 이어받았으므로, 이 값은 사건이 이어질 때만 성립한다. 기록마다 새로 판단하는 v2는 최대 3행(0.3초) 늦었다. 이상 파일은 이미 이상 상태로 시작해 사건 시작 시점이 없고, 파일 첫 기록에서 2단계 모델의 첫 경보는 valid A 1행(0.1초), B 0행이었다. 이상 흐름을 test 기록부터 따로 돌려도 2단계·잠금 모델의 F1은 같았다(2.7절 †).
- 불확실성: 2단계 모델의 정상 오경보 기록 0/120(A)·0/180(B)의 Clopper–Pearson 단측 95% 상한[11]은 2.47%·1.65%로 설계값(1/121 = 0.83%)보다 크다(기록을 서로 독립인 시행으로 본 참고 계산이다). 1단계(잠금 모델)는 B에서 3/180으로, α 1% 설계 기대(1.49기록)와 통계적으로 구별되지 않는다(위). conformal 문턱의 실측(†): E3 시간순 5창 정상 300기록에서 v2의 정상 오경보 기록 비율은 α 1·3·5·10%에서 0.67·2.67·4.67·9.33%로 명목 근처였지만, 창마다 α 10%에서 0~15%로 흔들렸고 R1을 붙이면 α 3% 이상에서 명목보다 커졌다(3.67·6.00·11.67%). 그래서 도입 뒤 실측이 α를 넘으면 재보정한다(4.3절). 이상 기록 탐지 11/11의 95% 하한은 76.2%다. 이상 11기록은 한 사건의 연속 구간이라 사건 단위 표본은 1이다. 문턱은 valid 정상 기록의 conformal 순위로 정했지만 R1이 경보를 더하고 시간순 분할이라 오경보율을 α로 보장하지는 않으므로, 실제 오경보율을 분할마다 보고했다.
- 경보 운영 지표: 정상 test 구간은 달력 시간으로 16.1분(A)·24.1분(B)뿐이다. 2단계 경보 사건은 0건이지만 포아송 95% 상한은 시간당 11.2·7.5건이다(경보 사건률이 일정하다는 가정). 1단계 경보 사건은 A 0건·B 3건(시간당 약 7.5건, 95% 상한 약 19건)으로 α 1% 설계치(시간당 약 3.7기록, 4.3절)와 통계적으로 구별되지 않는다. 1단계는 운전원 대응을 요구하지 않는 표시라(4.2절) 운전원 경보 예산은 2단계에 적용하고 1단계 양은 도입 첫 달에 따로 잰다. 산업 경보 관리 기준(운전원당 시간당 약 6건 이하면 수용 가능성이 매우 높음)[5]과 맞춰 보려면 더 긴 정상 기록이 필요하다.
- 이상 확률: 경보와 별도로 v2의 확률 층이 이상 확률을 낸다. v2 점수를 valid의 정상 행(0)과 이상 행(1)에만 단조 회귀(isotonic regression)로 맞춰 우도비를 구하고 이를 사전 오즈에 곱해 확률로 바꾼다(test 행은 보정에 쓰지 않음). 사전 비율을 test 파일의 이상 행 비율(A 7.3%·B 5.0%)로 두면 행 단위 Brier는 A 0.0046·B 0.0038로, 비율만 쓴 예측(0.068·0.048)보다 낮다. 현장 가정 1% 확률의 Brier는 0.018·0.012다. 두 확률은 제출 예측 파일의 열(v2_prob_site1pct, v2_prob_fileprior)로 함께 낸다. 파일 비율 열은 test 파일의 이상 행 비율을 사전으로 쓴 평가용 참고값이다. 운영 예측은 현장 가정 1% 열이다. 순위는 사전과 무관해 두 열 모두 test 행 AUROC가 0.977·0.979다(단조 회귀가 점수를 계단 모양으로 묶어 동률이 생기므로 2.4절 v2 점수의 0.975·0.974와 조금 다르다). 파일 비율 확률은 확률 구간(0·0.01·0.1·0.5·0.9·1)별 평균 확률과 실제 이상 비율의 가중 차이(ECE)가 0.007·0.006이다. 현장 가정 1% 확률은 우도비 표시 상한(보정 기록 120개 + 1) 때문에 55%에서 멈춰(그림 14의 55.0%) 경보 행끼리 순위를 가르지 못한다(B test v2 오경보 3행도 55%). 따라서 운영 판단은 conformal 경보로 하고 확률은 기록·추세 관리에 쓴다. 같은 사건의 앞부분(valid)으로 맞추고 뒷부분(test)으로 잰 값이라 다른 사건에서는 알 수 없다.

- 공정 산업의 표준인 PCA 관리도(Hotelling T²·SPE)[6]는 교과서 99% 한계를 그대로 쓰면 valid 정상 기록의 49%(A)·45%(B)에서 한 행 이상 한계를 넘어, 기록 단위 운영에는 맞지 않았다(test 기록 판정 F1 0.163·0.127). 창이 겹쳐 생기는 자기상관, 부하의 이봉 분포, 기록마다 수십 번 반복되는 검정 때문이다. 같은 특징을 conformal로 보정하면 고부하 정상 오경보는 0이 되지만 기록 위치 0~1은 점수가 없고 2~6행은 둔하다.
- 표준 순차 검출인 CUSUM[7]·EWMA[8]도 기록 경계에서 상태를 이어 가면 R1 수준이 된다. 기록마다 0으로 되돌리면 v2보다 조금 오르는 데 그친다(CUSUM 0.978·0.975). 이득의 핵심은 수집 공백을 넘는 기억이다. 둘의 차이는 경보 해제에서 난다(2.5절). 단, 상태를 이어 가는 CUSUM에서 valid로 고른 k=5는 격자 끝값이고 정상 점수 최댓값(A 4.42·B 3.52)보다 커서 α 보정이 퇴화했다(사실상 누적값이 0을 넘으면 경보). B test 1.000은 이 높은 문턱 덕이다.
- R1은 어떤 점수 모델에도 붙일 수 있어 베이스라인에도 붙여 보았다(아래 † 표). test에서는 IsolationForest+R1도 1.000/1.000이고, max|z|+R1·v1+R1은 v2+R1과 같은 1.000/0.995이다. test 이상 11기록은 60초 안 간격으로 이어진 한 사건이고 전류 파형이 끝까지 정상으로 돌아오지 않아, 경보가 한 번 켜지면 나머지 행은 앞단 모델과 상관없이 맞는다. 그래서 test 1.000은 "이 사건에서 정상 오경보가 없고 경보가 사건 끝까지 유지됐다"로 읽어야 한다.
- R1은 켜진 경보를 이어 갈 뿐 첫 경보는 만들지 못하고, 앞단 모델의 오경보도 번지게 한다. R1을 붙인 모델끼리의 차이는 사건 앞부분을 포함한 valid 실시간 F1(평균: IsolationForest+R1 0.426, v2+R1 0.997), 정상 오경보(B test 단독→+R1: 5NN 5→12행, MLP 오토인코더 2→9행, v2 3→3행), 이상 흐름을 test 기록부터 따로 돌린 결과(IsolationForest+R1 0.612/0.609, v2+R1 1.000/0.995)에서 드러난다. 다만 v2의 크기 성분과 같은 양인 max|z|는 R1을 붙이면 세 곳 모두 v2+R1과 거의 같다(valid 0.996, B test 오경보 3행, test부터 1.000/0.995, v1+R1도 같음). max|z|에 R2까지 붙여도(max|z|는 크기 성분뿐이라 R2는 '전류 파형이 정상이면 보류'가 된다) α 1% valid 0.997·test 1.000·1.000으로, 2단계 모델(0.998·1.000·1.000)과 차이가 거의 없다. α 5%에서는 test B 오경보가 0행(2단계 모델 9행)이다. 따라서 R1·R2를 붙인 뒤에는 이번 사건의 점수에서 v2 파형·동역학 성분이 더하는 몫이 드러나지 않는다. 그 몫은 R1 없는 탐지(크기만 0.404·0.428 → v2 0.965·0.970), 사건 첫 기록 안의 미탐(valid A 2행 대 1행, 첫 경보는 둘 다 0.1초), 크기 성분만으로는 못 잡는 전류 파형 이상(2.4절 성분 절제)에서 보인다. R2의 파형 판정은 v2 성분이 아니라 규칙용 R²다(2.3절). 5NN+R1은 잠금 후보에 없던 조합이며 valid(0.998)는 2단계 모델과 같은 수준이다.

- 사후 확인: 가이드북 LSTM을 보완해도 남는 오류(†)
  - v2·R1·R2와 2단계 모델을 정하고 test를 채점한 뒤, 가이드북 LSTM 오토인코더의 낮은 F1(test 0.289·0.238, 2.4절 주 비교표)이 모델 능력 때문인지 설계 때문인지 가렸다. LSTM 오토인코더 틀 안에서 기록 앞부분 처리(가변 길이 창), 점수 방식(채널별 꼬리 점수의 창 평균, 꼬리 척도는 v2 방식), 용량·학습량을 바꾼 설정 26개를 학습했다(162회). 채점 방식과 조합한 변형 516개 가운데 valid만으로 하나를 골라 잠근 뒤, 새 seed 3개로 다시 학습한 앙상블을 썼다. 변형 격자·선택 규칙·교체 검토 조건은 결과를 열기 전에 정했다. 이 비교는 모델 선택에 쓰지 않았고, 이미 한 선택을 사후에 점검한 결과다.
  - 보완한 LSTM은 이번 사건에서 valid 0.968, test 0.975·0.972로 v2(0.963, 0.965·0.970)보다 조금 높지만, 차이가 단일 seed의 표준편차(0.005)와 test 범위(0.964~0.976) 안이라 같은 수준으로 본다. 2.4절 주 비교표의 가이드북 방식과의 F1 차이 상당 부분은 모델 능력보다 기록 앞부분 처리와 점수 방식에서 나왔고, F1로는 보완 LSTM과 v2가 갈리지 않는다. R1을 붙이면 보완 LSTM은 valid 0.990·test B 0.985로 v2+R1(0.997·0.995)보다 낮다(위 R1 † 표).
  - 두 모델에 남는 오류를 견주면 아래와 같다(따로 적지 않으면 α 1%, 분할 A·B와 구별하려고 오류는 가~마로 적는다). 가·나는 두 모델에 모두 있는 오류로 R1·R2가 줄인다. 다·라는 LSTM에만, 마는 v2에만 있고 규칙을 붙여도 남는다.

  - 오류 나는 2단계 모델에서는 α 1% test에서만 0행이 된다(α 3% 1행, 5% 9행). 넓힌 R2를 붙인 보완 LSTM+R1+R2는 α 3·5%에서도 test 0행이지만, valid를 포함한 분할 B 정상 300기록으로 넓히면 α 5% 경보 행이 34행으로 2단계 모델(11행)보다 많다. 넓힌 R2는 R1·R2용 전류 파형 확인을 최종 판정자로 쓰므로 이 0행은 LSTM 단독의 성능이 아니다.
  - 가·나는 기록이 5초 이하로 끊기는 수집 구조와 부하 변화에서 생긴다. R1은 베이스라인(위 R1 † 표)과 보완 LSTM 모두에서 미탐을 없앴지만, 보완 LSTM에서는 오경보도 다음 기록으로 이어 붙여 분할 B test 오경보가 3행에서 10행으로 늘었다. R2를 원래 뜻대로(진동 채널만 넘은 경보를 보류) 옮겼을 때는 보완 LSTM의 오경보를 줄이지 못했고, '전류 파형이 정상이면 LSTM 경보를 모두 보류'로 넓힌 형태에서만 0행이 되었다. 이 개선과 R1의 해제는 모두 R1·R2용 전류 파형 확인(기록 첫 행부터의 사인 적합 R², 2.3절)에 기댄다. 이 확인은 앞단 모델과 무관하게 붙일 수 있으므로, 넓힌 R2를 붙인 보완 LSTM이 2단계 모델과 같은 test 값을 낸 것은 앞단 모델보다 규칙의 효과다.
  - 다·라는 규칙으로 해결되지 않는다. 이번 이상 파일과 정상을 가장 잘 가르는 신호는 전류 파형 붕괴이고(2.2절, 기록 단위 AUROC 1.000), 이 결과는 그 신호를 직접 보는 성분이 있는 v2를 기반 모델로 둔 판단과 맞는다. 다만 파형 붕괴가 고장 때문인지 수집 조건 때문인지는 가를 수 없어(2.1절) 고장 서명을 확인한 것은 아니고, 파형을 직접 보는 v2는 표본 시각 흔들림에 더 민감하다(2.6절 E5 ②). 그래서 이 결과는 v2 선택을 증명하지 않고, 전류 파형 이상을 놓치지 않아야 한다면 파형 성분이 필요하다는 조건부 근거다. 단, 오류 다는 결과를 열기 전에 정한 교체 검토 조건 5개 중 보완 LSTM이 유일하게 채우지 못한 조건이고, 오류 라는 사전 조건에 없던 사후 관찰이다.
  - 보완 LSTM이 나은 점도 있다. 진동 단독 주입(E1b)을 v2보다 잘 잡는다(최대 46.9%. 다만 16칸 중 11칸은 25% 미만이라 별도 진동 모델을 대신하지 못함, 3.6절). 분할 B 정상 300기록의 오경보 기록도 v2보다 적다(α 1% 2 대 4, α 5% 8 대 13). 두 모델을 함께 쓰는 시험은 하지 않았다. 최종 설정 모델 하나를 학습하는 데 CPU(Apple M2, 6개 동시 실행)로 약 1시간이 걸린다(v2는 수 초).
  - 한계: 변형 516개를 같은 valid 사건으로 골라 낙관이 남는다(새 seed 앙상블의 test 평균 0.973은 선택 seed 변형의 test 최고 0.971보다 높다). 최종 설정은 학습 12회 모두 1000에폭 예산을 다 썼으므로 더 학습하면 달라질 수 있다. 격자를 짤 때 test에서 본 사실(20행 창이면 test 이상 행 54.6%가 점수 없음)도 썼다. 한편 v2·R1·R2는 전체 이상 데이터를 본 뒤 정해 v2 쪽에 유리한 비대칭도 있다. 보완 LSTM은 run_all.py 밖의 별도 실험이라 수치 대조에 넣지 않았다(6장). 같은 코드·seed라도 LSTM 학습은 PC마다 조금 달라서(가이드북 방식 test 0.289·0.238이 다른 PC에서 0.285·0.215), run_all.py는 가이드북 방식 LSTM을 허용 오차 0.05로 대조한다.

## ◦ 2.8 정상 자료로 고정한 진동 보완 실험(사후 †)

- 목적과 구분: 기존 v2의 전류형 탐지를 유지하면서 진동만 변하는 조건의 감시 범위를 넓힐 수 있는지 별도로 시험했다. 이 절은 기존 잠금 모델을 정한 뒤의 추가 연구다. 전체 이상 자료가 이미 팀에 알려진 상태이므로 독립 test나 새 고장 검증으로 부르지 않는다. 기존 잠금 모델·R1·R2·확률 보정은 그대로 보존했다.
- 선택 절차: A·B 공통 정상 학습 범위에서 기록 0~119를 적합, 120~239를 보정, 240~299를 선택 평가에 썼다. 후보는 기본·진동 단독 8개와 결합 48개, 모두 56개다(경로별 α 1% OR 4개는 경보 예산이 달라 참고 대조로만 둔다). 오경보 제약 아래 탐지력이 큰 후보를 고른다는 원칙에 따랐고, 이상 라벨 없이 합성 주입으로 후보를 평가하는 방식[30]을 썼다. 순위 규칙은 우리가 정했다. 정상 선택 평가 오경보 기록률이 5% 이하이고 2.6절 E5 ①처럼 센서 값이 일정하게 이동해도 증가가 2%p 이하인 31개 가운데, 합성 주입 가족별 평균 탐지율의 최솟값, 네 가족 평균, 정상 조건 변화의 최악 경보율 순으로 골랐다. 동률이면 2.5절 잠금 규칙처럼 단순한 후보를 택한다. 후보 격자와 규칙은 실행 전에 정했고, 코드는 선택·설정·코드 해시를 잠근 뒤에만 이상 파일을 읽는다.
- 고정한 모델: 통합 후보(코드 이름 V2+VD3@1)는 v2에 진동 차분 잔차 경로(VD3)를 더한 것이다. VD3는 2.4절 † Ridge 예측 오차(과거 5행×3채널)의 후속형이다. 직류 이동(E5 ①)에 둔감하도록 기록 안 1차 차분을 쓰고, 3.6절의 진동 감시 공백을 겨냥해 예측 대상을 진동 2채널로 좁혔다. 같은 기록의 과거 최대 5행에서 세 센서의 차분으로 현재 진동 2채널의 차분을 Ridge로 예측한다. 상·하부 관계 변화(1.6절)도 보도록 두 잔차를 정상 학습 잔차 전체로 추정한 Ledoit–Wolf 수축 공분산[29]의 Mahalanobis 제곱거리로 채점하고 최근 3개 점수를 평균한다. 예측 잔차를 감시하는 것은 자기상관이 있는 공정의 표준 관리 방식이다[31]. 과거 전류도 입력이므로 전류와 완전히 독립된 경로는 아니다. 기록 경계에서 초기화하며 VD3 첫 점수는 5번째 행부터 가능하고, 그 전에는 v2 성분으로 판단한다.
- 하나의 경보 예산: 두 경로 점수를 각 정상 train의 꼬리 척도 g로 변환한 뒤 S=max(g(v2), g(VD3))로 합쳤다(진동 가중치 1). 정상 보정 기록마다 S의 최대값 M을 구해 한 번만 보정하고, p=(1+M≥S인 기록 수)/121이 0.01 이하이면 경보한다. 최소 p가 1/121이라 두 경로에 α 0.5%씩 나누면 어느 경로도 경보할 수 없다. 그래서 4.3절 † Ridge OR처럼 경로마다 α를 쓰지 않고 하나로 묶었다. 아래 개별 α 1% OR는 예산이 다른 참고 대조다.
- 정상 선택 평가에서 통합 후보의 무주입 오경보는 0/60기록, 상수 이동 뒤 최대 증가는 1.67%p(1기록)였다. 가족별 탐지율 최솟값은 10.83%, 네 가족 평균은 18.59%다. 선택 조건은 상수 이동만 담은 제한된 조건이며, 시각 흔들림을 포함한 정상 조건 변화 전체의 최대 경보율은 91.67%였다. 이 선택만으로 센서 변화 전반에 강건하다고 할 수 없다.

# □ 제3장. 영향요인 및 오류분석〔15점〕

## ◦ 3.1 주요 영향 변수와 상호작용

- 가장 강한 변수는 전류 파형이다. 겉보기 주파수로 고정한 사인을 10행 이상 기록 전체에 맞추면 R² 중앙값이 정상 0.995, 이상 0.095다.
- 진동은 크기와 시간 구조가 함께 바뀐다. 상부 진동 표준편차는 6.3배(전 행 합산 기준)가 되고 자기상관(lag-1) 중앙값이 −0.031에서 0.686으로 올라 느린 흔들림이 된다.
- 상호작용: 정상에서는 하부 진동이 전류 진폭(부하)을 따르고(v2 개발 때 분석, 17행 이상 정상 469기록, SD–RMS 순위 상관 0.865), 이상에서는 상·하부가 음의 상관을 보인다(상관 중앙 −0.36). 그래서 크기만 보면 고부하 정상과 이상을 혼동한다. R2가 전류 파형을 함께 보는 이유다.
- PCA 관리도 기여 분석도 같다. 이상 행 T² 기여는 전류 사인 잔차 비율(A 26%·B 28%), 상부 진동 RMS(26%·25%), 하부 진동 lag-1(15%·16%) 순이고 SPE는 하부 진동 RMS(44%)와 전류 잔차(39%·38%)가 크다. 하부 진동이 부하를 따르던 정상 관계의 붕괴가 SPE에 잡힌다.
- 모델 쪽에서 본 영향: R1 없이 test 행 F1은 크기 성분만 0.404·0.428 → 전류 파형 추가(v1) 0.904·0.912 → 초반 파형 창·동역학 추가(v2) 0.965·0.970으로, 전류 파형 성분이 가장 크게 기여한다(2.4절). 인공 주입에서는 크기 성분만 진동 주입에 반응하고(최대 35.0%, 분할 A는 8.9% 이하), 파형·동역학 성분이 전류 파형 주입을 잡는다(2.4절 † 성분 절제). 파형·동역학 성분은 전류 채널만 입력으로 쓰므로 이 분담은 설계에서 정해진 것이고 시험은 그 분담이 구현대로 작동함을 확인했다. 규칙까지 붙이면 R1은 미탐을, R2는 고부하 오경보를 줄인다(3.4절).

## ◦ 3.2 정상 운전변화와 오경보 발생조건

- 정상 valid·test 기록의 실시간 오경보를 운전 상태·모델별로 셌다(사후). 부하 등급은 전류 진폭 혼합분포 경계(127.2·225.1)로, 정숙 구간은 변화점 검출로 나눴다. 표에는 A가 든 B(valid+test 300기록)만 썼고, 각 칸은 경보가 1행이라도 난 기록 수다(차이가 보이게 α 5%). 단일 점수 모델(max|z|·LSTM 오토인코더·v2)은 보정 방식상 valid 120기록의 오경보가 α 5%에서 모두 6기록으로 같으므로(R2를 붙인 두 모델은 2기록), 표는 점수가 높은 정상 기록이 어느 운전 상태에 몰리는지를 보여 준다.

| 운전 상태 | 기록 | max\|z\| | LSTM 오토인코더 | v2 | v2 + R2 | 2단계(v2+R1+R2) |
|---|---:|---:|---:|---:|---:|---:|
| 정숙 구간(연속 저부하) | 90 | 0 | 0 | 0 | 0 | 0 |
| 변동 구간·저부하 | 58 | 0 | 0 | 0 | 0 | 1 |
| 변동 구간·중부하 | 77 | 2 | 7 | 4 | 2 | 2 |
| 변동 구간·고부하 | 53 | 10 | 1 | 9 | 1 | 1 |
| 변동 구간·짧은 기록(8행 미만) | 22 | 0 | 0 | 0 | 0 | 0 |
| 전체 | 300 | 12 | 8 | 13 | 3 | 4 |

- 학습에 없던 정숙 구간에서는 오경보가 거의 나지 않았다. 학습의 연속 저부하는 최장 4기록(0.62분)인데, test에서는 정숙 구간을 포함해 저부하 기록이 84·91기록(11.18·12.11분, A·B) 이어진다. 그래도 정숙 구간에서 10개 모델 × α 1·3·5% 오경보는 모두 합쳐 1행(분할 A의 LSTM 오토인코더, α 5%)이었다. 진동이 작고 전류 파형이 정상이라 이상 점수가 오히려 낮다.
- 오경보는 고부하 정상에 몰린다. 분할 B, α 5%에서 단일 모델 7개(베이스라인 5종, v1, v2)의 오경보 기록 중 66%가 고부하, 33%가 중부하였다. 고부하 기록의 오경보 비율은 평균 14.0%(모델 7개 합산 52/371, Clopper–Pearson 양측 95% 구간 10.6~18.0%)로 전체 3.8%(79/2100, 3.0~4.7%)의 3.7배다(같은 기록을 모델마다 겹쳐 센 참고 구간). α 1% v2 오경보 기록 4개(303·423·461·570)는 모두 상부 진동 SD가 분할 B 학습 기록의 98.6~99.6% 분위였다. 위험한 쪽은 학습에 없던 아래쪽(정숙)이 아니라 학습 분포의 위쪽 꼬리(더 센 부하)다.
- R2는 이번 고장 사건의 탐지를 줄이지 않으면서 이 오경보를 줄인다(착안 때 본 자료 안의 확인. α 5% 고부하 7/50→0/50기록, 같은 기록의 준-표본 밖 재확인, 2.5절 †). 분할 B 고부하 오경보 기록이 v2 9/53(95% 구간 8.1~29.8%)에서 1/53(0.05~10.1%)이 되고(α 5%) test 미탐 행은 α 1·3·5% 모두 v2와 같다. 정상 기록의 v2 경보는 대부분 크기 성분 단독이었고 파형 성분은 한 번도 켜지지 않았다. 남는 오경보는 파형을 판단하기 전(기록 앞 8행 미만)의 크기 경보와 중부하의 동역학 성분 경보다. 부하 등급 경계를 3분위로 바꿔도 결론은 같았다(R2의 비용은 2.6절 E1b).
- R1에는 비용이 따른다. α 5%에서 중부하 기록 446의 경보 2행이 다음 저부하 기록 447의 앞 7행으로 번졌다(2단계 모델 A 10·B 11행, v2+R2 3·4행, 모두 valid+test 합계). 운영 α를 1%로 두는 근거 중 하나다.
- 위 표의 운전 상태는 부하 등급·정숙 구간뿐이다. 기동·예열(2.2절), 금형 교체 뒤 시운전, 소재·두께·행정 속도·유온 변화는 정상 기록에 표시가 없으므로 도입 첫 달에 운전 일지로 표시해 상황별 오경보를 센다.

## ◦ 3.3 잘 작동하는 조건과 실패하는 조건

- 잘 작동하는 조건: 고장이 여러 기록에 걸쳐 이어지고 전류 파형도 흐트러지며 수집 조건이 학습 때와 같을 때다(2.6절 E3, 3.2절).
- 실패하는 조건(2단계 모델): 이어받을 직전 기록이 없는 사건 첫 표본(미탐), 파형을 판단하기 전(기록 앞 8행 미만)에 크기 성분만 커진 고부하 정상과 중부하의 동역학 성분 경보(오경보, 3.2절), α를 느슨하게 했을 때 R1이 다음 기록으로 이어 붙인 오경보(3.2절), 약한 전류 파형 이상(2.6절 E1, 강도 0.5에서 2.5%·13.5%), 전류 파형은 그대로이고 진동만 바뀌는 고장(세 성분이 둔한 데다 R2가 크기 경보를 2단계로 올리지 않음, E1b), 진폭 감소·센서 끊김(E2), 학습 때와 다른 수집 조건(전류 수준·표본 시각, E5)이다. 오류별 수치와 집중 조건은 아래 표와 그림 10에 모았다.

## ◦ 3.6 적용 조건

- 1.000은 단일 고장 사건, 행 단위, α 1%에서의 결과다.
- R2는 전류 파형이 흐트러지는 고장에만 맞는다. 기어 마모가 파형을 흐트러뜨리는지는 가설이고, 측판·끝면 마모는 문헌 서명이 전류 감소라(1.3절) 파형이 유지되면 R2가 크기 경보를 2단계로 올리지 않아 1단계로만 알린다. 세 성분은 커지거나 흐트러지는 변화만 봐서 진폭 감소·센서 끊김(2.6절 E2, 탐지 0~2%)은 잡을 수 없다(별도 센서 건전성 점검, 4.4절).
- 대안으로, 수백 시간에 걸친 마모(1.3절)는 같은 운전 조건의 전류 진폭 기준선을 주·월마다 비교해 추세로 본다. 전류 진폭은 부하 등급을 나눌 때 이미 계산하므로 센서가 더 필요 없다(검증 안 한 제안).
- R2를 거치지 않는 1단계(v2+R1)도 진동 단독 주입을 기록 하나 기준 B 최대 35.0%만 잡는다(v2와 같은 값). 진동형 고장(베어링·커플링) 감시에는 별도 진동 모델이 필요하다. 사후에 견준 Ridge 예측 오차가 진동 단독 주입을 최대 95.7% 잡아, 기록 안에서 갑자기 생기는 진동 변화에 한한 후보다(2.4절 †). 전류 파형 주입은 거의 못 잡으므로 v2+R1과 함께 1단계에 두는 구성을 4.3절에서 사후로 계산했다.
- 모델이 수집 조건에 민감하므로(2.6절 E5) 현장에 옮길 때는 현장 정상 데이터로 문턱을 다시 맞추고 표본화 시각을 동기화해야 한다.

- 별도 보완 실험(2.8절): 전류가 대체로 정상인 진동 잡음·충격에는 정상 전용으로 고정한 진동 차분 잔차 경로가 추가 탐지를 제공했다. 지속 증폭, 느린 수준 변화, 전류 진폭 감소는 여전히 거의 못 잡는다. 시각 흔들림과 겉보기 전류 주파수 −0.1Hz 이동에는 정상 기록 경보가 급증한다. 결합 모델의 한 문턱 보정과 새 정상 날짜 검증을 거쳐 적용 범위를 정한다.

## ◦ 4.2 경보에서 조치까지

- 경보는 두 단계다. 1단계 "주의"는 사전 잠금 모델 v2+R1의 경보이고, 공식 성능(test 행 F1 1.000·0.995)이 이 단계의 값이다. 2단계 "점검 요청"은 R2 교차 확인을 통과한 v2 경보에 R1을 붙인 경보(2단계 모델 v2+R1+R2, 1.000·1.000)로, 늘 1단계 경보 안에 있다(2.5절). 60초 안에 이어지는 경보는 한 사건으로 묶는다. 2단계 승격 규칙은 test 확인 뒤 과업 ②를 겨냥해 더한 운영 권고안이다(2.5절). 두 단계 경보는 제출 예측 파일의 `locked_v2_R1_realtime`(1단계)·`final_v2_R1_R2_realtime`(2단계) 열로 행마다 나오고(그림 12·13), 아래 점검 콘솔과 담당 절차는 R1·R2가 없는 v2 기준 프로토타입·운영 문서에서 가져온 제안이다.
  - 1단계: 콘솔에 표시만 하고 사람은 부르지 않는다. R2가 2단계로 올리지 않는 진동 크기 단독 경보(고부하 정상과 진동형 고장이 섞임)가 여기 남으므로, 같은 교대에 1단계 사건이 되풀이되면 품질 샘플 검사를 앞당기고 보전원이 다음 정지 때 아래 표의 진동 항목을 본다. 되풀이 기준 횟수는 도입 첫 달의 1단계 경보량으로 정한다.
  - 2단계: 운전원이 바로 아래 표의 운전 중 항목을, 보전원이 그 교대 안에 [정지] 항목을 본다. 현장 출동은 2단계에서만 한다. 표는 v2 조치표를 고친 것이며, 계측·수집 이상을 배제할 수 없어(2.1절) 운전 중에 볼 수 있는 계측 항목부터 시작한다.
  - 종료: R1의 자동 해제는 화면 표시만 끈다. 점검자가 콘솔 양식에 확인 시각·담당·결과(정상 확인·이상 확인·보류)·조치를 적고, 결과가 정상 확인이나 이상 확인이면 사건이 닫힌다. 보류면 열린 채로 남는다.

| 경보 근거 | 확인 대상(가설) | 점검 순서(운전 중 → [정지]) |
|---|---|---|
| 크기(진동 센서)* | 기어 마모·체결·베어링·부하 변화, 또는 센서 부착 이상 | 센서 부착·케이블 → 베어링 소음·온도 → 작동유 레벨·온도 → [정지] 체결 볼트·커플링 정렬 |
| 전류 파형·예측 오차 | 모터·전원·계측·수집 시각, 또는 출력 유압 불안정 | 수집 장비 표본화 시각 → 출력 압력 안정성 → 릴리프 밸브 → [정지] 전류센서 영점·접지 |
| 전류 치우침·순시값 정상 범위 초과 | 전류센서 영점 이동·포화, 또는 고압 유지 부하 | 전류센서 체결·케이블 → 램 정지 상태의 릴리프 작동 여부 → [정지] 무전류 상태의 전류센서 영점·포화(상전류에는 직류 성분이 없음) |
| 진동 + 전류 함께 | 캐비테이션·에어레이션(2.1절에서 두 관찰에 함께 맞아 '부합 가능'), 기어 마모로 유압 약화, 또는 계측·수집 변화 | 센서 부착·수집 설정 → 흡입측 소리(고음은 캐비테이션, 불규칙한 소음은 에어레이션[19])·유면·거품 → 출력 유압 → [정지] 흡입 필터·작동유 오염 → 전류센서 영점 |

  * 진동 크기 단독 경보는 1단계로는 그대로 나가고, 2단계로는 파형을 판단하기 전인 기록 첫 7행에서, 그 뒤에는 전류 R²가 정상 기준에 못 미칠 때만 올라간다(R2).
- 이상 양상별로 먼저 볼 곳(사후 분석): 10행 이상인 이상 17기록은 모두 전류 파형이 무너지고 치우쳤지만, 진동은 세 양상으로 갈렸다(정상 기록 분포의 0.5~99.5% 범위 기준, 10행 미만 4기록은 판단 보류). 21기록은 한 사건의 연속 구간이라 이 묶음은 고장 종류가 아니라 사건 안에서 기록마다 바뀐 양상이고, 원인을 가르지도 못한다. 그래서 위 표의 점검 순서를 양상에 따라 아래처럼 좁힌다. 신호가 가리키는 부위부터 보는 현장 관례에 따른 추정이다.

| 양상(이 사건의 기록) | 신호 | 먼저 볼 곳 |
|---|---|---|
| 상·하부 진동 모두 큼(9기록, 사건 전 구간) | 두 진동 SD 모두 정상 범위 위 | 흡입측(흡입 필터·유면·흡입 배관 공기 유입) → 펌프 소음 → [정지] 커플링 |
| 상부 진동만 큼(5기록, 기록 11·12·14·16·18) | 상부 SD만 정상 범위 위, 하부는 범위 안 | 상부 센서 쪽 체결·지지와 센서 부착 → [정지] 커플링 정렬 → 흡입측 |
| 진동 정상·작음, 전류만 이상(3기록, 기록 3·19·20) | 진동 SD가 정상 범위 안 또는 아래, 전류 치우침 큼 | 전류센서 영점·배선, 모터 전원 → 램 정지 상태의 고압 유지 여부(2.2절) |

- 품질 조치(품질 담당): 2단계면 의심 시간대 가공품을 보류해 전단면·버·치수를 확인한다. 의심 시간대는 경보 직전 마지막 정상 기록의 끝부터 경보가 풀릴 때까지로 잡되, 측정이 띄엄띄엄이라(1.6절) 실제 시작은 더 앞설 수 있다. 파인블랭킹 품질은 V링력·역압에 달려 있으므로[12], 유압 약화가 의심되면 전단면 품질부터 본다.
- 정상 확인으로 닫힌 구간은 다음 재보정의 정상 자료로, 이상 확인된 사건은 시작 시각·유형을 붙여 고장 라벨로 쌓는다(3.5절의 빈 고장 이력).
- 그림 12는 제출 예측 파일의 두 열로 분할 B test 기록마다 단계별 경보를 그린 것이다. 정상 180기록 가운데 1단계가 울린 기록은 3개(아래 콘솔의 "주의" 3건과 같은 기록)이고 2단계는 0개이며, 이상 11기록은 모두 두 단계가 함께 울렸다.

- 그림 13은 같은 분할 B test 기록에서 성분과 단계별 경보를 행 단위로 그린 것이다.

[그림 13: 두 단계 경보 카드 예시(분할 B test) — (a) 이상 기록 11은 v2가 끊긴 행까지 R1이 채워 기록 전체가 2단계, (b) 정상 기록 423은 v2가 크기 성분만 넘어 1단계 "주의"로 울렸지만 R2로 2단계에는 오르지 않음]

- 점검 콘솔(참고, v2 기준 프로토타입): v2의 로컬 웹 콘솔(Press Guard)이 우선순위순 사건 대기열, 사건별 경보 근거·정상 기준 대비 편차·권장 점검 항목, 위 결과 양식, 기록 재생(모의 운용)을 갖췄다.
  * 그림 14는 분할 B의 정상 test와 이상 21기록 전체(valid 포함)를 v2 기준으로 분석한 화면이다. 이상 사건 1건이 2단계 "점검 요청"으로, 고부하·중부하 정상 기록 3건이 1단계 "주의"로 올라와 있다. 이 3건은 분할 B test에서 잠금 모델이 오경보를 낸 3기록과 같고, R2가 2단계로 올리지 않는 경보라 새 경보 체계에서도 1단계 "주의"다.
  * 콘솔은 아직 v2 경보 기준이고 2단계 승격도 v2 운영 문서의 "사건 안 2행" 규칙을 쓴다. 1단계에 R1 이어받기를, 2단계 승격에 R2를 넣는 것이 도입 전에 할 작업이다. 실제 설비 제어 명령은 보내지 않는다.

[그림 14: 제출 모델과 다른 v2 기준 화면 — 점검 콘솔(v2 경보 기준, R1·R2 미반영; 분할 B 정상 test + 이상 21기록) — KPI·사건 대기열·경보 근거. '주의' 3건은 R2가 2단계로 올리지 않는 정상 오경보(새 체계에서도 1단계)이고, 이상 확률 55.0%는 표시 상한이며 고장 확률이 아니다. 콘솔의 구간·건은 기록, 관측은 행이다.]

- 정지 손실과의 연결: 이 경보는 고장 전 예고가 아니라 고장 상태 진입을 수집 주기 안에 알린다(2.1절). 2~3일 정지(1.1절) 자체를 줄인다는 근거는 이 데이터에 없다. 줄일 수 있는 것은 작업자가 소음으로 알아차리기 전까지 가공한 불량품과 계속 운전에 따른 2차 손상이다(추정). 그 크기는 행정 속도와 인지 지연으로 정해지므로, 도입 첫 달에 경보 시각과 작업자 인지 시각을 함께 기록해 잰다.

## ◦ 4.3 경보 운영 기준

- R1은 수집이 잠시 끊겨도 경보를 이어 가고 전류 파형이 정상으로 확인될 때만 푸는 규칙이다(2.3절). 정상 기록으로 번진 경보는 대부분 8행 안에 풀렸다. 이 해제는 화면 표시에만 적용한다(4.2절).
- 경보 시각: 첫 경보 0.0초(2.5절)는 데이터 시각 기준이다. 기록이 최대 50행(5초)씩 묶여 올라온다면(1.4절, 추정) 화면에는 최대 약 5초 늦게 닿는다. 사건이 수집 공백(정상 파일 기준 중앙값 4.2초, 90% 분위 8.4초) 중에 시작되면 첫 경보는 다음 기록까지 밀린다. 이 하한은 수집 구조에서 생기므로 수집 설정(4.4절 ①)으로 줄인다.
- 주입 강도를 시간에 따라 키운 확장(†): 실제 이상은 처음부터 이상 상태라 '고장 전 경보'를 잴 수 없다(2.1절). 그래서 2.6절 E1·E1b 주입을 시간 축으로 늘렸다. test 정상 흐름의 한 시점부터 2·5·10분에 걸쳐 주입 강도를 0에서 최대(전류 파형은 E1 강도 1, 진동 단독은 E1b 대역 잡음 1·감쇠 충격 4)까지 기록마다 키우고(완성 뒤 1분 유지), 2단계 모델, 1단계(잠금 모델), v2의 첫 경보를 쟀다(α 1%. 시작 시점 4곳 × 분할 2에 전류 파형은 seed 3개로 24회, 진동 단독은 주입 4종 × seed 3개로 96회, 대조는 8회).

| 합성 열화(열화 시작 → 최대 강도) | 2분 | 5분 | 10분 |
|---|---|---|---|
| 전류 파형(2단계): 완성 전 경보 비율 · 완성까지 남은 시간 중앙값 | 95.8% · 0.49분 | 100% · 2.02분 | 100% · 4.50분 |
| 전류 파형(2단계): 경보 시점의 상대 강도(최대 = 1) | 0.74 | 0.59 | 0.55 |
| 진동 단독: 완성 전 경보 비율(2단계 / 1단계) | 14.6% / 30.2% | 20.8% / 45.8% | 20.8% / 69.8% |
| 대조(주입 없음): 같은 구간 경보 비율(2단계 / 1단계) | 0% / 12.5% | 0% / 25.0% | 0% / 37.5% |

  - 전류 파형 열화는 완성 전에 거의 모두 2단계 경보가 났고, 첫 경보는 강도가 최대의 55~74%일 때였다. 최대 강도(E1 강도 1)에서 2단계 모델의 기록 하나 탐지율은 48.6·65.2%지만(2.6절), 열화 구간에는 기록이 여럿이라 그중 한 기록에서만 경보가 나도 잡힌 것으로 센다. 이 최대 강도도 실제 사건의 파형 붕괴(R² 중앙값 0.095)보다 훨씬 약하다(2.4절).
  - 진동만 커지는 열화는 R2가 크기 단독 경보를 2단계로 올리지 않아 2단계 경보가 14.6~20.8%에 그쳤고(2.6절 E1b와 같은 비용), 1단계 "주의"로는 30.2~69.8%가 알려졌다. 다만 1단계는 주입 없는 같은 구간에서도 12.5~37.5%가 울려 우연 경보가 섞여 있고, 2단계는 대조 구간에서 경보가 없었다. 1단계 값은 이 시험에서 모두 v2 단독과 같았다(R1은 첫 경보를 만들지 못해 첫 경보 기준으로는 v2와 같다).
  - 상승 속도와 최대 강도는 우리가 가정한 값이고, 경보가 고장 완성보다 얼마나 앞서는지는 이 두 값이 정한다. 그래서 실제 설비에서의 선행 시간은 이 시험으로 말하지 않는다. 이 시험은 주입이 커지는 구간 안에서 경보가 울리는지를 확인한 것이다.
- R2는 크기만 크고 전류 파형이 정상인 경보를 2단계로 올리지 않고 1단계로 둔다. 고부하 작업 때 출동 경보가 쌓여 무시되지 않게 하려는 것이다. 대신 진동만 나타나는 고장은 주로 1단계로만 알려 출동이 늦어질 수 있고, 진동형 고장을 제대로 감시하려면 별도 진동 모델이 필요하다(3.6절).
- 1단계 병행 진동 감시(권고, 사후 †): 잠금 모델 v2+R1의 경보에 Ridge 예측 오차(2.4절)의 경보를 행 단위 OR로 더하면, α 1% test에서는 오경보가 늘지 않았고(B 3행 그대로, Ridge의 1행이 그 안에 듦) 전류 파형 주입 탐지도 그대로(48.6·66.3%)였으며 진동 단독 주입의 기록 탐지는 28.3~96.1%로 올랐다(같은 주입에서 v2+R1 2.5~35.0%, 96.1%인 하부 감쇠 충격에서 v2+R1 18.9%). 대신 α 5%에서는 분할 B 정상 오경보 기록이 17에서 24/300으로 늘었다. α 1% test에서 오경보가 그대로인 것은 Ridge의 오경보 1행이 우연히 v2+R1의 오경보와 겹쳤기 때문이고, 두 α 1% 경보의 OR이라 1단계 설계 오경보는 시간당 최대 약 7.4기록이다. 같은 사건·같은 기록 위의 사후 계산이므로 도입 첫 달에 1단계 병행으로 시험하고, 2단계 승격 규칙은 바꾸지 않는다.
- 경보량 목표: α 1% 기록 단위 보정을 연속 운전에 옮기면 설계 오경보는 시간당 약 3.7기록이다(정상 기록의 교환 가능성 가정, R2 보류·R1 번짐·60초 묶음 전). 이는 R2 전이라 1단계 양의 설계치이며, 운전원 경보 예산(시간당 약 6건)[5]은 출동을 요구하는 2단계에 적용한다. test 정상 구간이 짧아(16~24분) 실측으로 확인되지 않으므로 도입 첫 달에 단계별 경보 사건을 기록하고, 넘치거나 실측 오경보율이 α를 넘으면 α를 낮추거나 다시 보정한다(1%보다 낮추려면 보정용 정상 기록이 120기록보다 많아야 한다).
- 재보정 자료: 점검으로 '정상 확인'된 기록만 쓴다. α 1%·보정 120기록에서는 문턱이 보정 기록 최대값 하나로 정해져, 이상이 섞인 기록 하나가 문턱을 크게 올린다. 분할 B 보정 기록 하나에 진동 감쇠 충격(강도 4)을 섞으면 문턱이 v2 3.52→5.56, 통합 후보 3.68→18.03으로 올랐다. 정상 오경보는 3→0기록이 됐지만 간헐적 끊김 탐지는 통합 후보 34.9→24.6%로 줄었다(†, 2.8절 주입). 전류 파형 왜곡은 1~2기록에서는 문턱이 거의 그대로였고 5기록에서 크게 올랐다(v2 15.08, 통합 후보 18.14). 겉보기 전류 주파수가 학습 범위를 벗어나도 재보정한다(2.8절).
- 운전 상태 연동: 오경보가 고부하 정상에 몰리므로(3.2절), PLC의 행정·대기 상태 신호를 받으면 운전 상태별 기준을 둘 수 있다.
- 중소기업 확산: 추가 센서 없이 외부에 붙이는 진동 2·전류 1채널로 동작해 인프라가 약한 공정에도 옮길 수 있다(가이드북도 강조). 옮길 때는 그 설비의 정상 데이터로 표준화와 문턱을 다시 맞추고(정상 학습 → valid 보정 → α 1%) 운전 상태를 확인한다. 다만 v2는 짧은 창의 과도 변화를 보는 구조라 느린 펌프 누설을 다룬 UCI 유압 시험대 자료에는 옮겨지지 않았다(2.6절).

- 신규 통합 후보의 운영 위치(2.8절): 위 Ridge OR는 과거 사후 비교이며, 이번 후보는 두 경로를 합친 점수에 한 번만 경보 예산을 적용한다. 기존 1단계·2단계 결과와 확률 열은 그대로 보존한다. 시험 운영에서는 진동 차분 잔차 경로가 올린 경보를 1단계 "주의"로 표시하고 4.2절 표의 '크기(진동 센서)' 점검 순서를 따르며, 2단계 승격 규칙은 새로 만들지 않는다. 경보마다 점수가 높아진 경로(전류/진동), 관측 부족(진동 차분 점수가 없는 기록 앞 4행), 수집 조건 점검 여부와 겉보기 주파수를 함께 기록한다. 새 보정 없이 기존 v2 확률을 통합 후보의 고장확률로 옮기지 않는다. 새 날짜의 정상·고장 자료는 제출 ZIP의 동결 모델 평가 도구로 다시 학습·보정하지 않고 평가한다(6장).

# □ 제5장. 창의성 및 차별성〔10점〕

◦ 성과로 이어진 기여 세 가지
  - 전류 파형 성분: R1 없이 test 행 F1을 크기 성분만 0.404·0.428에서 v1 0.904·0.912로 올렸다. 크기 성분이 구조상 볼 수 없는 약한 전류 파형 왜곡 주입(강도 1)은 크기+파형 조합이 46.4·53.9%, 동역학까지 더한 v2가 48.6·66.3% 잡는다(2.4절 †). 이 특징은 5NN에 넣어도 같은 수준으로 재현돼(2.4절 †) 학습기와 무관하게 유효하다. 특징은 이상 자료를 본 뒤 정했고 물리 대응은 설계 뒤에 점검했다(1.5·2.3절).
  - R2 교차 확인(가설 규칙): 고부하 정상의 크기 단독 경보를 2단계로 올리지 않아, 착안 자료 안에서 분할 B α 5% 고부하 오경보 기록을 9/53에서 1/53으로 줄였다. 같은 기록을 착안 기록만 빼고 시간순 5창으로 다시 학습해도 α 5% 정상 오경보 기록이 10/288에서 2/288로 줄었지만(†, 준-표본 밖 재확인) 효과 크기는 주장하지 않고 도입 첫 달에 표본 밖에서 잰다. 걸러진 경보는 1단계로 남는다(2.5·3.2·4.2·4.3절).
  - 수집 조건 흔들림 시험(E5): 모델이 무너지는 경우를 찾아 현장 이전 조건(재보정, 표본 시각 동기화)을 정했다(2.6·3.6절).

◦ 가이드북 기본 틀과의 대조: 가이드북 LSTM 오토인코더 실습(정상만 학습)과 모델·평가 틀을 견준다. 점수는 조건이 달라 방법만 대조한다(2.4절).

| 항목 | 가이드북 기본 틀 | 이 보고서 | 절 |
|---|---|---|---|
| 분할 | 정상 앞부분으로 학습하고, 나머지 정상과 이상 사건을 임곗값용 창과 평가용 창으로 나눔 | 정상 기록을 시간순 train/valid/test로 나누고 valid 선택을 해시로 잠근 뒤 test를 채점 | 1.7·2.5절 |
| 평가 단위 | 20행 창이 수집 공백을 가로지르고 창 단위로 판정 | 형식 누수를 지운 입력에서 기록 안 행마다 실시간 판정해 채점. point-adjust는 쓰지 않음(R1이 주는 비슷한 이득은 1.7절에 밝힘) | 1.6·1.7·2.4절 |
| 모델 점수 | LSTM 오토인코더 복원 오차 | 크기·파형·동역학 세 성분의 꼬리 점수 최댓값(켜진 성분이 경보 근거) | 2.3·4.2절 |
| 문턱 | 이상 라벨이 든 검증 창으로 임곗값을 고름 | 정상 valid 기록만으로 conformal 문턱(α 1%)을 정하고 α 1·3·5% 민감도를 보고 | 2.3·2.5절 |
| 경보 규칙 | 창마다 임곗값 판정 | R1 사건 지속(수집 공백을 넘어 경보 유지)·R2 교차 확인(크기 단독 경보를 전류 파형으로 걸러 2단계 출동에서 뺌) | 2.3·3.4절 |
| 오경보 분석 | 혼동행렬의 오경보 수까지. 발생 조건은 다루지 않음 | 운전 상태(정숙 구간, 부하 등급)별로 모델마다 오경보를 세고, 원인(크기 성분 단독 경보)을 R2와 운영 α로 이음 | 3.2~3.4절 |
| 검증 | 평가 구간 한 번의 채점 결과 | 같은 조건의 베이스라인·표준 기법·보완한 가이드북 LSTM·예측 계열(Ridge) 대조, 인공 고장 주입·진폭 감소·분할 변경·수집 조건 흔들림 시험, 오경보 이항·포아송 상한 | 2.4~2.7절 |
| 재현 | 초기 가중치가 실행마다 달라 결과가 소폭 다를 수 있다고 밝힘 | 명령 하나로 전처리부터 예측 파일·수치 대조까지 실행. 새 가상환경에서 보고서 수치 43개 일치, 예측 파일 바이트 동일(줄바꿈 맞춤) | 6장 |

◦ 선택 과정의 감사 가능성(해시 잠금): 공식 성능을 잠금 규칙이 고른 v2+R1(test B 0.995)로 두고 test 확인 후 더한 2단계 승격 규칙(v2+R1+R2)과 나눠 적어, 각 수치가 어느 단계의 선택에서 나왔는지 읽을 수 있게 했다. 2단계를 더해도 잠금 모델의 경보는 그대로다(1.7·2.5·4.2절).
◦ 수집 조건 흔들림 시험: 정상·이상이 다른 날에서 와, 모델이 고장 대신 수집 조건 차이를 잡을 가능성을 직접 시험했다. 이상 기록의 전류 평균을 지워도 21/21을 탐지해 전류 수준에는 기대지 않았지만, 표본 시각을 0.1ms 흔들면 정상 기록 경보율이 B 35.2%까지 올라 파형·시각 차이의 영향은 배제하지 못했다. 흔들림을 5ms까지 키워야 정상 기록이 이상일만큼 무너지고 흔들림은 치우침을 만들지 못해, 이상일의 변화가 모두 흔들림 탓은 아니었다. 하지만 v2 파형 성분은 0.2ms에도 정상 기록 59.4%에서 켜지고 탐지는 치우침에 기대지 않으므로(③), 모델 경보에 시각 차이가 섞였을 가능성은 남는다(†). 이 결과로 현장 이전 조건(재보정, 표본 시각 동기화)을 정했다(2.6절 E5, 3.6절).
◦ 신호 물리로 표본 간격 역산: 전류 고조파가 0.600Hz를 60Hz 계열의 접힘으로 보는 가설과 맞음을 보이고 계통 직결이면 표본 간격이 약 99·101ms임을 역산했다. 그래서 시각을 계산값으로 보고 실측 타임스탬프를 수집 개선 첫 단계에 넣었다(1.4·4.4절).
◦ 세션 교락의 크기 측정: 라벨 지도학습은 형식 누수를 지운 자료에서도 F1 0.793~0.970을 냈지만, 고장 없는 같은 날 정상끼리도 약 1시간 떨어지면 ROC-AUC 중앙값 0.75~0.87로 갈랐다. 지도학습 점수는 성능 비교에서 빼고 사후 대조로만 적었다(2.6절).
◦ 오경보 상한을 운영 단위로 환산: 정상 오경보 0/120·0/180의 이항 95% 상한(2.47%·1.65%)과 시간당 포아송 95% 상한(11.2·7.5건)을 산업 경보 관리 기준(운전원당 시간당 약 6건)과 견줬다(각각 기록 독립·사건률 일정 가정의 참고값). valid로 보정한 이상 확률을 제출 예측 파일의 열로 냈다(2.5절).
◦ 설비 물리 진단 매트릭스: 유압 계통·기어펌프 고장 서명을 정리해 초당 10회로 남는 정보(관측 진폭의 크기, 저주파 구조, 전류 파형)를 가렸다. v2의 세 성분이 이 정보와 대응함을 설계 뒤에 점검했고, ISO 13379-1 방식 매트릭스로 이 데이터가 가를 수 있는 것과 없는 것을 나눴다. 이는 경보 근거별 점검 순서로 이어진다(1.3~1.5·2.1·4.2절).
◦ 표준 기법 대조와 R1의 해제 동작: 공정 표준 PCA 관리도와 CUSUM·EWMA를 같은 분할·같은 보정으로 돌렸다(사후). CUSUM·EWMA도 기록 경계에서 상태를 이어 가면 R1 수준이 되어, 이득의 핵심이 수집 공백을 넘는 기억임을 보였다. 차이는 경보 해제에서 났다(R1 0.7초, 상태를 이어 가는 CUSUM 11.4~12.2분, 2.5·2.7절).
◦ 오류 조건을 원인과 운영 규칙까지 이음: v2의 미탐(기록 시작 직후)과 오경보(고부하 정상의 크기 성분 단독 경보)를 R1·R2와 운영 α로 이었다(test 미탐 A 22→0·B 16→0, 오경보 B 3→0, 분할 B α 5% 고부하 오경보 9/53→1/53, 착안 자료 안의 확인). 오경보의 고부하 집중을 정숙 구간과 대조해 확인했고, R2의 비용(2단계의 진동 단독 주입 탐지율 최대 23.7%p 손실)도 쟀다. R1·R2는 전체 데이터를 본 뒤 착안했으므로, test 효과를 표본 밖 근거로 쓰지 않고 효과가 몰리는 운전 조건을 따로 보였다(3.2~3.4절).

◦ 추가 기여(사후, 2.8절): 4.3절 † Ridge OR는 진동 감시를 넓혔지만 경로마다 α를 써서 1단계 설계 오경보를 최대 두 배로 늘렸다. 이를 v2와 진동 차분 잔차를 정상 기록 최대값 하나로 보정하는 단일 경보 예산으로 바꿨다. 같은 조건의 기준선과 함께 감시 범위의 이득(진동 잡음·충격)과 남는 실패 조건(지속 증폭·겉보기 주파수·시각 흔들림)을 같이 남겼다. 개선 폭은 같은 자료의 실측 범위로 한정한다.

  - ZIP에서 다시 실행하면 정상 전용 선택부터 새로 하여 새 잠금 파일(selection_lock.json)을 만든다. 그다음 verify_improvement.py가 결과표를 reference_results 폴더의 기준표와 대조한다. 배포본은 선택 대상이 아니고 보고서 결론에도 쓰지 않은 참고 계산 3개를 뺐고, 남은 56개 후보와 OR 4개의 계산은 원래 코드와 구문(AST) 단위로 같다. 같은 조건 비교와 정상 조건 민감도는 기준표가 아직 ZIP에 없어 --extra-audits 실행 결과로 확인한다.
  - 결과 파일(모두 press_improvement의 outputs 폴더): 선택 기록은 config.json, development_candidates.csv, selection.json에 남는다. 실제 평가는 actual_metrics.csv, 주입과 정상 조건 변화는 A_injection.csv, B_injection.csv, A_stress.csv, B_stress.csv에 남는다. 같은 조건 비교와 정상 조건 민감도는 strong_baselines, normal_sensitivity 폴더에 남는다.
  - 새 수집 자료 평가: `validate_holdout.py evaluate`로 동결 모델을 다시 학습·보정하지 않고 새 CSV를 평가한다. 정답 열이 없으면 경보 건수만 내고 탐지율·오경보율이라고 부르지 않는다. 기존 파일의 부분·재명명·시간 이동 사본은 중복 검사로 거부한다. 출처 선언과 중복 검사만으로 별개 고장 사건임이 입증되지는 않는다.
