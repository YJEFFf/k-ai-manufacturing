# 프레스 실행 전 확정 명세

이 문서는 다음 구현자가 수식·분모·선택·예외 처리를 임의로 정하지 않고 실행할 수 있도록 남은 설계 결정을 확정한다. 2026년 10월 3일의 기존 실험 결과를 알고 작성한 **후속 실험 계획**이다. 여기서 정의한 K1, 학습 증강, 운영 정책, 외부 모델의 성능을 이번 문서 수정에서 계산하지 않았다. 검증용 가상 배열은 실제 데이터 성능과 별도로 관리한다.

현재 결론은 C1을 최종 모델로 지정하지 않고, SKAB의 두 구조 비교와 아래 K1 한 종류, 제한 증강을 등록된 기준으로 검사하는 것이다. 채택할 새 후보가 없다는 결과도 허용한다. v2 복귀는 실행 경로에 없다.

## 기준 문서와 실행 범위

진행 상태는 [execution_revision.json](execution_revision.json), 후속 구현의 세부 수치와 분기는 [execution_contracts.json](execution_contracts.json)을 따른다. 이 문서와 JSON의 의미가 다르면 구현을 멈추고 명세 오류로 수정한다. 둘 중 유리한 규칙을 임의로 고르지 않는다.

원래 [protocol.json](protocol.json)은 SHA-256 `daedfe0705d0a2f0d12fced334e195c4c3643a095e92d9c88f766fd398ad38b8`로 보존한다. 원명세 재현에는 [design_v1.json](../../analysis/press_master_validation_2026-10-03/design_v1.json)의 명시적 보충을 함께 적용한다. 이번 문서는 이후 작업의 추가·변경만 규정하며 과거 결과를 새 규칙으로 덮어쓰지 않는다. 특히 기존 3건·10%p·5%p·20부모의 채택 문턱은 유지한다.

| 단계 | 실행 대상 | 완료 조건과 분기 |
|---|---|---|
| E1 | SKAB fit/dev/cal, 전역 G와 1차 양측 C | 그룹·블록·라벨·점수·순위·사건 대응표와 dev 결과. cal은 임계값 계산 전용 |
| E2 | 프레스 B1·C1d1과 K1 대조 | 아래 한 수식, 기존 개발 주입과 손실. 미지원·실패도 결과로 종료 |
| E3 | 프레스 kNN k=5의 A0/A1/A2 | 두 증강 비율과 3seed의 모든 대조·생성 실패·부모별 참조 확인 |
| E4 | 후보 선택, 확률 진단, I0/P23 운영 비교 | 선택 규칙, 대상 확률, 정책 선택 및 변경 이유를 기록 |
| E5 | 사전 동결 후 H1/H2와 SKAB test | 동결 파일에 등록한 모델·정책만 계산. 실패로 재선택하지 않음 |
| E6 | 새 환경 재현과 주장 범위 검사 | 학습→추론→집계, 체크포인트 재로딩, 행·기록 대응과 분모 일치 |

E1의 C는 구조 대조이고 프레스 채택 결과에 종속되지 않는다. SKAB K1은 프레스 K1이 개발 채택 기준을 통과했을 때만 추가하는 세 번째 구조다. 이 분기는 지금 고정하며 SKAB 결과로 프레스 후보를 역선택하지 않는다. SKAB에서 증강 kNN을 자동 추가하지 않는다. 프레스 원시 파형 crop과 SKAB의 이미 계산된 RMS 블록은 같은 증강이 아니다.

Beihang은 아래에 정한 별도 보조 실험이다. ESPset·UCI의 추가 모델 학습, A3·O1, 새로운 관계 특징·신경망·EWMA·자동 정상 갱신은 이번 실행 범위 밖이다. 기존 문서의 후보 설명은 실행 승인이 아니며 해당 실험을 나중에 추가하려면 별도 명세와 결과 열람 이력을 먼저 남긴다. 파일을 확보한 상태와 모델 검증을 마친 상태를 구분한다.

## 공통 수치와 입력 오류

float64, 표준편차 ddof=0, NumPy 선형 보간 백분위 `method="linear"`를 사용한다. 회귀 설명변수의 fit 표준편차가 0이면 나눗수 1로 두어 중심화한 상수열은 0이 된다. 반응변수의 무척도 축은 02의 MAD→IQR→제외 규칙을 따른다. 순위 판정은 p의 유리한 반올림 없이 `(1+상위 동점 포함 개수)/(n+1)<=alpha`로 비교한다. 사람이 보는 문턱 숫자를 반올림한 뒤 재판정하지 않는다. 회귀·생성기·전처리의 모든 fitted 값은 해당 역할의 실제 fit에서만 구한다. JSON의 NaN/Infinity는 금지하고 미정의 값은 null과 사유 코드로 저장한다.

파싱·역행·동일 시각의 상충 센서값·비유한 센서값은 원행 대응을 가진 입력 오류다. 현재 계약은 이런 오류를 임의 보간하거나 삭제한 뒤 정상적인 수집으로 계속 평가하지 않는다. 해당 수집의 수치 평가를 `input_contract_failed`로 멈추고 오류 행·영향 그룹·미완료 분모를 남긴다. 다른 정상 수집의 표는 남길 수 있지만 전체 외부 평가를 완료/통과로 표시하지 않는다. 같은 시각·같은 수치의 완전 중복만 지정 규칙으로 합친다. SKAB의 주석 충돌은 센서 입력 오류와 다르며 앞서 정한 마스크·범위 평가로 계속 처리한다.

유한하지만 길이가 짧은 기록, 평탄 신호, 보정 표본 부족은 입력 파일 실패와 다르다. 축소 특징 또는 판정 유보와 품질 요청으로 남긴다. 프레스에서 n>=2인 채널의 값이 정확히 일정하면 평탄 표시를 하되 유한한 다른 점수는 계속 계산한다. SKAB의 일정한 전류 수준을 프레스 원시 파형 평탄과 같은 계측 오류로 표시하지 않는다.

Q1은 누락/비유한·역행/시각 충돌에서 입력 실패, 완전 중복에서 결과 불변, 평탄에서 품질 표시, 공백에서 상태 초기화가 맞는지 검사한다. ADC 상한을 모르므로 임의 clipping 파형을 넣고 모델이 물리적 포화를 식별했다고 주장하지 않는다. 그 경우 보이는 평탄/점수 변화만 기록한다. 파일 경로나 namespace는 부모 중복 통제와 추적에만 사용하며 예측 특징이 아니다.

## K1 조건 불가 판정을 유지하는 보정 대조

### 가설과 고정 수식

가설은 C1의 조건부 점수 꼬리를 전체 정상 cal에 섞는 것이 조건 불가 기록의 문턱을 바꾸는 손실 원인이라는 것이다. K1은 이 한 요소만 검사한다. B1 및 C1d1의 적합, 길이별 척도, 전류 성분, fit 게이트를 그대로 사용한다. 전역 척도 전환·새 특징·단측화·증강을 동시에 결합하지 않는다.

`sB(x)`는 B1 점수, `sC(x)`는 C1d1 점수다. `g(x)`는 fit에서 고정한 원래 전류 게이트를 통과하고 양쪽 조건부 진동 잔차와 두 모델 점수가 모두 유한할 때 1이다. 질의 라벨·평가 분포는 g에 사용하지 않는다. 아래 순위는 동점을 `>=`로 센다.

```text
CB = {sB(z): z는 실제 정상 cal, sB(z)가 유한}
CC = {sC(z): z는 실제 정상 cal, g(z)=1}
pB(x) = (1 + count(CB >= sB(x))) / (|CB| + 1)
pC(x) = (1 + count(CC >= sC(x))) / (|CC| + 1)
n_required(alpha) = max(39, ceil(1/alpha) - 1)

if sB(x) is not finite or |CB| < ceil(1/alpha)-1:
    return unsupported_with_quality_request
if g(x)=1 and |CC| >= n_required(alpha):
    p_decision(x) = pC(x); route = conditional_reference
else:
    p_decision(x) = pB(x); route = baseline_reference
request = p_decision <= alpha
```

`|CB| < ceil(1/alpha)-1`이면 해당 α의 판정은 미지원이다. 정상으로 채우지 않고 보수적 부담에 관측 부족 요청을 포함한다. 두 p를 OR하거나 최솟값으로 합치지 않는다. `g=0`인 기록의 점수·p·임계 초과 판정은 같은 적합·보정판의 B1과 정확히 같아야 한다. 전류 무효 주입 뒤 g가 꺼진 경우에도 이 계약을 적용한다. 조건부 cal이 부족하면 전체 후보를 다른 α로 구제하지 않고 B1 경로로 처리한다.

39는 α=0.05에서 최소 p 간격 1/40과 두 꼬리 순위 위치를 확보하는 **개발 설계값**이다. 안정성이나 조건별 오경보 보장을 뜻하지 않는다. 주 α에서 P0/P1 중 한 분할이라도 CC가 39개 미만이면 K1의 효과는 판단 불가로 남기고 최종 개선 후보로 채택하지 않는다. 0.03·0.01은 보조 표이며 부족한 CC와 CB를 각각 표시한다.

B1과의 정확한 p·판정 동등성은 유한 점수와 CB의 α 해상도가 지원되는 경우의 계약이다. 지원되지 않는 α는 이번 후속 비교의 모든 모델에 같은 미지원 표시·보수적 품질 부담 규칙을 적용한다. 과거 집계의 미지원 α 표를 새 품질 부담 수치로 소급 덮어쓰지 않는다.

K1은 정상 cal을 회귀·척도·게이트 학습에 재사용하지 않는다. 같은 cal 관측이 CB와 CC에 함께 들어갈 수 있지만 각각 지정된 점수의 순위를 계산하는 데만 쓴다. cal 결과를 보고 39·게이트·점수·α를 바꾸지 않는다. 채택에는 원래 P0/P1 기준과 모든 손실 셀을 그대로 적용하고 C1d1 대비도 보조로 남긴다. g=1인 전류 변화나 진동 감소의 손실까지 없어지는 수식은 아니므로 해당 시험을 생략하지 않는다.

### 이 방법이 보장하지 않는 것

조건 경로를 나누어도 pooled B1 참조를 쓰는 fallback의 조건부 오류율은 알려져 있지 않다. 따라서 K1의 전체 명목 5% 오경보 보장을 주장하지 않는다. `p_normal_tail`에는 실제 참조 종류와 참조 수를 함께 기록하고, 전체 스트림의 요청을 직접 센다. **확정할 수 있는 성질은 fallback 판정의 B1 동등성**이고 전체 성능 개선은 실행 후 판단한다. 일반적인 conformal p값 연구도 가정과 구성 방법을 구분하므로 이 새 혼합 규칙에 정리를 이식하지 않는다. [원논문 초록과 서지](https://arxiv.org/abs/2104.08279)

추가 결과에는 길이×원래 게이트×최종 route별 부모 수, cal 포함 수, 기존 C1/B1/K1의 판정 차이와 원인이 필요하다. K1 실패 후 문턱·39·게이트를 바꾼 K2를 이 실행 안에서 만들지 않는다.

## 후보 수와 최종 선택

새 점수·보정 후보는 K1 하나다. 새 증강 후보는 A2 비율 0.5와 1.0 두 개다. seed는 반복 검증이며 별도 우승 후보가 아니다. 기존 12개 탈락 후보를 성능이 좋았던 일부 셀만으로 재등록하지 않는다. 구현 오류가 확인되면 영향받는 비교 전체를 같은 버전으로 다시 계산하고 원래 결과를 보존한다.

증강은 각 seed 11·29·47에서 원래 채택 조건을 통과해야 한다. 세 seed 평균은 효과 요약과 동률 순위에 사용하며 가장 좋은 seed를 고르지 않는다. 최종 재적합 seed는 결과와 무관하게 11로 고정한다. 증강 이익은 무증강 A0와 비교하고 B1 대비 채택도 통과해야 한다. 판단 불가 손실 셀 하나라도 있으면 통과가 아니다.

여기서 **학습 증강 seed와 평가 주입 seed는 두 축**이다. 각 A2 학습 seed마다 기존 평가 주입 seed 11·29·47 세 개를 모두 적용해 원래의 부모 내 평균과 seed별 손실 제한을 계산한다. 두 seed 번호가 같은 세 쌍만 골라 평가하지 않는다. 같은 평가 부모·주입 seed의 파형은 모든 학습 seed와 후보에 공통이다. 학습 3판×주입 3실현을 독립 고장 9건으로 세지 않는다. 최종 정렬의 정상 요청은 학습 3판의 합을 3으로 나눈 값, 계열 POD는 각 학습판의 원래 집계값 평균이다. 요청 평균은 정수 합/3으로 정확 비교한다.

통과 후보 정렬은 전체 정상 요청 수 오름차순, 세 개발 계열 중 최저 대표 POD 내림차순, 아래 고정 복잡도 순위, 저장된 학습 상태의 수치 개수, 참조 배열 byte 수, 측정한 한 기록 추론 중앙시간, 마지막으로 후보 ID 사전순이다. 수치율 비교의 허용오차는 1e-10이며 정수 건수에는 허용오차를 적용하지 않는다. 복잡도 순위는 B1=0, A0=1, K1=2, A2=3이다. 이 순위는 성능 보장이 아니라 동률의 재현 가능한 처리다. 과거 탈락 C1/C2/S0~S5는 이 정렬의 선택 집합에 없다.

추론 비용은 같은 기계·CPU 단일 스레드에서 입력 특징 계산과 판정을 포함하고 디스크 입출력은 제외한다. 개발 평가 입력을 고정 순서로 한 차례 순회하는 작업을 5회 준비 후 20회 측정해 기록당 시간을 구한다. 배치 크기·환경·참조 수·메모리를 같이 남긴다. 비용 측정 실패는 0으로 채우지 않고 그 동률 후보의 선정 미완료 사유로 남긴다.

통과 후보가 없으면 `selected_candidate=null`, `comparison_reference=B1`, `improvement_established=false`다. B1은 실험·확률·정책 연결을 확인하는 참조로 계속 사용할 수 있으나 채택 성공으로 바꾸지 않는다. 이 경우에도 미리 정한 G/C 외부 비교와 B1·C1d1의 H1/H2 반응 범위 감사는 완료한다. 최종 개선 모델이 없다는 이유로 예정된 실패 증거를 생략하지 않는다.

## SKAB의 블록과 외부 평가

### 입력과 적합

고정판·30그룹 예약·237개 충돌 마스크는 [데이터 계약](03_data_sources.md)을 유지한다. 모델 함수는 파일 경로나 라벨을 받지 않고 시각·센서값과 적합 상태만 받는다. 라벨은 fit/cal 제외 및 평가 모듈에서만 쓴다. 각 원파일 내부 순서의 역행은 먼저 검사한다. 서로 다른 파일의 중복 제거 후 그룹 시각순 합치는 것은 허용하지만 파일 내부 오류를 정렬로 숨기지 않는다.

fit 그룹 내 양의 시각 차를 그룹마다 구해 중앙값을 낸 뒤 그 중앙값들의 중앙값을 `dt_fit`으로 고정한다. test로 간격을 다시 추정하지 않는다. 중복 관측을 한 번만 남기고 `1.5*dt_fit` 초과 공백에서 구간을 끊는다. 각 구간 첫 관측부터 비중첩 20표본을 만든다. 뒤의 불완전 블록도 분모·품질 상태에 남긴다. 정상 라벨에 맞춰 블록 시작을 이동하지 않는다. 블록 판정 가능 시각은 마지막 표본 수신 시각이며 프레스의 0.5초 타임아웃을 추가하지 않는다.

모든 표본이 유한하고 확정 정상이며 충돌 없는 완성 블록만 정상 fit/cal에 쓴다. 특징은 두 진동 RMS의 중앙값, `abs(median(Current))`, `median(abs(Current-median(Current)))`의 자연로그 4축이다. 로그 바닥은 실제 fit의 양수 중앙값×1e-6, 표준화는 fit 중앙값과 MAD→IQR 규칙이다. RMS 음수는 품질 오류, 전류 부호는 원값에서 중앙값·MAD를 구한 뒤 처리한다. 이미 제공된 RMS의 시간 평균을 빼지 않는다. 유한 상수 Current 블록은 그 자체로 오류가 아니며 MAD=0도 fit 로그 바닥으로 처리한다. 이 판단을 프레스 원시 파형의 정확 평탄 채널 검사와 혼동하지 않는다.

G는 `[|zV0|,|zV1|,|zIlevel|,max(zIdisp,0)]` 중 유효 성분의 최댓값이다. C는 양수 전류 크기의 fit 1~99백분위 안에서 진동 두 축을 1차 조건부 잔차로 바꾼다. 회귀는 fit 설명변수 평균·표준편차와 평균제곱오차+0.001 페널티, 절편 무페널티다. 범위 내 fit 부모가 30개 미만이거나 양쪽 잔차 척도가 유효하지 않으면 전체 조건 경로를 끄고 G를 쓴다. 길이가 동일하므로 길이별 척도는 없다. 진동의 조건화 이외의 점수·정책은 G/C에서 같다.

cal 점수는 확인된 정상 블록을 합쳐 각 블록에 같은 비중으로 순위 보정한다. 이것을 그룹에 동일 비중을 준 보정이라고 부르지 않는다. 그룹별 cal 수와 꼬리 기여를 공개한다. α 필요 표본수와 동점은 원명세대로다. K1이 추가되면 sB/sC는 동일 G/C 점수, g는 이 SKAB C의 전류 크기 지원 게이트와 유한 잔차 조건으로 대체해 CB/CC 규칙을 적용한다. 프레스의 사인/R² 게이트는 가져오지 않는다.

### 라벨과 사건

`anomaly`와 `changepoint`는 별도 주석이다. [SKAB 원저자 설명](https://raw.githubusercontent.com/waico/SKAB/b2c0d46c2971dcbfe71e26087b6d231998bb91c2/README.md)을 근거로 원 라벨 의미를 기록하고, 우리 블록·사건 규약을 공식 리더보드 점수와 직접 비교하지 않는다.

고정판의 `data/anomaly-free/anomaly-free.csv`에는 라벨 열이 없으며 [원 데이터 설명](https://github.com/waico/SKAB/blob/b2c0d46c2971dcbfe71e26087b6d231998bb91c2/data/README.md)이 정상 모드 수집으로 지정한다. 취득 manifest의 정확한 경로·해시와 일치하는 이 파일만 anomaly=0, changepoint=0의 출처 기반 주석을 부여한다. 이름에 normal이 들어가는 임의 파일에 이 규칙을 적용하지 않는다. 이는 기존 237개 충돌 마스크를 만든 규칙과 같다. 다른 파일과 겹쳐 라벨이 충돌하면 정상으로 우선하지 않는다.

한 관측의 여러 anomaly 주석 중 최소·최대를 `(l,u)`로 둔다. 위 출처 기반 예외 이외에 주석이 없거나 이진 값이 아니면 `(0,1)`이고 라벨 품질 오류다. 블록 정답 범위는 `L=max(l_i), U=max(u_i)`다. 충돌 플래그는 anomaly와 changepoint 모두에서 보존한다. 충돌 없는 확정 블록의 주 지표와 전체 블록의 범위 지표를 함께 출력한다. changepoint만 충돌해 anomaly 범위가 확정되는 경우에도 fit/cal 제외는 유지한다.

이진 예측 b에 대해 전체 평가 블록의 가능한 confusion 범위는 다음과 같다. 기계 점수 유보는 b=0, 별도 운영 부담에서는 요청 1이다. 각 식의 합은 같은 전체 블록 집합에서 구한다.

```text
TP_low=sum(b*L)        TP_high=sum(b*U)
FP_low=sum(b*(1-U))    FP_high=sum(b*(1-L))
FN_low=sum((1-b)*L)    FN_high=sum((1-b)*U)
F1_low=2*TP_low/(2*TP_low+FP_high+FN_high)
F1_high=2*TP_high/(2*TP_high+FP_low+FN_low)
```

분모 0은 미정의로 표시한다. precision은 TP 범위를 예측 양성 수로 나누고 recall은 `TP_low/(TP_low+FN_high)`와 `TP_high/(TP_high+FN_low)`를 쓴다. 0/0이 가능한지 별도 표시한다. 불완전 블록은 기계 예측 유보와 위 범위 집계, 운영 품질 요청에 모두 남긴다. 모호 블록을 지운 표만 전체 성능으로 제시하지 않는다.

주 사건은 동일 연속 구간에서 충돌 없는 anomaly=0 관측 다음에 시작하는, 충돌 없는 anomaly=1의 최대 연속 구간이다. 첫 관측부터 1이면 좌측 검열, 모호 주석·관측 공백에 닿으면 경계 불확실, 끝까지 1이면 우측 검열을 기록한다. 확정 사건의 시작 `t_on`부터 마지막 양성 관측 `t_last`까지 새 알림이 시작해야 사건 내 탐지다. 블록이 닫히기 전에 짧은 사건이 끝나면 늦게 탐지한 블록은 블록 TP일 수 있어도 사건 내 탐지가 아니다. 사건 종료 뒤 첫 완성 블록까지의 반응은 별도 `late_detection`이다. 사건 전부터 켜진 알림은 `preexisting_request`이며 새 조기 탐지로 세지 않는다.

발생 시각이 확정된 사건은 EOF·관측 공백에서 우측 검열돼도 관측 종료까지의 탐지 여부를 평가한다. 이때 미탐은 `not_detected_by_observation_end`이며 전체 고장 지속기간의 영구 미탐이라고 쓰지 않는다. 발생이 좌측 검열되거나 시작 주석이 모호한 사건은 신규 탐지율 분모에서 분리하고 수·관측 내 반응을 남긴다. 사건 중간에 모호 주석이 나타나면 그 직전까지를 검열 구간으로 표시하며 모호한 뒤 구간을 확정 양성으로 이어붙이지 않는다.

사건별 미탐·탐지시각·지연과 좌/우 검열·모호 사건 수를 모두 보존한다. 종료가 확정된 사건과 우측 검열된 관측 구간의 탐지율을 각각 표시하고, 정책의 paired 손실 제한에는 발생이 확정된 두 종류 모두를 사용한다. 모호 라벨 전부 0/전부 1 시나리오는 민감도 분석으로만 표시하며 가능한 모든 사건 지표의 엄밀한 상·하한이라고 부르지 않는다. changepoint는 원 주석 시각과 알림의 차이를 별도 표로 남기고 anomaly 사건에 맞춰 이동하지 않는다.

### 집계와 외부 결론

전체 블록 합산과 그룹별 값, 유효 분모가 있는 그룹의 동일 비중 평균을 함께 출력한다. 미정의 그룹은 0으로 채우지 않고 제외 수·이유를 표시한다. 핵심 비교는 동일 α의 정상 요청/100블록, 확정 사건 탐지 수, 미탐, 지연, 모호·불완전 커버리지다. 길거나 쉬운 그룹 하나의 합계 이익만으로 외부 개선이라고 하지 않는다.

외부 두 구조의 비교 결과 자체는 반드시 남긴다. 외부에서의 일관된 개선 표시는 모든 평가 그룹에서 정상 요청률이 증가하지 않고, 확정 사건 탐지를 잃지 않으며, 둘 다 탐지한 사건의 지연이 악화되지 않는 경우에만 가능하다. 그중 적어도 한 항목은 엄격히 개선되어야 한다. 평가할 정상이나 사건이 없어 판단할 수 없는 조건은 `not_established`다. 이 보수적 설명 기준은 프레스의 3건·10%p 채택 기준과 별개이며 test로 모델을 바꾸는 규칙이 아니다. 엇갈린 결과는 항목별로 제시한다.

## 정상 증강의 완전한 대조

A0는 실제 fit 원본이다. A2의 목표 자식 수는 `floor(r*N_fit)`이며 r=0.5·1.0이다. 부모 길이보다 **엄격히 짧은** 20·30·40표본 crop이 하나 이상 가능한 실제 fit 부모만 생성 가능 집합에 넣는다. 짧은 부모도 원본 참조·평가 분모에서는 유지한다. 모든 원본 부모가 동일한 crop 기회를 갖는다는 잘못된 설명 대신 생성 가능 부모 사이의 균등 배정을 명시한다.

가능 부모 M개에 각 `Q//M`개를 배정하고 남은 `Q%M`개는 고정 seed 순열의 앞 부모에 하나씩 배정한다. M=0이면 A2는 미지원이다. 각 부모에서 가능한 길이를 균등하게 고르고 시작 위치를 `0..n-length`에서 균등하게 고른다. 같은 `(부모,길이,시작)`을 중복 생성하지 않는다. 가능한 조합을 모두 썼으면 실패 수를 남기고 다른 부모의 할당량을 늘려 메우지 않는다. 구현은 조합 목록을 만든 뒤 길이 균등, 해당 길이의 남은 위치 균등으로 선택해 재시도 무한 루프를 피한다.

난수기는 고정 환경의 NumPy PCG64다. 키는 `["normal_crop",fold,parent_key,seed]`를 `ensure_ascii=True,separators=(",",":")`로 JSON 직렬화한 SHA-256의 앞 8바이트 little endian 정수다. 부모 할당 순열은 parent_key 자리에 `"allocation"`을 사용한다. 비율을 키에서 빼 r=0.5의 각 부모 자식 목록이 r=1.0 목록의 접두 부분이 되게 한다. 전체 자식 수에는 중복 원본 A1도 같은 성공 부모와 할당을 사용한다. A1 자식은 대응 A2의 부모 파형 전체를 그대로 복사한다.

crop은 세 채널·원시 시각을 같은 위치에서 자른다. 원부모의 source namespace와 ID를 유지하고 별도 child ID를 붙인다. 특징·게이트를 다시 계산하며 원부모의 값으로 복사하지 않는다. 로그 바닥·중심·척도·결측 대체·원래 게이트 정의는 실제 fit 원본에만 적합한다. 길이별 척도에는 자식의 길이를 사용한다. 정상 cal은 증강하지 않는다.

질의와 같은 원부모의 모든 참조를 제외한 뒤, 각 참조 부모에서 원본·자식까지의 거리 최솟값을 한 개만 남기고 서로 다른 5부모의 평균 거리를 쓴다. 단순 중복 A1은 A0와 점수·p·판정이 같아야 한다. A2는 부모당 이웃 수는 통제하지만 참조 위치가 늘어나는 기하학적 효과까지 제거하지는 않는다. 같은 가중치라는 표현으로 그 효과를 숨기지 않는다.

형식상 생성 성공, 유효 특징 변화, 원본과 동일한 특징의 자식, 실패를 각각 센다. 실패를 정상 자식으로 대체하지 않는다. A2가 통과해도 같은 프레스에서의 탐색적 증강 이익으로 표현하며 독립 고장 수 증가나 외부 검증 완료라고 쓰지 않는다.

## 알림 정책과 선택 규칙

### 같은 입력을 받는 두 상태 기계

모델 채택은 기존처럼 기록별 `b=(p<=0.05)`를 기준으로 한다. 운영 비교는 이 b를 바꾸지 않고 I0 즉시 알림과 P23 지속 알림에 똑같이 넣는다. **두 정책 모두 같은 해제·묶음 규칙**을 사용한다. 기록별 임계 초과 수와 알림 시작 수는 다른 열이다.

상태는 `active`, 최근 최대 3개 유효 b, 연속 음성 수다. 분할·수집 그룹 시작에서 초기화한다. 시간축은 `decision_available_time`이다. 직전 판정 후 30초를 초과해 다음 판정이 오면 직전 판정+30초에서 상태를 관측 불가로 닫고 이력을 지운다. 정확히 30초면 유지한다. 파일 끝은 마지막 판정에서 우측 검열하며 관측하지 않은 30초를 점유시간에 더하지 않는다.

유효 b를 받은 순서는 이력 추가 → 음성 연속 수 갱신 → active이고 음성 2개 연속이면 해제·이력 초기화 → inactive일 때 시작 조건 검사다. I0는 현재 b=1이면 즉시 시작한다. P23은 현재 b=1이고 최근 최대 3개 중 2개 이상이 1일 때 시작한다. 처음 두 유효 기록이 모두 1이면 두 번째에서 시작할 수 있다. 현재 b=0인 시점에 과거 양성만으로 새 알림을 만들지 않는다. active 중 양성은 새 시작이 아니라 반복 억제다.

점수 미지원·파싱 오류·관측 부족은 두 정책 모두 즉시 품질 요청을 만들고 기계 알림 이력을 초기화한다. 진행 중 기계 알림은 정상 해제가 아니라 `closed_unknown`으로 종료한다. 유한 점수와 평탄 채널 품질 표시가 함께 있으면 기계 b와 품질 요청을 모두 유지한다. 한 판정에서 둘이 발생해도 사람에게 보내는 새 티켓은 최대 하나로 묶고 이유는 둘 다 저장한다. 품질 요청을 P23으로 지연시키지 않는다.

최소 출력은 임계 초과 기록 수, 기계 알림 시작 수, 품질 요청 수, 통합 티켓 시작 수, 반복 억제 수, 활성 구간 합집합 시간, 사건 내 신규 탐지·기존 알림·늦은 탐지·미탐, 실제 초 지연과 추가 판정 횟수다. 품질 요청은 해당 판정의 단일 티켓으로 세며 확인 처리 시간을 만들지 않는다. 시작의 정상 여부는 그 판정 블록의 라벨이다. SKAB의 정상 점유 대조는 현재 블록이 확정 정상인 `[현재 판정,다음 판정 또는 30초 종료)`에서 활성 구간과 겹친 길이이고, 모호 블록은 정상일 수 있는 상한에도 포함한다. 이는 저장 판정 구간 대리값이며 물리적인 연속 정상 노출시간이 아니다. 서로 다른 정책의 알림 묶음 차이를 모델의 기록 FPR 개선이라고 부르지 않는다.

### 개발 선택과 현장 적용을 구분

P23을 개발 대표 정책으로 선택하려면 같은 고정 모델의 I0 대비 다음을 **모두** 만족해야 한다.

1. P0/P1 정상 합계의 통합 티켓 시작이 1건 이상 감소하고, 각 분할과 각 SKAB dev 그룹에서 정상 시작 수·활성 점유시간이 증가하지 않는다. SKAB 정상 여부가 모호한 블록에서는 정상 요청 수의 상한도 증가하지 않아야 한다.
2. D1/D2/D3 및 L1/L2의 단발 변화 재생과 T1, SKAB dev 확정 사건에서 I0가 사건 내 새로 탐지한 건을 하나도 잃지 않는다. 단발 스트레스는 해당 부모만 바꾼 전체 평가 스트림을 각각 다시 재생해 측정하며 서로 다른 부모 주입을 한 스트림에 이어붙이지 않는다. 선택 대표 강도·모든 대상·seed를 사용하고 지원 실패도 별도로 보존한다. 프레스 스트레스의 판정 기한은 마지막 변화 기록의 판정 가능 시각이다. 이는 완성 기록 시험의 관측 기한이며 물리 고장의 실제 종료 시각으로 해석하지 않는다.
3. 둘 다 사건 내 탐지한 모든 사건에서 추가 대기는 유효 판정 1회 이하다. 실제 초 지연은 별도로 모두 공개한다. 사건이 끝난 뒤의 판정으로 이 조건을 통과시키지 않는다.
4. 각 프레스 개발 분할에서 비교 가능한 변화가 있고 SKAB dev에 비교 가능한 확정 사건이 적어도 하나 있어야 한다. 부족·계산 실패·동률은 I0 유지다. 유리한 유형·seed만 골라 통과시키지 않는다.

추가 1회는 이 연구의 사전 개발 허용값이며 현장 안전 한계가 아니다. 현장 응답 시간과 미탐 비용을 모르는 상태에서 초 단위 SLA나 비용 최적성을 만들지 않는다. 연구용으로 P23이 통과해도 실제 설비 적용은 별도 확인 대상이다. P23이 실패하면 I0를 고정하고 3-of-5 등 다른 정책을 이어서 탐색하지 않는다.

프레스에서 선택한 정책을 SKAB에 자동 복제하지 않는다. 프레스 선택에는 조건 1~4를 모두 적용하며, SKAB의 G와 C 두 구조 모두에서 조건 1의 그룹별 정상 부담과 조건 2~3의 사건 제약을 통과해야 한다. K1이 추가됐으면 K1도 포함한다. 프레스 모델에 kNN이 선택돼도 이 외부 검사는 시간 정책의 보조 반례 시험이며 외부 kNN 검증으로 부르지 않는다.

SKAB 각 구조의 보조 정책 선택은 그 구조의 dev만 사용한다. 5개 dev 그룹 전체의 정상 통합 티켓 시작이 1건 이상 줄고 그룹별 정상 시작·점유·모호 정상 요청 상한이 증가하지 않으며, 확정 사건을 하나도 잃지 않고 추가 1판정 제한을 만족해야 한다. 비교 가능한 사건이 없거나 동률이면 I0다. 외부 구조의 기본 비교표는 항상 I0로 맞추고 정책 효과는 별도 표에 표시한다.

## 아직 만들지 않은 평가 변화의 정의

개발 D1/D2/D3 및 L1/L2는 기존 design_v1의 생성기와 실제 실현 강도를 유지한다. 제로 강도는 원배열을 복사해 바이트 동일성을 유지한다. 비영점 생성 실패는 전체 원부모 분모에서 탐지 0, 별도로 지원 부모만의 결과와 지원률을 낸다. “유효 변화만 집계”라는 표현으로 어려운 부모를 주 지표에서 빼지 않는다. 원본에서 이미 경보였던 부모의 POD와 새로 경보가 된 비율도 함께 낸다.

### T1 지속 변화

P0/P1 평가 스트림을 각각 시간순으로 놓고 20·60기록 길이별로 앞에서부터 비중첩 구간을 만든다. 마지막 부족 구간은 미지원으로 센다. 구간 내부 판정 간격이 30초를 초과하면 그 구간은 재조합하지 않고 미지원이다. 각 구간을 독립 시나리오로 원래 전체 스트림에 한 번씩 주입하며 앞부분은 원본 그대로 재생한다.

진동 두 축을 각각 별도 대상으로 한다. j=0..L-1에서 해당 기록의 AC 파형을 `1+a*j/(L-1)`배 하고 원래 DC를 돌려놓는다. a=0.25·0.5, 제로 대조 a=0이다. 기존 “상대 크기 ramp”의 의미는 이 **곱셈형 AC 증가**로 고정한다. 종료 다음 기록은 원본이다. 실제 감소의 완만한 버전까지 검증했다고 주장하지 않는다. 결정적 변환이라 seed 복제로 표본 수를 늘리지 않는다.

변화 시작은 j=1 기록의 첫 표본이고 판정 기한은 마지막 주입 기록의 `decision_available_time`이다. 원파형의 마지막 변화 시각도 별도로 저장하며 이 판정 기한을 실제 고장 종료 시각이라고 부르지 않는다. 원본 상태가 이미 active이면 기존 알림 표시에 남긴다. 정상 대조와 paired 판정 차이, 시작·기한·실제 배율, 탐지·지연·미탐을 보존한다.

### H1 다른 협대역 출현

P2 fit 정상의 길이 20 이상·유한 비상수 진동 기록에서 AC 신호를 `rfft(...,n=512)`로 계산한다. 0.01~0.49 주기/표본 범위의 power를 기록마다 합 1로 정규화한 뒤 기록 동일 비중 평균을 구한다. 채널별 최댓값 주파수 하나를 fit의 대표 톤으로 둔다. 동률은 낮은 주파수를 택한다. 양쪽 채널의 대표 톤에서 ±0.02 이내인 0.10·0.25·0.40 후보를 제외한다. 남은 주파수를 모두 별도 셀로 평가하고 유리한 한 주파수만 고르지 않는다. fit에 유효 톤을 추정할 기록이 없거나 후보가 모두 제외되면 H1 미지원이다.

P2 평가 부모의 진동 한 축에 `sin(2*pi*f*t+phase)`를 더한다. phase는 보류 seed 101·211·307로 `[0,2*pi)`의 균등분포에서 한 번 뽑으며 t는 표본 번호다. PCG64 키는 `["heldout","P2",parent_key,"H1",target,frequency,seed]`이고 frequency는 "0.10"·"0.25"·"0.40"의 문자열이다. compact ensure_ascii JSON→SHA-256 앞 8바이트 little endian 변환은 crop과 같다. 강도는 키에서 뺀다. 추가 파형을 demean 후 RMS=1로 만들고 기존 fit-only 생성기의 해당 부모 참조 RMS×강도 0.1·0.25·0.5·1을 곱한다. 20표본 미만 또는 유효 RMS=0은 미지원이다. 실제 원본·주입 후 RMS 비율이 설계 강도와 같다고 가정하지 않는다. fit 참조와 위상·주파수·실현 에너지를 저장한다.

### H2 위상 변화와 관측 불변성

P2 평가 부모의 진동 한 축씩 ±pi/6·±pi/3을 적용한다. n>=20에서 AC 파형의 rfft를 구하고 DC는 그대로 둔다. 양의 주파수 계수에 `exp(i*delta)`를 곱하되 n이 짝수면 마지막 Nyquist 계수는 변경하지 않는다. `irfft(...,n=n)` 후 원래 DC를 더한다. n이 홀수면 마지막 계수도 일반 양의 주파수이므로 회전한다. 제로 위상은 재변환하지 않고 원배열을 반환한다. [NumPy 1.26의 실수 FFT 규약](https://numpy.org/doc/1.26/reference/generated/numpy.fft.rfft.html)

회전 가능한 주파수 에너지가 전체 AC 에너지의 1e-12 이하이거나 AC 에너지가 0이면 미지원이다. 실수성·길이·DC·스펙트럼 절댓값·AC RMS 보존을 상대 1e-10과 절대 `1e-12*max(원 RMS,fit 로그 바닥)`으로 검사한다. peak는 보존된다고 요구하지 않는다. 변화량이 수치 허용오차 이하면 생성 실패다. 위상은 결정적이므로 3seed를 복사해 독립 시험으로 세지 않는다.

**RMS와 전류만 쓰는 B1/C1/K1은 이 H2 변화에 원리상 새 정보를 얻지 못한다.** 점수 불변성과 기존 경보를 구분해 음성 대조로 해석한다. 이는 실행 전 알 수 있는 관측 한계이고 낮은 H2 POD를 구현 오류로 만들거나, 이를 고치려고 보류 결과를 본 뒤 관계 특징을 추가하지 않는다. peak를 쓰는 kNN은 반응할 수 있지만 이를 위상 관계를 학습한 증거로 단정하지 않는다. H2는 현실의 고장 라벨이 아니라 표현의 반응 범위 감사다.

RMS 모델의 H2 점수가 수치 허용오차 안에서만 달라졌는데 문턱 동점이 깨져 판정이 바뀌면 `numerical_boundary`로 분리한다. 원예측은 보존하지만 이를 새 위상 변화 탐지 이익으로 세지 않는다. 원래 켜진 경보도 새 탐지와 분리한다. 선택 기준에는 H2 결과가 들어가지 않는다.

## 확률 출력과 선정의 연결

확률 진단은 원래 정상 0~40 적합, 40~50 헤드, 50~60 정상 문턱, 60 이후 평가와 이상 0..13/14..20 분할, q 가중 logistic 목적함수를 유지한다. 이 수치는 한 이상 에피소드 안에서의 라벨 구분 진단이다. 실제 고장 확률이나 독립 확률 검증으로 바꾸지 않는다.

K1의 헤드 입력은 **fit만으로 정의한** `sC(x) if g(x) else sB(x)`다. 50~60분 cal로 만든 p나 cal 부족에 따라 달라지는 route를 40~50분 헤드 학습 입력으로 쓰지 않는다. 다른 후보는 자신의 fit-only raw score다. K1의 raw score 순서와 route별 최종 순위가 같다는 보장은 없으므로 점검 우선순위는 선언한 라벨 확률, 알림은 p_decision으로 각각 구분한다.

헤드는 q마다 원식으로 한 번 적합한다. float64에서 시작값 a=0, b=log(q/(1-q)), a>=0 제약의 L-BFGS-B, analytic gradient, maxiter=10000, ftol=1e-12, gtol=1e-8로 고정한다. BCE는 logit eta에서 `logaddexp(0,eta)-y*eta`로 계산하며 학습 확률을 임의 clipping하지 않는다. 최종 projected gradient 무한대 노름 1e-6 이하·유한 목적함수·제약 충족을 검사한다. 실패하면 최적화 오류로 남기고 그 출력을 성공 확률로 사용하지 않는다. 점수 상수 또는 head 한 클래스 부재는 `uninformative`/`unsupported`로 구분하며 상수 q 참조를 남긴다. L2·q·점수 변환을 평가 Brier가 좋아지도록 재조정하지 않는다.

헤드 적합에서 유한 raw score가 없는 기록은 ID·사유를 남기고 제외하며 남은 각 클래스 수로 q 가중치를 다시 정의한다. 평가에서 확률을 만들지 못한 기록은 null로 남기고 전체 분모·클래스별 지원률을 공개한다. 지원 부분의 손실은 같은 부분의 상수 q와 비교하되 전체 평가 성능으로 바꾸지 않는다. 평가 지원률이 100%가 아니면 전체 확률 이익은 `not_established`다. 누락 확률을 정상 0으로 채우지 않는다.

실제 평가 혼합과 q 가중 혼합의 Brier·log loss, 확률 분포, 고유 예측 수를 모두 출력한다. q=0.1 가중 평가에서 지원률 100%이고 상수 q 대비 두 손실이 모두 낮을 때만 “선언한 혼합에서 상수보다 유용한 라벨 확률”이라고 한다. 하나라도 동률·악화면 이익 미확인이다. 임의로 확률을 벌려 0.55 집중을 없애지 않는다. 실패해도 정의된 헤드 출력과 참조를 보존하고 확률 성능 실패를 명시한다.

최종 후보가 있으면 그 후보와 B1의 헤드를 진단한다. 없으면 B1과 C1d1 두 참조를 진단하되 그 결과로 탈락 모델을 재선택하지 않는다. 모델 선택 1회 → 확률 진단 순서다. 확률 진단의 문턱은 별도의 50~60분 참조이며 주 탐지 모델의 P2 40~60분 cal과 결과를 섞지 않는다.

## Beihang 보조 실행의 경계

정상 1번의 각 시간·값 쌍을 따로 검사하고 진동 3축·속도만 사용한다. 한 쌍의 시각과 값이 둘 다 빈 칸인 행은 서로 다른 채널 길이를 맞춘 저장 패딩이므로 그 쌍에서만 제외하고 수를 남긴다. 한쪽만 비었거나 유효 쌍 안의 값이 비유한이면 입력 오류다. 전 행 `dropna()`를 하지 않는다. 모든 축이 존재하는 공통 시간 범위는 각 축 첫 시각의 최댓값 t0부터 마지막 시각의 최솟값까지다. `[t0+k,t0+k+1)`의 1초 창으로 묶는다. 시간 역행은 오류, 1.5배 fit 중앙 간격을 넘는 내부 공백은 해당 창 미지원이다. 정상 1번 공통 경과시간의 앞 60%, 다음 20%, 마지막 20%를 쓰며, 각 경계 b에서 `k=floor(b-t0)`인 창 하나를 비운다. 경계가 정수 초이면 경계에서 시작하는 창을 제외한다. 각 역할 안에 완전히 들어간 창만 사용한다. 채널별 중앙 간격과 로그 바닥·척도는 앞 60%에서만 구한다.

모든 진동 축에 2개 이상, 속도에 2개 이상 유효 표본이 있고 창을 완전히 관측한 경우 진동 AC RMS 3개, 속도 크기 중앙값, 속도 MAD의 log 특징을 만든다. 글로벌 G는 진동 3축·속도 크기의 양측 이탈과 속도 MAD 증가의 최대다. 조건부 C는 속도 크기 양수·fit 1~99백분위·최소 30부모의 같은 1차 ridge/양측 잔차 규칙을 사용한다. 전류 사인·프레스 길이별 척도는 쓰지 않는다. 20% 중간 구간은 구조 오류 검사이며 모델·문턱 탐색용으로 쓰지 않는다.

정상 2번과 마모 9파일을 열기 전에 G/C와 전체 전처리·보정 상태를 동결한다. 파일별 공통 시작으로 같은 1초 창을 만들고 전처리 통계는 정상 1번 fit에서 고정한 값을 사용한다. 정상 2번은 정상 요청, 마모 파일은 상태 라벨 탐지와 관측 속도 구간별 값을 제시한다. 속도 구간은 fit 속도 크기 0/25/50/75/100백분위, 동률 경계는 합치고 범위 밖은 별도다. 파일이 여러 조건을 포함해도 자연 고장 시작을 만들지 않는다. 대응·표본·시간축이 미지원이면 그 부분을 실패로 남기고 압력 채널로 바꾸지 않는다.

이 보조 결과는 프레스 후보 재선택에 쓰지 않는다. 수행하지 못하면 Beihang 검증을 미완료로 표시하며 SKAB 결과로 대신 완료 처리하지 않는다.

## 동결 파일과 완료 판정

개발 명령은 허용된 fit/dev/cal만 읽고 성능 시험은 별도 명령으로 실행한다. 구조 감사의 과거 test 접근 이력은 보존한다. 아직 열지 않은 모델 test 성능의 차단을 입력 경로 허용 목록과 접근 로그로 확인한다. 이미 본 P2는 새 맹검으로 바꾸지 않는다.

시험 명령은 다음 내용의 동결 manifest가 없거나 해시가 다르면 실행하지 않는다. 입력 원본·그룹 예약·충돌 마스크, 현재 명세와 원명세, 실행 코드·환경, 특징·적합 상태·순위 참조, 선택된 후보 ID 또는 null, 비교 기준, 증강 부모/seed/비율, α·정책, 평가 라벨/사건/분모, H1/H2 생성기와 seed, 시험할 모델 목록, 계획된 주장과 판단 기준이다. 목록은 프레스 B1·C1d1·선택된 후보(있을 때, 중복 제거), SKAB G·C·허용된 K1이다. 결과를 본 뒤 목록을 줄이지 않는다.

H1/H2와 SKAB test는 같은 동결판으로 평가한다. H1이 실패해도 SKAB 명세를 바꾸지 않는다. 소스 오류 수정은 버그 ID·영향 범위·결과 열람 시각을 남기고 동일 비교 전체를 새 버전으로 재계산한다. 결과를 본 뒤 알고리즘을 바꾸면 해당 시험은 개발 자료로 전환되며 새 독립 검증이라고 재사용하지 않는다.

| 산출물 | 반드시 있어야 할 정보 |
|---|---|
| input_manifest / record_map | 원파일 해시, source namespace, 원행→부모→역할→판정 시각, 제외·품질 사유 |
| fitted_state | 모든 로그 바닥·척도·회귀·kNN 부모/자식 참조·순위 배열·특징 순서·환경. 요약 JSON만으로 체크포인트를 대신하지 않음 |
| prediction | 역할·모델·부모·시각·score와 score 정의·p와 참조/분모·α 지원·기계 판정·품질·유보·확률 대상/q |
| request_log / event_table | 두 정책 상태 전이, 통합 티켓, 시간 점유, 기존/신규/늦은/미탐, 라벨 불확실성 |
| selection_record | 모든 후보의 통과·실패·판단 불가, 원래 기준, 최종 정렬, 선택 null 가능 |
| result_tables | TP/FP/FN 원분모, 그룹별/합산, 합성 원부모와 지원률, 증강 seed별·통합값, 확률 상수 대조 |
| source_use_manifest | 사용 원파일과 고정판, 질문·역할·채널·변환·고지, 공개 Git과 제출 자료 범위 구분 |
| run_manifest | 명령·코드·설정·입력·환경·seed·접근 목록·실행 비용·완료/실패 상태 |

한 기록의 결과를 원행에 대응시킬 때 판정 가능 시각을 반드시 남긴다. 앞 행으로 복사한 값은 사후 대응이고 인과적 행 예측이 아니다. 새로운 미지 CSV는 같은 입력 계약으로 처리하며 정답 라벨·파일명으로 분기를 고르지 않는다. 공식 시험 형식이 추가로 주어지면 입력 어댑터만 버전 관리하고 동결 모델을 임의로 재선택하지 않는다.

새 환경 1회 재실행에서 같은 부모/분모/선택/판정이 일치해야 한다. 같은 고정 환경의 결정적 집계는 정확 비교하고, 다른 허용 BLAS 등의 부동소수점 차이는 score 상대 1e-10·절대 1e-12 이내라도 판정이 달라지면 통과가 아니다. 저장 체크포인트 재로딩과 재적합 결과도 대조한다. 캐시는 입력·코드·현재 명세·부모 계보·환경·seed 해시가 모두 맞을 때만 허용한다.

완료 상태는 `design_closed`, `implementation_complete`, `candidate_admitted`, `external_evaluated`, `field_validated`를 따로 둔다. 계산 테스트가 통과해도 나머지를 자동 true로 만들지 않는다. 이번 작업에서 완료할 수 있는 것은 실행 전 설계와 문서 검수다. 실제 성능, 생성 성공률, 외부 지원 표본수, 실행 비용, 현장 비용·독립 고장은 아직 측정해야 한다. 대회 보고서·발표·제출은 기존 별도 착수 지시를 유지한다.
