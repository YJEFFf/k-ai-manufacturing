# 데이터 부족의 보완과 증강 실험

현재 부족한 것은 단순한 행 수보다 **서로 다른 정상 조건, 독립 고장 에피소드, 실제 고장 시작과 운전 이력**이다. 증강은 학습의 민감도와 강건성을 시험하는 수단이며 독립 현장 고장을 만드는 방법이 아니다. 확보한 외부 자료는 실험 회차·개체·변화 형태를 추가하지만 프레스의 새 날짜나 설비를 대신하지 않는다.

## 부족한 증거와 보완 수단

| 부족 | 당장 보완할 방법 | 해결되지 않는 것 |
|---|---|---|
| 정상 변동의 학습 범위 | 조건부 기준, 정상 crop, 조건·길이별 다변량 잔차 재표본화 | 본 적 없는 실제 생산 상태·계절·설비 |
| 약한 변화에 대한 비교 | 강도별 합성 주입, 미사용 계열, 감소·복합 스트레스 | 실제 고장 원인과 합성 형태의 일대일 대응 |
| 새 실험 회차 | 중복 수집 그룹을 분리한 SKAB | 새 프레스 현장·새 장치 일반화 |
| 조건과 마모의 구분 | Beihang의 정상 속도 변화·마모 상태 | 자연 고장 선행시간·압력 원인 해석 |
| 개체 이동 | ESPset의 11개 펌프 ID 분할 | 시간 기반 조기탐지·전류 조건부 모델의 직접 검증 |
| 실제 확률·작업자 부담 | 확률 대상을 명시하고 향후 확인 표본·그림자 운전 설계 | 실제 고장률·비용·독립 임상식 보정 근거 |

현재 실행 대상은 A0/A1/A2다. 자식 수·부모 할당·crop 위치·난수·실패·seed 채택·T1/H1/H2의 미기재 세부는 [08 확정 명세](08_execution_contracts.md)를 따른다. 아래 A3/O1은 후속 연구 후보 설명이며 현재 실행하지 않는다.

## 정상 학습 증강의 대조군

첫 학습기는 kNN k=5로 고정한다. 증강의 효과를 비교하면서 알고리즘·특징·기본 스케일·문턱 정책을 함께 바꾸지 않는다. 전처리 스케일은 실제 fit 원본에서만 고정한다. 한 부모의 여러 자식이 이웃 k개를 독점하지 않게 [모델 명세](02_protocol.md)의 서로 다른 부모 이웃 규칙을 적용한다. 이는 부모별 참조 위치 확대의 기하학적 효과까지 같게 만드는 것은 아니다.

| 군 | 학습 입력 | 바뀌는 요소 |
|---|---|---|
| A0 | 실제 정상만 | 기준 |
| A1 | 실제 정상의 동일 반복·가중치 재현 | 저장 수·반복 비중 대조. 같은 규칙이면 A0와 결과가 같아야 함 |
| A2 | 실제 정상 + 같은 기록의 동기 crop | 관측 길이·시작 위치 다양화 |
| A3 | 실제 정상 + 조건 안에서 다변량 잔차 재표본화 | 잔차 변동 다양화 |

증강 목표 수는 실제 fit 부모 수의 0.5·1배를 내림한 정수, seed는 11·29·47이다. 적법한 crop이 가능한 부모 사이에서만 균형 할당하며 짧은 부모도 원본 참조와 평가에는 남긴다. 할당과 실패 처리의 정확한 규칙은 08에 있다. 증강만 수십 배 늘리거나 보정 집합을 증강하지 않는다. kNN은 학습 step이 없으므로 원부모 수·자식 수·이웃 규칙·저장비용을 대조한다.

A2는 길이 20·30·40 중 부모 길이보다 엄격히 짧은 crop을 세 채널에서 동일 위치로 자른다. 동일 길이 전체 복사는 A1 대조에 속한다. 연결 경계가 생기는 원형 roll은 기본에서 제외한다. 짧은 원기록을 늘리는 보간·패딩은 새 관측으로 취급하지 않는다. crop 뒤 특징을 다시 계산하며 원본 특징 벡터를 복사하지 않는다. 실제 정상이라는 라벨은 제공 정상 부모에서 상속하지만, 조건 변화의 일반화를 입증한 표본이라는 뜻은 아니다.

A3는 파형을 무작위 이어붙이는 대신 정상 구조와 잔차를 나눈 뒤 같은 조건·길이에서 재표본화한다. 전류의 0.06 사인 성분, 진동의 조건별 스케일을 적합 원본에서 추정하고 남은 세 채널 잔차 벡터를 함께 다룬다. 연속 잔차 블록 길이는 fit의 자기상관 범위에서 정하되 부모 길이의 절반을 넘기지 않는다. 20표본 미만이거나 호환 부모 20개 미만이면 그 셀은 생성하지 않는다. 접합점의 차분·스펙트럼·상관이 fit 원본 범위를 지나치게 벗어나면 생성 실패로 남긴다. 허용범위는 fit 내 원본 간 분할로 정하고 평가 자료를 보며 고치지 않는다.

위상 이동, gain, offset, 잡음 추가가 항상 정상이라는 가정은 하지 않는다. 신호 순서 뒤집기, 채널 교환, 독립 채널 위상 변경, 임의 time-warp, 정상·이상 raw mixup은 기본 정상 증강에서 제외한다. 알려진 단위 변환은 역변환 전처리의 시험이며 실제 학습 다양성이 아니다.

## 합성 이상 노출과 학습 효용

OE 실험은 O1 GBM 구조를 고정한다. 양성은 실제 고장이 아니라 개발 3계열의 신호 변화다. 강도 0은 정상 대조이며 양성으로 넣지 않는다. 단순 반복만으로 없는 양성 클래스를 만들 수 없으므로, A0 정상 전용 kNN과 O1을 비교한 차이를 순수 증강 효과라고 부르지 않는다.

O1 내부 대조는 두 단계다. 먼저 고정된 합성 양성 집합과 실제 정상만으로 학습한다. 다음에는 같은 양성을 그대로 두고 음성 쪽에 A2 또는 A3만 추가한다. 같은 부모 가중치·클래스 총 가중치·100 boosting iteration을 유지해 **정상 증강의 추가 효과**를 분리한다. 합성 비율 변경은 실제/합성 수와 가중 비중을 모두 기록하고, 반복한 동일 합성본과 새로운 난수 실현을 비교한다.

개발 계열 하나를 빼고 나머지 두 계열로 학습한 세 변형을 통해 생성기에 과적합했는지 본다. 최종 보류 계열은 이 과정에 쓰지 않는다. 실제 이상 라벨을 사용한 지도 모델은 [확률 진단](02_protocol.md)의 별도 트랙이다. 정상 전용, 합성 이상 사용, 실제 라벨 사용을 결과표에서 구분한다.

## 평가용 변화 라이브러리

강도는 fit 정상의 채널·조건별 RMS 또는 잔차 척도에 대한 상대값이다. 새 상태의 정상 진폭을 test에서 추정해 강도를 맞추지 않는다. 물리 마모율·압력 손실·고장 확률이라고 이름을 붙이지 않는다.

| 역할 | 변화 | 비영점 강도와 정의 |
|---|---|---|
| 개발 D1 | 진동 대역 제한 잡음 | 추가 RMS/fit 기준 RMS = 0.1, 0.25, 0.5, 1, 2 |
| 개발 D2 | 감쇠 충격 | peak/fit 잔차 σ = 0.5, 1, 2, 4, 8. 기록당 최소 1개 실제 주입, 위치 균등 |
| 개발 D3 | 전류 잔차 증가 | 추가 RMS/fit 잔차 RMS = 0.25, 0.5, 1, 2 |
| 보류 H1 | 다른 협대역 출현 | 후보 0.10·0.25·0.40 주기/표본 중 fit 강한 톤 ±0.02를 피함. 상대 RMS 0.1, 0.25, 0.5, 1 |
| 보류 H2 | 채널 관계 변화 | 동일 길이의 한 채널 위상 ±π/6·±π/3, 진폭 유지. 짧은 기록의 타당성 미달은 미지원 |
| 손실 L1 | 진동 감소·전류 감소 | 배율 0.75, 0.5, 0.25, 0. 소실은 계측 가능성도 병기 |
| 손실 L2 | 전류 조건화 불가 + 진동 변화 | D1 중간 두 강도 + 전류 평탄 또는 파형 훼손 |
| 품질 Q1 | 누락·평탄·포화·역행·중복·공백 | 관측 부족/계측 요청의 동작 계약. 기계 원인 정답으로 강제하지 않음 |
| 지속 T1 | 크기 변화 ramp | 실제 평가 구간 안의 20·60기록 동안 0→상대 0.25·0.5 |

D1/D2/D3·L1/L2는 이미 동결한 design_v1의 fit-only 생성기를 유지한다. D2에서 확률 1%만 부여해 실제 변화가 없던 짧은 기록을 유효 변화로 표시하지 않는다. 실제 비영 변화 여부·에너지를 저장한다. AC 처리 후 변화가 사라지면 생성 실패이며, 주 지표의 전체 부모 분모에는 탐지 0으로 남긴다. 지원 부모만의 지표는 별도 표다.

H2는 실수 Fourier 쌍의 위상을 회전하되 DC와 짝수 길이 Nyquist는 유지하고 원 길이로 역변환한다. AC RMS·스펙트럼 크기는 보존하지만 peak 보존을 요구하지 않는다. RMS·전류만 보는 모델의 점수 불변성은 예상된 음성 대조다. 실제 고장 탐지 실패 또는 관계 학습 성공으로 자동 해석하지 않는다. 홀수 길이·미지원 에너지·허용오차는 08에 고정했다.

각 개발·보류 계열에는 제로 변화 원본 대조도 둔다. 학습 자식은 fit 부모, 개발 주입은 P0/P1 evaluation 부모에서 만든다. 보류 H1/H2는 동결 후 P2 evaluation 부모에서 생성한다. H1은 seed 101·211·307, 결정적인 H2와 T1은 seed 중복 실행을 표본 수로 세지 않는다. 학습·개발은 seed 11·29·47이며 같은 강도 곡선 안의 기초 난수는 공유한다. 난수키·실패 처리는 08과 design_v1의 각 역할 정의를 따른다. P2 부모 자체는 이미 본 자료이고 보류 결과는 후보 재선택에 쓰지 않는다.

## 누수와 주입 실패를 막는 계약

실제 분할을 먼저 정하고 모든 자식은 부모와 같은 역할을 가진다. 두 부모를 혼합하면 두 부모 모두 fit에 있어야 한다. 생성기·스케일·주파수 선택·전처리도 fit만 사용한다. 정상 문턱 보정에는 실제 정상만 쓴다. 외부 장치 데이터와 프레스 raw를 한 학습 표로 합치지 않는다.

`augmentation_manifest`에는 원데이터 해시, 부모 ID들, 수집 그룹, split, 연산 버전, 강도 설계값, 실제 실현 강도, 시드, 변화 시작 위치, 변한 채널, 학습/개발/보류 목적, 변환 근거를 넣는다. 평균 POD는 원부모 단위로 먼저 계산한다. 동일 부모의 여러 seed를 독립 고장 사건으로 세지 않는다.

주입 검수에는 강도 0의 바이트/값 동등성, 동일 seed 재현, 비변경 채널 동일성, 유효 강도 증가, 채널 동기화, 기록 밖 접합 없음, 무한·NaN 없음, 중복 그룹 분리, test로 생성기 적합 금지를 포함한다. 계측 이득과 실제 진폭 증가처럼 관측이 같은 쌍에는 서로 반대 정답을 강제하지 않는다.

## 채택과 실패

학습 증강은 **증강하지 않은 실제 정상 평가**와 개발 변화·손실에서 A0 및 B1 대비 등록 기준을 검사한다. 현재 A2의 외부 증강 어댑터는 실행하지 않으므로 독립 외부 효용은 미검증으로 남긴다. SKAB의 G/C 구조 대조를 A2의 외부 검증으로 대체하지 않는다. 내부 이익은 같은 프레스 자료에서의 탐색적 증강 효과로만 기록한다.

생성기의 기초 범위·시간 구조·채널 관계·암기·실제 효용·seed 안정성을 함께 검사한다. 파형 그림이나 t-SNE가 비슷하다는 이유로 채택하지 않는다. a50은 격자 내 추정 가능할 때 계열별로 보이고, 큰 강도의 완전 분리만으로 작은 변화 개선을 주장하지 않는다.

GAN·VAE·확산은 이번 실행 범위에서 제외한다. 독립 프레스 양성이 하나여서 같은 에피소드 복제와 생성기 편향을 판별하기 어렵고 현재의 A0/A1/A2 대조부터 필요하다. 나중에 검토하더라도 입력 의미·학습 중복·이용 조건·검증 역할을 새로 사전 등록해야 하며 이번 계획의 자동 후속 단계로 실행하지 않는다.

## 실제 추가 수집을 설계하는 방법

공개 자료로 채워지지 않는 핵심은 같은 프레스의 여러 날짜·설비·운전 조건과 확인된 고장·정비 사건이다. 요청할 항목은 원 취득 주기·다운샘플/필터·센서 감도·단위·게인·시간 생성 방식, 동기 전류·진동, 속도·압력·유온·생산 상태·금형, 점검 결과와 고장/정비 시작·종료 시각이다. 이 계획 작성 중 외부 기관이나 팀원에게 연락하지 않았다.

먼저 무경보 구간도 일정 비율로 표본 점검하는 그림자 운전을 설계한다. 경보 사례만 확인하면 검증 라벨이 선택 편향된다. 정비로 실제 결함을 확인한 독립 에피소드는 날짜·설비·부품·직전 정비로 묶고, 같은 고장의 반복 관측을 새 사건으로 세지 않는다. 안전상 고장을 유발하는 시험을 요구하지 않고 기존 정비 기록과 승인된 시험 자료를 우선한다.

표본량은 목표 비용·오경보·민감도를 정한 뒤 정한다. 아래는 일정률/독립성 가정의 **계획 계산 예시**다. 현재 상관된 기록에 그대로 적용한 보장값이 아니다.

| 목표 예시 | 모두 성공 또는 0건일 때의 95% 단측 조건부 필요량 |
|---|---|
| 정상 판정 FPR 상한 1% | 독립 정상 판정 약 299개, `1−0.05^(1/n)≤0.01` |
| 사건 탐지율 하한 90% | 독립 사건 29개를 모두 탐지, `0.05^(1/n)≥0.9` |
| 시간당 오경보 상한 1/8시간 | 동질 Poisson 가정에서 0건인 약 23.97시간, `−log(0.05)/T≤1/8` |

한 조건에서 24시간을 모았다고 교대·시동·금형·온도 전체를 검증한 것은 아니다. 조건별 반복 날짜를 확보하고 사건 유형별 목표를 나누며 드리프트·군집을 반영해 필요량을 늘린다. 실제 고장 1건을 29개로 증강해 마지막 표의 사건 수를 채울 수 없다. [재계산](evidence/press_audit.json), [NIST의 모형 설명](https://www.itl.nist.gov/div898/handbook/apr/section4/apr451.htm)
