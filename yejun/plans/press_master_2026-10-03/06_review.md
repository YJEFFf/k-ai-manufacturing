# 반론과 남은 한계

이번 계획은 최종 모델의 성능 검수 통과서가 아니다. 프레스 핵심 모델 7설정과 후속 개선안 6개는 구현·학습·평가했으며, 새 후보 12개 모두 전체 채택 기준을 통과하지 못했다. 정상 학습 증강·외부 모델 평가·확률 헤드·운영 정책·제품 전체 구현은 아직 실행하지 않았다. 두 계획의 논리, 원자료와 출처, 완료한 실험, 앞으로의 실행 계약을 구분한다. 현재 세부 계약은 [실행 전 확정 명세](08_execution_contracts.md), 계획 재검수의 발견·처리는 [검토 기록](evidence/plan_review.json)에 있다.

## 다른 검수자가 가장 먼저 확인할 항목

1. 프레스 원본 두 개의 해시와 599/21 기록이 규칙에서 재현되는가. 짧은 이상 8개가 전류 사인 조건화에서 빠져도 전체 평가에 남는가.
2. 기록 완료 판정과 가이드북 창 판정을 같은 성능 순위로 섞지 않았는가. 소급 열이 인과적 예측으로 저장되지 않는가.
3. SKAB 30수집 그룹과 237주석 충돌 관측이 코드의 split·정상 cal·평가 분모에 실제 반영되는가. 이름만 새 JSON으로 바꾸고 원파일 창을 섞지 않았는가.
4. Beihang의 11개 시간축과 3 kHz 출력 압력 차이를 확인했는가. `dropna()`나 행 번호 결합이 다른 채널을 잘못 자르지 않는가.
5. 조건부 점수가 전류 무효·범위 밖에서 진동 판정을 버리지 않는가. 미상 이득과 실제 진폭 변화를 억지로 반대 정답 처리하지 않는가.
6. 단측·OE·표현 모델이 감소·복합 변화 손실을 통과했는가. 채택 기준에 보류 계열이나 외부 test가 들어가지 않았는가.
7. 증강 A0/A1/A2/A3에서 같은 모델·스케일·부모 가중치·이웃 수가 유지되는가. O1의 알고리즘 차이를 순수 증강 이익으로 부르지 않는가.
8. `p_dataset_label`이 실제 라벨을 사용한 별도 트랙이라는 사실과 q가 결과 파일에 남는가. 전체 모델을 정상 전용·현장 확률로 잘못 소개하지 않는가.
9. 블록·씨앗·창을 독립 사건 수로 셌는가. 무경보·완전 탐지에서 신뢰구간의 가정을 명시했는가.
10. 원자료·논문·코드 라이선스를 구분했는가. 다운로드 스크립트만으로 학습 데이터 제출 요구를 충족했다고 하지 않는가.

## 이 권고를 바꾸는 결과

조건부 후보가 전류 무효·감소 손실 기준을 통과하지 못한 결과를 확인했다. C1 우선 개발 가설을 보류하고 B1을 비교 기준으로 남겼으며, 전역 기준도 최종 배포 적격으로 자동 승인하지 않는다. 정상 증강은 무증강 동종 모델과 B1의 등록 기준을 모두 통과해야 한다. 현재 A2의 독립 외부 효용은 미검증이며 SKAB 구조 비교로 대신 입증했다고 쓰지 않는다. 순차 정책은 08의 사건 손실·추가 대기·정상 부담 규칙을 모두 통과할 때만 개발 대표로 선택하고 나머지는 I0다. 외부 성과가 엇갈리면 조건별 결과를 남긴다.

모든 후보가 필수 계산 계약을 통과해도 탐지력이 부족하면 현장 도입 준비 완료로 끝내지 않는다. 다음으로 필요한 자료와 판별 가능한 질문을 제시한다. 통과 후보가 없으면 최종 개선 모델은 null이고 단순 기준은 참조로 유지한다. 단순 기준을 사용하는 데모가 완성됐다는 사실과 최종 모델 개선의 입증은 별도다.

수상 경쟁력은 복잡한 모델 수나 유리한 F1 한 줄로 입증되지 않는다. 핵심 실험에서는 이익과 손실을 확인했지만 전체 개선 조건을 통과한 새 후보는 없었다. 남은 외부·증강·확률·운영 항목도 실제 실행 결과로 판단하며, 모델의 수상 확률이나 예상 점수 상승으로 환산하지 않는다.
