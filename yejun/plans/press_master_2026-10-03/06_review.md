# 반론과 남은 한계

이번 계획은 미래 모델의 성능 검수 통과서가 아니다. 새 모델은 아직 구현·학습하지 않았다. 현재 검수한 것은 두 계획의 논리, 원자료에서 설계를 바꾸는 사실, 출처와 실제 외부 파일, 누수·평가·실행 명세의 일관성이다. 독립 검수자가 재검토할 수 있도록 확정된 사실과 가설을 분리했다.

## 가장 강한 반론에 대한 판단

| 주장 또는 설계 | 필요한 전제 | 반례 또는 경쟁 설명 | 현재 판단과 수정 | 남는 약점 |
|---|---|---|---|---|
| 조건화가 오경보를 줄임 | 전류가 정상 진동 변동을 유용하게 설명 | 전류도 고장에 따라 바뀌어 고장 진동을 정상화 | 시험할 가설. 전역 모델·전류 제거·복합 변화와 비교 | 관측 3채널만으로 인과 부하 식별 불가 |
| 단측이 좋은 정상 대기를 구분 | 감소는 중요 이상이 아님 | 센서 이탈·성능 감소·저에너지 고장 | 양측을 기본 경쟁자로 남기고 손실 셀 통과 요구 | 실제 감소 고장 라벨 부족 |
| AC 평균 제거로 형식 편향 완화 | DC 차이가 내보내기 교란 | 실제 저주파 변화도 제거됨 | 공통 AC를 주 입력, raw·matched 감사 및 감소 시험 | 수집 필터·단위 교란은 남음 |
| 실제 이상 구분이 뛰어남 | 고장과 날짜·수집 경로가 분리됨 | 한 날짜·한 파일을 구분하는 쉬운 문제 | 비맹검 한 에피소드 탐색으로 제한 | 독립 프레스 고장은 새 수집 필요 |
| 합성 민감도가 개선됨 | 합성 형태가 유용한 스트레스 | 생성기와 특징의 공통 설계로 유리한 시험 | 보류 계열·부모 분리·다른 실제 외부 라벨 평가 | 합성은 실제 고장 검증 대체 불가 |
| 외부 파일 분할이면 독립 | 각 파일이 다른 수집 | SKAB 공유 행·주석 충돌 | 실제 발견해 그룹·충돌 마스크로 수정 | 숨은 유사 복제·동일 시험대 의존은 남음 |
| Beihang으로 조건 효과 확인 | 채널 의미·시간 정렬 타당 | 다중 시간축·문헌과 저장 간격 불일치 | 일차 진동·속도만, 압력·유량 보류 | 정상 2회·정비 후 재시험의 독립성 미확인 |
| 외부 개체 결과가 프레스에도 적용 | 센서·고장·운전 분포가 충분히 유사 | ESPset은 스펙트럼·다른 펌프 | 개체 분할 방법의 보조 근거로만 | 프레스 현장 전이 성능 미검증 |
| 순위 p가 1% 오경보 보장 | 고정 점수와 교환가능한 정상 cal/test | 시간 변화·상관·선택 후 같은 자료 재사용 | 명목 순위와 실측 FPR 병기, 무조건 보장 제거 | 현장 데이터와 인수 시험 필요 |
| 확률 헤드가 현장 고장확률 | 라벨·유병률·조건부 분포가 현장과 같음 | 제공 양성 하나, 합성 양성의 형태 사전 | 제공 라벨/합성/현장 시나리오 분리 | 실제 현장 확률은 아직 식별 불가 |
| 지속성이 작업자 부담을 줄임 | 지연 비용·미탐 증가가 수용 가능 | 짧은 사건을 놓치거나 확인이 늦음 | 같은 점수로 요청·지연·미탐을 동시 비교 | 현장 비용·대응 시간 미확인 |
| 재보정으로 정상 드리프트 추적 | 확인된 정상 피드백 확보 | 느린 고장도 기준에 흡수 | 기본 갱신 OFF, 지연 피드백·흡수 시험 | 미점검 자료의 정상성은 자동 확정 불가 |

## 다른 검수자가 가장 먼저 확인할 항목

1. 프레스 원본 두 개의 해시와 599/21 기록이 규칙에서 재현되는가. 짧은 이상 8개가 전류 사인 조건화에서 빠져도 전체 평가에 남는가.
2. 기록 완료 판정과 가이드북 창 판정을 같은 성능 순위로 섞지 않았는가. 소급 열이 인과적 예측으로 저장되지 않는가.
3. SKAB 30수집 그룹과 237주석 충돌 관측이 코드의 split·정상 cal·평가 분모에 실제 반영되는가. 이름만 새 JSON으로 바꾸고 원파일 창을 섞지 않았는가.
4. Beihang의 11개 시간축과 3 kHz 출력 압력 차이를 확인했는가. `dropna()`나 행 번호 결합이 다른 채널을 잘못 자르지 않는가.
5. 조건부 점수가 전류 무효·범위 밖에서 진동 판정을 버리지 않는가. 미상 이득과 실제 진폭 변화를 억지로 반대 정답 처리하지 않는가.
6. 단측·OE·표현 모델이 감소·복합 변화 손실을 통과했는가. 채택 기준에 보류 계열이나 외부 test가 들어가지 않았는가.
7. 증강 A0/A1/A2/A3에서 같은 모델·스케일·부모 가중치·이웃 수가 유지되는가. O1의 알고리즘 차이를 순수 증강 이익으로 부르지 않는가.
8. `p_dataset_label`이 실제 라벨을 사용한 별도 트랙이라는 사실과 q가 결과 파일에 남는가. 전체 모델을 정상 전용·현장 확률로 잘못 소개하지 않는가.
9. 블록·씨앗·창을 독립 사건 수로 셌는가. 무경보·완전 탐지에서 신뢰구간의 가정을 명시했는가.
10. 원자료·논문·코드 라이선스를 구분했는가. 다운로드 스크립트만으로 학습 데이터 제출 요구를 충족했다고 하지 않는가.

## 이 권고를 바꾸는 결과

조건화가 개발 분할에서 일관된 이익을 주지 않거나 전류 무효·감소 변화에서 손실이 크면 전역 기준을 채택한다. 증강이 실제 정상 부담을 키우거나 독립 외부 라벨에서 추가 이익이 없으면 기본 학습에서 뺀다. 순차 경로가 지연·미탐을 키우면 즉시 요청을 유지한다. 외부 성과가 장치별로 엇갈리면 범용성을 주장하지 않고 해당 조건별 실패를 남긴다.

모든 후보가 필수 계약을 통과해도 탐지력이 부족하면 현장 도입 준비 완료로 끝내지 않는다. 다음으로 필요한 자료와 판별 가능한 질문을 제시한다. 반대로 단순 기준이 이기면 그것이 최종 시스템이며, 연구의 기여는 조건·오류·데이터·평가·운영 계약의 검증된 개선에 둔다.

수상 경쟁력은 복잡한 모델 수나 유리한 F1 한 줄로 입증되지 않는다. 이 계획은 대회가 요구하는 모델·확률·오류·활용·재현성에 대해 근거가 이어지게 만들었다. 실제 효과는 동결한 실험을 수행한 뒤 판단해야 한다.
