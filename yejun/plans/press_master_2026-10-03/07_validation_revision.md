## 남길 연구 질문

**관측 전류와 진동의 관계를 사용하되, 정상 상태 변화의 확인 부담과 진동 감소·전류 이상을 놓치는 손실을 함께 줄일 수 있는가.** 조건화는 이 질문을 풀기 위한 후보 중 하나다. 하부 진동에서 확인한 강한 관계와 작은 변화 민감도는 유지할 연구 가치이고, 상부 진동과 후반 정상 상태까지 설명했다는 근거는 없다.

기여의 중심은 세 가지 결과가 연결되는 데 둔다. 실제 정상에서 발생한 요청의 양과 원인, 약한 변화 및 감소·전류 무효에 대한 탐지 범위, 다른 수집 그룹에서 같은 절차를 재적합했을 때의 결과다. 새로운 모델 수, 합성 행 수, 외부 ZIP 용량은 성과 지표로 쓰지 않는다.

## 다음 실행 순서

### 1 SKAB 개발 계약을 먼저 구현한다

현재 확보한 35파일·30수집 그룹과 충돌 관측 237개의 마스크를 그대로 쓴다. fit 14그룹, dev 5그룹, cal 5그룹을 구현 대상으로 하고, test 6그룹의 모델 성능은 동결 전 계산하지 않는다. 이미 수행한 구조·라벨 일치 감사와 성능 미열람을 구분한다. [그룹 예약](evidence/skab_group_reservation.json), [입력 계약](03_data_sources.md)

첫 구현은 **전역 기준과 1차 양측 조건부 기준 두 구조**로 제한한다. 다른 자료에서 구현한 전류 사인 게이트를 복사하지 않고, 제공 진동 RMS 2개의 20표본 블록 중앙값과 Current 중앙값·산포를 쓴다. 조건값은 양수인 Current 크기 중앙값의 로그이고 fit 1~99백분위 안에서만 조건화한다. 평균·스케일·로그 바닥·회귀는 fit에서만 정한다. 진동 RMS를 다시 AC 원시 파형으로 해석하지 않는다.

외부 어댑터 작성 시 Current 산포의 정의는 블록 MAD로 고정하고, 전류 중앙값은 크기 `abs(median(Current))`로 고정한다. 전역 점수는 진동 2축과 전류 크기의 양측 이탈, 전류 산포 증가의 최댓값이다. 조건부 점수는 지원 범위 안의 진동 두 축만 1차 회귀 잔차의 양측 점수로 교체한다. 그 외는 같은 입력·척도·보정·정책을 쓴다. 20표본 완성 블록의 길이가 같으므로 프레스의 여러 길이 구간을 억지로 만들지 않는다. fit 유효 부모가 30개 미만인 조건부 경로는 미지원이다. 이 대응은 **프레스에서 선택된 최종 모델의 전이**가 아니라 두 구조의 외부 대조다.

완료 산출물은 원파일→중복 수집 그룹→블록의 대응, 충돌/부분 블록 수, fit·cal 정상 제외 사유, 두 구조의 dev 요청·사건 반응·지연 표다. 전체 그룹의 점수를 합친 결과와 그룹별 결과를 함께 보며 긴 파일 한 개가 결론을 독점하는지 확인한다. 모호한 라벨은 최선·최악 경계와 커버리지로 남긴다.

### 2 정상 기준과 문턱의 문제를 하나의 가설로 좁힌다

새 검토의 가설은 **조건부 경로에서 달라진 보정 꼬리가 조건 불가·짧은 기록 경로의 문턱까지 움직여 손실을 만드는가**다. 이번 프레스 실험에서 동일한 전역 fallback 점수와 서로 다른 문턱이 손실을 만드는 사례를 이미 확인했다. 다음 구현은 이를 길이×조건 지원×점수 성분별 보정 기여로 계량하고 SKAB처럼 길이가 고정된 자료에서도 발생하는지 대조한다.

정상 기준을 전역으로 바꾸거나 부분적으로 섞는 것만으로 해결됐다고 보지 않는다. 이미 S0~S5를 실행했으므로 같은 구간에서 비슷한 파라미터를 탐색하지 않는다. 추가 대조는 **K1 한 종류로 확정했다.** 조건 불가 시 B1의 pooled 정상 참조와 판정을 유지하고, 지원 게이트 안에서만 C1d1의 해당 정상 cal 순위를 사용한다. 주 α에서 조건 cal 39개 미만이면 B1 경로, P0/P1 어느 쪽이든 미지원이면 K1 채택 판단 불가다. 수식·표본 필요량·확률 헤드 연결은 08에 고정했으며 결과를 보고 문턱을 조절하지 않는다.

정상 cal을 다시 학습 데이터로 쓰거나 두 경로의 α=5%를 각각 적용해 OR한 뒤 전체가 5%라고 주장하는 방법은 채택하지 않는다. 보정법을 바꾸면 전체 결합 점수와 정책으로 정상 부담·손실을 다시 계산한다. 짧은 기록과 조건 불가 경로의 **최종 판정**이 유지되는지 확인하며, 점수 함수만 같은 것으로 충분하다고 보지 않는다.

### 3 정상 학습 증강은 작은 대조부터 진행한다

증강은 관측 길이·정상 변동에 대한 학습 효용 시험이다. kNN k=5에서 실제 정상 A0, 동일 반복 A1, 동기 crop A2만 실행한다. A1은 부모별 이웃 규칙 아래 A0와 같아야 한다. A2는 부모보다 짧은 길이 20·30·40, fit 부모 수의 0.5·1배 내림, seed 11·29·47이다. 생성 가능 부모의 균형 할당·중복·실패와 모든 seed의 채택 기준은 08에 확정했다. 전처리와 정상 cal은 실제 원본으로 고정한다. [증강 계약](04_augmentation.md)

증강 효과는 같은 무증강 kNN과 비교하고 B1 대비도 유지한다. 정상 요청·D1/D2/D3·감소·복합 손실·생성 실패·부모 수·저장 비용을 함께 기록한다. crop이 새 고장 에피소드나 새 운전 조건을 만들었다고 세지 않는다. A3·O1은 이번 실행에서 제외하며 A2 실패를 이유로 자동 확대하지 않는다.

O1 합성 이상 노출과 생성 모델은 최소 경로에서 제외한다. 하나의 실제 이상 에피소드로 합성 고장의 현실성을 검증할 수 없기 때문이다. 현재의 개발 주입은 **평가용 스트레스**이며 정상 학습 증강 효과를 입증한 결과가 아니다.

### 4 확률과 운영 요청을 연결한다

확률 요구는 원명세의 별도 라벨 진단을 구현해 충족한다. 점수 모델 정상 적합 0~40분, 헤드 정상 40~50분과 이상 0~13, 문턱 정상 50~60분, 평가 정상 60분 이후와 이상 14~20의 역할을 유지한다. q=0.1 기준과 0.01·0.05·0.2 민감도에서 상수 q 대비 Brier·log loss·확률 분포를 측정한다. 새로운 헤드가 0.55 집중 문제를 해결했다고 미리 결론 내리지 않는다. 같은 고장 에피소드 내부 분할이라는 제한은 확률 정의에 붙인다.

점검 화면의 주 정보는 확인 우선순위, 관측 근거, 확률 하나의 정확한 대상이다. score와 정상 꼬리 p는 내부 판정 근거로 관리하고, 합성 확률은 추가 실험이 있을 때만 연구용으로 둔다. 네 수치를 동시에 고장 확률처럼 보여주지 않는다.

운영 정책은 같은 후보 점수의 I0 즉시 요청과 P23 2-of-3만 비교한다. 두 정책의 묶음·해제 규칙을 같게 하고, P23의 선택은 정상 새 티켓 1건 이상 감소·분할/외부 그룹 악화 없음·I0가 잡은 사건 손실 없음·추가 대기 1판정 이하를 모두 요구한다. 판단 불가·동률은 I0다. 정확한 상태 기계, 품질 요청, 단발/지속 변화 재생과 외부 보조 정책 선택은 08을 따른다. 현장 비용·초 단위 허용 지연을 검증한 규칙으로 표현하지 않는다. 전체 정책은 외부 test 전에 동결한다.

### 5 후보와 전체 정책을 동결한 뒤 남겨 둔 시험을 연다

선정에는 원래 P0/P1 기준을 유지한다. 정상 요청 3건 이상 감소 또는 두 개발 계열 +10%p, 어느 10분 구간도 추가 요청 1건 초과 금지, 등록 손실 셀의 하락 5%p 이내, 서로 다른 지원 부모 20개 이상, 두 분할·모든 seed의 조건을 바꾸지 않는다. P2 결과에 맞춰 채택 기준을 낮추지 않는다. 외부 dev에서 결정할 어댑터·정책도 test 전에 해시로 고정한다.

시험 공개 순서는 H1/H2 보류 변화와 SKAB test다. 외부 자료의 선택·재적합 역할은 별개 표로 기록한다. H1/H2의 부모인 P2 자체는 이미 본 자료이므로 **새 변화 형태의 보류 시험**이라는 한계가 있다. SKAB의 성공은 다른 수집 그룹에서 방법을 검증한 성과이며 프레스의 독립 고장 검증을 대신하지 않는다. 어느 시험이든 결과를 본 뒤 수정하면 해당 시험은 다음 버전의 개발 자료가 된다.

통과 후보가 없으면 `selected_candidate=null`과 비교 기준 B1을 동결하고 고정 참조의 확률·보류·외부 감사까지 진행한다. 비교 기준을 개선 모델로 채택했다고 쓰지 않는다. 외부에서 좋은 결과가 나와도 프레스 손실 시험 실패를 지우지 않는다. 모든 통과 후보의 동률 순서와 시험 목록은 08에 고정했다.

### 6 재현과 주장 범위를 확정한다

최종적으로 한 명령이 입력 해시→적합→정상 보정→추론→집계→검수를 연결해야 한다. 계산 계약 통과와 모델 채택 통과를 별도 상태로 둔다. 실제 라벨 사용, 합성 사용, 정상만 사용한 모델을 구분하고, 시드·증강 자식·같은 이상 21기록의 반복 평가를 독립 표본으로 합산하지 않는다.

현재 검증용 코드는 [재현 명령](../../analysis/press_master_validation_2026-10-03/README.md)에 있다. 제품 구현으로 옮길 때 같은 입력의 결과가 유지되는지 계약을 승계한다. 대회 보고서·발표자료 작성은 이 검증 완료와 별개이며 현재 저장소의 작성 보류 지시를 유지한다.

## 데이터 부족을 보완할 우선순위

| 부족한 증거 | 사용할 확보 자료와 추가 작업 | 완료를 판단할 근거 | 해결되지 않는 부분 |
|---|---|---|---|
| 다른 수집 회차에서의 정상 요청·변화 탐지 | SKAB 30그룹, 충돌 마스크, 비중첩 20표본 | 동결된 6 test 그룹의 요청·사건·지연·모호 라벨 표 | 같은 프레스의 새 고장 |
| 전류만으로 설명되지 않는 운전 상태 | Beihang 진동 3축·속도, 정상 1번의 적합/보정과 정상 2번·마모 9파일의 보류 | 관측 속도 조건별 정상 요청과 상태 분류, 공통 시간축 검수 | 실제 자연 고장 시작, 프레스 부하의 인과 식별 |
| 관측 길이 변화 | A0/A1/A2 fit 부모 대조 | 실제 정상 부담과 사전 손실 시험, 부모 중복 통제 | 새로운 날짜·설비·정비 사건 |
| 펌프 개체 이동 | ESPset 11개 ID 예약, 현재 모델 실행 범위 밖 | 추후 별도 실행에서 ID·라벨별 검증 필요 | 현재는 개체 일반화 성과 없음 |
| 실제 고장 확률과 현장 효과 | 동일 프레스의 날짜·설비·상태·확인/정비 사건 및 그림자 운전 | 경보·무경보 모두의 확인 표본, 사건 그룹과 비용 기록 | 공개 자료나 증강으로 자동 충족할 수 없음 |

Beihang은 확보한 자료 중 운전 조건 가설을 추가 확인하는 우선 보조 자료다. 진동·속도만 먼저 사용하고 아직 정리되지 않은 압력·유량 축을 끼워 넣지 않는다. ESPset은 개체 이동 보조 검증으로 뒤에 둔다. UCI는 기존 실패의 회귀 확인이며 새로운 독립 외부 검증 수에 다시 더하지 않는다. NLN-EMP 센서 전체 20.8 GB 취득은 현재 필수 작업에서 제외한다. 확보한 데이터와 검증 질문이 이미 있어, 다운로드 용량을 늘리는 것보다 실제 외부 대조를 끝내는 것이 우선이다.

동일 프레스의 추가 자료가 가능해지면 우선 필요한 항목은 원 취득률·필터·센서 단위/게인, 속도·압력·생산 상태·금형, 여러 날짜의 정상, 확인된 결함·정비 시각이다. 단순히 정상 행만 늘리지 않고 정상 상태 전환과 실제 감소형 결함이 구분되는 기록을 확보해야 한다. 요청할 명세를 준비하는 것이며 이번 작업에서 외부 기관에 연락하지 않았다. 독립 사건 수의 조건부 표본량 계산은 [기존 수집 설계](04_augmentation.md)를 유지한다.

## 범위를 줄여도 남길 것

필수 범위는 공통 기준과 조건부 대조, 전체 정상 부담, 감소·전류 무효 손실, 확률 대상과 상수 비교, 보류 변화, SKAB 그룹 검증, 재현이다. A3·O1·생성 모델·추가 신경망·자동 정상 갱신·추가 UI·ESPset 모델 확대·가이드북 LSTM 완전 재현·과거 구조 재적합은 현재 실행 범위 밖이다. Beihang은 08의 고정한 보조 명세로 유지한다.

확인한 성과는 구체적으로 말한다. 하부 진동의 조건 관계와 제한된 작은 변화 이익, 길이별 보정의 실패 원인, 공개 데이터의 수집 중복과 라벨 충돌, 결정 규칙의 재현은 확인했다. 정상 요청과 모든 등록 손실을 동시에 개선한 최종 탐지기, 실제 프레스 독립 고장 확률, 수상 가능성의 수치 상승은 확인하지 못했다. 이 구분이 이후 검수의 출발점이다.
