# 프레스 유압펌프 과제: 연구와 재설계 계획

작성·출처 확인 기준일: 2026-10-01. 대상: 제6회 K-인공지능 제조데이터 분석 경진대회 일반 국민·대학(원)생 부문, 과제 ③.

**이번 산출물은 팀의 의사결정을 위한 계획이다.** 주제는 프레스로 유지한다. 자료 조사와 기존 결과 검토를 바탕으로 접근법을 비교했으며, 새 모델 구현·학습·실험·데이터 대량 수집·대회 보고서·발표자료 작성은 진행하지 않았다. 아래 실행 항목은 사용자가 이후 작업을 지시했을 때의 계획이다.

## 1. 지금 바꿔야 할 것

재설계의 중심 질문은 **“운전 조건이 달라져도 정상은 정상으로 처리하면서, 확인할 가치가 있는 신호 변화를 얼마나 빨리 발견할 수 있는가?”**다. 기존 모델의 점수를 조금 더 높이는 문제만으로 좁히지 않는다.

현재 자료는 정상과 이상을 구분하는 실험에는 쓸 수 있지만, 독립적인 고장 사례·정상 운전 조건·고장 전 이력이 부족하다. 따라서 다음 세 가지를 함께 계획해야 한다.

1. 주어진 프레스 데이터에서 비교 가능한 AI 모델과 명확한 실패조건을 만든다.
2. 출처가 확인된 외부 자료로 정상 조건 변화, 느린 이상, 새 설비 적응을 각각 검증할 방법을 설계한다.
3. 데이터가 입증하는 범위와 현장 적용에 추가로 필요한 근거를 구분한다.

**잠정 우선순위는 조건을 고려한 정상 모델, 빠른 변화와 느린 변화를 나누는 모델, 새 환경의 정상 기준을 이용하는 모델의 비교다.** 셋을 모두 합친 복잡한 모델을 먼저 만들자는 뜻은 아니다. 값싼 비교 실험으로 무엇이 실제 병목을 해결하는지 확인한 뒤 주력 접근 하나를 선택한다. 딥러닝·사전학습 모델도 경쟁 후보로 남기되, 같은 검증 조건에서 판단한다.

사용자의 추가 질문을 반영해 **데이터 증강·합성도 독립적인 비교 축**으로 포함했다. 제한된 정상 변환, 다변량 잔차 재표본화, 가상 이상 주입, T-SMOTE, VAE·TimeGAN·확산 모델을 조사했다. 우선 고정된 모델에서 증강의 실제 효용을 비교하며, 합성 자료를 새 독립 고장 사례나 보정 표본으로 계산하지 않는다.

## 3. 과제 요구를 다시 고정하기

로컬에 보관된 주최 측 과제공개 원문과 [원문 추출본](../../analysis/press_rubric_review/official_task_extract.txt)을 확인했다. 핵심 요구는 상·하부 진동과 전류를 이용한 조기 이상 탐지, 정상 운전변화로 생기는 오경보 감소, 미탐지·오경보 조건 분석이다.

| 공식 평가 항목 | 배점 | 계획에서 확보할 결과 |
|---|---:|---|
| 데이터 이해·진단 | 15 | 관측 단위, 시간 공백, 라벨 의미, 저장 형식 차이, 조건 변화 진단 |
| AI 예측모델 개발 | 40 | 기준선 포함 2개 이상 비교, 이상 확률 출력의 정의, 최종 모델 선택 근거 |
| 영향요인·오류분석 | 15 | 센서 상호작용과 조건별 FP·FN, 실제 예시와 분모 |
| 현장 활용 | 10 | 경보 후 확인할 항목, 판단 유보, 현장 인수 조건 |
| 창의성·차별성 | 10 | 확인 가능한 문제에 대응하는 방법적 기여 |
| 코드·재현성 | 10 | 이후 실행 단계의 분할·설정·출처·환경·산출물 추적 |

이 비중상 데이터 한계 설명만으로 과제를 마칠 수는 없다. **명확하게 정의한 AI 모델 비교가 중심**이어야 한다. 반대로 복잡한 모델이나 화면이 한계를 없애주지도 않는다.

로컬 공식 문서의 제출 마감은 **2026-10-08 23:59 KST**다. 실시간 공지 페이지는 이번 조사에서 정상 열람하지 못했으므로 최신 변경 여부는 미확인이다. 기존 팀 문서에 적힌 외부 데이터 허용 안내도 개정 공지 원문을 확보하기 전에는 확정 규정으로 인용하지 않는다. 외부 자료 조사는 계속할 수 있으며, 실제 대회 실험·배포에 포함할지는 해당 규정과 배포 조건을 확인한 뒤 결정한다.

## 4. 기존 작업에서 확인된 사실과 해석

아래 수치는 이번에 다시 실험한 결과가 아니라 저장소의 기존 분석·비교 결과를 읽은 것이다. 검토 기준 커밋은 `85de5da09ae95f4c8dac5be66f573add790eb05e`다. 작업 시작 시 공용 `README.md`에 기존 미커밋 수정이 있어 최신 원격 변경을 반영하는 `pull --rebase`는 진행되지 않았다.

### 4.1 데이터의 실제 정보량

| 항목 | 기존 분석에서 확인한 내용 | 계획에 주는 제약 |
|---|---|---|
| 크기 | 정상 20,000행, 이상 600행 | 행 수를 독립 사례 수로 해석하지 않는다. |
| 기록 묶음 | 정상 600개, 이상 21개, 묶음 내부 약 10 Hz, 최대 50행 | 창·기록·고장 사건의 단위를 분리한다. |
| 수집 날짜 | 정상 7월 12일, 이상 7월 17일 | 날짜·수집 조건과 고장 라벨이 분리되지 않는다. |
| 이상 이력 | 이상 파일은 한 날짜의 약 3분 범위 | 21개 기록을 21회의 독립 고장으로 세지 않는다. 독립 고장 사건 수는 확인되지 않았다. |
| 시간 공백 | 정상 기록 사이 약 1.5~16.6초 공백 | 공백을 연속 측정으로 이어붙이지 않는다. |
| 라벨 | `Equipment_state`는 파일별 상수 | 정확한 고장 시작 시점이나 고장까지 남은 시간을 알 수 없다. |
| 계측 정보 | 단위·센서 설정·ADC 원주파수·회전수 불명 | 특정 고장 주파수, 전력, 펌프 효율을 계산했다고 주장할 수 없다. |
| 저장 형식 | 정상·이상의 소수 정밀도와 전류 격자 차이 | 수치 형식을 이용한 쉬운 구분을 먼저 통제한다. |
| 운전 정보 | 제품·금형·스트로크·압력·유량·유온 열 없음 | 신호로 나눈 상태는 실제 운전 상태의 대용값이다. |

근거: [프레스 진단·근거 보강 표](../../analysis/press_evidence/README.md), 공용 원본 `데이터셋/프레스_유압펌프_예지보전/Guidebook_소성가공 예지보전 AI 데이터셋.pdf`의 변수·수집 설명. 원본 PDF의 인쇄 쪽과 PDF 페이지 번호는 1쪽 차이가 있으므로 인용 시 둘을 구분한다.

정상 전류의 약 0.6 Hz 패턴과 AR(2)의 유사 주기는 관측된 신호 구조다. 이를 60 Hz 전류의 앨리어싱 또는 유압펌프 고유 물리라고 확정할 수 없다. 형식을 맞추는 전처리도 날짜·계측 설정의 교락까지 해결하지는 않는다.

### 4.2 기존 성능이 말해주는 것

| 분할 | v1 행 F1 | v2 행 F1 | v2 정상 경보 기록 | v2 이상 탐지 기록 | v2 최대 기록 시작 후 탐지시간 |
|---|---:|---:|---:|---:|---:|
| A | 0.910 | 0.962 | 0/120 | 21/21 | 0.5초 |
| B | 0.920 | 0.971 | 3/180 | 21/21 | 0.5초 |

근거: [기존 통합 비교표](../../analysis/press_selection/unified_comparison.md). A와 B는 동일 이상 600행을 공유하고 정상 구성·양성 비율이 달라, A→B의 F1 차이를 개선량으로 해석하지 않는다. 지연은 **기록이 관측되기 시작한 뒤의 시간**이며 고장 발생 전 선행시간이 아니다.

여기서 얻는 판단은 다음과 같다.

- 기록 단위 탐지율은 이미 포화에 가깝다. 기존 기준선도 21/21을 탐지하므로 탐지율만으로 새 기여를 설명하기 어렵다.
- 같은 성분을 쓰는 kNN·Fisher 결합·지도학습 대안이 일부 지표에서 v2와 비슷하거나 더 좋다. 기존 fmax 구조의 우위를 전제하지 않는다.
- A의 정상 평가 구간은 보정 구간보다 조용하다. B의 정상 경보는 신호로 추정한 부하 상태에 집중됐다. 단, 그 상태가 실제 생산부하인지는 확인되지 않았다.
- 기존 UCI 실험에서 조건 간 이동과 느린 변화에 취약한 결과가 있었다. 외부 결과는 프레스 모델의 범용성을 입증한 성공 사례가 아니라, 현재 구조가 놓치는 질문을 찾는 단서다.
- 기존 인공 변화 실험에서 간단한 규칙이 더 잘 잡는 변화도 있었다. 모델을 복잡하게 만드는 것과 검출 범위가 넓어지는 것은 별개다.

추가 근거: [외부 유압계 실험](../../analysis/press_external/README.md), [보강 실험 E1~E3](../../analysis/press_supplement/README.md). 팀 내부 AI 심사자의 점수는 공식 평가나 독립 현장 검증으로 사용하지 않는다.

### 4.3 유지할 자산과 다시 열어둘 결정

| 유지할 자산 | 다시 검토할 결정 |
|---|---|
| 원본 보존, 시간 공백 처리, 인과적 추론의 기본 원칙 | 0.6 Hz 패턴 의존 정도, AR(2)와 사인 성분의 중복 |
| 기존 v1/v2 동결 결과와 오류 기록 | fmax 결합이 최종 선택이어야 하는지 |
| 수치 형식 차이 진단과 matched 비교 | 정밀도를 낮추면서 잃는 약한 이상 정보 |
| 재현성 기록·모델 설정·검수 기반 | 기록 길이별 문턱, 현장 경보 예산과 보정 표본 수 |
| 기존 비교 모델과 현장 판단 초안 | 확률의 의미, 새 날짜·설비로의 이동, 운전 상태 대용값 |

기존 코드를 버릴 이유는 없다. 기존 결과는 비교 기준으로 고정하고, 이후 별도 실험에서 변경의 가치를 검증하는 편이 적합하다.

## 5. 여러 방향을 유지하는 연구 포트폴리오

| 방향 | 핵심 질문 | 우선순위 | 가장 큰 실패 위험 |
|---|---|---|---|
| A. 조건을 고려한 정상 기준 | 같은 정상이라도 부하·상태가 다르면 기준이 달라져야 하는가? | 주력 비교 | 상태를 나누다 고장까지 정상화하거나 보정 표본이 부족해짐 |
| B. 빠른 변화와 느린 변화 | 순간 파형 훼손과 지속적인 수준 변화를 나누면 개선되는가? | 주력 비교 | 공백을 넘어 잘못 누적하거나 정상 전환에 느린 경보가 쌓임 |
| C. 센서 간 관계 | 개별 센서보다 상·하부·전류 사이 관계가 더 안정적인가? | A/B와 경쟁 | 짧은 창의 상관이 불안정하고 날짜 차이를 학습함 |
| D. 현장 정상 기준 적응 | 새 환경의 확인된 정상 소량으로 성능을 회복할 수 있는가? | 외부 검증 우선 | 정상으로 잘못 받은 고장을 기준에 흡수함 |
| E. 지도·약지도 확률 모델 | 제한된 라벨에서 확률을 어떻게 정의하고 비교할 것인가? | 과제 충족 필수 비교 | 같은 이상 파일을 나눠 독립 검증으로 오해함 |
| F. 특징·표현·사전학습 모델 | 새로운 표현이 간단한 특징보다 안정적인가? | 조건부 도전자 | 짧은 기록, 정규화, 미래 정보, 사전학습 중복 |
| G. 판단 유보와 계측 확인 | 이상 신호와 관측 신뢰 부족을 어떻게 함께 전달할 것인가? | 공통 운영 설계 | 경보를 다른 이름으로 바꿔 FP가 줄었다고 주장함 |
| H. 순차 경보 정책 | 점수의 시간 흐름을 어떻게 작업자 알림으로 바꿀 것인가? | 공통 비교 | 반복 검정, 알림 억제로 미탐 숨기기 |
| I. 물리 모델·디지털 트윈 | 압력·유량·회전수까지 있으면 어떤 검증이 가능해지는가? | 장기 확장 | 현재 없는 센서를 가정하고 물리적 진단을 과장함 |
| J. 추가 계측·검토 우선순위 | 어떤 자료를 더 모으면 불확실성을 가장 줄일 수 있는가? | 장기 확장 | 수집 가능성을 확인하지 않고 일정에 포함함 |
| K. 데이터 증강·합성 | 같은 실제 평가 자료에서 증강이 학습 효용을 높이는가? | 독립 비교 축 | 고장 단서를 정상화하거나 합성 패턴만 학습함 |

구체적인 입력, 후보 알고리즘, 반례, 최소 실험, 채택·중단 조건은 [접근법 비교](02_research_options.md)와 [증강 계획](04_augmentation_plan.md)에 있다. 우선순위는 실제 성능 순위가 아니라 현재 근거와 구현 부담을 보고 정한 계획상 판단이다.

## 6. 팀이 선택할 수 있는 세 가지 주력안

### 안 1. 운전 조건 변화에 강한 프레스 이상 탐지

중심은 A 또는 C다. 기존 정상의 높은 신호 수준에서 생기는 오경보를 설명하고, 전역 기준과 조건별 기준을 비교한다. 주어진 과제의 정상 운전변화 요구와 가장 직접적으로 맞닿아 있어 **현재의 1순위 검토안**이다.

필수 증거는 단순 문턱 완화보다 낫다는 비교, 조건별 탐지 손실, 실제 조건이 기록된 외부 자료에서의 검증이다. 외부 검증이 없으면 결론은 “관측 신호 상태에 따른 조건화의 가능성”으로 제한한다.

### 안 2. 빠른 이상과 느린 열화를 함께 살피는 탐지

중심은 B다. 현재 모델의 순간 변화 탐지 장점을 유지하면서, 상태가 비교 가능한 기록의 평균·산포·관계 변화에 별도 통계를 둔다. 기존 UCI 실패와 인공 변화의 사각지대를 정면으로 다룬다.

필수 증거는 지속 변화에서의 탐지 이익과 정상 운전 전환에서의 오경보 부담이다. UCI의 고장 심각도 등급을 자연 열화 시간축으로 바꾸거나, 인공 주입 결과를 실제 고장 조기 예측으로 표현하지 않는다.

### 안 3. 새 환경에서 정상 기준을 다시 세우는 탐지

중심은 D와 G다. 새 환경에 기존 문턱을 그대로 적용할 때와 확인된 정상 자료로 기준을 보정할 때를 비교한다. 설비·조건 이동 문제를 다룰 수 있는 공식 데이터가 핵심이다.

필수 증거는 목표 환경의 고장 라벨을 보지 않고도 적응할 수 있다는 비교다. 프레스의 새 날짜 정상 자료는 현재 없으므로, 이 안을 주력으로 선택해도 프레스 현장 적응이 입증됐다고 할 수 없다.

세 안 모두 E의 확률 출력 정의와 H의 동일 경보 정책 비교를 포함한다. K의 증강은 고정 모델에서 효과를 분리해 검증하고, F의 현대적 모델은 하나를 조건부 도전자로 배치한다. I/J는 주력 실험을 대신하지 않으며 자료 여건이 충족될 때의 확장 계획으로 둔다.

## 7. 외부 데이터를 쓰는 목적

외부 데이터의 행을 프레스 원본에 합쳐 표본 수를 키우는 방식을 기본안으로 삼지 않는다. 센서 의미, 단위, 샘플링, 고장 종류가 다르기 때문이다.

| 검증 질문 | 우선 검토 자료 | 확인된 범위와 주의점 |
|---|---|---|
| 유압 운전 조건 변화와 펌프 이상 | UCI/ZeMA hydraulic systems | 공식 배포·조건 라벨 확인. 기존에 이미 사용했으므로 새 독립 검증이라고 부르지 않는다. |
| 여러 이상 시작 시점에서의 탐지 | SKAB | 원저자 자료·논문 연결 확인. 물 순환 장치이며 배포처 이용 조건 정리가 먼저다. |
| 운전 전환과 날짜 변화 | AI4EU robotic pump | 기관·DOI·설명 PDF 확인. 건강 상태 근거가 없으면 FP·고장 재현율 측정에 쓰지 않는다. |
| 다른 개체의 정상 기준 활용 | PHM 2022 hydraulic rock drill | 학회 공식 과제·설명 확인. 압력 센서 기반이며 프레스와 센서 조건이 다르다. |
| 속도·부하 변화와 실제 주입 고장 | Beihang aviation piston pump | 데이터 DOI와 논문 원문 연결 확인. 비동기 센서·표 설명의 불일치 검토가 필요하다. |
| 센서 표현·조건 이동의 보조 비교 | Paderborn, MIMII DUE, ESPset | 각각 베어링·음향·스펙트럼 자료다. 같은 펌프의 추가 고장 사례로 세지 않는다. |

데이터별 정확한 원출처와 도입 상태는 [출처와 데이터 조사](01_sources_and_data.md)를 따른다. **기관·논문 연결이나 이용 조건을 충분히 확인하지 못한 신규 데이터는 도입 대기 목록에만 둔다.**

## 8. 이후 검증의 핵심 규칙

1. 현재 프레스 자료는 팀이 반복해서 본 탐색 자료다. 새 분할을 만든다고 미열람 시험셋으로 되돌아가지 않는다.
2. 분할은 설비·날짜·실험 회차를 먼저 정하고, 그 안에서 창을 만든다. 같은 원기록의 창이나 증강본을 양쪽에 나누지 않는다.
3. 모델 점수, 문턱, 경보 정책을 나누어 비교한다. 알림 묶기만으로 탐지 모델이 좋아졌다고 하지 않는다.
4. 행 F1·AP 외에 기록별 FP, 조건별 오류, 사건 탐지율, 실제 시작 시점 이후 지연을 구분한다. point adjustment로 전체 이상 구간을 맞힌 것으로 고치지 않는다.
5. 판단 유보와 계측 확인 요청도 작업자 부담에 포함한다. 유보된 이상을 평가에서 지우지 않는다.
6. 정상과 다른 정도인 p값, 제공 라벨에 대한 추정 확률, 현장 고장 확률을 구분한다.
7. 인공 변환은 알고리즘의 반응을 알아보는 시험이다. 변환했다고 새 독립 설비나 실제 고장 사건이 생기지 않는다.
8. “개선 없음”, “표본 부족으로 판단 불가”도 유효한 결론이다. 결과를 보고 성공 기준을 바꾸지 않는다.

## 9. 다음 실행을 결정하는 기준

팀 검토 후 실행한다면, 먼저 **비교 기준·출처·분할을 확정하고 A/B/C를 작게 비교**하는 순서를 권한다. 외부 데이터 한 종류를 주력 질문에 맞춰 선정하고 D 또는 F를 추가한다. 모든 후보를 한꺼번에 구현하는 방식은 피한다.

선택은 다음 순서로 한다.

1. 원출처·라벨·검증 단위를 설명할 수 있는가?
2. 미래 정보 없이 계산되고 기준선과 같은 조건에서 비교되는가?
3. 같은 탐지 수준에서 정상 부담이 줄거나, 같은 정상 부담에서 새로운 이상 형태를 잡는가?
4. 최악 운전 조건의 성능이 무너지지 않는가?
5. 복잡성을 추가한 부분을 제거했을 때 이익이 사라지는가?
6. 계산 비용과 현장 확인 절차가 감당 가능한가?

세부 실험 순서, 작업별 예상 공수, 2인 분담안, 10월 8일 마감에 따른 축소안, 장기 수집안은 [검증·실행 계획](03_validation_and_execution_plan.md)에 있다. 공수는 계획상 추정이며 실제 측정값이 아니다. 사용자의 시간 제한 없는 조사 요청과 대회 제출 기한은 별개로 다룬다.

## 10. 피드백을 받으면 바꿀 부분

이번 계획은 기존 방식의 어느 부분이 팀에 가장 큰 어려움이었는지 확정되지 않은 상태에서 넓게 구성했다. 다음 정보가 들어오면 후보의 우선순위와 일정을 조정할 수 있다.

- 막혔던 지점이 성능·논리·구현 복잡도·차별성·현장성 중 어디에 가까운지.
- 팀원이 맡을 수 있는 작업과 실제 사용 가능한 시간·장비.
- 데이터 제공사나 실제 프레스 현장에 접근할 가능성이 있는지.
- 대회 기간 안의 완성도와 이후 연구 확장 중 어느 쪽에 더 무게를 둘지.

이 정보가 없어도 조사와 계획은 성립한다. **계획 문서를 검토한 뒤 별도의 실행 지시가 있기 전까지 구현·실험·보고서 작업으로 넘어가지 않는다.**
