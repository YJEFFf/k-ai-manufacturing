# 03. 실행 계획 — 세로 절편 R1 → R2 → R3 (+ 선택 R4)

[근거 표기] `[C 문서§]` Claude v2, `[X 문서§]` 코덱스, `[新]` 통합하며 새로 정함. 모델과 프로토콜 정의는 `02_merged_plan.md`를 따른다.

## 0. 운영 원칙

1. **세로 절편으로 짓는다** [C05 §0].
   - 각 절편은 `run_all --quick`이 통과하는 상태로 커밋한다.
   - 두 도구가 교대로 일해도 저장소는 언제나 한 명령으로 돈다.
2. **사전 등록 → 구현 → 선택 → 동결** [C05 §0].
   - `config/protocol.yaml`을 정의의 단일 출처로 둔다.
   - 확정 해시를 모든 산출물에 남긴다.
3. **결과를 보고 성공 기준을 바꾸지 않는다** [X README §8].
   - "개선 없음", "판단 불가", "위반(공개)"도 정식 결론이다.
   - 결과를 본 뒤 바꾼 것은 변경 이유와 전·후 결과를 함께 남긴다.
4. **새 폴더에서 시작한다.** 이름은 예준이 정하고, 제안은 `yejun/press_v3/`이다.
   - 기존 `press_guard`는 고치지 않는다.
   - 기존 패키지는 선택 참고 행으로만 실행한다(R2).
5. **샘플 단위와 마지막 행 실시각을 쓴다** [C05 §0]. S1k 해석에만 기대는 것은 조건부로 표시한다.
6. **실행 시간 예산** [C05 §0].
   - `--quick`은 CPU 10분 이내, 전체는 30분 이내로 잡는다.
   - 가이드북 LSTM-AE(B0)와 MiniRocket은 캐시를 두고 별도 명령으로 돌린다.
7. **도전자는 시간 상자로 묶는다** [新]. 각 0.3–0.4 도구-일을 넘기면 멈추고 그때까지의 결과를 "판단 불가"로 기록한다.

## 1. 코드 구조 (제안)

[C05 §1]에서 바뀐 곳만 적는다.

```
yejun/press_v3/
  config/protocol.yaml        # + 합동 보정, 기준선 갱신 상한, 노출 정의, 길이 구간, 출력 네 층 이름, 결론 범주, 도전자 카드
  config/injection_grid.yaml  # 계열·격자(해시 기록)
  src/press_v3/
    data.py         # + 완전 중복 1행 제거, 장시간 대기 태그
    signal.py       # + 길이 구간 표준화
    inject.py       # 주입(슬립 일관) + augment_manifest 기록
    augment.py      # [新] U0–U4 학습 증강 격자, 같은 step 대조
    models.py       # 한 줄 규칙, IF, MSPC, PHI-Prob(A·D), 지도 대조
    challengers.py  # [新] C-REL, C-SLOW, C-REP(sktime MiniRocket, 선택 의존성)
    calibrate.py    # 합동 교차 conformal, 상한 있는 기준선 갱신, 확률 헤드(q 민감도), PPV 시나리오
    alarm.py        # 경보 단계·지속성·빠른 경로·병기 태그·이유 코드, 정책 전체 집계
    evaluate.py     # 분할 3종, 지표(노출 정의·길이 구간·작업자 부담), POD GLM, 선택 규칙, 교란 시험, 고정 정책 표
    legacy_ref.py   # [新, 선택] press_guard 복사본의 GuardModel.fit(split="custom")·StreamDetector로 참고 행을 만든다
    run_all.py      # --quick / --full / --with-b0 / --with-rep
  external/uci_r4.py  # [新, 선택 R4]
  outputs/  # predictions_rows.csv(전 20,600행, Git 제외), predictions_bursts.csv, augment_manifest.json, metrics/, tables/, figures/, run_manifest.json
```

- 의존성은 CPU만 쓴다. numpy, pandas, scipy, scikit-learn, statsmodels, matplotlib, PyYAML이다.
- 선택 의존성은 따로 둔다. `requirements-b0.txt`(TensorFlow)와 `requirements-rep.txt`(sktime, numba)다.
- 행 단위 예측 파일은 Git에 올리지 않는다(`yejun/.gitignore`).

## 3. Tier 2 (Tier 1 동결 뒤, 이 순서로)

[C05 §3]을 따르되 순서를 조정한다.

1. 베이즈 누적(2상태 전진 재귀, 경보 사건 PPV)
2. 계열을 맞바꾼 판, FV-RING 포함·제외 판
3. 느린 지표 S-slip·S-duty, FC-CIRC 회로 계열, N-COLD
4. 작은 1D-CNN 오토인코더 + 순서 파괴 탐침
5. 가이드북 LSTM-AE 버스트 단위 개선판
6. Venn–Abers 구간, 사람 참여 재보정 시뮬레이션
7. (조건부) U5 생성 모델 하나 — U2·U3가 이익을 보였을 때만

## 4. 컷 목록 (시간이 모자라면 앞에서부터 자른다)

1. Tier 2·3 전부(생성 모델 U5 포함)
2. R4 외부 적용성
3. U2·U3 증강 변형
4. 도전자 C-REP → C-REL 순서로(C-SLOW는 점진 고장과 직결되므로 마지막에 자른다)
5. 기존 v2 참고 행
6. 보류 계열 축소: FV-COUP만 자른다. **기계 채널 보류 계열은 최소 FV-TONE 하나를 남긴다** [新]
   - v2 컷 목록은 보류를 FI-FRIC 하나로 줄였다. 그런데 FI-FRIC은 전기 채널이라, 그렇게 자르면 기계 채널의 Q2 시험이 사라진다.
7. N-EXT·N-VOLT
8. MSPC를 주 비교표에서 빼고 IF만 남김
9. 부록 교란 시험은 EDA 스크립트 재실행 출력으로 대체
10. 두 OS 일치 검사 대신 macOS 깨끗한 가상환경 1회

**자르면 안 되는 것**
- 부하 미상·정지 규칙
- 단측 판정과 상한 있는 기준선 갱신
- 합동 conformal
- SP-block FA/h(노출 정의 포함)
- 공식 분할 F1 표
- 출력 네 층(`p_anomaly`의 q 명시)
- 개발 계열과 기계 보류 계열 하나 이상의 a50
- 고정 정책 표
- 경보 정의표·점검 카드
- 한 명령 실행
