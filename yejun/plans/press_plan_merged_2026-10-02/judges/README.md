# 블라인드 심사 설정 (2026-10-02)

두 계획 중 하나(Claude v2)의 저자가 비교를 맡았으므로, 자기 계획을 후하게 볼 위험을 줄이려고 독립 심사자 2명을 따로 돌렸다.

## 사본과 블라인드

- `make_blind.py`로 두 계획의 본문 사본을 임시 폴더에 만들었다(저장소에는 사본을 두지 않음).
- Claude v2 사본에서 지운 것:
  - 제목의 "Claude"
  - 작성자 줄(도구·모델 이름·폴더 경로)
  - README §6 "코덱스 계획과 비교할 때 볼 점"(Claude가 미리 만든 잣대라 Claude에 유리할 수 있음)
  - §7의 "코덱스 초안을 열지 않았다" 줄
  - 02 문서의 "Claude"(→ "계획자")
- Claude v2 사본에 넣지 않은 것: `06_review_response.md`, `reviews/`, `sources/`(README에 "이 사본에는 없음"으로 표시). `eda/` 스크립트와 출력은 넣었다.
- 코덱스 사본: 저자 표시가 없어 원문 그대로 복사했다.
- 배정(순서 편향 방지를 위해 반대로):
  - 심사자 1: 계획 X = Claude v2, 계획 Y = 코덱스
  - 심사자 2: 계획 X = 코덱스, 계획 Y = Claude v2
- 두 사본 모두 한쪽은 "내부 검토를 거친 v2", 다른 쪽은 "첫 판"이라고 알렸다. 저자가 아니라 합칠 내용의 질을 보라고 했다.

## 잣대

양쪽 계획의 기준을 합친 중립 12개 기준이다. 각 1–5점에 근거(절 번호)를 붙였다.
- C1 과제 요구 적합성
- C2 데이터 이해·진단
- C3 최종 모델·출력 정의
- C4 검증 설계 타당성
- C5 오경보 통제 근거
- C6 조기탐지·미탐 분석(합성·증강 설계 포함)
- C7 대안의 폭과 공정한 비교
- C8 실행 가능성(날짜는 평가하지 않음)
- C9 현장 활용
- C10 출처·라이선스
- C11 주장 절제·정직성
- C12 창의성·차별성

관점은 둘이다.
- 심사자 1: 방법론·통계·데이터. C2–C6·C11을 깊게 봄
- 심사자 2: 대회 심사·실행·현장. C1·C7–C10·C12를 깊게 보고, 공식 배점표 기준 예상 점수 범위를 추정함

둘 다 각 계획에서 설계를 바꾸는 사실 주장을 4개 이상 원자료·저장소로 확인하게 했다.
