# 04. 검증·실험 프로토콜 (사전 등록안)

이 문서는 실험을 돌리기 **전에** 고정하는 규칙이다.
- 확정한 커밋 해시와 주입 격자 YAML의 해시를 모든 산출물의 `run_manifest.json`에 기록한다.
- 확정 뒤에 바꾸면 변경 이유와 바꾸기 전·후 결과를 함께 남긴다(변경관리).

[근거 표기] `[R#]` 리서치 주제(02 문서), `[D§]` 01 문서, `[A§]` 03 문서.

## 1. 원칙

1. **증거를 위계로 나눈다** [R5].
   - L1 실제 이상 1 에피소드: 최종 1회 시험. 어떤 선택·임계값·보정에도 쓰지 않는다.
   - L2 실제 정상 데이터 + 물리 동기 주입: 모델 선택, 검출한계, 강건성의 주 근거.
   - L3 외부 공개 데이터(ZeMA 등): 주입 크기와 교란 크기의 앵커로만 쓴다.
   - L4 문헌.
2. **임계값·보정은 정상 데이터만으로 한다.** 실제 이상 버스트는 탐지율 보고에만 쓴다. 오경보 보정에는 절대 섞지 않는다. 감사 로그로 증명한다 [R4].
3. **실제 이상을 이미 봤다는 사실을 공개한다.** 이 계획의 EDA에서 이상 파일을 분석했다(01 문서).
   - 그래서 실제 이상과 닮은 주입 계열(흔들림 모드 F9)은 보류 시험에서 뺀다.
   - "가장 닮은 계열을 빼도 결론이 같은가"를 민감도로 보고한다.
4. **판정 단위는 버스트, 경보 단위는 경보 개시(사건), 시간 단위는 실시각 버스트 시각이다.** 행 단위 지표는 가이드북 비교용 부록으로만 둔다(유사반복 주석) [R3][R8].
5. **모든 후보를 같은 분할·같은 지표·같은 경보 예산으로 비교한다.** 결과가 나쁜 후보와 실패한 격자 칸도 빼지 않는다.

## 2. 데이터 분할

### 2.1 정상 데이터 — 네 가지 분할을 모두 쓴다

| 분할 | 학습 | 보정(임계값·확률) | 시험 | 용도 |
|---|---|---|---|---|
| A. 시간순 (주 분할) | 00:00–00:40 | 00:40–01:00 | 01:00–01:17 (장시간 대기 + 재가동) | 대표 수치. 가이드북 분할과 비교 가능 |
| A′. 시간 역순 | 00:37–01:17 | 00:17–00:37 | 00:00–00:17 | 순서 효과 점검 [R4] |
| B. 블록 교차검증 | 10분 블록 7개 중 6개, 블록 안 앞 70 % | 블록 안 뒤 30 % (또는 교차 conformal) | 남은 1개 블록 | 경보율의 블록 간 변동과 신뢰구간 |
| C. 상태 보류 | 장시간 대기·재가동 제외 전부 | 〃 | 01:00–01:17 | **학습에 없던 정상 운전 상태와 그 전환에서의 오경보** |

- 블록 경계에서 앞뒤 5 버스트를 버퍼로 버린다 [R5]. 같은 운전 상태 안에서는 버스트가 거의 독립이고(τ ≈ 1), 의존의 주원인은 상태 전환이다 [R4].
- 학습 구간의 정상 데이터는 "정상"으로 가정한다. 숨은 이상이 있을 가능성은 한계로 적는다.

### 2.2 이상 데이터

- 600행, 21 버스트(10행 이상 17), 1 에피소드 → 시험 전용.
- 보고 단위는 에피소드(1/1), 버스트(21/17), 행(600, 부록)이다.
- 지지 범위 밖 버스트(정상 부하 범위를 벗어난 것)는 "판정 보류"로 따로 센다 [D4-1].

### 2.3 합성 데이터

- 고장 주입은 각 분할의 **시험 정상 버스트에만** 한다.
  - 예외: D(OE-GBM)는 학습 블록에 **개발용 계열만** 주입해 학습한다. 평가에서는 그 계열을 뺀다(leave-one-family-out).
- 긴 스트림(램프용 4–8시간)은 시험 블록 버스트의 정상 블록 부트스트랩(stationary bootstrap)으로 만든다. "77분 원천을 재사용했다"고 명시한다 [R5].
- 시드는 `hash(family, severity, channel, state, burst_id, fold)`로 고정한다.
- 증강은 물리적으로 중립인 것만 쓴다: 버스트 위상 무작위화, 버스트 블록 부트스트랩, 버스트 잘라내기. 시간왜곡·순열·믹스업은 금지한다 [R5].

## 3. 주입 라이브러리 — 사전등록 격자 (R5-INJ v1을 우리 특징 체계에 맞춤)

모든 연산은 **샘플 단위**로 정의한다. 주파수는 주기/샘플이다. 괄호는 S1k 해석의 Hz다.

### 3.1 고장 계열 F (경보가 나야 맞음)

| 계열 | 메커니즘(출처) | 주입 구현 | 크기 격자 | 용도 |
|---|---|---|---|---|
| F1 광대역 진동 에너지 증가 | 마모·헐거움·공동현상의 광대역 에너지 [R1][R5] | 같은 버스트의 위상 무작위(IAAFT) 대리잡음을 더해 RMS 비 g. 채널: 상·하·둘 다. 상태: 전체 / 부하만 | g ∈ {1.1, 1.2, 1.3, 1.5, 1.75, 2, 2.5, 3, 4} | 개발 |
| F2 충격성 | 치면·베어링 손상의 충격 + 감쇠 [R1][R5] | 표본당 확률 p의 감쇠 충격(공진 0.1–0.45 주기/샘플), 진폭 a·σ_burst | p ∈ {0.5, 1, 2, 5, 10}%, a ∈ {3, 5, 8} | 보류 |
| F3 협대역 톤 출현 | 릴리프 밸브 채터, 새 맞물림 성분 [R1] | 진폭비 ρ 정현. f ~ U(0.1, 0.45) 주기/샘플(정상 톤 0.179·0.355 ± 0.005는 별도 칸) | ρ ∈ {0.25, 0.5, 1, 2} | 보류 |
| F4 펌핑 톤 증가 | 간극 증가 → 압력맥동 증가 [R1] | 0.179·0.355 톤 진폭 × (1+τ), 부하 조건부 | τ ∈ {0.1, 0.2, 0.5, 1.0} | 개발 |
| F5 토크 맥동 → 전류 변조 | 부하토크 변동이 고정자 전류를 변조 [R5] | **0.0600 주기/샘플 반송파를 AM 변조해 같은 샘플 격자에서 재합성 + 원 잔차.** 변조 주파수 ~ U(0.005, 0.45) 주기/샘플(파일럿 [D8]) | m ∈ {2, 5, 10, 20}% | 개발 |
| F6 마찰 증가 → 전류만 | 마찰토크 증가 [R5] | 부하 버스트 A60 × (1+ε), 무부하 × (1+ε/4). 진동은 그대로 | ε ∈ {2, 5, 10, 20}% | 보류 (식별불가 쌍 확인용) |
| F7 듀티사이클 변화 | 내부누설 → 충전 시간 증가 [R1][R5] | 10분 창 부하 버스트 비율을 블록 재표본으로 올림 | +10, +20, +30 %p | 보류 (느린 지표 S1 전용) |
| F8 결합 이탈 / 센서 이상 | 센서 장착 헐거움·이득 저하 [R1][R9] | 한 채널만 이득 × {0.5, 0.7, 1.5}, 위상 변화, flat-line, 오프셋 +3σ, 채널 결측, 직류 계단 | — | **L0 "계측 점검"으로 분류되는지** 혼동행렬로 시험 |
| F9 흔들림 모드 링잉 | 헐거움·충격으로 유닛 흔들림. **실제 이상에서 관측된 형태** [D4] | 0.07–0.12 주기/샘플 감쇠 링잉, 상·하부 역위상, 버스트당 0–3회 | 진폭 0.1–1.0 | 민감도 전용(선택·보류 시험 모두 제외) |
| F10 램프(점진 성장) | 조기탐지의 본질 [R5] | F1/F4/F5를 0에서 목표까지 선형 증가 | 목표 F1 g=3, F4 τ=1, F5 m=20 %. 기간 T ∈ {10, 30, 60, 120} 분 | 조기탐지 지표 |

- **개발용(모델 선택):** F1, F4, F5와 그 램프
- **보류용(최종 보고):** F2, F3, F6, F7
- **계열 맞바꾼 판:** F2·F3·F6으로 개발하고 F1·F4·F5를 보류한다. 순환 논리 의존도를 공개하기 위해서다 [R5].
- 크기 앵커: ZeMA(CC BY 4.0) 계산값을 쓴다 [R5].
  - 내부누설: 모터전력 +0.45 % / +1.05 %
  - 오일 +8–21 °C: 전력 −3 – −6 %, 진동 +9 – +28 %
  - 장비가 다르므로 비율만 차용하고 결론을 기대지 않는다.

## 4. 지표

### 4.1 주 지표 (표의 첫 열들)

| 지표 | 정의 | 불확실성 |
|---|---|---|
| **FA/h** | 정상 시험 구간에서 지속성 규칙 적용 후 경보 **개시** 수 ÷ 실시각 노출 시간. FA/100버스트 병기 | Poisson 정확(Garwood) 95 % 구간. 0건이면 3/T. 정상 전체 1.28 h에서 0건이어도 상한 2.34/h [R3][R4] |
| 버스트당 FPR(상태별) | 지속성 적용 전 | Clopper–Pearson/Wilson. 고정 보정집합의 실제 FAR 분포(Beta) 병기 [R4] |
| 에피소드 탐지·**첫 경보까지 시간** | t₀ = 첫 이상 샘플(10:51:07.943). 지연 = 판정에 쓴 마지막 버스트의 실시각 − t₀. 초와 버스트 수로 | 에피소드 1/1의 CI [0.025, 1] 명시 |
| 버스트 재현율 + **FN 목록** | 21개(10행 이상 17개) 중 몇 개. FN 버스트의 부하·진동·전류 특성표 | CP 구간 + "같은 에피소드 반복 측정" 주석 |
| 우연 예측기 대비 | 같은 경보 시간 비율을 갖는 무작위 경보의 에피소드 적중 확률 | "탐지"는 낮은 경보 시간 비율에서만 의미가 있다 [R4] |

### 4.2 보조 지표

| 지표 | 정의 |

| 운영 | 버스트당 추론 시간, 모델 크기, 전체 실행 시간 |

| 시험 점수로 임계값 결정, 무작위 행 분할, 겹치는 창 분할 | 누수 |
| 계열 평균 POD | 서로 다른 데이터를 묶은 평균 곡선은 어느 것도 대표하지 않는다 [R5] |
| 긴 창의 BH-FDR | 보정 표본이 부족해 검정력이 0이다. 1시간 창이면 보정 표본이 4,669개 필요하다 [R4] |
| 고장 중에 갱신하는 적응형 conformal | 고장을 "적응"해 지워 버린다. 갱신은 확인된 정상 구간에서만 한다 [R4] |

## 5. 모델 선택 규칙 (사전 등록)

1. **제약 1 (오경보 예산):** 운영 임계값에서 아래 두 조건을 모두 만족해야 한다.
   - 분할 B 버스트당 FPR 평균 ≤ α_op(기본 1 %), 블록별 최댓값 ≤ 3α_op
   - 분할 C(장시간 대기·재가동) FPR ≤ 2α_op
2. **제약 2 (형식 불변성):** N8 재양자화 전후 경보가 바뀐 버스트 0개, 점수 순위상관 ≥ 0.99.
3. **제약 3 (계측·정상 변화 강건성):** **기계 채널** 경보율이 명목 α_op의 2배를 넘지 않아야 한다. 대상 조건은 다음과 같다. 전기·계측 채널은 따로 보고한다.
   - I1 ≤ 1 ms
   - I2 ±10 %
   - N2 ±20 %
   - N3 ±5 %
4. **목적:** 제약을 만족하는 후보 중에서 개발용 계열(F1, F4, F5) 각각의 a50을 구하고 순위를 매긴다. **계열별 순위의 중앙값이 가장 좋은 후보**를 고른다(계열 평균 POD를 쓰지 않기 위해 순위 결합).
5. **동점(부트스트랩 90 % 구간이 겹침):** 아래 순서로 고른다.
   - 설명 가능성: 이유 코드가 물리 지표로 바로 나온다
   - 추론 속도
   - 의존성 수
6. **실제 이상 결과는 선택이 끝난 뒤에 연다.** 선택된 모델이 실제 이상 버스트를 놓치면 그 사실과 원인을 그대로 보고하고 선택은 뒤집지 않는다.
7. **F9 민감도:** F9를 개발용에 넣었을 때와 뺐을 때 선택 결과가 같은지 보고한다.

## 6. 통계 처리와 "정직한 보장 진술"

### 6.1 이 데이터로 검증할 수 있는 해상도 — 주장의 상한

| 항목 | 값 |
|---|---|
| 정상 버스트(10행 이상) | 가압 187, 중간 86, 대기 142, 장시간 대기 83, 재가동 32 (합 530); 전체 599 |
| 경보 0건일 때 버스트 FPR 95 % 상한 | 장시간 대기 83개 → 3.6 %; 정상 전체 599개 → 0.50 % |
| 경보 0건일 때 FA/h 95 % 상한 | 정상 전체 1.28 h → 2.34/h; 분할 A 시험(01:00–01:17, 0.282 h) → 약 10.6/h |
| "교대당 1건" | 버스트당 α ≈ 2.7×10⁻⁴. 보정에 3,700개 이상 필요 — **이 데이터로 검증 불가**. 실증에는 오경보 없는 정상 운전 ≥ 24 h 필요(주 1건은 ≥ 503 h) [R4] |
| 상태별 conformal p값 해상도 | 1/(n_cal+1). 교차 conformal로 0–60분 전부를 쓰면 상태당 0.5–1.2 % |
| 고정 보정집합의 실제 FAR | Beta(l, n+1−l). 보정 240–300개면 α=0.01의 실제 FAR 95 % 상한 약 2 % [R4] |

### 6.2 진술 단위표 — 보고서에 쓸 수 있는 문장의 범위 [R4]

| 단위 | 보장·추정할 수 있는 것 | 필요한 가정 | 권장 표현 |
|---|---|---|---|
| 행 | 사실상 없음 | 행 독립(불성립) | 본문에 쓰지 않음 |
| 버스트 | P(경보 \| 정상) ≤ α(보정집합 평균) | 보정·운영 버스트 교환가능 | "07-12 00:00–01:00 조건에서 보정, 명목 α, 실제 FAR 95 % 상한 x %" |
| 경보 사건 | 개시 건수/노출 시간, Poisson CI | 사건 간 근사 독립 | "정상 1.28 h 0건 → 95 % 상한 2.3건/h(동일 조건 한정)" |
| 교대·주 | 기대 오경보 수 | 정상성·독립·상태 분포 동일 | "설계값이며 실증 아님. 실증은 그림자 운전으로" |

### 6.3 신뢰구간 방법

- 정상 쪽: 10분 블록 단위 군집 부트스트랩(2,000회), 또는 정상 블록 부트스트랩. 상태 전환을 포함하는 블록 길이를 쓴다.
- 합성 쪽: (블록 × 주입 시드) 부트스트랩. 비교는 같은 버스트·같은 시드의 짝지은 차이로 한다.
- 이상 쪽: 에피소드 1개이므로 일반화 신뢰구간을 붙이지 않는다. 버스트 단위 구간에는 "에피소드 안 변동만 반영" 주석을 단다.
- 다중 비교: 후보·격자 수를 표에 적는다. 선택 규칙은 하나다. 사후에 지표를 바꾸지 않는다.

## 7. 교란·지름길 진단 (필수)

"교란이 없다"는 증명할 수 없다. 대신 **교란이 있었다면 실패했을 시험**을 여러 개 통과했는지 보인다. 통과를 "확증"으로 쓰지 않는다 [R8].

| ID | 시험 | 방법 | 판정·쓰임 |
|---|---|---|---|
| C1 | 분석 단위 위계 공개 | 행 / 버스트 / 운전 구간 / 에피소드 / 날의 표 | 이상 쪽 유효 표본 = 에피소드 1개 |
| C2 | 음성 대조: 정상 vs 정상 | 앞/뒤 절반, 0–60분 vs 장시간 대기를 블록 CV 분류기로 | 정상 상태끼리도 갈린다(파일럿 AUC 0.554 / 0.967) [D6] |
| C3 | 음성 대조 특징 | 버스트 길이·앞 공백·시작 시각 ms 위상만으로 파일 구분 | AUC 0.5 근처여야 함(R8: 0.44–0.62) |
| C4 | 형식 불변성 | N8 | 제약 2 |
| C5 | 누수 탐침 | TimeStamp만, 행 번호만 쓰는 분류기 | 입력에서 뺐음을 증명 [R3] |
| C6 | 부하 매칭 비교 | 보수적 부하(최대 \|I\|) 기준 정상 법칙 대비 | 상부진동 초과(중앙 4.2배)가 고장 쪽 근거 [D4-1] |
| C7 | 지지 범위 점검 | 정상 부하 범위 밖 이상 버스트 목록 | "판정 보류"로 따로 보고 |
| C8 | 특징군 제거·재학습 | 군 다섯 개(진동 진폭/진동 동역학/전류 진폭/**전류 동역학**/결합) | 전류 동역학 군에만 기대는 탐지는 "계측 의존" 경고 |
| C9 | 계측 스트레스 | I1–I3 | 제약 3 |
| C10 | 정상 행동 모델 불변성 | 진동 ~ f(부하)를 생산 구간과 휴지 구간에 각각 적합하고 잔차 분포 비교 | 차이가 작아야 잔차 점수를 신뢰 |
| C11 | 지도학습 대조 | 정상 vs 실제 이상으로 학습한 분류기를 보류 계열·N·I 계열에 적용 | 실제 레이블 학습의 지름길 위험 시연 |
| C12 | 블록 순위 검정 | 이상 에피소드 통계가 같은 길이 정상 블록 28개 중 몇 위인지(최소 p = 0.034) | 진동 통계와 지름길 통계가 둘 다 최소 p면 "유의성으로 고장 대 세션을 가를 수 없음"을 명시 [R3] |
| C13 | 순서 파괴 탐침 | 버스트 안 샘플 순서를 섞어 시퀀스 모델 재평가 | 진폭 의존인지 동역학 의존인지 |
| C14 | 설명 감사 | 실제 이상 버스트의 상위 기여 특징이 계측 민감 군인지 | 상위가 부하 대비 진동이어야 한다 |
| C15 | 샘플링 가설 | S10/S1k 근거 3종 재계산 [D2-2] | 결론을 보고서 데이터 장에 가설로 |

**주장 장부(claims ledger)** — 실험이 끝나면 한 장으로 정리한다.
- 주장하는 것(예): "같은 부하의 정상 대비 상부진동이 크고 저주파 흔들림이 많은 이 에피소드를, 정상 운전 변화·계측 변동에서는 오경보를 예산 안으로 유지하면서 X 버스트(Y초) 안에 경보한다. 계열별 검출한계는 a50 = …"
- 주장하지 않는 것: 다른 날·다른 고장으로의 일반화, P(고장)의 실측 보정, 고장 부위 확정, 현장 오경보율 실증.
- 각 주장과 한계를 C 시험 번호와 4절 지표로 연결한다.
