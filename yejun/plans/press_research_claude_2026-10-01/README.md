# 프레스 유압펌프 과제 재설계 계획 — Claude 초안 v2 (2026-10-02)

## 결론 세 줄

1. **최종 모델: PHI-Prob(부하 보정 물리지표 이상확률 모델, 가칭).** 전류로 부하를 추정하고, 같은 부하의 정상 대비 진동 초과 같은 물리 건강지표를 악화 방향으로만 검정한다. 그다음 운전 상태별로 오경보율을 보정하고 이상 확률(`p_anomaly`)과 3단계 경보로 낸다. 점수 헤드(물리지표 결합 대 합성 고장 노출 GBM)는 사전 등록한 규칙으로 고른다.
2. **주장은 세 가지다.**
   - 정상 운전 변화에서 오경보를 통제한다. 실데이터에서 장시간 대기 경보율이 양측 판정 16.9 %, 우리 단측 판정 0.0 %였다.
   - 학습에 안 쓴 고장 종류에서도 작은 크기부터 잡는다(합성 고장의 a50).
   - 경보를 이유 코드와 점검 카드로 현장 조치에 잇는다.
3. **가장 큰 위험은 데이터다.**
   - 이상 에피소드는 하나뿐이다.
   - 정상·이상 두 파일은 전류·진동 모두 수집 경로가 다르다(전류 배율 10⁴ 차이).
   - 이상 구간에는 전동기가 돌지 않았을 가능성이 크다.
   - 그래서 실제 이상으로는 "조기탐지"를 주장하지 않는다. 조기탐지는 합성 고장으로만 보인다.

작성: Claude Code (Opus 5.5). 위치: `yejun/plans/press_research_claude_2026-10-01/`. v1(커밋 3eb49a1)을 독립 검토 3종으로 고친 판이다.

## 4. 위험과 한계

- 실제 이상 에피소드로는 조기탐지·고장 부위·일반화를 주장할 수 없다. 한 에피소드이고, 수집 경로가 다르고, 전동기 비가동일 가능성이 있다.
- 현장 오경보 목표(교대·주 단위)는 이 데이터로 실증할 수 없다. 정상 1.28시간에서 0건이어도 단측 95 % 상한이 2.3건/시간이다.
- 검출한계(a50)는 하룻밤 77분 정상 변동만 반영한 낙관적 하한이다. 합성 결과는 "설계한 계열에 대해서"만 유효하다.
- 다음은 현재 센서로 원리적으로 가를 수 없다. 원인과 대책은 04 §3.4에 있다.
  - 진동 소폭 증가 ↔ 센서 이득·열 드리프트
  - 마찰형 전류 증가 ↔ 전압 변동
- 일부 출처는 서지·초록 수준으로만 확인했다(세션 웹 검색 한도 소진, 02 문서의 확인 열 참고).

## 6. 코덱스 계획과 비교할 때 볼 점 (양쪽에 같은 잣대)

1. **실행 범위의 현실성.** 최소 완결판이 있는가. 중간에 멈춰도 한 명령으로 도는가.
2. **최종 모델 한 줄 정의와 이상 확률 정의.** 사전확률·기준 유병률을 명시하는가.
3. **실제 고장 처리 규칙.** 전류 정보가 없는 이상 구간을 어떻게 판정하는가(보류·계측으로 빠지지 않는가).
4. **공식 분할 F1 대응.** 단순 규칙 F1 1.000을 알고 있는가. 그래서 평가조건을 어떻게 넓혔는가.
5. **데이터 진단 깊이.** 단위·격자 지문, 샘플링 해석, 드리프트, 정상 안의 운전 변화를 다뤘는가.
6. **교란 처리.** 실제 이상을 튜닝에서 뺐는가. 비맹검 사실을 공개하는가.
7. **증강·합성 고장.** 물리 근거와 현실 크기가 있는가. 개발·보류 계열을 나눴는가. 이득 변화와 구별되는가. 평균 POD를 쓰지 않는가.
8. **오경보 통제의 실데이터 근거.** 장시간 대기·재가동·드리프트를 실데이터로 시험하는가.
9. **현장 활용.** 경보 정의표, 점검 카드(안전 포함), 비용 근거, 도입 절차가 있는가.
10. **출처 관리.** 등급·확인 방식·라이선스·사용 위험이 있는가. 금지 출처가 있는가.
