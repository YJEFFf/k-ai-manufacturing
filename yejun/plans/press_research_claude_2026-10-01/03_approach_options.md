## 0. 한 문장 전략과 최종 모델

> **정상 운전 변화에는 조용하고, 작은 고장에는 먼저 울리는 경보.**
> 실제 이상 구간은 진동 크기만으로도 대부분 구분될 만큼 뚜렷하다(공식 분할에서 단순 규칙 F1 1.000 [D6]). 그래서 공식 분할 F1만으로는 모델 간 차이가 드러나지 않는다. 과제가 강조한 두 축으로 평가조건을 넓힌다.
> - 오경보 감소(정상 운전 변화)
> - 조기탐지(더 작은 이상)

### 최종 모델 — PHI-Prob (부하 보정 물리지표 이상확률 모델, 가칭) [v2]

| 단계 | 내용 |
|---|---|
| 1. 운전 상태·부하 | 전류 60 Hz 진폭(A60)으로 펌프 부하를 추정한다. 전류 채널이 무효(60 Hz 소실, 배율 지문 변경)면 "부하 미상"으로 두고 정상 최대 부하 기준으로 보수 판정한다. 60 Hz와 회전 톤이 모두 없으면 "정지" 상태다 |
| 2. 물리 건강지표 | 같은 부하의 정상 대비 상·하부 진동 초과, 펌프 톤 초과, 광대역·충격성, 구조 모드 들뜸, 전류 파형 왜곡 — 모두 악화 방향 단측 |
| 3. 점수 | 기계 채널과 전기·계측 채널 각각에서 표준화 지표의 양의 부분 최댓값(기본) 또는 합성 고장 노출 그래디언트 부스팅 점수(물리 방향 단조 제약). 둘 중 선택 규칙으로 고른다 |
| 4. 상태별 보정 | 운전 상태마다 정상 오경보율을 설계값 α_op에 맞춘다(교차 conformal, 확인된 정상 구간으로 기준선 갱신) |
| 5. 이상 확률 | 공통 확률 헤드: 점수 → 등장성 보정 → `p_anomaly`(기준 유병률 q 명시). 현장용으로는 경보 단계별 적중 확률(PPV, 고장 상태 유병률 시나리오)로 환산 |
| 6. 경보 | 3단계 + 계측 점검(병기) + 비가동 중 이상 진동 + 판정 보류(좁게) → 이유 코드 → 점검 카드 |

**선정 근거(한 줄):** 같은 오경보 예산에서 학습에 안 쓴 고장 종류까지 더 작은 크기에서 잡고, 정상 운전 변화·센서 이상에 강건하며, 경보 이유가 물리량으로 나온다. 실제 선택은 [P5] 규칙으로만 한다.

## 1. 층 구조

| 층 | 하는 일 | v2 핵심 |
|---|---|---|
| L0 수집 건전성(SQI) | 데이터 무결성과 계측 이상을 분리 | **채널별 LSB 지문**(격자 간격·배율·감도), 60 Hz 소실, 톤 소실, 평탄·포화·중복·시각 역행, 짧은 버스트. **덮어쓰지 않고 병기 태그로 단다** |
| L1 운전 상태·부하 | 정지 / 기동·전이 / 생산 / 장시간 대기, 부하 A60, 부하 미상 판정 | [v2] 생산 중 무부하·가압은 상태가 아니라 스트로크 위상이다 [D5]. 슬립 ŝ는 L1에서 뺀다 |
| L2 건강 지표 | 2절 | [v2] 펌프 톤(M6a)과 전자기 톤(M6b) 분리, 구조 모드(M5)는 비맹검 표시 |
| L3 점수 | 채널별 점수 | [v2] Cauchy 결합 폐기 → 점수 결합 후 conformal 1회 |
| L4 보정·확률 | conformal p값, `p_anomaly`, 경보 PPV | [v2] π = 고장 상태 유병률(λ × D)로 정의 |
| L5 경보 | 3단계 + 계측 점검 + 비가동 중 이상 진동 + 판정 보류, 지속성, 해제 | [v2] 단계 이름 통일, 확률 조건을 3단계에서 뺌 |
| L6 설명·조치 | 이유 코드, 물리 비교 문장, 점검 카드 | [v2] 카드 맨 앞에 안전 3줄 |

## 2. 운전 상태와 건강 지표 (L1·L2)

모든 특징은 버스트 단위다. 주파수는 주기/샘플이고 괄호 안 Hz는 S1k 기준이다 [D2-2].

### 2.1 운전 상태·부하 (L1)

| 판정 | 조건(초안, 값은 정상 데이터와 물리로 WP0에서 고정) | 쓰임 |
|---|---|---|
| 전류 유효 | 0.0600 주기/샘플 사인 R² ≥ 0.95 그리고 배율 지문 = 정상 | 부하 A60 사용 |
| 부하 | A60, 토크 성분 I_T = √(A60² − I₀²)(A60 > I₀일 때만) | 진동의 부하 조건부 기준 |
| **부하 미상** [v2] | 전류 무효 | 정상 학습 전체 **최대 포락선**(가장 관대한 기준)으로 진동 초과 판정 |
| **정지** [v2] | 전류 무효 그리고 상부 360 Hz 톤 진폭 < 장시간 대기 최솟값의 절반(정상 데이터에 없는 상태라 물리로 정의) | "비가동 중 이상 진동" 판정 경로 |
| 장시간 대기 | 무부하 위상이 n분 이상 연속(n은 WP0에서 고정, 초안 3분) | 별도 기준선 |
| 생산 | 그 밖 | 기본 기준선 |
| 지지 범위 밖 | A60이 정상 학습 [p0.5, p99.5] 밖 그리고 전류 유효 | 판정 보류(좁게) — 부하 미상 규칙으로도 결론이 바뀌는 경우만 |

- 스트로크 위상(마지막 행 시각 mod 2.9006초)은 전류와 독립적인 기대 부하를 준다. S1k 조건부라 Tier 2 공변량으로 둔다.

### 2.2 기계 채널(M) — 진동

| 지표 | 정의 | 물리 해석 | 방향 |
|---|---|---|---|
| M1 하부진동 초과 | log RMS(AI1) − ĝ₁(부하)의 표준화 잔차. 부하 미상이면 포락선 대비 | 같은 부하에서 진동이 크다 | 단측 |
| M2 상부진동 초과 | AI0에 같은 방식 | 〃 | 단측 |
| M3 광대역 잔차 | 톤(0.179·0.355 ± 0.005)을 뺀 잔차 RMS의 부하 조건부 초과 | 공동현상·마모의 광대역 에너지 | 단측 |
| M4 충격성 | 톤 제거 잔차의 첨도·파고율 | 베어링·치면 손상·커플링 충격 | 단측 |
| M5 구조 모드 들뜸 | 0.06–0.15 주기/샘플 대역 에너지(상태별 기준선) | 헐거움·외부 가진·작업 충격·밸브 채터(원인 특정 안 함). **이상을 본 뒤 만든 지표 → 비맹검** | 단측 |
| M6a 펌프 톤 초과 | 하부 0.179 톤 진폭의 부하 조건부 초과 | 간극 증가에 따른 압력맥동 | 단측 |
| M6b 전자기 톤 | 상부 0.36 톤(전원 6배 고정) | 전원 고조파·전자기. **펌프 카드와 연결하지 않음** | 단측(전기 채널로 보냄) |
| SQI-pair | 하부/상부 179 Hz 진폭비·위상차 | 센서 체결 상태(한쪽이 헐거워지면 먼저 바뀜) | 양측(L0) |

### 2.3 전기·계측 채널(E)

| 지표 | 정의 | 해석 |
|---|---|---|
| E1 파형 왜곡 | 60 Hz + 홀수 고조파 적합 잔차 ÷ A60 | 전기 이상 또는 계측 이상(이중 해석) |
| E3 상태 대비 전류 과다 | 같은 상태 정상 대비 A60 초과 | 과부하·마찰 — 전압·센서 이득과 식별 불가 |
| L0 연동 | 60 Hz 소실 + 톤 있음 → 전류 센서 이상 / 60 Hz 소실 + 톤 없음 → 정지 | [v2] 전류 단독으로 기계 경보를 내지 않음 |

### 2.4 느린 지표(S, Tier 2)

| 지표 | 정의 | 비고 |
|---|---|---|
| S-drift | 확인된 정상 구간의 M1·M2 잔차 EWMA = 기준선 | Tier 1에도 필요(기준선 갱신) |
| S-slip | 10분 창 가압 버스트의 슬립 중앙값 | [v2] 버스트 단위로는 잡음이 커서(잔차 SD 0.41 %p vs 전체 범위 0.83 %p) 느린 지표로만 쓴다 |
| S-duty | 스트로크 위상별 부하 곡선 모양(듀티) | 내부누설·언로딩 회로 이상의 느린 지표 |
| E2-pattern | 무부하 A60·가압 I_T·가압 슬립의 세 양 패턴 | 이득 드리프트 / 전압 변화 / 토크 증가 구분(전압 기준 채널이 있으면 바로 판별) |

### 2.5 금지 특징과 규칙

- **탐지기 입력 금지:** 자릿수, 고유값 수, 최소 간격, 절대 시각, 요일, 행 번호, 파일 출처, TimeStamp. 단, 격자 지문은 L0 무결성 검사에만 쓴다.
- **방향 규칙:** M·E 지표는 악화 방향 단측이다. "너무 조용함"은 L0으로 보낸다.
- **채널 규칙:**
  - 기계 경보(2·3단계)는 기계 채널 증거로만 낸다.
  - 전기 채널 단독 신호는 "전기·계측 점검" 알림으로 따로 세고, 예산도 따로 둔다.

## 3. 점수·보정·확률 (L3·L4)

| 결정 | v2 기본안 | 근거 |
|---|---|---|
| 지표 결합 | 채널별 **결합 점수 = 단측 표준화 지표의 양의 부분 최댓값**(대안: 합). 그 점수에 conformal을 한 번 적용한다 → 교환가능성 아래 유한표본에서 유효하다. 해상도 1/(n+1)이 한 번만 들고 "조용한 지표가 극단 지표를 지우는" 상쇄가 없다 | 검토(방법론) P1-3 |
| Cauchy 결합 | **쓰지 않는다.** 보장이 가우스 코퓰라 아래 작은 α의 근사이고, 지표 6개·보정 300개 이하에서는 단일 지표 고장이 α = 1 %에 도달하지 못한다 | Liu & Xie 2020, 검토 |
| 보정 집합 | 시험 블록을 뺀 모든 블록의 교차 conformal(out-of-fold). α_op는 상태당 보정 표본 n에 맞춰 사전에 정한다(n ≥ 1/α_op에 여유) | Vovk 2015, Barber et al. 2021 |
| 기준선 갱신 | 확인된 정상 구간에서만 EWMA로 갱신한다. 경고 이상이 나면 동결한다(적응형 conformal의 "고장 흡수" 함정 회피) | [D4] 드리프트, R4 |
| 채널 합집합 | 기계·전기 각각 α_op/2(합집합 FPR ≤ α_op) | 검토 |
| **공통 확률 헤드** | 모든 후보 점수 → 개발 계열의 보류 버스트 혼합에서 등장성 보정 → `p_anomaly`(기준 유병률 q, 예: 10 %를 명시) | 검토(전략) P0-2 |
| 경보 PPV | **P(고장 \| 경보)** = POD·π / (POD·π + PFA·(1−π)). π는 **고장 상태 유병률 = λ × D**(λ 고장률, D 검출 가능 열화 기간)로 정의한다. 마모형(예: λ 0.2/년, D 2–8주 → π ≈ 10⁻²)과 급성형을 나눈다. 지속성을 통과한 경보 사건 단위로 계산한다 | 검토(현장·방법론) |
| 우도비 상한 | conformal 해상도 때문에 버스트 하나의 우도비 ≤ 약 80–200이다. 도달 가능한 최대 사후확률을 표로 함께 적는다 | 검토(현장) |
| 조치 임계 | 비용–손실: 점검 비용 C_I, 놓친 고장 비용 C_U, 조기 수리 비용 C_P에서 PPV > C_I/(C_U − C_P)이면 점검. 비용비 10/50/100/300 × π 민감도 표 | R9 |

## 4. 경보 (L5) — 단계 이름 통일 [v2]

| 출력 | 조건(초안) | 의미·대응 |
|---|---|---|
| 정상 | — | — |
| **1 주의(관찰)** | 기계 채널 p < α₁, 지속성 2-of-3. α₁은 설계 예산 하루 1건 이하가 되도록 역산 | 정비 일일 보고(비가청 알림) |
| **2 경고(점검 권고)** | 기계 채널 p < α_op/2가 3-of-5 지속, 또는 부하 미상 상태에서 포락선 초과가 2-of-3 지속 | 이유 코드별 점검 카드, 교대 안 점검 |
| **3 위험(사이클 정지 후 판단)** | 부하와 무관한 물리 한계 초과(예: max\|AI0\| > 정상 최댓값의 3배 = 1.055, 이상 9/21 해당) 단일 버스트 빠른 경로(배수 3은 이상을 본 뒤 정한 값이라 비맹검으로 표시), 또는 경고가 10분 이상 지속되며 두 진동 채널 모두 증가 | 사이클 정지(상사점) 뒤 정비 책임자 판단. **자동 정지·안전 기능이 아니다** |
| 비가동 중 이상 진동 | 정지 상태 + 진동이 장시간 대기 기준을 넘음 | 원인 후보: 외부 가진·작업·센서. 펌프 마모 카드로 보내지 않음 |
| 전기·계측 점검(병기) | L0 플래그 또는 전기 채널 단독 지속 | 센서·케이블·DAQ·전원 점검. 기계 경보로 세지 않되 숨기지 않음 |
| 판정 보류 | 부하를 몰라 결론이 바뀌는 경우만 | 재현율에서는 **미탐으로 센다**. 정상 보류율 상한 ≤ 5 % |

- 짧은 버스트는 보류하지 않는다. 축소 특징으로 판정하고 "신뢰 낮음"으로 표시한다.
- 경보 예산 사슬은 04 §6에 있다(버스트 α → 지속성 → 설계 FA/h → 교대·일 기대값 → 그림자 운전 실증).

## 5. 비교군 (L3 후보)

### 5.1 주 비교표 (심사에 닿는 표, 6행 × 같은 평가조건)

| 행 | 내용 |
|---|---|
| 공식 LSTM-AE(B0) | 가이드북 코드 그대로 재현(결과 캐시) |
| 한 줄 규칙 | max\|AI0\| > 정상 최댓값 |
| Isolation Forest(또는 kNN) | 범용 단일 클래스, conformal 임계 |
| 상태별 PCA(MSPC) | T²·SPE, conformal 임계 |
| PHI-Prob — 물리지표 점수 헤드 | 2–4절 |
| PHI-Prob — OE-GBM 점수 헤드 | 개발 계열 주입 학습, 단조 제약 |

열 구성:
1. 공식 분할 행 단위 F1·정밀도·재현율
2. 실제 에피소드 탐지(범주별)·첫 경보(버스트 수)
3. 상태 보류(장시간 대기·재가동) FPR·FA/h
4. 정상 변화·계측 스트레스 FPR
5. 개발 계열 a50
6. 보류 계열 POD(고정 크기)
7. Brier(합성 혼합)

표 머리 문장: "실제 고장은 단순 규칙도 모두 잡는다(①②). 모델의 차이는 ③–⑦에서 난다."

### 5.2 부록·보조

- B-const는 문장 하나("모두 정상이면 정확도 97.09 %")로 처리한다.
- 지도학습 대조(정상 vs 실제 이상)는 표 아래 한 줄이다. "실제 레이블로 학습한 모델은 ①②에서 만점이지만 ⑤⑥에서 무너진다."
- Tier 2: B0 버스트 단위 개선판, 1D-CNN 오토인코더, 베이즈 누적(2상태 전진 재귀), 계열 맞바꾼 판
- Tier 3: 시계열 기초모델(MOMENT·Chronos, 라이선스 확인분만)
- 쓰지 않음(비교 가치 낮음): B-rand, B-range, B-rms, B-1nn, B0 무작위 가중치판

### 5.3 기여 사다리 (창의성 항목을 결과에 연결) [v2]

같은 분할·같은 경보 예산에서 한 단계씩 더한다.

| 단계 | 구성 |
|---|---|
| 1 | 한 줄 규칙 |
| 2 | 다변량 양측(IF·MCD, conformal 임계) |
| 3 | 단측 판정 |
| 4 | 부하 정규화 |
| 5 | 상태별 conformal |
| 6 | 기준선 갱신(드리프트) |
| 7 | 지속성 |
| 8 | OE-GBM 헤드(단조 제약) |

열은 다음과 같다.
- 장시간 대기·재가동 FPR(실데이터)
- 드리프트 구간 FPR
- 정상 변화·계측 스트레스 FPR
- 개발 계열 a50
- 보류 계열 POD

이미 있는 근거: 같은 보정에서 장시간 대기 경보율이 양측 16.9 %에서 단측 0.0 %로 줄었다 [D8].

## 6. 설명·조치 (L6)

- 운영자 화면에는 SHAP류보다 **물리 비교 문장과 확신도**를 먼저 보인다. 예: "하부진동이 같은 부하 정상의 2.4배, 상위 1 % 밖." 설명만 붙이면 정답 여부와 관계없이 수용만 는다는 연구가 있다 [R9].
- 경보 카드에는 해당 버스트 원신호를 같은 부하 정상 분포 띠(5–95 %) 위에 겹쳐 보인다.
- 모델 감사용(Clever Hans 점검): TreeSHAP(IF·GBM), 특징군 제거 재학습. Friedman H, ALE, RBC, Ojala–Garriga는 Tier 2다.
- 점검 카드 맨 앞 안전 3줄 [v2]:
  1. 잠금·표지
  2. 어큐뮬레이터 잔압 방출과 압력 0 확인
  3. 가드·고온 작동유 주의

## 7. 차별점 (v2 재정렬)

1. **실데이터로 보인 운전 상태 변화 오경보 통제.** 장시간 대기에서 양측 16.9 % 대 단측 0.0 %, 열 드리프트와 기준선 갱신. 과제 문구 "정상적인 운전변화를 이상으로 판단하는 오경보"에 합성이 아닌 실데이터로 답한다.
2. **단위·격자 지문으로 본 계측 경로 진단 → 수집 건전성 층.** 다음을 가른다.
   - 전류 센서 이상
   - 설비 정지
   - 수집 설정 변경
   - "센서 이상 ≠ 고장"을 데이터로 보인다.
3. **기계 채널 / 전기·계측 채널 분리와 부하 미상 규칙.** 실제 이상처럼 전류 정보가 없는 상황에서도 진동으로 판정한다(이상 14/17, 정상 오경보 0/251).
4. **학습에 안 쓴 고장 종류에서의 검출한계(a50·a90)와 식별 불가 쌍 선언.** 현재 센서로 원리적으로 가를 수 없는 경우를 미리 말한다.
5. **경보 예산 사슬과 경보 PPV(고장 상태 유병률 시나리오)·비용–손실 임계.**
6. 데이터 이해 상자: 1 kHz 스냅샷 해석과 2.9006초 스트로크. 헤드라인으로 쓰지 않는다.
