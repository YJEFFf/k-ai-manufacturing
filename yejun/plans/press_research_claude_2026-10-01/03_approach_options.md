# 03. 접근 설계 — 여러 패러다임을 나란히 놓고 고른다

[근거 표기] `[R#]` = `02_research_sources.md`의 리서치 주제, `[D§]` = `01_data_diagnosis.md`의 절, `[P§]` = `04_evaluation_protocol.md`의 절.

## 0. 한 문장 전략

> 이 데이터에서 "이상 파일을 가려내는 일"은 한 줄 규칙으로도 된다 [D6]. 그래서 계획의 무게를 네 가지로 옮긴다.
> 1. **정상 운전 변화와 계측 변동에 울지 않는 것**(오경보 통제)
> 2. **더 작은 고장을 더 일찍 잡는 것**(등급별 검출한계·검출지연)
> 3. **그 둘을 정직한 증거로 보이는 것**(사전등록, 교란 진단, 주장 장부)
> 4. **점수를 확률·경보·조치로 바꾸는 것**(현장 의사결정)

경쟁팀 공개 저장소 몇 곳이 이미 공개한 것들은 출발점일 뿐 차별점이 아니다 [R2]. 앨리어싱, 형식 누수, 단순 합성 주입이 여기에 든다. 우리 차별점은 아래 7절에 모았다.

## 1. 시스템을 층으로 나눈다

| 층 | 하는 일 | 핵심 선택지 |
|---|---|---|
| L0 수집 건전성(SQI) | 평탄·포화·탈락·중복·시각 역행·짧은 버스트·60 Hz 소실·직류 계단을 "계측 점검"으로 분리. **억제하지 않고 별도 알림** [R9] | 규칙 기반(고정) |
| L1 운전 상태 | 버스트마다 부하 상태(무부하/부하 연속값/장시간 휴지)와 지지 범위 안·밖 판정 | 전류 60 Hz 진폭(A60), 토크 성분 I_T, 슬립 ŝ |
| L2 건강 지표 | 물리량 특징(2절) | 기계 채널(M), 전기·계측 채널(E), 느린 지표(S) |
| L3 탐지기 | 점수 산출 | 3절 후보 |
| L4 보정·결합 | 점수 → p값 → 확률 | 상태별(Mondrian) conformal, Cauchy 결합, 기저율 시나리오 확률 |
| L5 경보 논리 | 3단계 경보, 지속성, 해제, 3상태 출력 | k-of-n, CUSUM(ARL₀ = 경보 예산), 베이즈 고장상태 필터 |
| L6 설명·조치 | 이유 코드 → 점검 카드 | 지표별 기여, 물리 비교("같은 부하 정상 대비 ×k"), 반사실 설명 |

L0·L1·L2·L5·L6은 모든 후보가 같은 것을 쓴다. 후보 비교는 L3·L4에서만 한다. 그래야 "탐지기 차이"가 깨끗하게 드러난다.

## 2. 건강 지표(L2) — 물리에서 나온 특징

모든 특징은 버스트 단위로 계산한다. 주파수는 주기/샘플 단위로 정의해 샘플링 해석(S10/S1k, [D2-2])과 무관하게 한다. 괄호 안 Hz는 S1k 해석 기준이다.

### 2.1 운전 상태(L1) 변수

| 변수 | 정의 | 물리 의미 | 근거 |
|---|---|---|---|
| A60 | 0.0600 주기/샘플(60 Hz) 사인 최소제곱 진폭 | 상전류 첨두 | [D3] |
| I_T | √(A60² − I₀²), I₀ = 정상 무부하 군집 중앙(약 121) | 토크 성분 = 펌프 부하. 자화전류를 뺀 값 | R1(유도전동기 전류 근사) |
| ŝ (상대 슬립) | 1 − (톤 주파수 ÷ 전류 주파수) ÷ (무부하 기준 비) | 회전속도로 본 두 번째, 독립적인 부하 추정 | [D2-2], R1 |
| 상태 | 무부하(A60 < 130) / 부하 / 장시간 휴지(무부하가 n분 이상 연속) | 펌프 언로딩·어큐뮬레이터 충전 | [D5] |
| 지지 범위 플래그 | A60·I_T·ŝ가 정상 학습 범위의 [p0.5, p99.5] 밖 | 외삽 영역 → "판정 보류" | R8(positivity) |

### 2.2 기계 채널(M) — 진동

| 지표 | 정의 | 물리 해석 | 방향 | 근거 |
|---|---|---|---|---|
| M1 하부진동 초과 | log RMS(AI1) − ĝ₁(I_T)의 표준화 잔차(정상 조건부 분위수 회귀) | 같은 부하에서 진동이 크다 | 클수록 나쁨 | [D4] Spearman 0.857, R3 잔차 SD 0.59 → 0.20 |
| M2 상부진동 초과 | AI0에 같은 방식 | 〃. 실제 이상에서 가장 강건한 증거 | 클수록 나쁨 | [D4-1] 중앙 4.2배 |
| M3 광대역 잔차 | 펌핑 차수 톤(0.179/0.355 주기/샘플)을 뺀 잔차 RMS의 부하 조건부 초과 | 공동현상·마모의 광대역 에너지 | 클수록 나쁨 | R1 표 (a) ①③ |
| M4 충격성 | 톤 제거 잔차의 첨도·파고율 | 베어링·치면 손상의 충격 | 클수록 나쁨 | R1 ②, R5(첨도로 스파이크 POD 0.75–0.96) |
| M5 흔들림 모드 | 0.07–0.15 주기/샘플(70–150 Hz) 대역 에너지 비율 × 상·하부 역위상 상관 | 헐거움·충격으로 유닛이 흔들리는 모드 | 클수록 나쁨 | [D4], R1 ⑨ |
| M6 펌핑 톤 초과 | 톤 진폭의 부하 조건부 초과 | 간극 증가로 압력맥동이 커짐 | 클수록 나쁨 | R1 ①, R6(톤–부하 상관 0.975) |

### 2.3 전기·계측 채널(E) — 전류. 모두 "전기 또는 계측" 이중 해석을 붙인다

| 지표 | 정의 | 물리 해석 | 근거 |
|---|---|---|---|
| E1 파형 왜곡 | 60 Hz + 홀수 고조파 적합 잔차 RMS ÷ A60, 직류 오프셋 | 토크 맥동, 전기 이상, **또는 계측 이상** | [D3], R8 |
| E2 물리 일관성 잔차 | I_T와 ŝ의 정상 관계(회귀)에서 벗어난 정도 | 정상 운전 변화(압력·타수·휴지)는 관계를 지킨다. 전기·계측 이상은 관계를 깬다 | R1 3.5 |
| E3 상태 대비 전류 과다 | 같은 상태 정상 분포 대비 A60 초과 | 과부하·마찰 증가 — 단 전압·이득 변화와 식별 불가 | R5 식별불가 쌍 |

### 2.4 느린 지표(S) — 여러 버스트에 걸친 추세

| 지표 | 정의 | 물리 해석 | 근거 |
|---|---|---|---|
| S1 부하 체류 비율 | 10분 창의 부하 버스트 비율. 정상 생산 구간 분포 대비 | 내부누설 → 어큐뮬레이터 충전 시간 증가(η_v 0.95 → 0.82면 약 1.16배) | R1 ①, R5 F7 |
| S2 무부하 전류 기준선 | 무부하 버스트 A60의 이동 중앙값 | 전원 전압 변화(정상) 대 자화 특성 변화 | R1 표 (b) |
| S3 지표 추세 | M1–M6의 EWMA | 서서히 진행하는 열화 | R4·R5(CUSUM/EWMA) |

### 2.5 금지 특징과 방향 규칙

- **금지:** 숫자 자릿수, 고유값 수, 최소 간격, 절대 시각, 요일, 행 번호, 파일 출처, TimeStamp 자체. 코드 단위 테스트로 막는다 [D2-1][R3].
- **방향 규칙:** M·E 지표는 악화 방향 단측 검정이다. "너무 조용함"은 L0으로 보낸다. 파일럿에서 본 대기 구간 오경보의 원인이 양방향 판정이었다 [D8].
- **채널 규칙:** 정지 검토(3단계)는 기계 채널 증거가 있어야 한다. 전기·계측 채널만의 경보는 "전기·계측 점검" 카드로 간다.

## 3. 탐지기 후보 (L3) — 서로 다른 패러다임

노력: S ≤ 0.5일, M ≈ 1일, L ≥ 2일(한 도구 기준).

### 3.1 기준선(반드시 보고) — 시계열 이상탐지 벤치마크 비판이 요구하는 비교 [R3]

| 코드 | 기준선 | 용도 |
|---|---|---|
| B-const | 상수 "모두 정상" | 정확도가 왜 무의미한지 보임(행 기준 97.09 %) |
| B-rand | 무작위 점수 | 점수 보정 없는 지표가 어떻게 속는지 보임. point-adjust는 쓰지 않음 |
| B-range | 센서 범위 이탈(정상 학습 min/max 밖) | 최소한 넘어야 할 기준 |
| B-rms | 버스트 RMS 자체를 점수로 | 진폭 이상 기준 |
| B-one | 한 줄 규칙 max\|AI0\| | 이 데이터의 사소함(triviality)을 수치로 |
| B-1nn | 정상 학습 대비 1-NN 거리 | 강한 비모수 기준 |
| B-pca | PCA 재구성오차(SPE) | 벤치마크에서 딥 모델보다 강했던 기준 |
| B-shew | 단측 Shewhart(버스트 RMS 관리도) | 현장 해석이 가장 쉬움 |
| B0 | **가이드북 LSTM-AE 원본 재현**(분할·\|x\|·창 20·"+100"·P=R 임계 그대로) | 공식 베이스라인 |
| B0′ | B0 교정판: 버스트 안 창, 원신호, 정상 보정 conformal 임계, 우리 분할 | "검증 설계를 바로잡으면 무엇이 바뀌나" |
| B0-rnd | B0와 같은 구조, 학습 안 한 무작위 가중치 | 학습 효과 분리 |

탐침(probe):
- P-leak: TimeStamp만, 행 번호만 쓰는 분류기 → 입력에서 뺐음을 증명
- P-short: 전류 동역학만 쓰는 탐지기 → 지름길 상한
- P-order: 버스트 안 샘플 순서를 섞은 입력으로 시퀀스 모델 재평가 → 진폭 의존인지 동역학 의존인지

### 3.2 주력 후보

**A. PHI-C — 물리 건강지표 + 상태별 conformal (주력 1)**
- **무엇:**
  1. M1–M6과 E1–E3 각각에 대해, 같은 부하 상태 정상 분포 기준의 단측 conformal p값을 낸다(Mondrian conformal).
  2. 채널 안에서 p값을 Cauchy 결합으로 합친다. Cauchy 결합은 유의수준이 작을 때 지표 간 의존 구조와 무관하게 근사적으로 유효하다(Liu & Xie, JASA 2020). 정확한 보장은 아니므로 실제 경보율을 함께 보고한다.
  3. 기계 증거 p_M과 전기·계측 증거 p_E를 따로 낸다.
  4. 이유 코드는 가장 작은 p값의 지표다.
- **왜 여기서:**
  - 오경보 원인(운전 상태, 양방향 판정, 계측 변동)을 구조로 막는다.
  - 상태별 오경보율을 직접 정한다. ISO 17359 §8.4의 "고장인지 운전조건 변화인지 구별"을 구현하는 형태다 [R9].
  - 경보 이유가 물리량으로 바로 나온다.
- **약점:** 지표 밖의 고장 형태는 못 본다(→ C·D와 결합). 상태당 보정 표본이 적다(→ 교차 conformal, 상태 병합 [P6.1]).
- 노력 M. Tier 1.

**B. 상태별 MSPC + CUSUM/EWMA (주력 2, 산업 표준 비교군)**
- **무엇:** 상태별로 PCA T²·SPE를 계산한다. 원인 변수는 재구성 기반 기여(RBC)로 보인다.
  - 기계 채널 HI에 단측 CUSUM·EWMA를 건다.
  - **정상 ARL₀를 경보 예산(예: 교대당 1회 ≈ 3,700 버스트)에 맞춰 설계한다** [R9 I-09].
- **왜:**
  - 공정감시에서 가장 익숙한 방식이다.
  - 작은 지속 변화의 누적 감지, 즉 조기탐지에 이론적 근거가 있다(ARL).
  - SPC run rule을 덧붙이면 ARL₀가 370 → 166으로 줄어 오경보가 는다. 그래서 run rule은 쓰지 않는다 [R9].
- **약점:** 다변량 omnibus 거리는 한 방향 변화를 희석한다(R3: 6특징 MCD에서 두 진동 ×2 증가가 1 %만 탐지). → SPE·단측 HI 위주로 판정한다.
- 노력 M. Tier 1(MSPC) / Tier 2(CUSUM 설계).

**C. 범용 단일 클래스 ML (비교군)**
- **무엇:** kNN 거리(주), Isolation Forest(참고), LOF·OCSVM(Tier 2). L2 특징 + 통계 특징 → conformal p.
- **왜:** "AI 모델" 비교군이다. 사람이 설계한 지표 밖의 이상도 본다. 문헌상 전역 이상에는 kNN이 강건하다 [R3].
- **약점:**
  - IForest는 정상 부하 변화에 운다(파일럿 20–39 %, R3 FA 17.9/h) [D8].
  - 범위 밖 점수가 포화되는 문제도 있다.
- 노력 S. Tier 1(kNN, IF).

**D. 합성 고장 이상노출 분류기 OE-GBM (주력 3, 확률 모델)**
- **무엇:**
  1. 학습 정상 버스트(0)와, 같은 버스트에 개발용 계열을 강도별로 주입한 버스트(1)로 분류기를 학습한다.
     - 분류기: scikit-learn `HistGradientBoostingClassifier`
     - 특징: L2 지표 + 통계
  2. 물리 방향이 분명한 지표에 **단조 제약**(`monotonic_cst`, 이진 분류에서 지원 확인)을 건다. "같은 부하에서 진동 초과가 커지면 이상 확률이 줄 수 없다"를 강제한다.
  3. 확률은 보류 합성 혼합에서 보정한다.
  4. 현장 사전확률로 베이즈 조정한 **기저율 시나리오별 확률**로 낸다(4절).
- **왜:**
  - "이상 확률"을 직접 낸다.
  - 불균형 학습·확률 보정·제조 지식 결합을 한 모델에서 보인다.
  - **실제 이상 데이터를 한 번도 보지 않고 학습하므로 실제 에피소드가 진짜 보류 시험이 된다.**
- **약점:** 합성 계열을 외울 위험(순환 논리). 문헌에서도 인공 손상으로 학습한 모델이 실제 손상에서 "quite low"였다(Lessmeier, R5).
  - → 학습에 쓴 계열은 평가에서 빼고(leave-one-family-out), 계열별로 보고한다 [P3].
  - 아주 작은 강도는 라벨 잡음이 된다 → 강도 하한을 둔다.
- 노력 M. Tier 1.

### 3.3 보조·확장 후보

**E. 시퀀스 딥러닝 (교정판 오토인코더 / 예측 잔차)**
- 버스트 안 시퀀스(최대 50샘플)에 작은 1D-CNN 오토인코더나 TCN을 학습한다. 잔차 → 상태별 conformal p.
- 시계열 기초모델(MOMENT: MIT, Chronos: Apache-2.0)은 Tier 3 부록 실험으로 둔다.
  - Moirai 가중치(CC-BY-NC), TimesFM 3.0 가중치(비상업)는 쓰지 않는다 [R3].
  - 버스트 ≤ 50샘플이라 입력 대부분이 패딩되는 한계도 적는다.
- 벤치마크 연구들은 단순 방법이 자주 이긴다고 보고한다 [R3]. 결과를 그대로 보고한다.
- 노력 M(E), L(기초모델). Tier 2 / 3.

**F. 모델 기반 고장진단(시스템 식별)**
- AR(2) 극 추적은 E1의 시스템 식별 판이다. 부하 → 톤 진폭 패리티 잔차는 M6의 동역학 판이다.
- 정보가 A와 같으므로 **A의 지표 정의 근거로 흡수**한다. 별도 후보로는 Tier 3이다.

**G. 베이즈 고장상태 필터 (L5 상위안이자 확률 산출 방식)**
- 숨은 상태 {정상, 고장}의 2상태 HMM이다.
  - 전이: 고장 위험률(사전)
  - 방출 우도비: POD/PFA에서 얻은 우도비, 또는 D의 보정된 오즈
  - 출력: P(지금 고장 상태 | 지금까지 데이터)
  - Shiryaev–Roberts·CUSUM 같은 최적 변화 탐지와 같은 계열이다 [R4].
- **왜:**
  - "이상 확률"을 사전확률이 명시된 사후확률로 낸다.
  - 지속성(증거 누적)이 확률식 안에 들어간다.
  - 조기탐지(작은 증거 누적)와 오경보 통제를 한 식으로 다룬다.
- **위험:** 고장률 사전은 데이터로 추정할 수 없다. → 사전확률 민감도 표를 붙인다.
- 노력 M. Tier 2.

**H. 지도학습 대조 모델 (정상 vs 실제 이상) — 지름길 시연용**
- 실제 레이블로 학습한 GBM이다. 실제 이상에서는 만점일 것이다.
- 보류 합성 계열은 놓치고 정상 변화·계측 스트레스에는 운다는 것을 보이는 **대조군**이다 [P7 C11].
- 최종 후보에서 뺀다. 노력 S. Tier 1.

## 4. 보정·결합(L4)과 경보(L5)

| 결정 | 기본안(Tier 1) | 상위안(Tier 2) | 근거 |
|---|---|---|---|
| 상태 구분 | 무부하 / 부하. 부하 안은 I_T 연속 조건부. 장시간 휴지는 무부하에 포함하되 별도 오류 분석 | 3상태 이상 | 상태당 보정 표본 ≥ 100 [P6.1] |
| 보정 집합 | 교차 conformal(out-of-fold). 표본 효율은 좋지만 보장은 분할 conformal보다 약하다(jackknife+/CV+ 이론 하한 1−2α). 그래서 실제 FAR을 반드시 같이 보고 | 분할 conformal(표본 충분 시) | Vovk 2015, Barber et al. 2021 |
| 지표 결합 | 채널별 Cauchy 결합(Fisher는 독립 가정이 필요해 제외) | D의 학습된 결합 | Liu & Xie 2020 |
| 확률 | ① conformal p값(정상 꼬리 확률, "P(고장)이 아님" 명시) ② **기저율 시나리오별 사후확률**: P(고장\|x) = POD·π / (POD·π + PFA·(1−π)). π ∈ {10⁻³, 10⁻⁴, 10⁻⁵}/버스트 | G 필터 사후확률 | R3, R4, R5, R9 |
| 조치 임계값 | **비용–손실 규칙: P > p\* = C_I / (C_U − C_P)**. 비용비 1:10–1:1000 민감도 표 | decision curve, 상대 경제가치 그림 | R9 |
| 지속성 | 2-of-3 버스트 on-delay, 3 버스트 off-delay, 극단값(물리 한계 초과) 즉시 경로 | CUSUM(ARL₀ = 예산) 또는 G | R9(지연이 무의미 경보를 크게 줄이지만 지연 비용이 있음) |
| 부분 버스트 판정 | 버스트 끝에서만 | 접두 k행마다 보정 | — |

**경보 체계** — ISA-18.2식 경보 정의표(결과·대응시간·조치·근거)로 문서화한다 [R9]:

| 출력 | 조건(초안) | 의미·대응 |
|---|---|---|
| 정상 | — | — |
| 1 관찰(알림) | 기계 또는 전기 결합 p < α₁ 버스트 1개 | 교대 기록만 |
| 2 점검 권고 | 기계 채널 2-of-3 지속, 또는 사후확률 > p\* | 이유 코드별 점검 카드 발행, 교대 안 점검 |
| 3 정지 검토 | 기계 채널 물리 한계 초과(예: 부하 보정 진동이 정상 최대의 3배 이상), 또는 사후확률 > 0.95가 3 버스트 지속 | 반장 호출, 정지 여부 판단 |
| 계측 점검(별도) | L0 플래그, 또는 전기·계측 채널만 지속 | 센서·케이블·DAQ 점검. 기계 경보로 세지 않되 숨기지 않음 |
| 판정 보류 | 지지 범위 밖, 짧은 버스트 | 다음 버스트 대기 + 기록 |

조건의 구체 값(α₁, k-of-n, 물리 한계 배수)은 04 문서의 경보 예산과 FA/h–지연 곡선으로 확정한다. 그때 R4가 제안한 아래 강화 조건도 후보로 함께 비교한다.
- 경고: 두 진동 채널이 모두 증가하고, CUSUM 주 예산 임계를 넘고, 10분 이상 지속
- 위험: 모든 보정 버스트를 넘음(p = 1/(n+1)) + 크기 기준 + 2채널·2버스트 일치

위험 단계에는 지속성 규칙 없이 바로 가는 빠른 경로를 남긴다. 큰 변화에서는 Shewhart형 단일 판정이 누적형보다 빠르기 때문이다.

## 7. 이 계획의 차별점 (경쟁팀 공개 결과와 겹치지 않는 축)

1. **샘플링 주기 재해석(S1k 가설)과 그 물리적 검증.** 슬립 비, 실시각 2.9초 사이클, 60.0 Hz가 근거다. 다른 팀들은 "0.6 Hz 앨리어싱"에서 멈췄다 [D2-2][R2].
2. **두 독립 부하 추정(전류 I_T, 진동 슬립 ŝ)의 물리 일관성 잔차.** 정상 운전 변화와 전기·계측 이상을 가르는 장치다 [R1].
3. **기계 채널과 전기·계측 채널 분리, 계측 스트레스 시험, 수집 건전성 층.** 데이터가 계측 교란을 안고 있다는 진단에 정면으로 답한다.
4. **부하 대리변수의 함정 분석과 보수적 부하 매칭.** "상부진동 초과 중앙 4.2배"가 고장 쪽 근거다 [D4-1].
5. **사전등록 MAPOD형 검출한계**(계열별 a50/a90, 평균 POD 금지), 램프 검출지연, 식별 불가 쌍 명시 [R5].
6. **경보 예산 공학.** ARL₀ = 교대당 1회 설계, k-of-n 산술, FAR–MAR–AAD 교환. "검증 가능한 오경보 하한"도 정직하게 밝힌다 [R3][R9].
7. **기저율 시나리오 확률 + 비용–손실 임계값 + 자연빈도 표현.** "확률"의 의미를 운영 언어로 옮긴다 [R9].
8. **같은 수행기관 데이터셋까지 본 출처(provenance) 진단** [D2-1].
