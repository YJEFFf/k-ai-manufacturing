# 프레스 유압펌프 통합 연구 계획

2026-10-02 · 계획 확정판 1 · 작성 Codex · 원안 비교 `6a8961d`·`108409d` · 추가 검토 `2cc5400`

**주력 연구는 관측된 운전 조건을 고려하는 진동·전류 변화 탐지다.** 전류에서 얻은 조건 대리값과 진동의 관계를 정상 자료로 학습하고, 조건을 설명하고도 남는 변화가 있는지 살핀다. 전류가 평소 패턴을 벗어나 조건화에 쓸 수 없을 때도 진동 판정을 계속한다. 기존 v2와 단순 모델을 같은 조건에서 비교하고, 증강과 외부 자료로 개선의 범위를 확인한다.

이 계획은 Codex의 [10월 1일 계획](../press_research_2026-10-01/README.md), Claude의 [10월 2일 수정 계획](../press_research_claude_2026-10-01/README.md)을 비교하고, 작업 중 커밋된 [Claude의 추가 통합안](../press_plan_merged_2026-10-02/README.md)까지 검토한 권고안이다. 원본은 보존한다. **이번 작업의 통합 권고 기준은 이 폴더다.** 이전 문서의 더 많은 후보·강한 물리 해석·다른 평가 규칙은 참고 자료이며 자동으로 합쳐지지 않는다.

이번에 수행한 것은 문서·기존 코드·저장된 결과 검토, 공식 자료 재확인, 계획 작성이다. 새 모델, 학습, 고장 주입, 성능 재계산, 외부 센서 원자료 취득, 보고서·발표자료 작성은 하지 않았다. 이후 실행 항목은 별도의 실행 지시가 있을 때 착수한다.

## 1 연구 질문과 선택 이유

주 질문은 **관측 조건이 바뀌어도 정상의 확인 요청을 줄이면서, 작은 신호 변화·지속 변화·전류 정보 부족 상황의 탐지력을 유지할 수 있는가**다. 예상 효과는 가설이며, 아직 개선을 입증한 결과가 아니다.

이 질문을 고른 이유는 세 가지다.

1. 과제의 정상 운전변화 오경보 요구와 직접 연결된다. 기존 v2의 실패 기록과 Claude의 조건별 진동·시간 변화 진단을 함께 활용할 수 있다.
2. 현재 세 센서로 검토할 수 있다. 압력·유량·회전수·실제 단위를 먼저 알아야만 작동하는 물리식에 의존하지 않는다.
3. 틀렸을 때의 결론이 명확하다. 조건화가 고장 단서를 지우거나 단순 모델보다 나아지지 않으면 조건화를 채택하지 않는다.

비교 대상 중 기존 v2와 단순 모델도 최종안이 될 수 있다. 새로운 이름의 모델을 반드시 승자로 만들지 않는다. 계획의 중심을 정하는 것과 실험 전 최종 성능 순위를 확정하는 것은 다르다.

## 3 현재 근거의 상태

| 근거 | 이용할 수 있는 의미 | 넘지 않을 범위 |
|---|---|---|
| 정상 20,000행과 이상 600행 | 제공 라벨의 탐색적 구분, 정상 내부의 조건별 오류 분석 | 행을 독립 사례로 세지 않음 |
| 이상 파일의 여러 기록 | 한 수집 에피소드 내부의 변화 | 21개 독립 고장 또는 새 날짜 검증으로 취급하지 않음 |
| 전류의 약 0.06 주기/표본 패턴 | 표본 순서 기반 파형 특징, 조건 대리값 후보 | 취득 속도·실제 60 Hz·토크를 확정하지 않음 |
| 서로 다른 수치 격자와 저장 형식 | 계측·처리 경로 차이의 유력한 단서 | 배율 역산으로 A/g 단위·전동기 정지를 확정하지 않음 |
| 진동의 차분 격자·기록 평균 차이 | 공통 평균 제거 감사를 추가할 근거 | 실제 감도·특정 장비·처리 과정을 유일하게 식별하지 않음 |
| Claude의 단측 0 대 양측 16.9% 대기 구간 경보 | 저장된 파일럿의 해당 조건 결과. 단측 비교의 동기 | 일반적 오경보 개선이나 감소형 이상 탐지 유지의 증거는 아님 |
| Claude의 2.9006초 주기·시간 잔차 추세 | 추가 검증할 관측 구조 | 실제 스트로크·유온·열 드리프트의 확정 측정은 아님 |
| 기존 UCI 적용 실패 | 순간 변화와 느린 수준 변화가 다른 문제라는 근거 | 새로운 외부 시험 또는 프레스 범용성의 증거는 아님 |

정상 기록 수 600과 599는 경계 규칙이 다른 데서 나온다. 과거 분할을 보존하고, 새로운 공통 비교에서는 중복 처리와 경계를 통일한다. 상세 규칙은 [검증 명세](02_protocol.md)에 있다.

## 4 최소 모델 구성

흐름은 **기록 구성 → 관측 품질 표시 → 특징 → 정상 기준과의 차이 → 정상 꼬리 순위 → 확인 요청과 이유**다.

| 구성 | 기본 결정 | 설명 |
|---|---|---|
| 관측 품질 | 결측·중복·시각 오류·전류 패턴 부적합을 표시 | 품질 표시로 이상 기록을 평가에서 삭제하지 않음 |
| 조건 대리값 | 전류의 표본 단위 사인 진폭 | 실제 부하라는 명칭 대신 관측 전류 조건을 사용 |
| 기본 특징 | 진동 RMS·크기, 전류 RMS·파형 적합 잔차, 두 진동의 관계 | 단위 미상 그대로 계산하고 정상 기준과 비교 |
| 조건부 모델 | 진동 log RMS를 전류 조건으로 설명하는 1차·2차 회귀 | 같은 조건의 정상에서 벗어나는 정도를 학습 |
| 전류 부적합 | 조건부 진동식을 외삽하지 않고 전역 진동 기준 사용 | 전류 단독 변화는 별도 이유로 계속 탐지 |
| 방향 비교 | 잔차 양측을 기본으로 하고 증가 방향 단측을 경쟁 후보로 둠 | 단측 채택은 감소·소실 변화에서 잃는 탐지력을 포함해 결정 |
| 보정 | 학습과 분리한 실제 정상 보정 부분에 고정 모델 적용 | 작은 자료를 상태별로 잘게 나누는 보정은 기본에서 제외 |
| 확률 | 정상 꼬리 p값과 제공 라벨 확률을 별도 출력 | 합성 여부·기준 혼합비·학습 그룹을 기록 |
| 알림 | 우선 즉시 요청 1종으로 모델 비교, 이후 지속성 효과 분리 | 계측 확인·판정 유보 요청도 총 부담에 포함 |

물리 해석은 특징 선정의 아이디어다. 예를 들어 진동의 특정 대역은 우선 주기/표본 단위로 다룬다. 펌프 날개 통과 주파수, 전동기 정지, 고장 부위로 이름을 확정하지 않는다.

새로운 모델의 비교는 다음 범위로 고정한다.

| 모델 | 역할 | 첫 단계 포함 |
|---|---|---|
| 동결 v2 | 이전 결과를 그대로 보존하는 기준 | 필수, 원래 A/B 표로 별도 보관 |
| 동일 조건에 재적합한 v2 구조 | 새 분할에서 기존 방식과 공정하게 비교 | 필수 |
| 전역 크기·파형 점수 | 조건화 없는 간단한 기준 | 필수 |
| 조건부 잔차 모델 양측·단측 | 주력 가설 비교 | 필수 |
| 같은 특징의 kNN | 점수 결합 방식의 효과 분리 | 필수, k=5·10만 |
| 합성 이상 노출 GBM | 합성이 간단한 모델보다 추가 이익을 주는지 | 증강 단계의 조건부 후보 |

가이드북 LSTM-AE는 출처와 학습 조건을 붙인 참고 비교다. Claude의 60 epoch 결과를 800 epoch 원설정의 완전 재현으로 부르지 않는다. 재현을 선택하면 실제 사용한 창·점수·문턱을 일치시킨 별도 표를 만든다. 전체 기록을 보는 모델과 시점별 모델의 F1을 한 순위표에 섞지 않는다.

## 5 증강과 데이터 부족 대응

데이터 부족은 세 종류로 나눈다. **학습 변동 부족**은 제한 변형·잔차 재표본화로, **약한 변화 평가 부족**은 합성 시험으로, **독립 고장·날짜 부족**은 외부 회차 또는 실제 추가 수집으로 보완한다. 앞의 두 가지로 세 번째가 해결됐다고 하지 않는다.

증강은 모델을 하나 고정한 뒤 비교한다.

1. 실제 자료만 사용한다.
2. 같은 자료를 반복하거나 학습 가중치만 바꾼다.
3. 동일 기록 내 crop·공통 위상 이동처럼 제한된 변형을 추가한다.
4. 같은 조건의 다변량 잔차를 묶음으로 재표본화한다.
5. 합성 이상에 노출시킨 GBM을 비교한다.

비율은 실제 학습 기록 대비 0·0.5·1배다. 학습 횟수 효과를 분리하고, 실제 평가가 개선될 때만 2배를 후속 검토한다. 생성기는 정상 자료만으로 시작할 수 있지만, GAN·VAE·확산 모델은 위 비교가 끝나고 독립 회차가 확보된 경우의 후속 후보 하나로 제한한다. 금지한 방법으로 단정하지도, 최소 구성에 넣지도 않는다.

주입은 기계 고장명이 아니라 **관측 신호 변화**로 정의한다. 광대역 증가·충격·협대역 변화·전류 파형 훼손·지속적인 수준 변화·관계 변화가 대상이다. 센서 이득과 진동 변화처럼 관측만으로 구별하기 어려운 경우는 어느 한쪽의 무조건 정답으로 학습하지 않는다.

보류 주입 계열은 모델 적합·선택에 쓰지 않는다. 다만 같은 팀이 특징과 주입 계열을 설계했으므로 완전히 독립적인 실물 고장 검증은 아니다. 작은 크기의 탐지는 민감도이고, 실제 고장보다 먼저 경보했다는 선행시간과는 구분한다.

## 6 외부 검증의 첫 선택

**첫 외부 검증은 원저자 GitHub판 SKAB v0.9로 계획한다.** 고정 커밋은 `b2c0d46c2971dcbfe71e26087b6d231998bb91c2`이며, 파일 목록과 분할은 [예약 명세](evidence/skab_split_reservation.json)에 기록했다. 이번에는 README·라이선스·파일 목록만 읽었고 센서 CSV는 취득하지 않았다.

선정 이유는 여러 실험 파일, 진동 RMS·전류 관측, 이상·변화점 표기가 있어 정의된 변화 이후의 탐지와 오경보를 함께 비교할 수 있기 때문이다. 프레스 원시 파형과 다른 표현이며 유압유 프레스의 실증으로 쓰지 않는다. 프레스에서 학습한 가중치를 옮기는 대신 동일한 정상 기준 학습 절차를 외부 정상 자료에 재적합하는 방법 검증이다.

GitHub판은 GPL-3.0 표기이며 과거 조사한 Kaggle판의 AGPL 표기와 혼합하지 않는다. 실제 도입 단계에서 파일별 조건·라벨·시간·회차를 확인하고 제출에 필요한 제공 형태를 정리한다. 원본 재배포가 해결되지 않으면 해당 자료를 제출 입력에 포함하지 않는다. **접근·라벨·이용 조건이 충족되지 않으면 새로운 외부 검증을 완료했다고 하지 않고 내부 연구 범위로 마감한다.** 이미 사용한 UCI로 이름만 바꾸어 독립 검증을 대체하지 않는다.

다른 질문을 위한 후속 자료는 유지한다. PHM 2022는 새 개체 정상 참조, Beihang은 조건·주입 고장, AI4EU는 운전 패턴 변화를 위한 후보다. Claude의 NLN-EMP는 전류·진동 고장 종류 확장 후보로 편입한다. 이번 필수 구현 범위에는 동시에 넣지 않는다.

## 7 검증과 모델 선택

주 비교는 완성된 기록을 같은 시점에 판정하는 방식이다. 기록의 닫힘을 알 수 있는 시각을 지연에 포함한다. 시점별 예측은 그 시점까지의 입력만 쓰는 별도 표로 평가한다.

정상 평가에는 앞 시기에서 학습·보정하고 뒤 시기를 평가하는 세 구간을 둔다. 조용한 후반부 결과만 고르는 것을 막고, 10분 블록별 결과도 공개한다. 블록을 빼고 나머지 전체로 학습하는 검증은 후반 자료를 이용하는 회고 분석이므로 온라인 일반화와 구분한다.

모델을 바꾸는 기준은 다음과 같다.

- 같은 명목 문턱의 실제 오경보 차이와 동일 부담에서의 탐지 차이를 함께 본다. 명목 α가 같다는 이유로 실제 부담도 같다고 가정하지 않는다.
- 정상 요청이 줄어도 특정 변화 종류의 탐지가 크게 떨어지면 채택하지 않는다. 전류 단독 변화·진동 감소·짧은 기록·조건화 불가 상황을 포함한다.
- 복잡한 모델은 사전에 정한 실용 개선 기준을 넘어야 한다. 효과가 작거나 방향이 불안정하면 단순 모델을 유지한다.
- 데이터 누수·미래 정보·분모 누락 같은 필수 조건을 통과하지 못한 모델은 선택하지 않는다. 전부 실패하면 재설계 필요로 끝낸다.
- 프레스 기존 자료의 결과는 탐색적이다. SKAB의 예약된 시험 파일을 열어 수정하면 그 파일은 이후 개발 자료로 상태를 바꾼다.

정확한 설정·비교 순서·수치 기준은 [검증 명세](02_protocol.md)에 고정했다. 수치 기준은 계획상 선택이며 현장 허용 비용을 검증한 값이 아니다.

## 8 실행 단계와 범위

| 단계 | 완성 상태 | 다음으로 넘어가는 조건 |
|---|---|---|
| 1 공통 기준 | 원본·기록·시각·분할·지표가 연결되고 단순 기준선이 끝까지 실행됨 | 분모와 인과성 확인 |
| 2 주력 비교 | v2 구조·조건부 모델·kNN의 같은 조건 비교, 확률 출력의 정의 | 복잡도 대비 이익 판단 |
| 3 증강과 변화 시험 | 무증강 대조, 개발·보류 계열, 지속 변화·전류 부적합·드리프트 평가 | 학습 효용과 손실 구분 |
| 4 외부 검증 | 예약 파일의 검수·외부 정상 재적합·시험 평가 | 주장 범위 확정 |
| 5 결과 고정 | 설정·출처·실패 사례·재현성 검수, 이후 의사결정 자료 | 구현 지시 범위의 종료 |

각 단계는 전처리에서 결과표까지 이어지는 완결 상태로 남긴다. 기존 계획의 UI·복잡한 운영 단계·추가 신경망은 앞 단계보다 먼저 만들지 않는다. 예상 공수, 2인 분담, 마감 대응은 [실행 계획](04_execution.md)에 있다.

## 9 확정된 것과 조건부인 것

**계획 단계에서 확정한 것:** 주 질문, 최소 모델 범위, 공통 데이터·시간 단위, 증강 비교군, 외부 첫 후보와 파일 분할 방식, 채택·중단 규칙, 진행 순서와 축소 순서다.

**실행 후 결정할 것:** 어떤 모델이 이기는지, 어떤 증강이 효과가 있는지, 외부 자료에서도 이익이 있는지다. 이를 알아야 계획이 완료되는 것은 아니다.

**외부 확인이 필요한 것:** 실제 취득 속도·단위·운전/정비 이력이다. 확인되지 않을 때는 표본 단위·관측 조건·원인 미확정 출력으로 계속할 수 있게 설계했다. 현재 팀 가용 시간은 미확인이라 일정은 조건별로 제시한다.

가장 강한 남은 반론은 조건 대리값인 전류 자체가 고장·계측 변화의 영향을 받는다는 점이다. 조건부 모델이 이를 정상화해 버리면 전역 모델이 더 낫다. 이 반론을 전류 정보 부족 시험, 원 특징 유지, 외부 회차 비교로 시험한다. 두 센서군만으로 해결되지 않는 경우는 추가 센서·현장 기록이 필요한 한계로 남긴다.
