# 데이터 진단 (자동 생성)

입력: `press_data_normal.csv`, `outlier_data.csv` (해시는 manifest.json). 주 전처리: `matched`.

## 1. 구조

| 항목 | 정상 | 이상 |
|---|---|---|
| 행 (잘못된 행) | 20,000 (0) | 600 (0) |
| 기간 | 2022-07-12 00:00:00 ~ 01:16:55 | 2022-07-17 10:51:07 ~ 10:53:53 |
| 경과 시간 / 기록 시간(0.1초×행) | 76.9분 / 33.3분 | 2.8분 / 1.0분 |
| 기록구간(Δt≠0.1초에서 끊음) | 600 | 21 |
| 구간 길이 최소/중앙/최대 (50행 구간 수) | 1/37/50 (202) | 3/28/50 (5) |
| 중복 타임스탬프 / 결측 | 1 / 0 | 0 / 0 |
| `Equipment_state` 값 | [0] | [1] |
| Δt 정확히 0.1초 / 0초 / 0.15초 초과 공백 | 19,400 / 1 / 598 | 579 / 0 / 20 |
| 0.15초 이하 Δt의 SD (0초 포함 / 제외) | 0.718ms / 0.000ms | 0.000ms / 0.000ms |
| 구간 내 lag-1 자기상관 (AI0/AI1/AI2) | 0.033/0.319/0.928 | 0.718/0.651/0.827 |

- 기록구간은 타임스탬프 간격이 0.1초가 아닌 곳에서 나눈 기록 단위다. 설비 기동·프레스 스트로크·독립 고장 사건을 뜻하지 않는다.
- 0초 간격은 중복 타임스탬프이며, 0.15초 이하 Δt의 SD는 그 중복 시각을 포함할 때만 0이 아니다. 샘플링 클록 지터의 증거로 쓰지 않는다.
- 라벨은 파일 단위 상수이고 정상·이상이 서로 다른 하루씩이라 상태·파일·날짜가 교락되어 있다. 이 데이터로는 분리할 수 없다.

## 4. 전류 파형

기록구간(길이 ≥ 10) 전체에 단일 사인+상수를 0~5Hz 격자에서 적합한 사후 진단이다. 경보 특징(trailing 창 R²)과는 정의가 다르다.

| | 적합 구간 수 | R² 최소/중앙/최대 | 적합 주파수 중앙값 (사분위) | 정확히 0.600Hz인 구간 |
|---|---:|---|---|---:|
| 정상 | 530 | 0.993/0.996/1.000 | 0.600 (0.600~0.600) | 411 |
| 이상 | 17 | 0.291/0.451/0.783 | 0.220 (0.105~0.725) | 0 |

- 정상 구간의 전류는 약 0.6Hz 사인파로 잘 설명되고 이상 구간은 그렇지 않다. '60Hz 교류를 10Hz로 표본화한 앨리어싱'이라는 설명은 실제 표본화 간격을 확인하지 못한 가설이다.
- 그림 `fig_current_waveform.png`는 정상 1구간·이상 2구간(길이 50)의 측정값과 구간 전체 사인 적합이다.
