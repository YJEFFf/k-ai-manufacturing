# 과제 재선정을 위한 자료 확보 목록

기준일: 2026-09-22. **추가 자료를 확보한 뒤 다섯 과제를 다시 비교하며, 판단 기준은 오직 수상 가능성이다.** 기존 ② 용접 선택은 재검토한다. 아직 새 순위를 정하지 않는다.

## 1. 현재 확보 상태

- KAMP 무료 제조AI 데이터셋 **50종의 목록·공개 상세·가이드북 메뉴** 확인 완료.
- 현재 작업 폴더의 가이드북 PDF는 **1종**: 2022 로봇용접 예지보전(식별자 45). 77페이지 본문 검토 완료.
- 현재 작업 폴더에서 확인한 원본 데이터는 **대회 ② 용접 엑셀과 CSV**다. 다른 네 대회 원자료는 현재 폴더에 없어 다시 확보해야 한다.
- 45번 가이드북의 실습 데이터 CSV 네 개는 아직 현재 폴더에 없다.
- 나머지 가이드북과 추가 데이터 원본은 미확보다. 공개 설명을 읽은 것을 파일 확보나 원본 검증 완료로 세지 않는다.
- KAMP 다운로드는 로그인이 필요하다. 현재 도구에는 로그인된 웹 브라우저를 조작하는 기능이 없어, 로그인 후 다운로드한 파일이 로컬에 있어야 후속 검증을 진행할 수 있다.

아래는 **무료 50종 전체**를 누락 없이 관리하는 목록이다. 다섯 과제 원 자료, 관련 추가 후보, 그 밖의 범용 참고자료로 나눈다. 관련 후보에는 직접적인 데이터 보충 가능성과 분석방법 참고가 함께 있으므로 관계를 확인한다. 별도 ‘실증 데이터셋’ 메뉴나 KAMP 밖의 자료까지 모두 확보했다는 의미는 아니다.

## 5. 확보할 파일과 검증 순서

각 항목에서 가이드북 PDF, 원본 데이터 압축파일, 별도로 제공되는 실습 코드·변수 설명·라벨 설명을 함께 확보한다. 다운로드 날짜와 출처를 남긴다. 별도 파일이 없는 항목은 ‘미제공 확인’으로 기록하며, 보이지 않는다고 임의로 없다고 단정하지 않는다.

- 가이드북은 기존 ‘관련 자료’ 폴더, 원본 압축파일은 기존 ‘데이터셋’ 폴더에 저장한다. 이름이 같은 파일은 KAMP 식별자를 앞에 붙여 구분한다.
- 압축파일은 보존한 채 항목별 폴더로 모두 풀어 내부 파일 목록·행 수·열·시트·이미지·라벨을 검사한다.
- PDF의 라벨 정의·센서·수집 시기·실험 분할·평가지표를 원본과 대조한다.
- 자료 사이의 중복·동일 원천 여부와 날짜·제품·설비 단위 분할 가능성을 확인한다.
- 외부 자료 사용 허용 여부가 미확정이면 ‘제공 데이터만 사용’과 ‘추가 데이터 허용’ 두 조건으로 수상 가능성을 비교한다.
- 자료가 준비된 뒤 다섯 과제를 같은 기준으로 재평가한다. **공식 평가요건 충족, 신뢰할 수 있는 성능 검증, 기존 가이드와 차별화되는 기여, 현장 효과와 설명 가능성, 제출·발표의 설득력**을 근거로 판단한다. 이는 임의의 별도 목표가 아니라 수상 가능성을 판단할 근거다.
- 편의성·개인 취향을 별도 가점으로 두지 않는다. 난이도나 소요시간은 최종 결과의 완성도와 실패 가능성에 영향을 주는 범위에서만 고려한다.

자료와 데이터는 로컬에 관리한다. GitHub에는 기존 사용자 지시대로 데이터셋·관련 자료를 올리지 않는다.
