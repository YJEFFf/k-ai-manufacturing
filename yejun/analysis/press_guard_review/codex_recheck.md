## 발견 및 수정

### R1. 검증·동결의 완료 판정 누락 (높음)

원본을 건드리지 않고 임시 복사본으로 재현했다. 수정 전 아래 다섯 경우 모두 종료 코드 0 또는 빈 오류 목록이었다.

| 실제 반례 | 수정 전 결과 |
|---|---|
| `audit.json`의 `checks`를 빈 목록으로 변경, `all_ok` 유지 | verify 통과 |
| `manifest.json`의 `code_hashes`를 빈 객체로 변경 | verify 통과 |
| 분석 요약의 v2 미탐을 A/B 모두 0으로 변경 | verify 통과 |
| 불확실성 표 `boot_mean`에 123을 더한 뒤 `--freeze` | 잘못된 표를 새 기대값으로 동결 |
| 격리한 코드 경로에서 `analyze.py`·`audit.py`·`serve.py`를 오류 코드로 교체 | integrity 오류 없음 |

원인: 필수 항목 대신 manifest에 있는 항목만 순회했고, 분석 산출물과 예측·그림은 실행 해시 검사에서 빠져 있었다. audit를 데이터 해시에만 연결해 코드·모델·분석 결과가 바뀌어도 같은 데이터이면 과거 검사를 재사용했다. 기대값도 존재 여부만 확인했다.

`contracts.py`에 필수 코드/파일/검사 14개를 명시했다. 학습 → 분석 → audit 실행을 해시 식별자로 연결하고, 분석 갱신 시 이전 audit 연결을 무효화한다. 분석 원본의 v1 예측·기준모델 표와 후보 실행 코드도 확인한다. verify와 freeze는 누락·변조·오래된 검사·설정 불일치를 거부하고, 기대값의 내용 해시도 검증한다. 웹 성능 탭도 현재 파일과 연결되지 않은 과거 검사를 통과로 보여주지 않는다.

추가로 CSV 비교에서 NaN/+inf/−inf를 서로 구분하고 정수 열을 float로 바꾸어 미세하게 수정해도 잡도록 고쳤다. 서명 없는 manifest 자체까지 일관되게 다시 쓰는 공격을 막는 암호학적 인증은 아니며, 커밋된 기대값과 Git 이력이 최종 출처다.

### R2. 계산 불가 점수를 0으로 표시 (중간)

API는 아직 창이 차지 않은 성분을 `null`로 보내는데 JS의 `Number(null)`은 0이다. 결과적으로 첫 두 전류 예측 점수와 첫 다섯 파형 점수가 실제 관측값 0인 것처럼 그려졌다. 차트의 범위·선·레이블·마커에서 결측을 제외하도록 수정했다. 모델 예측은 영향을 받지 않았다.

### R3. 재생·큰 업로드·필터 상태 (중간)

- 재생 슬라이더를 0으로 내린 뒤 그래프에 마우스를 대면 없는 행을 읽어 예외가 발생하는 경로를 차단했다.
- 허용된 50,000행 한 구간의 성분 150,000개를 `Math.min(...values)`에 전달하던 호출 인자 한계를 제거했다.

## 토의 항목에 대한 판단

1. **패키지 구성:** 현재 두 디렉터리를 유지하고, 향후 배포는 하나의 묶음·하나의 진입 안내로 제공하는 편이 낫다. v2는 v1의 공통 코드뿐 아니라 `analysis/press_advance`의 비교 자료에도 의존한다. v2 폴더만 떼어 배포하면 재현되지 않는다. 검증된 v1을 지금 물리적으로 합치는 변경보다 명시적인 의존 구조를 유지하는 편이 범위가 작다. ZIP 조립은 아직 하지 않는다.
2. **α=3% B 표기:** 감출 여지가 없는 운영상의 대가다. 같은 α=3%에서 v1 4/180 → v2 5/180, α=5%에서는 6/180 → 7/180이다. v2 자체도 1%→3%에서 정상 알림 3→5구간, FP 행 3→7, FN은 31로 동일, F1은 0.970990→0.967687이다. 주 비교는 기존 α=1%를 유지하고 3/5%는 대안 운영점으로 수치를 함께 보이는 판단에 동의한다.
3. **위치 0·1 개선 불가능 주장:** 현재 AR(2)·사인 창으로 계산할 수 없다는 판단은 맞지만, 다른 방법까지 불가능하다는 결론에는 동의하지 않는다. 위치 0은 세 센서의 공동 정상 분포, 위치 1은 두 관측의 차이나 AR(1) 잔차를 시험할 수 있다. 개선된다는 증거는 아직 없으며 같은 자료 재탐색·오경보 증가 위험이 있다. 새 후보를 소수로 고정하고 정상 보정을 다시 거쳐 주 α에서 정상 알림을 늘리지 않는지 확인해야 한다. 이번 재검수에서는 새 모델 탐색이나 구간 경계 통과를 하지 않았다.
