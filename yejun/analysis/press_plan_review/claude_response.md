# Codex 적대적 검토에 대한 재검토 — 2026-09-24 (Claude Code)

대상: [README.md](README.md)의 R1~R8, 추가 구현 사양, 권고안 B. 검토 방법: 코덱스가 제시한 사실 주장을 원본 zip에서 직접 재계산했다(`verify_codex_claims.py`, 저장소 루트에서 실행). 새 패키지 구현·새 창 선택 절차 실행·LSTM 학습은 하지 않았다.

**판정: 코덱스의 사실 주장은 전부 재현됐다. R2·R3·R5·R6·R7·R8과 추가 구현 사양은 그대로 수용한다. R1·R4는 결론은 맞지만 코덱스가 제시한 대안도 같은 종류의 관례이거나 근거가 약해, 아래처럼 고쳐 반영한다. 코덱스가 놓친 점 세 가지를 추가한다.** 계획 파일은 아직 수정하지 않았다(예준이 시작을 지시하면 "계획 수정안"을 한 번에 반영한다).

## 2. 항목별 판정

### R1 (w=8 물리 근거) — 결론 수용, 대안은 수정
- 수용: "반주기 = 최소 창"에서 8이 나오지 않는다. 현재 적합은 sin·cos·상수 + 주파수 격자 탐색이므로 "3모수" 설명도 구현과 맞지 않는다. 물리 규칙처럼 쓰지 않는다.
- 반박: 코덱스의 `ceil(...)+1 = 10`도 span 관례이며 지속시간 관례로는 9다. 어느 정수도 물리 법칙이 아니다. 따라서 "물리 규칙 → 특정 w"를 버리고, **사전 등록한 라벨 없는 규칙 + 관례 명시 + 전 후보 공개**로 간다.
- 코덱스가 말하지 않은 점: 창이 짧으면 주파수 탐색 때문에 깨진 파형도 사인으로 잘 맞는다(준용이 w=5 관찰). 이는 통계적 성질이라 정상 데이터만으로는 절반(정상 R² 분포의 조밀함)만 잴 수 있다. 그래서 w 규칙의 근거는 "정상 데이터 안에서의 안정성"으로 한정하고, 검출력은 라벨을 본 뒤에야 알 수 있음을 명시한다.
- 반영: P0-3 = 학습 내부 A/B/C 중첩 안정성 규칙(주), 반주기는 후보 범위의 타당성 근거(관례 명시)로만, 후보 집합 {5..12}가 라벨 실험 뒤 고정된 이력과 w=8 탐색 이력 공개, 후보 전부의 결과 표.

### R2 (α_eff·p값 해석) — 수용, 표현 통합
- 수용: 주변 경계와 고정 문턱의 미래 오경보율은 다르다. 개별 p값은 그 경보가 오경보일 확률이 아니고 1−p는 사후확률이 아니다. MC 검사는 순위 구현 검사일 뿐이다. n=120에서 α<0.83%는 경보 불가.
- 추가(R2와 R5의 통합): 문턱 = 보정 최댓값일 때 실제 초과율은 iid 가정에서 Beta(1,120)을 따르고, 그 95% 상한이 R5의 2.47%와 같은 수다. 따라서 운영점마다 **명목 예산 / 이론 경계(α_eff, 가정 명시) / 실측 정상 알림 수 / 독립 가정 95% 상한** 네 열을 한 표에 둔다.
- 코덱스가 말하지 않은 점: 1% 운영점은 보정 최댓값 하나에 걸리는 고분산 운영점이다. 4장(현장활용)의 운영점 선택은 3%·5% 예산까지 포함해 부담 허용치로 정하고, 1%를 헤드라인으로 고정하지 않는다.

### R3 (지터·수집 경로 단정) — 전면 수용
- 계획 Context·1장·W6의 "지터 SD 0.7ms", "DC 오프셋", "두 파일은 수집·저장 경로가 달랐다"를 고친다. 사실로 쓸 수 있는 것: 저장 자릿수 차이, 전류 격자 차이, 중복 시각 1건, 전류 표본평균 차이. 가설로 둘 것: 수집 장치·필터·클록 차이. `Equipment_state = 파일 = 날짜`까지가 사실이다.
- 진동 두 센서만으로 18/21이 유지된다는 코덱스 계산은 2단 방어에 그대로 쓴다. 단, 인과 증거가 아님을 같은 문장에 둔다.

### R4 (꼬리 확장 경계) — 결론 수용, POT 대안은 채택
- 수용: "연속·상한 없음"은 틀린 표현이다. 1−R²∈[0,1]이라 유한 최댓값이 있고, 학습 최댓값 지점의 log10(2) 단차는 남는다. σ_tail=0 처리가 빠졌다. 가동 검사는 사인 점수의 실제 가능 범위(1−R²=1)로 한다.
- 반박: 그 단차는 제안식이 만든 것이 아니라 이산 p값의 마지막 계단이며, 죽은 성분의 원인(동점 상한)과는 별개다. 필요한 성질은 "학습 최댓값 너머에서 동점 없이 강증가"이지 연속성이 아니다. 다만 코덱스의 "성분 간 상대 스케일이 결합을 바꾼다"는 지적은 맞고, 이것이 바로 POT를 쓸 구체적 이유다.
- 반영: P0-1의 주 설계를 **POT 꼬리(정상 학습 상위 5~10%에 지수 또는 GPD 적합, 두 성분에 같은 절차)**로 바꾼다. 접합점 위에서 매끄럽고, 척도가 자료에서 추정되며, 꼬리 표본에 퍼짐이 없으면 실패로 처리한다. 계획의 조각 선형식은 대안으로 남긴다. 수정 후 표는 다시 계산하고 코덱스의 6셀 수치를 기대 정답으로 쓰지 않는다.

### R5 (0건 경보 CI) — 수용
- 관측 카운트가 주 결과. 독립 가정 정확 이항 구간을 참고치로, 블록 부트스트랩은 0이 아닌 카운트에서의 시간 의존성 민감도로만. 60/20/20 평가 구간이 50/20/30 평가 구간의 부분집합이므로 합산하지 않는다.

### R6 (LSTM 준비 구간) — 수용, 확장
- 코덱스가 말하지 않은 점: 창 길이별 행 F1 상한(미판정=미탐, 오경보 0)은 w=5 0.926, w=8 0.871, w=10 0.833, w=20 0.630이다. 준용이 표의 **사인 단독 w=8 F1 0.867은 상한 0.871에 붙어 있다.** 결합 모델의 F1 0.915가 그보다 높은 이유는 준비 구간을 max-z가 채우기 때문이다. 즉 모델 간 행 F1 차이의 큰 부분이 준비 구간 정책의 산물이다.
- 반영: 주 지표는 구간 탐지·정상 알림 부담·지연으로 두고, 행 F1은 "전체 행"과 "판정 가능 행" 둘 다 병기하며 판정 가능 구간 수를 함께 적는다. LSTM-AE는 (가) 가이드북 그대로, (나) 우리 프로토콜, (다) **같은 max-z 준비 정책 부여** 세 가지로 비교한다. 코덱스가 나열한 가이드북 세부(100시점 이동, 끝 120행 제외, 검증 분리, 학습률 감소, 마지막 시점 오차, P=R 문턱)는 W7 사양에 넣는다.

### R7 (부하 대리 지표) — 수용
- 구간 전체 진폭·진동 SD는 오류 분석용(오프라인), 경보 시점 특징은 과거 관측만(온라인)으로 구분한다. 진폭 대리 지표는 사인 적합 진폭 또는 평균 제거 RMS로 하되 **길이 17관측(약 한 앨리어스 주기) 미만 구간은 표시하거나 제외**한다. "부하"라는 이름 대신 "전류 진폭 대리 지표"로 쓴다.

### R8 (수용 기준 혼동) — 전면 수용
- 구현 정확성 검사(결정적 재현, 순서 불변, 단위테스트, 가동 검사)와 가설 채택 조건(사전 등록, 미달 시 정상적인 실험 결과)을 분리한다. 기존 21/21·0/120·1/180·F1 0.92와 코덱스의 6셀 수치를 새 코드의 기대값으로 하드코딩하지 않는다. `numbers.json`은 실제 실행에서만 생성한다.

### 추가 구현 사양 표 — 전부 수용
미래값 불변 검사(G3), k-of-n 상태 규칙 확정 후 전체 정책 보정, 기록시간/가동시간 시나리오 구분, `predict.py` 모델 산출물 계약, 캐시 키에 코드·분할·설정·시드 포함 + 캐시 없는 재학습 검증, 원본 무결성 해시와 수치 허용오차 분리 + 경보 판정 차이 확인, 형식 감사는 파일별 규칙 발화율과 양방향 판별력(AUROC≈0.5), 그림은 구간 R²와 rolling R²의 역할 명시, 정렬 검사는 모델·분할·전처리·기준·분모까지 연결, 공식 필수사항과 추가 목표 구분.

### 권고안 B와 연구 질문 — 수용
"정상 데이터로 고정한 경보 절차에서 전류 파형을 추가하면, 진동 단독 대비 어떤 기록구간을 더 탐지하고 정상 알림 부담은 얼마나 달라지는가"를 제출물의 질문으로 삼는다. 뒤집을 조건(추가 탐지가 부담 증가를 정당화하지 못하거나 사인 성분이 수집 조건에 불안정)도 유지한다. 부담 허용치는 4장 분석에서 먼저 정하고 결과에 맞춰 바꾸지 않는다.

## 3. 코덱스가 놓친 점

1. **양자화가 부담 지표를 바꾼다.** 코덱스 자신의 표에서 50/20/30 정상 알림이 raw 6 → matched 4 → coarse 2다. matched 양자화를 기본 전처리로 삼는 P0-4 결정은 "형식 정보 제거"라는 장점만 보고 정했는데, 이 표는 양자화가 정상 참조 분포(사인 R²)를 바꿔 문턱을 움직인다는 뜻이다. 원인(양자화 잡음으로 정상 1−R²가 커져 참조 꼬리가 넓어짐 등)을 W5에서 확인하고, 전처리 채택은 결과를 본 뒤 근거와 함께 결정한다.
2. **행 F1 비교는 준비 구간 정책이 지배한다** (R6 확장, 위 상한표). 모델 비교표의 주 지표를 구간 단위로 옮기지 않으면 40점 장의 근거가 약해진다.
3. **1% 운영점의 분산** (R2·R5 통합). 보정 최댓값 하나에 걸리는 운영점을 헤드라인으로 두면 심사위원의 "실제로 얼마나 울리나" 질문에 취약하다. 운영점 표에 네 열을 두고 4장에서 3%·5%를 포함해 선택한다.
