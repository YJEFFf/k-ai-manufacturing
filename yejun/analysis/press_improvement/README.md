## 실험 범위

- 프로토콜: `exploratory-performance-v1`. 실행 전에 [config.json](config.json)에 기존 대조 3개와 새 후보 5개를 기록했다. 실행 중 후보를 추가하지 않았다.
- 기존 대조: 기본 결합, 진폭 보정 결합, 기본 결합에 최근 3점 중 2점 지속성 적용.
- 새 후보: 진폭 보정+전체 지속성, 크기 성분만 지속성, 진폭 보정 크기 성분만 지속성, 초반 5→8관측 창, 초반 6→8관측 창.
- 원본 검증·A/B 분할·matched 전처리·정상 학습과 정상 보정 범위는 기본 구현과 같다. 후보마다 정상 보정 구간 최댓값으로 문턱을 다시 계산했다. 이상 라벨로 문턱을 선택하지 않았다.
- 구간 보정의 conformal 및 cutoff, α=1/3/5%를 모두 저장했다. 아래 주 비교는 conformal α=1%다.
- matched로 적합·보정한 상태를 고정하고 평가 입력만 raw/coarse로 바꾸는 검사도 모든 후보에 적용했다. 새 입력 조건에서 재학습·재보정하지 않았다.
- 이전부터 본 이상 자료를 다시 사용하며, 초반 미탐 분석을 참고해 후보를 설계했다. 후보의 성능 평가·선택은 탐색적이며 독립 검증으로 해석하지 않는다. A/B도 같은 이상 21구간을 평가한다.

- 세 기존 대조 후보의 양 분할·양 기준·모든 α 집계가 기존 CSV와 허용오차 1e-8 안에서 일치했다.
- 8개 후보 모두, 양 분할에서 이상 자료의 앞 40행만 추론한 점수와 전체 추론의 앞 40행이 일치했다.

- 기본 패키지 `outputs/` 및 `artifacts/`의 파일별 해시가 실행 전후 동일했다.
- 실행 시간 8.23초. 환경과 입력·코드 해시는 [experiment_manifest.json](experiment_manifest.json)에 기록했다.
