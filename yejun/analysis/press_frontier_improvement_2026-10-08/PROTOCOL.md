# 경쟁 모델 아이디어 융합 개선 실험 — 실행 전 계약

작성: 2026-10-08. 기존 제출본 c898be2를 보존하고 별도 개선안을 만든다.
이 데이터의 이상과 test 결과는 이미 팀에 공개되었다. 아래 절차는 추가 선택 누출을 줄이는 사후 연구이며 새 독립 test가 아니다.

## 판단할 질문

정상 자료로만 학습·보정한 진동 예측 오차/공분산 경로와 기존 전류 파형 경로를 하나의 기록 단위 경보 예산으로 결합하면, R1 상태 이어받기 없이도 실제 이상 탐지를 유지하면서 진동 주입 탐지와 계측 섭동 강건성을 개선할 수 있는가?

## 고정한 개발/평가 분리

- 원본 SHA-256과 matched 양자화, 기존 기록 경계를 사용한다. 라벨·파일명·미래 행은 특징에 넣지 않는다.
- 후보 선택은 두 본평가 분할의 공통 train인 정상 기록 0~299만 사용한다. 내부 fit 0~119, calibration 120~239, development 240~299. 개발 단계에서 실제 이상 파일은 읽지 않는다.
- 후보와 모든 경보 변환을 잠근 뒤 기존 A(train 0~359,cal 360~479,test 480~599)·B(train 0~299,cal 300~419,test 420~599)로 각각 다시 학습·보정한다. 실제 이상 앞10/뒤11/전체21 기록은 모두 별도로 표시하며 후보 선택에 쓰지 않는다.
- 이상 21기록은 독립 고장 21건이 아니다. A/B도 독립 반복이 아니다. R1 없는 행 F1, 정상 오경보 행/기록, 이상 기록 탐지, 최초 경보 지연과 미탐을 함께 낸다. 첫 행부터 점수가 없는 후보도 모든 행 분모에 포함한다.

## 후보와 동일 예산

- V2: 기존 세 성분 점수(비교 기준), C: 파형·동역학 성분만(크기 단독 경보 제외).
- W: 기존 사인 파형만, CD: W와 정상 전류 차분 AR(2) 잔차의 결합(기록별 상수 이동에 불변). 초반 지연·직류 이동 강건성의 맞바꿈을 보는 고정 대안이다.
- VR: 과거 최대5행으로 진동2채널을 예측한 Ridge 잔차의 Ledoit-Wolf 거리.
- VD: 센서 차분을 입력/목표로 하는 같은 잔차 거리(기록별 직류 이동 불변).
- 각 VR/VD의 즉시 점수 및 최근3개 유효 점수 평균을 비교한다. 후보는 V2/C와 각 진동 경로를 train 꼬리 척도로 바꾼 뒤 max로 융합한다. baseline V2, C와 진동 단독도 공개한다.
- 개발 실행 전 후보 격자: 전류쪽 V2/C/W/CD × 진동 VR1/VR3/VD1/VD3 × 진동 점수 가중치 0.5/1/2. 가중치는 train 꼬리 척도에 곱하고 결합 후 정상 기록으로 다시 보정한다. 후보수는 기본/단독/비교기를 포함해 코드에 고정한다. 실제 이상 평가 전에 정상 개발자료만으로 하나를 잠근다.
- 경쟁팀 일반 알고리즘을 독립 구현한 10행 PCA-MSPC/진동 Mahalanobis 및 그 교집합을 참고 대조로 둔다. 경쟁팀 자체 창 단위 F1과 우리 행 단위 점수를 직접 비교하지 않는다.
- 각 최종 점수의 정상 calibration **기록 최대값**을 다시 보정한다. 공통 α=0.01, 민감도 α=0.03/0.05. 두 α=1% 경보의 단순 OR는 별도 비교이며 동일 예산 모델로 부르지 않는다.

## 개발 순위와 탈락 조건

- 합성 주입은 정상 개발 기록에만 넣고, 기준 진폭/잔차 크기는 내부 fit에서 계산한다. 진동 잡음·충격·지속 진폭 증가, 전류 파형 왜곡을 포함한다. 선언한 onset 앞의 샘플은 비트 단위로 동일해야 한다. 이 조건은 기존 전체 기록 평균 제거 주입의 한계를 고친다.
- 개발 seed 101, 평가 seed 811/1217/2027. 가족·강도·시작 위치를 실행 코드와 함께 잠근다. 평가 시 신규 seed를 쓴다고 독립 고장 일반화라고 부르지 않는다.
- 개발 정상 오경보 기록률 ≤5%, 각 센서 상수 이동 후 증가 ≤2%p가 1차 관문이다. 통과 후보 중 전류/진동 주입 가족별 평균 탐지율의 최솟값을 최대화한다. 동률은 평균 탐지율, 낮은 스트레스 오경보, 단순성 순으로 고른다.
- 기준 모델도 같은 표에 둔다. 관문을 통과한 후보가 없으면 실패를 기록하며 test를 보고 기준을 완화하지 않는다. 실제 test에서 악화되면 공식 모델 교체를 권하지 않고 보완 경로로 분리한다.
- 실제 이상·주입·계측 섭동 간 맞바꿈을 모두 공개한다. 합성 열화 성능을 실제 고장 선행 시간으로 바꾸어 쓰지 않는다.
