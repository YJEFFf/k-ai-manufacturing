## ③ 강점 (직접 확인한 것만)

**1. 데이터 이해**
- 기록 구조를 원본으로 확인했다. 정상 600·이상 21기록, 최대 50행, 기록 사이 공백 정상 1.545~16.643초·이상 1.78~8.57초이며 문서와 같다(`analysis/press_evidence/README.md:115`, `j3_independent.json`).
- 저장 형식 누설을 찾아 제거했다. 진동 소수 자릿수가 정상 6·이상 8~9다. 재계산으로 "진동 자릿수 ≥ 7" 규칙 하나가 F1 0.998이다. 팀은 matched 양자화로 제거했다(`press_supervised/README.md:13-22`, `press_submission/press/data.py:36-40`).
- 완전 중복 1행(00:43:33.196)을 찾고 문턱 영향을 확인했다(`analysis/press_evidence/README.md:113`). 재계산으로 중복 1행이 확인된다.
- 평가 구간 편향을 스스로 찾아 공개했다. A 평가가 가장 조용한 구간이다(MW p 2.9e-11). 재계산 2.92e-11·1.65e-3로 일치한다(`press_guard/README.md:64`, `analysis/press_evidence/README.md:20-31`).
- 가이드북 표 2·3 통계가 원본 재계산과 일치한다(가이드북 10~11쪽, `j3_independent.json` sensor_stats).
- 이상치를 지우지 않는 근거가 정량적이다. 1.5×IQR로 지우면 이상 신호의 41%가 사라진다(`analysis/press_evidence/README.md:217-224`).

**2. 모델 개발**
- 팀 코드를 쓰지 않은 독립 재구현(`j3_independent.py`)으로 결과가 **정확히** 재현됐다. v2 A 556/0/44·F1 0.961938, B 569/3/31·0.970990, 오경보 기록 423·461·570, v1 0.910082·0.920322, α1% 문턱 4.418(기록 461)·3.520(기록 303)(`press_guard/README.md:46-53`, `:64`).
- 비교 범위가 넓다. 같은 conformal 규칙에서 14개 모델(가이드북 LSTM-AE 포함)을 비교했다(`press_guard/outputs/model_comparison_v2.md`). 지도학습은 기록 묶음 21겹으로 비교했다(`press_supervised/README.md:24-41`). 같은 특징의 대안(Fisher·5NN·합)이 사후로 더 낫다는 사실까지 공개했다(`press_selection/README.md:22-38`, `:44-54`).
- 경보 층은 정상 자료만으로 학습·보정한다(`press_guard/model.py:481-506`). 라벨·날짜 불변성과 입력 묶음 1·7·128행 동일성을 audit 16개 항목이 확인한다(재현 실행에서 16/16 통과).
- 확률 층은 사전 비율을 분리한 우도비 구조다. LORO 교차 평가, Platt·상한 없는 등방 회귀와의 비교, 기준선(유병률·1−p·경보 0/1)을 갖췄다(`press_guard/README.md:102-128`, `outputs/probability_baselines_v2.csv`). 수치는 독립 재적합과 일치한다.
- 한계를 정직하게 공개한다. 단순 규칙 21/21, 짝 비교 p값의 비독립성, AR 차수의 사후성, 사전 등록 주장 정정(`press_guard/README.md:57-62`, `press_selection/README.md:169-172`).

**3. 영향요인·오류분석**
- 성분·센서 절제 수치가 독립 재계산과 모두 일치한다. 파형 제외 미탐 133/112, 예측 오차 제외 86/71, 크기 제외 56/56·20/21·B 오경보 3→1, AI0 제외 49/47, AI1 제외 45/34, 전류만 0.956/0.955, 진동만 0.448/0.491(`press_guard/README.md:145-147`, `j3_ablation.json`).
- 미탐이 기록 위치 0~1에 몰린다(A 26/42, B 20/42). 재계산으로 일치하며, 구조적 원인(초반 창)을 설명했다(`press_guard/outputs/position_vibration_misses_v2.csv:2-3`).
- 오경보를 운전 상태 분모(부하 21·51기록)로 다시 읽었다. 보정이 상태 혼합의 주변 보장이라는 점도 밝혔다(`analysis/press_evidence/README.md:320-335`).
- 오류 조건 요약표가 조건마다 분모·95% 구간·lift·근거 종류(관측/주입/스트레스)·파일:행을 단다(`press_guard/outputs/error_condition_summary_v2.csv`).

**4. 현장 활용**
- 새 CSV(라벨 없음)에서 `predict.py`가 그대로 돈다. 400행을 1.6초에 처리해 사건 1개와 격상 1건을 냈다.
- 콘솔이 실제로 작동한다. 임시 포트로 띄워 `/`가 200, `/api/overview`의 audit_ok가 True, `/api/analyze`(B)가 경보 572행·사건 4·격상 1을 냈다. 확인 뒤 종료했다.
- 판단표(근거 → 확인 대상 → 점검 항목 → FM 후보)가 코드 한 곳에서 나온다(`press_guard/model.py:74-91`). 9단계 운영 절차에는 [가정]과 [근거] 표시가 있다(`OPERATIONS.md:10-23`).
- 기대효과를 절감액으로 주장하지 않고 손익분기 배수로 표시했다(`OPERATIONS.md:64-71`).

**5. 창의성**
- conformal 순위 p값으로 알림 단위 오경보율을 분포 가정 없이 통제한다(`press_submission/press/calibrate.py:24-30`). 단, 길이 혼합에 대한 주변 보장이다(②-2 참고). Tippett 결합으로 경보마다 문턱을 넘은 성분이 있어 판단표로 이어진다(`press_selection/README.md:8-11`).
- 인공 고장 주입(E1)으로 탐지 하한과 지연을 쟀다. 프로토콜은 결과보다 먼저 커밋됐다고 문서에 적혀 있다. UCI 외부 적용 실패(AUROC 0.43~0.55)도 공개했다(`press_supplement/README.md:3-38`, `:40-57`).
- 표본화 시각 흔들림·상태 전환 스트레스로 현장 이식 조건을 정량화했다(`analysis/press_evidence/README.md:343-384`).

**6. 재현성**
- git 없는 사본에서 한 명령 재현이 13/13 통과했다(574초). 결과 CSV·그림이 커밋본과 **바이트 단위로 같았다**. 차이는 manifest·audit·summary JSON의 소요 시간과 실행 지문뿐이었다.
- 주최 측 ZIP 배치 경로(`runtime.install_data`)가 SHA-256 검사와 함께 작동한다(새 사본에서 확인).
- 동결값 비교(`verify.py` 59/59), 분석 패키지 계약 검사, 스트리밍 동일성 audit 16/16이 모두 통과했다.
- 새 가상환경(`requirements-lock.txt`, 설치 15.5초)에서 `--tests`까지 22/22가 통과했다. v2 시험 208개 통과·1개 건너뜀(주최 측 ZIP 경로 시험), v1 시험 44개 통과, 분석 패키지 시험과 웹 회귀 시험도 통과했다. 모든 단계가 1스레드, 바이트코드 파일 없이 하위 프로세스로 돈다(`press_guard/reproduce.py:91-100`).
