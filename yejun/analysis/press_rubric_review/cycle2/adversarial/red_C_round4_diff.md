# 적대적 검수 C — 4회차 변경분(6c61a88 → cc1aac2)과 검수 장치

검수 기록이며 대회 보고서가 아니다. 비교 대상은 커밋 `6c61a88` → `cc1aac2`(407개 파일, 검수 기록 275개 포함)다. 재실행과 반례 시험은 모두 임시 사본(git archive + 원본 CSV 2개)에서 했다. 저장소 작업 사본에서는 팀의 생성 스크립트를 돌리지 않았다.

## ① 결론 요약

「동결·전체 시험 통과」는 이 기기(macOS)에서 믿을 수 있다. 주 결과는 4회차에 바뀌지 않았다. 시험을 느슨하게 하거나 수치를 유리하게 바꾼 흔적은 찾지 못했다. 다만 4회차 새 기능에서 반례가 나왔다. 평가관 반례를 막으려고 넣은 역순 시각 처리가 새 약점을 만들었다.

- 주 결과 불변: 새 예측 파일에 옛 요약 규칙을 적용했다. 6개 파일 모두 경보·알림·단계·근거·조치 열의 행 단위 해시가 같다. 실수 열 21~23개 요약도 비트 단위로 같다. 저장 모델·보정기 4개의 SHA-256도 같다.
- 재현: 임시 사본에서 `reproduce.py --tests`가 24/24 통과했다(1,830초). `train.py --rolling`을 두 번 더 돌렸다. 실행 기록(manifest.json)만 달랐다. 새로 만든 행 단위 예측 6개는 동결 요약의 SHA-256과 바이트 단위로 같다.
- 시험 약화 없음: 지운 assert는 같은 검사로 옮겨졌다. 허용오차는 그대로다(CSV 1e-9, 예측 요약 상대 1e-7). 새 xfail은 없다. 비교 대상 열은 오히려 늘었다.

- 사건 격상: 경보 1행 두 기록을 0.3~60.0초로 이으면 사건 1개, 2단계다. 60.1초 이상이면 사건 2개다. 세 건과 70초 공백 뒤 재개도 규칙대로다. `incidents()` 격상 행은 predictions 유무와 무관하게 같다. simulate와도 같다.
- 기록 경계: 끝·첫 행 간격 0.12초는 한 기록, 0.13초는 두 기록이다(±20 ms 규칙대로). 50행 블록을 넘는 연속 기록(132행)도 일괄 = 스트림이다.
- 역순·중복·결측·2시간 공백·전체 내림차순을 섞은 입력: 일괄 = 스트림(청크 1·7·128)이다. 접두부 예측 16곳이 전체 예측의 접두부와 같다. 음수 의심 시간창은 0개다.
- 운전 상태: 인과적이다. 접두부 128곳이 같고, 직접 계산한 누적 표준편차와의 차이는 최대 8.5e-14다. 청크 1·7·128 모두 일괄과 같다.
- 감시 4갈래: 진동 2σ는 열화 의심, 변경 기록이 있으면 재보정 검토, 전류 ×1.5는 전류 수준 이동으로 지정대로 나온다. 필터는 「정상 확인」 앞뒤 공백을 허용한다. 빈 값·결측·열 없음·「정상확인」·영문은 미확인으로 뺀다. start>end·필수 열 누락은 오류를 낸다.
- 확률 단조성: A·B 보정기의 20만 점 격자와 관측 점수 전체에서 LR이 한 번도 내려가지 않는다. 합성 적합 400개(동률·정수 점수 포함)도 위반 0개다. 범위는 [floor, 121]이고, NaN·±inf 입력은 NaN이다.
