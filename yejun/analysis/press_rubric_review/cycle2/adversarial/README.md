## 문제없던 확인

- **독립 재구현:** A1·J1·J2 세 건이 경보·TP/FP/FN·F1·문턱·AR 계수까지 같다(p값 차 최대 1.1e-16).
- **누설:** 학습·보정·평가 구간의 행과 기록 겹침이 0이다. 경보 경로의 모든 적합값은 정상 자료로만 정했다. 확률 열의 기록 단위 교차 적합도 제대로 빠진다(A1·E).
- **형식 지름길 제거:** matched 뒤에는 형식 흔적이 없다. 격자 나머지 검정 24개가 모두 p ≥ 0.179이고, 나머지만 쓴 분류기는 AUROC 0.47~0.51이다. raw로 다시 적합해도 결과가 같다(A1).
- **분할:** A·B 분할은 v2 설계 전부터 있던 비율이다. 시간 역순 분할에서도 성능이 유지된다(F1 중앙 0.967). 무작위 분할 400개의 정상 알림률 0.86%는 명목 0.83%와 맞는다(A2).
- **초모수:** 채택값이 최댓값이 아니라 넓은 평탄 구간에 있다. 팀 중첩 선택 코드는 정말 중첩이다(A2).
- **사전 등록:** E1 프로토콜(a102ecf)이 결과(875f269)보다 먼저 커밋됐다(A2·E).
- **4회차:** 시험을 약화하지 않았다. 새 xfail이 없고, 정확 비교 열은 늘었다. 주 결과·저장 모델 SHA-256이 그대로다. macOS에서 24/24 재현, 학습 두 번 비트 동일(C).

## 이 기록의 정정(2026-09-29, 코덱스 재검수 [recheck_20260929](../recheck_20260929/README.md)와 부모 재계산 [red_M_verify.log](red_M_verify.log) 5·6절)

- **X-02의 "만"은 틀렸다.** v1 대비 미탐 감소 55행 중 위치 2~6이 A 49·B 51행이고, 위치 7 이후에서도 A 6·B 4행이 줄었다. "주로 기록 시작 직후"가 맞다.
- **X-04의 확률 비교는 평가 분포를 섞었다.** 예측 π만 1%로 바꾸고 평가 파일(이상 12.8%·9.0%)은 그대로 채점했다. 평가 비율도 1%로 맞추면 현재 확률 층 Brier(A 0.0025·B 0.0026)가 1−p(0.0083·0.0217)보다 낮다. 포화(경보 행 99.8%가 0.55)와 경보 여부를 넘는 추가 정보가 작다는 지적은 유지된다.
- **X-05의 원인 후보 중 5.0 Hz 기저는 기기 간 차이의 원인으로 확인되지 않았다.** x86-64에서도 5 Hz 투영은 macOS와 1.7e-16 안에서 같았다. 기기 간 차이는 파형 점수를 정상 기준 분포 순위로 바꿀 때 수학적으로 같은 점수의 순위가 뒤바뀌는 데서 나온다. 5 Hz 기저 퇴화 자체는 수학적 결함이라 따로 고쳤다.
- **X-08의 "두 위원 항목 점수가 0.5점 안에서 같다"는 틀렸다.** 모델 항목은 30.0 대 29.0이다. AR(4)와의 F1 차이(0.012·0.014)도 과적합의 크기로 확정할 수 없다. 서로 다른 p값 110개는 검정한 가설의 수가 아니다.
