# 4회차 검수 원칙

대회 보고서가 아니라 구현·실험 검수 기록이다. 공식 배점은 기존 official_task_extract.txt를 따른다.

- 데이터 15, 모델 40, 오류 15, 현장 10, 창의성 10, 재현성 10의 평가관을 각각 둔다.
- 3회차 항목 완료 여부와 새로 확인한 실제 결함을 코드·산출물·독립 재계산으로 판정한다.
- 이전 94.6점이나 97점 전망을 목표 점수로 삼지 않는다. 근거 없이 경쟁팀 순위나 수상 가능성을 단정하지 않는다.
- 고칠 수 있는 결함과 현재 자료로 해소할 수 없는 한계를 나누며 같은 한계를 여러 이유로 중복 감점하지 않는다.
- 주 지표·A/B 분할·경보 규칙·저장 모델을 보존한다. 새 분석은 사후 탐색/가설로 표시한다.
- 합성 주입은 실제 고장이나 정상 전환의 관측값으로 바꾸어 표현하지 않는다.
- 누적 검수로 인한 점수 상승보다, 정확한 반례·오류 수정·최종 사본의 재현을 우선한다.
- 모든 수정은 yejun 아래에 한정한다. 평가관은 round4 안의 자기 검수 기록만 쓴다.
