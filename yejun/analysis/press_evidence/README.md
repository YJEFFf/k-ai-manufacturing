# 프레스 진단·근거 보강 표 (2026-09-26)

데이터 진단·근거 보강 분석용 표다. 원본 CSV와 동결 v2 모델(`press_guard/artifacts/guard_{A,B}.json`)만 읽는다. v1·v2의 동결 기대값·모델·문턱·분할은 바꾸지 않았다. 이미 본 이상 21구간을 쓰는 기술 통계이며 **대회 보고서가 아니다.** 주최 측은 출제 데이터 문의에 답하지 않으므로, 해석은 아래 팀 규칙을 따른다.

`yejun/`에서 실행한다(PowerShell은 첫 줄 대신 `$env:OMP_NUM_THREADS=1; $env:PYTHONDONTWRITEBYTECODE=1`).

```bash
export OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1        # PowerShell: $env:OMP_NUM_THREADS=1; $env:PYTHONDONTWRITEBYTECODE=1
python analysis/press_evidence/build_tables.py                            # 약 10~20초, 아래 18개 표
python analysis/press_evidence/build_diagnostics.py                       # 보강 표 23개·그림 5장
python analysis/package_contract.py --package analysis/press_evidence     # 실행 기록 무결성 + 동결 기대값 비교
python -m pytest -q analysis/press_evidence/test_contract.py              # 변조·삭제 검출
python -m pytest -q analysis/press_evidence/test_diagnostics.py           # 위상·이득·주파수 진단의 의미 검증
```

입력·모델·코드·산출물 해시와 실제 BLAS 구성은 [manifest.json](manifest.json)에 있다.

**검증 계약.** [contract.json](contract.json)에 결과 46개(표 41·그림 5)와 실행 기록 두 개를 적었다. 공용 검사기 [package_contract.py](../package_contract.py)가 두 실행 기록의 입력·모델·코드·인용 파일·결과 해시를 현재 파일과 대조하고, 결과를 [expected/](expected)의 동결값과 비교한다(수치 허용오차 1e-9, 문자 정확 비교, 그림은 존재·크기만). 결과를 바꾸거나 지우면, 실행 뒤 코드·인용 파일이 바뀌면, 동결값을 바꾸면 실패한다. 동결(`--freeze`)은 무결성이 통과한 실행만 받는다. 두 스크립트는 결과를 이 폴더에 제자리로 쓴다(`--rerun`이 제자리 재실행 후 비교한다).

  - **v2의 반응**([current_offset.csv](current_offset.csv), 분석 전용 반사실 변환):
    - 이 이상 파일에서는 기록마다 전류 평균을 지워도 α1% 경보가 거의 같다(A 556→555행, B 569→567행, 21/21구간). 크기 경보는 모두 진동 센서에서 나왔다(전류가 최댓값인 크기 경보 0행).
    - 그 이유는 치우친 기록들의 파형이 이미 흐트러져 있기 때문이다. v2가 수준 이동에 둔감하다는 뜻이 아니다.
    - 파형 성분은 상수항을 함께 적합해 평균 이동에 반응하지 않는다. 예측 오차(AR(2)) 성분은 상수항 때문에 수준 이동 δ에 (1−φ1−φ2)·δ ≈ 0.14·δ만큼 반응한다.
    - 정상 평가 구간 전류를 이상 기록 |평균|의 중앙값(+81.4)만큼 옮기면 경보 기록이 A 0/120·B 8/180(원자료 0·3)이다. 최댓값(+272.4)만큼 옮기면 A 114/120·B 179/180이다. 경보는 거의 모두 예측 오차 성분이고 권장 확인은 「전류 파형·계측 확인」이다. 그래서 판단표의 이 행은 전류 센서 영점을 먼저 확인하게 했다.
    - 같은 평균 제거를 정상 평가 구간에 적용하면 B의 경보 구간은 3 → 4개다.
    - v2가 반응한 파형 흐트러짐과 진동 증가도 같은 날 수집 차이와 분리되지 않는다.
- 앨리어싱 가설(60 Hz 순시값, 독립 가우스 시각 흔들림)이 맞다면 R² 0.451은 표본화 시각이 RMS 약 2.4 ms 흔들린 것과 같은 크기다. 파형·예측 오차 성분은 수집 시각 변화에도 반응할 수 있다는 뜻이며, 이 가설은 검증할 수 없다.
- v2가 직접 쓰지 않는 차이(lag-1, 상·하부 상관)와 v1 패키지의 AE·LSTM이 반응할 수 있는 차이를 열로 구분했다.
- **팀 규칙: 어떤 신호 차이도 고장의 인과 증거로 쓰지 않는다.**

## R10 AR(2)와 사인 성분의 관계 — [ar2_oscillator.csv](ar2_oscillator.csv)

저장된 AR(2) 계수는 A·B 모두 복소 특성근(|r|=0.987)을 갖는다. 암시 주파수는 **0.6064 Hz**로, 사인 성분의 적합 주파수(정상 기록 대부분 0.600 Hz)와 같은 신호다. 순수 0.6 Hz 사인의 AR(2) 계수(φ1 1.8596, φ2 −1)와 비교하면, 저장 계수(1.833, −0.975)는 약하게 감쇠하는 같은 진동자다. 사인 성분은 6·8관측 창, AR은 3관측으로 같은 신호 가설을 서로 다른 시간 척도에서 쓴다. 0.6 Hz의 물리 원인은 확인하지 못했다(60 Hz 앨리어싱은 가설). "유압펌프 물리 모델"이 아니라 "관측한 전류 신호 구조"를 쓴 것이다.

### O1(a) 시간순 5겹 보정 곡선 — [rolling_calibration_curve.csv](rolling_calibration_curve.csv)

- 경계를 90·95로 바꿔도 모든 정상 알림이 부하 상태다.
- 동결 B 보정 최대 점수 상위 10개는 모두 부하 기록이다(부하>저수준 단측 Mann–Whitney p=0.0024). 부하 상태의 B α=1% 3/51(5.9%)은 참고 기준 1/62보다 크다. 독립·고정위험 이항 단측 p=0.049는 공유 보정 문턱의 불확실성을 무시한다. 독립·연속·교환가능 점수 가정에서 보정 부하 61개 최대값을 공유하는 Beta-Binomial(51,1,61)의 단측 참고 p=0.0914다. 5% 수준 위반을 단정하지 않는다. 실제 시간 의존성·사후 상태 분류 한계도 남는다.
- **따라서 A 0/120은 부하 기록 21개, B 3/180은 부하 기록 51개에서 잰 값이다.** R1 결론과 결정표(A/B·시간순 분할 행)의 한계 칸에 적었다. 오경보 조건을 분석할 때 이 분모를 쓴다.

### 결정표·관측 가능성·앨리어싱 정정

- **결정표:** 결정표 '블록 부트스트랩' 행이 v1 행을 인용하던 것을 v2 행으로 고쳤다. A는 퇴화(모든 복제 0)이고, B는 관측 3, 95% 0~6·0~6·0~5다(uncertainty_v2.csv).
- **관측 가능성:** [observability.csv](observability.csv)의 해석을 파일·센서별 값에서 쓰게 고쳤다. 이상 진동의 저주파 성격(위 O4(a))을 1 Hz 이하 전력 비중·기록 평균 제거 lag-1 열로 더했고, 고장 모드 대응표 FM1~FM3이 이를 인용한다.
- **앨리어싱:** 앨리어싱 조건을 k·10 ± 0.6 Hz 일반형으로 고쳤다(D4 절). 60 Hz 직입은 그 한 경우다.

## 정상 상태 전환 스트레스 — [state_transition_stress.csv](state_transition_stress.csv)

정상 전환은 기록 사이 공백에 가려져 학습·보정·평가에서 관측되지 않는다(기록 안 전환 지표 초과 0/469). 결측이 운전 상태와 맞물려 있어 정상 B 3/180과 같은 날 롤링 결과만으로 연속 수집의 오경보율을 알 수 없다. 아래는 **동결 A·B 모델을 읽기 전용으로 사용한 사후 스트레스 시험·가설**이다. 경보 규칙·문턱·분할·주 지표는 그대로다.

- 잇기: 같은 평가 구간의 50행 정상 기록 두 개를 25행에서 잇는다. 전류 0.6 Hz 위상을 맞추는 오프셋 0~16을 고르고 전류 평균을 맞춘다. 저수준→부하·역방향·같은 상태 두 대조 각각 시드 20260928의 200쌍이다.
- 이득: 각 원기록의 평균 중심 편차에 상태별 중앙값 비(전류 진폭 1.75, AI0 SD 1.76, AI1 SD 3.00) 또는 역수를 25행부터 계단·10행·20행 경사로 곱한다. 평가 풀은 A 저수준 31·부하 8, B 저수준 38·부하 17기록이며 이득 조건당 각각 한 번씩 쓴다.
- 표는 α 1·3·5%별 전환 전 경보 수, 전환 뒤 25행과 첫 20행 안 경보 수·비율, 첫 경보 성분, 원기록 수를 보존한다. 같은 원기록이 반복되는 합성 쌍 200개를 독립 기록 200개로 간주한 신뢰구간은 만들지 않는다.

| α1%, 전환 뒤 경보 비율 | A 저수준→부하 | A 부하→저수준 | B 저수준→부하 | B 부하→저수준 |
|---|---:|---:|---:|---:|
| 서로 다른 기록 잇기(200쌍씩) | 116/200 (58%) | 50/200 (25%) | 148/200 (74%) | 86/200 (43%) |
| 한 기록 안 이득 계단 | 30/31 (97%) | 3/8 (38%) | 37/38 (97%) | 9/17 (53%) |
| 10행(1초) 이득 경사 | 0/31 | 0/8 | 3/38 (8%) | 0/17 |
| 20행(2초) 이득 경사 | 0/31 | 0/8 | 2/38 (5%) | 1/17 (6%) |

같은 상태 대조도 하위 수준이 다르면 경보된다. 저수준끼리 잇기는 A 3/200(1.5%)·B 7/200(3.5%), 부하끼리는 A 50/200(25%)·B 60/200(30%)다. 같은 상태 대조 400쌍의 진폭비 `max(a/b,b/a)`를 층화하면 B는 <1.1배 13/256(5.1%), 1.1~1.3배 11/56(19.6%), 1.3~1.6배 26/66(39.4%), ≥1.6배 17/22(77.3%)다. 전류 위상만 맞추므로 진동 이음매는 대조에도 남는다. 저수준 대조의 첫 근거는 파형이며, 큰 상태 전환·큰 진폭비 대조에서는 대부분 예측 오차(AR(2))가 첫 근거다.

**검증 함의.** 계단 가정은 많은 전환을 경보하고 경사는 훨씬 적게 경보한다. 실제 전환 속도·모양은 공백 때문에 알 수 없어 어느 수치도 현장 전환 경보율로 채택하지 않는다. 전환을 포함한 정상 연속 자료로 재보정·재검증하기 전에는 대회 오경보 수치를 연속 수집 현장에 옮기지 않는다. [결정표](decision_table_diagnosis_v2.csv)의 결측·시간 적용률, A/B·시간순 분할 행이 이 표를 실행 시점의 `파일:행`으로 인용한다. conformal 행은 보정 상태 혼합에 대한 주변 보장과 부하 조건 B 3/51 대 1/62를 함께 적되, 독립·고정위험 이항 근사 p=0.049와 공유 보정 문턱을 반영한 참고 p=0.0914를 구분한다.

## 표본화 시각 흔들림 스트레스 — [sampling_jitter_stress.csv](sampling_jitter_stress.csv)

적대적 검수 J2가 제기한 수집 조건 민감도다(2026-09-29 추가). **동결 A·B 모델을 읽기 전용으로 쓴 사후 스트레스 시험·가설**이며 경보 규칙·문턱·주 지표는 그대로다.

- 방법: 정상 평가 기록(길이≥17, A 96·B 145개)마다 전류 사인(최적 격자 주파수)과 상수를 적합하고 잔차는 그대로 둔다. 사인 위상에 2π·(원 주파수)·δt를 더한다. δt ~ N(0, σ)는 표본마다 독립이고, 조건마다 5회 반복했다(시드 20260929). 진동은 그대로다.
- 시각 열은 명목값이라(기록 안 간격이 모두 정확히 0.100초, D4) 실제 흔들림을 잴 수 없다. 원 주파수도 모른다(D4의 0.6 Hz 해석 조건).

| α1% 경보 기록 비율(경보 2행 이상) | A | B | 흔들린 기록의 사인 R² 중앙(A·B) | 적합 주파수 0.6 ± 0.05 Hz 안(A·B) |
|---|---:|---:|---:|---:|
| 흔들림 없음 | 0% (0%) | 2.1% (0%) | 0.995·0.995 | 100%·100% |
| 60.6 Hz 가설(상용 전원 대역), σ 0.05 ms | 0% (0%) | 3.7% (0.6%) | 0.995·0.995 | 100%·100% |
| 60.6 Hz, 0.1 ms | 7.7% (1.3%) | 31.3% (8.3%) | 0.994·0.994 | 100%·100% |
| 60.6 Hz, 0.2 ms | 71.0% (48.5%) | 89.5% (73.1%) | 0.990·0.991 | 100%·100% |
| 60.6 Hz, 0.5 ms | 100% (99.8%) | 100% (100%) | 0.964·0.965 | 100%·99.7% |
| 60.6 Hz, 2.4 ms | 100% (100%) | 100% (100%) | 0.480·0.472 | 83.1%·80.8% |
| 50.6 Hz 가설, 0.2 ms | 51.5% (24.8%) | 76.6% (54.3%) | 0.992·0.992 | 100%·100% |
| 0.6 Hz 물리 주기(대조), 2.4 ms | 0% (0%) | 2.3% (0%) | 0.995·0.995 | 100%·100% |

- **앨리어싱 가설이 맞고 보정 자료보다 흔들림이 늘면, v2는 0.1 ms 수준에서도 오경보가 크게 는다(기록 단위 경보 비율).** 첫 경보 근거는 파형·예측 오차다. 0.1 ms에서는 사인 R² 중앙값이 거의 그대로(0.994)라, 파형을 눈으로 봐서는 알아채기 어렵다.
- **이상 파일의 파형은 이 흔들림으로 재현되지 않는다.** 2.4 ms는 이상 파일의 R² 중앙값 0.451에서 역산한 값이라 흔들린 정상 기록의 R²(0.480·0.472)가 비슷한 것은 당연하다. 적합 주파수를 보면 흔들린 정상 기록은 81~83%가 여전히 0.6 Hz에 가장 잘 맞지만, 이상 기록은 0%이고 중앙 0.22 Hz다(class_differences.csv). 표본마다 독립인 흔들림만으로는 이상 파형을 설명하지 못한다. 표본화 주기 편차 같은 다른 수집 가설과 실제 설비 변화는 시험하지 않았다.
- 0.6 Hz가 물리 주기라면 2.4 ms 흔들림도 영향이 없다. 어느 가설이 맞는지는 이 자료로 가릴 수 없다.
- 흔들림은 정상 신호의 분산을 키우지 않는다(같은 신호를 다른 시각에 뽑을 뿐이다). 그래서 이상 파일의 진동 SD 증가(×6.3·×2.0, R4)와 진동 크기 초과(21구간 중 18구간이 정상 q99 초과, FM1)는 시각 흔들림으로 설명되지 않는다. 센서 부착·이득 같은 다른 수집 변화인지 설비 변화인지는 역시 가릴 수 없다.
- **운영 함의:** 설치 전에 수집 장비의 표본화 시각 흔들림을 확인한다(하드웨어 시각 동기 수집). 일정한 흔들림은 그 자료로 다시 보정하면 문턱에 흡수되므로(파형 성분의 민감도는 줄 수 있다), 요건은 보정 뒤 흔들림이 늘지 않는 것이다. 새 수집 환경에서는 재보정 전에 정상 자료로 오경보율을 다시 확인한다.

## 한계

- 모든 표는 같은 날 정상 77분과 이상 2.8분의 기술 통계다. 날짜·시간대 교락은 이 표들로 해소되지 않는다.
- 이상 21구간은 3분 안의 연속 기록이다. 독립 고장 21회가 아니다.
- R4의 해석 분류는 가능성의 구분이며, 어느 차이도 원인을 확정하지 않는다.
- 전류 수준 치우침·표본화 시각 흔들림의 원인(계측·수집 대 설비)은 이 자료로 가릴 수 없다. 흔들림 스트레스는 원 주파수와 흔들림 모양을 가정한 민감도다.
- 보강 표의 관계·기대 신호·고장 모드 대응은 기술 통계와 가설이다. 부하·정비·고주파 계측이 없어 물리 원인을 확정할 수 없다.
- 저수준 대 부하 범위(하위 2~3수준)와 약 20초 주기는 전류 진폭으로 나눈 기술 분류다. 생산 주기·무부하라는 해석은 부하·스트로크 기록 없이 확인할 수 없다. 상태별 알림 분모는 결과를 본 뒤의 사후 분석이다.
- 정상 전환 순간은 기록 공백이 가려 학습·보정·평가에서 관측되지 않는다(기록 안 전환 지표 초과 0/469). 대회 오경보 수치는 상태와 맞물린 간헐 수집의 결과다. 전환 속도가 미관측이므로 위 모의는 가정별 민감도이며 실제 전환 경보율이 아니다. 전환을 포함한 정상 연속 자료로 재보정·재검증하기 전에는 대회 오경보 수치를 연속 수집 현장에 옮기지 않는다.
