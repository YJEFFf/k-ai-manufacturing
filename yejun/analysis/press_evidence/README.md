## R3 불균형·이상치·품질 지수 — [imbalance.csv](imbalance.csv), [outliers.csv](outliers.csv), [quality_index.csv](quality_index.csv)

- **불균형:** 이상은 행 600/20,600=2.9%, 구간 21/621=3.4%, 기록시간 60초 대 2,000초다. 평가셋의 이상 비율은 행 기준 A 12.8%·B 9.0%이고, 전부 양성으로 예측할 때 F1은 0.227·0.164다. **A와 B의 F1은 기준선이 달라 같은 잣대로 직접 비교하지 않는다.** 대응: 정상 자료만으로 학습·보정하고 구간 단위를 주 지표로 쓴다.
- **이상치:** 정상의 robust |z| 최대는 AI0 4.95, AI1 3.75, 전류 1.75다. 정상 최솟값·최댓값은 센서마다 각 1행뿐이라 포화·클리핑 흔적이 없다. A 학습 범위 밖의 정상 비학습 행은 AI1 2행뿐이다. 이상은 205/600행이 학습 범위 밖(AI0 166, AI1 67, 전류 57)이고 21구간 중 19구간(진동 기준 18구간)에 걸친다. **결정: 이상치를 제거하지 않는다**(이상 신호 자체).
- **가이드북 품질 지수:** 가이드북 62쪽 산식으로 다시 계산한 값이 보고치와 같다. 정상은 완전성 100%, 유일성 99.995%(보고 99.99%, 완전 중복 1행 때문, R20), 유효성·일관성 100%, 무결성 66.67%다. 이상은 모두 100%다. 정확성은 가이드북도 산출하지 않았다.

## R10 AR(2)와 사인 성분의 관계 — [ar2_oscillator.csv](ar2_oscillator.csv)

저장된 AR(2) 계수는 A·B 모두 복소 특성근(|r|=0.987)을 갖는다. 암시 주파수는 **0.6064 Hz**로, 사인 성분의 적합 주파수(정상 기록 대부분 0.600 Hz)와 같은 신호다. 순수 0.6 Hz 사인의 AR(2) 계수(φ1 1.8596, φ2 −1)와 비교하면, 저장 계수(1.833, −0.975)는 약하게 감쇠하는 같은 진동자다. 사인 성분은 6·8관측 창, AR은 3관측으로 같은 신호 가설을 서로 다른 시간 척도에서 쓴다. 0.6 Hz의 물리 원인은 확인하지 못했다(60 Hz 앨리어싱은 가설). "유압펌프 물리 모델"이 아니라 "관측한 전류 신호 구조"를 쓴 것이다.

## R19 명목 대비 실현 경보율 — [calibration_curve.csv](calibration_curve.csv)

정상 평가 기록구간의 최소 p값으로, α 격자 k/121(k=1~12)마다 실현 기록 경보율과 이항 단측 95% 상한을 계산했다.

- A는 모든 k에서 명목 이하다(k=1·2에서 0/120, k=3~6에서 1/120, k≥7에서 2/120). A 평가 구간이 조용한 시간대라(R1) 낮은 쪽으로 치우친 값이다.
- B는 **k=1~4에서 명목을 넘는다**(3/180=1.7% 대 0.8·1.7%, 5/180=2.8% 대 2.5%, 7/180=3.9% 대 3.3%). 모두 이항 상한(4.3~7.2%) 안이고 k≥5에서는 명목 이하다.
- 교환가능성 가정 아래 같은 날 자료에서의 주변 보장 점검이다. 새 날짜의 보장이 아니고, p값은 고장 확률이 아니다.
