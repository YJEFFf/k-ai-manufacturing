## 3. 확인으로 달라진 중요한 해석

### 56번: 100만 행이라는 크기보다 라벨의 성격이 중요하다

- PDF 17–18쪽: 원 자료는 1,030,635행×26열이고 설비 상태 종속변수가 없다.
- PDF 9–10쪽: `PassOrFail`은 분석 과정에서 임의로 설정하는 normal/abnormal이다. 실제 품질검사 결과가 아니다.
- PDF 31–32쪽: `No_Shot==0` 경계로 Lot을 구분하고 100샷 미만 Lot을 제외한다.
- PDF 36–43쪽: Lot의 평균·중앙값·사분위 통계에 IQR을 적용하고, PCA 2차원에 DBSCAN을 적용한다. IQR 이상변수가 4개 이상인 Lot 및 시각적으로 선택한 DBSCAN 군집을 합쳐 43개 Lot을 abnormal로 정한다.
- PDF 44–46쪽: 이 Lot 라벨을 소속 샷 전체에 부여하고, 전체 데이터 정규화 후 정상 샷을 무작위 분할한다.
- PDF 50·54쪽: 설명은 abnormal 검출 성능이지만 precision/recall 계산 코드는 `pos_label=0`이므로 정상 클래스 성능이다. 해당 수치를 불량 재현율로 인용하면 안 된다.
- PDF 54–57쪽: K-fold 코드에서 모델 생성은 반복문 밖에 있고 `fit`을 이어간다. 독립적으로 재초기화한 fold 평가와 같다고 볼 수 없다.

따라서 이 자료를 가져오면 **라벨이 없는 공정 로그가 늘어나는 것**이다. 원 과제의 양불량 정답 부족이 해결되거나, 가이드 수치를 그대로 제품 불량 검출 성능으로 쓸 수 있는 것이 아니다. 가이드의 상태 추정 규칙을 정답으로 놓고 유사한 규칙을 재학습하면 순환 검증이 된다.

파일 자체에도 문제가 있다. 로컬 ZIP은 20,879,464바이트로, 정상 ZIP 끝부분과 중앙목록이 없다. 로컬 헤더에서 주 CSV의 압축 크기는 24,214,987바이트인데 실제 남은 압축 데이터는 20,795,633바이트다. **3,419,354바이트가 부족한 잘린 압축파일**이다. 앞의 AAS 설정 파일 5개는 완전한 CRC를 확인했으나 주 CSV는 그렇지 않다.

진단 목적으로 압축 스트림 앞부분만 메모리에서 복원해 완전한 줄 883,092행×26열을 읽었다. 이 부분에는 결측 0, 전체행 중복 0, `_ID`와 `No_Shot` 제외 센서행 중복 6이 있었다. 그러나 전체 멤버 CRC를 검증할 수 없어 **정상 확보된 원본이나 완전한 분석 표본으로 세지 않는다.** 사용자께서 말씀하신 다운로드 실패 1개와 동일한 파일인지도 아직 확인되지 않았다.

### 55번: 검사 라벨이 있어도 결측을 양품으로 만드는 과정은 따로 검토해야 한다

- PDF 10쪽: 샷마다 2개 캐비티에서 나온 제품을 검사자가 수기로 검사하고 공정·센서와 매핑한다.
- PDF 17–19쪽: 안내상 7,535행, 공정 변수 16개·센서 15개·불량 유형 26개. 불량 컬럼의 0/1은 캐비티별 검사 유형이다.
- PDF 38쪽: 결측을 '양품 또는 품질검사 결과 없음'으로 보고 0으로 채운다고 명시한다. 두 상태를 구분할 수 없다면 양품 라벨의 신뢰도가 떨어진다.
- PDF 39–40쪽: 여러 불량 유형을 `argmax` 하나로 바꾼다. 설명의 '가장 큰 인덱스'와 실제 `np.argmax`의 첫 최댓값 선택은 일치하지 않는다. 복수 불량을 임의 단일유형으로 축약하지 않는 설계가 필요하다.
- PDF 42–46쪽: 캐비티를 행으로 펼친 후 무작위 분할한다. 같은 샷의 두 캐비티가 학습과 평가에 갈라지는 위험이 있다.
- PDF 45·47쪽: SMOTE를 전체 자료에 적용한 다음 학습·평가를 나눈다. 그 결과인 95% 정확도를 독립 평가로 받아들일 수 없다.
- PDF 46쪽: XGBoost라는 제목이지만 실제 코드의 모델은 `GradientBoostingClassifier`다.

이 자료는 **같은 샷을 하나의 그룹으로 묶고, 미검사와 정상 구분을 정리한 뒤에만** 추가 검증 자료로 의미가 있다. 원 사출 데이터의 라벨 대체재는 아니다.

54번 PDF 10쪽과 55번 PDF 12쪽의 수집기간은 모두 2020-07-20~07-30이고 다수의 공정 변수 이름도 같다. **두 자료가 동일 현장의 겹치는 샷을 포함할 가능성**이 있으므로 각각을 별개의 독립 현장 검증으로 세면 안 된다. 현재 ZIP 실체가 없어 샷/센서 해시 교집합은 아직 확인하지 못했다.

### 54번: '예지보전' 제목이 실제 목표를 보장하지 않는다

- PDF 8–10·15쪽: 목표는 작업자가 수기로 구분한 예열 가생산(1)과 정상 생산(0)의 분류다. 설비 고장 시각이나 남은 수명 자료가 아니다.
- PDF 10쪽: 수집기간은 2020-07-20~07-30, 제품 두 종류의 샷주기는 약 22초·36초다.
- PDF 31·35–37쪽: 샷/ID 제거, 전체 정규화 후 랜덤 분할. 외부 테스트는 분리한 뒤 SMOTE하지만 내부 튜닝 CV는 이미 증강된 학습 자료에 수행한다.
- PDF 42–46쪽: 중요변수 정상 표본의 IQR 범위를 제시한다. 정상 관측 범위는 인과적인 최적 제어조건이 아니다.

사출에서 예열·제품교체에 따른 정상적인 모드 변화가 이상으로 오인되는 문제를 설계할 때 참고할 수 있다. 실제 사출 원본에 운전 모드를 판별할 정보가 있는지는 원본 4번을 확인해야 한다.

### 49번: 제품 치수에 따른 검사 라벨이 있으나 기간은 하루다

- PDF 9–10쪽: 2020-10-30 하루의 17,280행×20열. `passorfail`은 외경과 두께 치수로 판정된 품질이다.
- 같은 가이드가 제품을 스틸 튜브로 설명하면서 변수는 압출기 수지온도·압력으로 설명한다. 공정 재료를 임의로 '플라스틱 사출'이라고 단정하지 않는다.
- PDF 10쪽의 기록 주기 0.05초 표기는 하루 17,280행과 맞지 않는다. 실제 timestamp 간격을 확인하기 전에는 표기 그대로 쓰지 않는다.
- PDF 11·31쪽: 품질 라벨 결측 16행을 제거한다.
- PDF 32·34·36쪽: 전체 자료에서 이상치 절삭·정답을 이용한 t-test 변수선택을 한 뒤 랜덤 분할한다. 평가 정보 유입 위험이 있다.
- PDF 42–44쪽: 의사결정나무 F1 0.9777, 랜덤포레스트 F1 1.0은 가이드의 해당 분할 결과이며 다른 날·설비 성능은 아니다.

## 4. 실제 읽은 추가 CSV 진단

### 53번 주조 공정최적화

- 73,612행×23열, 제품 `CylinderHead` 1종, 라인 1개. 날짜는 2021-08-04~10-11의 64일.
- `PassOrFail`: 0이 70,334행, 1이 3,277행, 결측 1행. 0/1의 검사상 의미는 가이드 실체 확인 후 확정해야 한다.
- `molten_capacity` 결측 16,316행, 여러 센서/라벨에 결측 1행. 라벨 결측을 정상으로 채우지 않았다.
- 전체행 중복 0, ID·카운터·날짜 제외 분석 센서벡터 중복도 0. 앞 날짜와 뒤 날짜 사이 완전동일 센서행 겹침도 0.
- 일정한 날짜 경계 2개로 앞 기간 학습→뒤 기간 평가. 랜덤 분할, 전체 정규화, 전체 SMOTE를 하지 않았다. 고정 HGB 모델을 0.5 임계값으로 평가했고 테스트에 맞춰 임계값을 조정하지 않았다.

| 학습→평가 | 평가행/1 라벨 | AP | F1 | precision / recall |
|---|---:|---:|---:|---:|
| 8/4~9/7 → 9/8~9/25 | 19,737 / 864 | 0.7681 | 0.5787 | 0.4612 / 0.7766 |
| 8/4~9/25 → 9/26~10/11 | 13,517 / 540 | 0.8282 | 0.6965 | 0.6306 / 0.7778 |

`mechanical_strength`와 `biscuit_thickness`의 실제 관측 시점을 아직 가이드로 확인하지 못했으므로 두 열을 제외한 감도실험도 실행했다. F1은 각각 0.3884와 0.6482였다. 이는 **그 두 변수가 누수라는 확정이 아니라**, 사용 시점이 불명확할 때 성능이 어떻게 바뀌는지를 확인한 것이다.

이 자료는 시간 순서 검증이 가능한 별도 사례다. 다만 금속 주조의 AP/F1을 플라스틱 사출 과제 성능으로 표기하면 안 된다. 다른 공정에서 같은 검증 절차가 동작하는지를 보이는 보조실험만 정당하다.

34,617행×20열, 제품 117종, `DateTime` 304종, 결측 0, 전체행 중복 2. 열은 당일/향후 예정 수주량, 작년 수주량, 예상 수주량, 날씨다. 사출 조건이나 제품 검사 라벨이 없다. ① 불량 예측을 직접 개선할 보충 학습자료로 사용하지 않는다.

## 5. 원본 확보 이전의 조건부 판단 — 최신 판단은 별도 원본 실사 참고

**추가자료가 많다는 이유로 ①을 1위로 올릴 근거는 없다.** 실제로 확인한 가장 가까운 대용량 사출 자료(56번)에는 검사 정답이 없고, 추가 품질 자료(49·53·55)는 서로 다른 제품·공정의 자료다.

①의 잠재 강점은 공정 변수와 품질·검사·관리 행동을 연결한 설명이 직관적이고, 제품/설비별 분포 변화·불확실성·검사 배정 같은 기여를 정량화할 여지가 있다는 점이다. 그러나 원 자료에서 **검사 정답의 의미, 서로 독립인 불량 발생 단위 수, 미래 날짜 테스트 가능성**을 통과하지 못하면 수상 논리의 핵심이 약하다.

차별화 후보는 다음 세 가지다.

1. **추천: 미관측 생산 조건에서 신뢰할 수 있는 불량 예측과 검사 배정.** 날짜·제품·설비 또는 Lot를 분리한 테스트를 하고, 불확실한 표본만 추가 검사로 보내는 정책을 평가한다. 목표는 검사 예산별 놓친 불량 수 감소다. 실측 검사비가 없으면 비용 절감액을 사실처럼 만들지 않고 비용비율별 민감도로 제시한다.
2. 정상 운전 모드 변화와 품질 이상을 분리하는 계층형 감시. 54·56번을 방법 참고로 쓰되, 원 자료의 실제 검사 정답으로 오경보·미검출을 검증할 수 있어야 한다.
3. 예측모델의 공정조건 추천. 단순 SHAP나 정상 IQR 범위를 최적조건이라고 부르지 않고, 관측 지지 영역과 변경 가능한 변수만 허용한다. 현장 개입 자료가 없으면 인과적인 불량률 개선을 검증했다고 주장할 수 없다.

이 중 1번이 가장 방어 가능한 후보지만, **추천은 원 자료 4번 확인을 전제로 한 조건부 판단**이다. 현재 검토 결과만으로 다섯 과제의 확정 순위를 정하지 않는다.
