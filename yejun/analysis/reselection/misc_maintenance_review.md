## 58: 검증 개선 여지는 있지만 가이드 수치를 그대로 기준으로 쓰지 않기

- PDF 7~9쪽에는 용량불량·용접불량·센싱와이어불량·온도센서불량을 설명한다. 따라서 “용접과 무관한 자료”라는 설명은 과도하다. 다만 **조립 후 충·방전 중 전압·온도 검사**이며 대회 ②의 용접 전류·가압·통전시간과 다르다. ③에도 같은 센서/고장 정의가 아니다.
- PDF 18쪽은 비지도 학습의 종속변수 없음을 설명하지만, PDF 81쪽은 별도 `..._Label.csv`를 평가 정답으로 사용한다. 학습 라벨이 없다는 사실과 평가 정답이 없다는 사실을 혼동하면 안 된다.
- 실제 별도 테스트 정답은 정상 10,792행, 이상 12,600행이다. Test01~04는 전부 정상, Test06·08·09는 전부 이상이고, Test05는 정상 757/이상 4,259, Test07은 정상 4,367/이상 227이다. 수만 행을 독립 고장 수만 건으로 해석하지 않는다.
- CRC 검사에서 얻은 전체 CSV 해시에는 동일 파일 복제가 없다. **행·신호 구간의 반복까지 검사했다는 뜻은 아니다.** 현재 이 추가 검토에서는 행별 반복을 확정하지 않았다.
- PDF 59쪽은 정상 `1000_chg.csv` 하나로 학습해 `Test07_NG_dchg.csv`를 평가한다. 여러 제품·회차를 제외하고 검증한 결과가 아니다. Test07을 센싱와이어불량이라 설명하지만 PDF 54쪽의 코드 주석은 용량불량이라 적어, 파일별 고장 유형에는 내부 불일치가 있다.
- **PDF 82쪽 코드 77은 테스트 전체에 PCA를 새로 `fit_transform`하고, 83쪽 코드 79는 결측대치기와 MinMaxScaler도 테스트 전체에 다시 적합한다.** 학습·테스트의 PCA 좌표계가 달라질 수 있고 미래 테스트 분포를 사용하는 회고적 전처리다. 온라인 탐지 기준으로는 학습 자료에서만 적합한 변환을 고정해 검증해야 한다.
- PDF 103쪽의 F1=0.7956은 해당 Test07 실습 결과다. ③에서 개선한 일반 이상탐지 방법을 여기에도 적용해 볼 가치는 있으나, 먼저 충전/방전·배터리 제품·회차 단위 분할과 전처리를 바로잡고 9개 테스트 전체를 평가해야 한다. 펌프 자체 성능 향상으로 해석할 수는 없다.

## 8: 품질 분류이며 가이드의 F1은 양품 기준

- PDF 8~10쪽: 식품 분말유크림 용해혼합 과정. `INSP`는 제품 수분함유량, `TAG`의 OK/NG는 양품/불량이다. 교반속도 0은 휴식·공정완료·투입·설비이상 등 여러 원인이므로 곧바로 고장 라벨로 바꾸면 안 된다. 온도·교반속도는 소수점 한 자리가 생략된 값이다.
- PDF 32~36쪽: 시간 순서 앞 70%/뒤 30%를 분리하고 학습 기준 정규화를 적용한다. 다만 학습행에 SMOTE를 적용한 다음 10행 창을 만들고, 그 창을 다시 무작위 학습/검증으로 나눈다. 합성 행을 실제 연속 시계열로 취급하는 문제와 겹치는 창의 내부 검증 누수를 검토해야 한다.
- PDF 30쪽은 OK=1, NG=0, PDF 42쪽의 F1=0.8912는 **양품을 양성으로 둔 수치**다. 이를 불량 탐지 F1이라고 인용하면 안 된다. 가이드 혼동행렬 설명과 일부 수치 사이에도 혼동 여지가 있어 원래 행렬부터 재계산해야 한다.

- 60 가이드 PDF 39~44쪽: 배정번호별 공정 평균/표준편차를 만들고 불량률 **0.046% 이상**을 위험으로 라벨링한다. 이 기준은 전체 자료의 3사분위수에서 정한 것으로 실제 설비 고장 판정이 아니다. PDF 48~51쪽은 무작위 80:20 분할·5겹 교차검증을 사용하고, 위험 F1=0.5를 보고한다. 새 검증에서는 품질 경계값을 사전 정의하거나 학습 구간에서 정하고, 배정번호·시간 기준으로 분리해야 한다.
- 61 가이드 PDF 25·31~33쪽: 배정번호별 최소/최대 특징으로 불량률을 회귀한다. 전체 자료로 스케일러를 적합한 뒤 95:5 무작위 분할하므로, 136개 기준 평가 표본은 약 7개뿐이다. PDF 37쪽의 “MAE” 코드에는 `mean_absolute_error(...) ** 2`가 있어 실제 MAE와 다른 값을 출력한다.
- 61 PDF 38~40쪽의 회귀계수 기반 조건 제안에는 음수 출력량, 100%를 넘는 출력량과 같은 물리 범위 확인이 필요한 수치가 있다. 가이드도 표본 부족으로 최소/최대가 역전되는 문제를 인정한다. 이를 검증된 최적 제어 조건으로 가져오면 안 된다.
