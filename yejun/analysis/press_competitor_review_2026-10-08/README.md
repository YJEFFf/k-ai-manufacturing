# 과제 ③ 공개 경쟁 레포 비교·채점 (2026-10-08)

2026-10-07~08에 찾은 과제 ③(프레스 유압펌프) 공개 레포 19개를 모두 받아, 우리 최종본과 함께 대회 서면평가 지표(100점)로 채점했다. 예준의 요청으로 진행했다.

## 방법
- **대상:** 공개 레포 19개(18팀으로 보임). 레포마다 기본 브랜치와, 기본 브랜치에 없는 커밋이 있는 다른 브랜치를 함께 받았다. 우리 쪽은 준용 최신본(origin/claude/press-cases b05570e)의 보고서 PDF(56쪽)와 제출 코드 zip이다. 모두 20개 출품이다.
- **익명화:** 출품마다 E01~E20을 무작위로 붙였다. 대응표는 [`mapping.json`](mapping.json)에 있다.
- **팩트시트:** 조사 에이전트 7개가 같은 양식([`factsheet_template.md`](factsheet_template.md))으로 작성했다([`factsheets/`](factsheets/)).
  - 코드는 실행하지 않고 읽기만 했다.
  - 모든 주장에 근거 경로를 붙였다.
  - 검증 설계(분할, 문턱, test 사용)를 코드에서 직접 확인했다.
  - 팀명·사용자명·내부 별칭은 지웠다.
- **채점:** 채점자 3명이 20개를 모두 같은 기준([`rubric.md`](rubric.md), [`judge_instructions.md`](judge_instructions.md))으로 채점했다. J1은 학계 ML 연구자, J2는 제조 설비 예지보전 현장 전문가, J3은 대회 운영위원 관점이다. 아래 점수는 세 사람의 평균이다.
- **수치 대조:** 상위 출품의 핵심 수치를 원본에서 직접 확인했다.
  - E19: 보고서 48쪽, 빨강 F1 0.931, 오경보 3창, 고장 버스트 15/17.
  - E02: 보고서 초안 490줄, 이상 17/17, 세그먼트 오경보 2.06%→0.00%.

## 우리 출품의 위치
- **순위:** 2위다. 채점자 3명 모두 E19를 우리보다 높게 줬다. E02와는 2:1로 우리가 앞섰다. 0.7점 차이는 채점자 간 편차(우리 83~88.5)보다 작다.
- **E19와의 차이:** 모델 −1.8, 코드 −0.8이고, 나머지 항목은 0.3점 이내다.
- **모델 항목 감점 이유:** 세 채점자가 같은 지적을 했다.
  - 기반 모델 설계(초반 창·전류 동역학)와 경보 유지·교차 확인 규칙을 test 오답을 본 뒤 정했다. 해시 잠금은 후보 간 선택만 통제한다.
  - 공식 test 1.000은 대부분 경보 유지 규칙의 효과다. IsolationForest를 포함해 어떤 앞단에 붙여도 0.98~1.00이 나오므로(보고서 2.7절) 모델 비교 지표가 아니다. 이 점을 point-adjust와 비슷하게 봤다.
  - J3은 하나를 더 들었다. 보고서의 베이스라인·AUROC 표 원자료가 zip에 들어 있지 않아 실행해야 확인할 수 있다.
- **E19도 받은 감점:** 평가 블록과 고장 기록을 모델 선정에도 썼고, 선정 기준을 결과를 본 뒤 바꿨다. 다만 E19의 보고 수치(빨강 F1 0.931)는 경보 유지 규칙에 기대지 않고, 제출된 예측 파일에서 그대로 다시 계산된다.
- **채점자가 꼽은 우리 강점:**
  - 형식 누수·세션 교란 진단이 conformal 문턱, 검증 선택 해시 잠금, isotonic 확률로 일관되게 이어진다.
  - 전류 교류·접힘·부하 추종 같은 신호 물리를 해석했다.
  - FN 위치와 FP 운전 상태를 정량화했다.
  - 운전원 경보 예산과 재보정 절차가 있다.
  - 한 명령 실행과 37항목 대조가 있다.

## 상위 경쟁 출품 요약
- **E19 (89.3):** 계획 8개를 병행한 작업공간이다. 최신 브랜치에 48쪽 보고서와 제출형 패키지(테스트 14건, 실시간 재생 검증)가 있다.
  - 모델: 버스트 안 10샘플 창, 1단 PCA-MSPC와 2단 진동 전용 마할라노비스, conformal p ≤ 0.01, 같은 버스트 3창 연속이면 빨강.
  - 선정: 버스트 시간블록 5겹으로 5종을 비교했는데, 탐지가 포화돼 계측 섭동 강건성으로 골랐다.
  - 확률: Platt 확률과 유병률별 사후확률을 낸다.
  - 성능: 빨강 F1 0.931(95% 0.892–0.955), 오경보 3창(0.10%), 고장 버스트 15/17. 가이드북 LSTM-AE는 F1 0.743으로 재현했다.
- **E02 (85.5):** 3인 팀, 커밋 164, PR 54, 보고서 초안이 있다.
  - 비교: 비지도 약 20종을 세그먼트 5겹과 시간 블록으로 비교했다.
  - 선정: 부트스트랩으로 후보 간 차이가 없음을 보인 뒤 운영 기준으로 2단계 경보를 골랐다. Ridge-VAR(1차 차분)가 넘으면 주의, Ridge와 MCD가 함께 넘으면 경보다.
  - 성능: 이상 17/17, 세그먼트 오경보 2.06%→0.00%(5겹), 1.70%→0.25%(시간 블록).
  - 그 밖에: 오경보 조건 통계 검정, 정적 HTML 대시보드, 챗봇이 있다.
  - 약점: 홀드아웃과 이상 확률이 없다.
- **E09 (81.5):**
  - 장점: test를 마지막에 한 번만 쓴 가장 깨끗한 절차다. 구간 단위 시간순 6:2:2 분할, val 정상 오경보율 1% 문턱을 썼다. FP/FN을 부하·전환·시간대별로 분석했다.
  - 모델: IF 점수와 LightGBM 확률의 하이브리드. test F1 0.866, 오경보율 1.4%.
  - 약점: val 이상이 3구간뿐이라 최종 결합이 동률 해소로 정해졌다.
- **E17 (76.3):** 제출 코드 형태다. 후보 13종 중 Isolation Forest를 4단계 관문(스트레스 오경보 → 정상 조각 오경보 → 부트스트랩 재현율 하한 → 탐지율)으로 골랐다. 경보는 3단계다. 관문을 시험 자료에서 계산했다.

## 해석할 때 주의
- **블라인드가 완전하지 않았다.** 채점자 3명 모두 E05가 우리 출품이라고 짐작했다. 자동으로 주어진 문맥(메모리 색인, git 상태의 `tvt/09_component_ablation.py` 같은 경로)이 E05 팩트시트의 경로·용어와 겹쳤기 때문이다. 세 사람 모두 같은 기준을 적용했다고 밝혔지만 영향을 배제할 수는 없다. E05 팩트시트 작성자도 우리 것임을 알아봤고, 약점을 같은 무게로 적었다고 밝혔다.
- **경쟁 출품 점수는 공개 자료 기준의 하한이다.** 보고서가 레포에 있는 곳은 E19(48쪽 PDF), E02(보고서 초안), E14(연구 보고서) 정도다. 나머지는 실제 제출 보고서에 더 많은 내용이 있을 수 있다. 특히 E09·E17·E03·E01·E18은 위로 올라갈 여지가 있다.
- **코드는 실행하지 않았다.** 외부 코드라 보안상 읽기만 했고, 재현성은 정적으로 점검했다.
- **레포는 10-07~08 시점의 모습이다.** 제출 전에 바뀔 수 있다. E19의 최신 브랜치가 실제 제출본인지도 알 수 없다.
- **E01과 E18은 같은 팀으로 보인다.** E01 README가 E18 레포를 팀원 저장소로 적는다. 따로 채점했다.
- **실제 심사와 다르다.** 실제 심사는 위원 5명이 보고서·발표자료로 하고, 최고·최저를 뺀 평균을 쓴다. 여기 점수는 그 근사가 아니라 같은 잣대로 매긴 상대 비교다.
