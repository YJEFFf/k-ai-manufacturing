## 1. 데이터 이해·진단
- 기록 단위 구조 [있음]: 정상 600·이상 21기록, 최대 50행(1.4·1.6절; `press_evidence/gaps.csv`).
- 샘플링·시간 공백 [있음]: 77분 중 측정 33분, 공백 중앙 4.2초, 시각이 계산값일 가능성 제기(1.4절).
- 중복 행 [있음]: 정상 1행, 처리 방식 명시(`press_evidence/duplicate_rows.csv`).
- 결측·이상치 [있음]: 결측 0, 이상치 유지(`press_evidence/outliers.csv`).
- 클래스 불균형 [있음]: 이상 2.9%, 전부 양성 F1 기준선 0.227·0.164 제시(`press_evidence/imbalance.csv`). 정상만 학습해 대응.
- 날짜·세션 교란 [있음]: 지도학습이 같은 날 정상끼리도 1시간 떨어진 블록을 ROC-AUC 0.75~0.87로 가름(2.6절; `domain/05_supervised_confound.py`).
- 저장 방식 차이 [있음]: 자릿수 규칙만으로 행 F1 0.992(원본 CSV로 재계산해 확인). 두 파일을 같은 격자로 반올림(`code/<개인폴더>/<이전패키지폴더>/press/data.py` 125–134).
- 변수 의미 [있음]: 전류는 교류 순시값, 0.6Hz는 60Hz 계열 접힘 가설, 하부 진동은 부하 추종(1.4절).
- 이상 한 사건 한계 [있음]: 2분 46초 한 사건, 사건 단위 표본 1(1.6·2.5절).
- 전처리: 정밀도 맞춤, 기록 분할, 창은 기록 안에서만(1.7절).
- 검증전략 연결: 정상 기록 시간순 분할 두 가지와 이상 앞 10기록 검증·뒤 11기록 시험(`tvt/lib.py` 24–25; `tvt/01_scores.py` 80), 구간 간 시각 겹침 0을 assert(`tvt/01_scores.py` 84–90). 다만 시험 정상은 보정 구간보다 저부하 비율이 크게 높아(78%·65% 대 35%·32%; `press_evidence/split_state_composition.csv`) 오경보 추정이 낙관적일 수 있다(보고서도 인정).

## 2. 모델
- 베이스라인: IsolationForest, 가이드북식 LSTM 오토인코더(20행 창), 한 행 max|z|, 5NN, MLP 오토인코더. 모두 정상만 학습, 같은 분할·같은 conformal 보정 α 1%(`tvt/01_scores.py` 117–125; `tvt/evalcore.py` 15–30).
- 비교한 모델: 주 비교(모두 비지도)는 2성분 모델, 기반 모델, 부하 조건부 진동 성분 추가형 2종, 기록 단위 모델 7종, 규칙 조합. test 이후 사후 대조는 PCA 관리도, CUSUM·EWMA, 보완 LSTM(516개 변형 중 검증으로 선택), 지도학습 3종(교란 대조용).
- 최종 모델과 선정 근거: "검증 실시간 행 F1 최고, 0.002 이내면 단순한 쪽" 규칙(`tvt/02_select_on_valid.py` 16, 36–41)이 기반 모델+규칙 1을 골라 해시로 잠갔고(`tvt/03_score_test.py` 18–29) 이것이 공식 성능이다. 규칙 2를 더한 2단계는 test 확인 뒤 추가한 운영안으로 분리했다. 기반 모델 근거는 규칙 없는 test F1(0.965·0.970 대 베이스라인 최고 0.498), 문턱 무관 AUROC(0.975·0.974 대 0.895·0.862), 성분 절제(2.4절).
- 검증 설계: 기록 단위 시간순 분할이라 같은 기록이 학습·평가에 함께 들어가지 않고 창도 기록을 넘지 않는다. 문턱은 검증 정상 기록 최대 점수의 conformal 순위(검증 채점은 자기 기록 제외, `tvt/01_scores.py` 39–51). test 이상 흐름은 검증 기록에서 이어 돌려 규칙 1이 직전 판정을 이어받는다(`tvt/evalcore.py` 59–74).
  - test를 보고 정한 것: 규칙 2. 또 기반 모델 설계(초반 창·AR(2))와 확인 2행은 이상 21기록 전체를 본 뒤 정했고, 규칙 1·2는 test 정상 구간과 이상 21기록 전체에서 기반 모델의 오답을 본 뒤 만들었다(`cases/README.md` 39–60행; `code/<개인폴더>/<기반모델폴더>/model.py` 32·497행). 해시 잠금은 그 뒤 후보 간 선택만 통제한다(1.7·2.3절이 밝힘).
- 보고 성능(test 행 F1, α 1%): 잠금 모델 1.000·0.995(오경보 0·3행), 2단계 1.000·1.000, 기반 모델 0.965·0.970(미탐 22·16행). 예측 파일로 재계산해 일치하고 파일 해시도 `expected_results.json`과 같다. 행이 주 단위, 기록이 보조. 이상 test는 한 사건 뒷부분 11기록(324행), 정상 test는 달력 16·24분. 베이스라인·AUROC·운전 상태 표는 산출물이 없어 확인하지 못했다. 보완 LSTM 0.975·0.972는 `<보완실험폴더>/outputs/03_comparison.json`에서 확인.
- 이상 확률: 있음. 검증 정상·이상 행으로 isotonic 우도비를 맞추고 사전(현장 1%, test 파일 비율)으로 변환(`tvt/08_probability.py` 38–46). Brier·AUROC 재계산 일치. 현장 1% 확률은 55% 상한에서 멈춰 경보끼리 순위를 못 가리고, 파일 비율 사전은 test 라벨 비율을 쓴다(평가용 명시).
- 누수·과대평가 위험:
  1) 검증·시험 이상이 한 사건의 앞뒤라 선택과 채점이 같은 사건에 의존(`tvt/lib.py` 25).
  2) 위의 설계 단계 test 노출.
  3) 규칙 1을 붙이면 어느 앞단 모델이든 test 0.982~1.000(IsolationForest도 1.000, 2.7절 표)이라 공식 1.000은 모델 비교 지표가 아니다. test 기록부터 따로 돌리면 0.612 대 1.000으로 갈린다(보고서가 밝힘).
  4) 규칙 1의 기록 채우기는 point-adjust와 비슷한 행 F1 이득(1.7절 인정).
  5) 두 분할은 이상 test가 같다.

## 3. 영향요인·오류분석
- 영향변수: 기록 특징 AUROC(전류 사인 R² 1.000, 진동 자기상관 0.945), 성분 누적 F1(크기만 0.404·0.428 → 파형 추가 0.904·0.912 → 3성분 0.965·0.970), 성분 절제 주입(`tvt/09_component_ablation.py`), PCA 기여 분해(3.1절).
- 상호작용: 정상 하부 진동 SD가 전류의 1.73제곱에 비례(R² 0.93), 부하를 빼도 이상 진동 z 8~9, 상·하부 상관 0.28→−0.36(2.2절). 이를 규칙 2로 연결.
- FN 조건 (정량): 기반 모델 test 미탐 22·16행 중 기록 위치 0~1이 14·12행(예측 파일로 확인), 진동이 작은 이상 기록 3개(3.3절). 인공 주입에서 진동 단독 변화는 최대 35%, 진폭 감소는 0~2%만 잡는다(2.6절).
- FP 조건 (정량): 운전 상태 5종×모델 5종 표, 고부하 오경보 비율 14.0%(95% 10.6~18.0) 대 전체 3.8%, 학습에 없던 정숙 구간은 10모델×3α 합계 1행(3.2절; `domain/06_operating_regime.py`). test 오경보 3행 위치 41·40·11 확인. 규칙 2 효과(9/53→1/53)는 착안 자료 안의 사후 확인이라 효과 크기를 주장하지 않는다고 적음.

## 4. 현장 활용
- 경보 단계: 1단계 "주의"(잠금 모델, 표시만), 2단계 "점검 요청"(규칙 2 통과, 출동).
- 점검 우선순위: 경보 근거별 점검 순서 표, 이상 양상별 먼저 볼 곳(`domain/07_anomaly_patterns.py`).
- 작업자 행동: 의심 가공품 보류, 콘솔 양식으로 사건 종료.
- 실시간 적용: 행 단위 판정, 묶음 업로드 시 최대 5초 지연. 합성 열화 시험에서 전류 파형 열화는 95.8~100%가 최대 강도 전에 경보(4.3절).
- 재보정·운영: 설계 경보량과 ISA-18.2 운전원 예산 비교, 도입 첫 달 측정 후 α 조정, 현장 재보정, 시각 동기화, 수집 개선 4단계(4.3·4.4절). 웹 콘솔은 규칙 1·2 미반영(보고서 인정).

## 5. 창의성·차별성
- 확률보정·불확실성: conformal 문턱, isotonic 우도비 확률과 Brier·ECE, Clopper–Pearson·포아송 상한, 기록 단위 부트스트랩.
- 제조지식: 유압·기어펌프 고장 서명 문헌, 나이퀴스트·접힘으로 관측 가능 정보 선별, ISO 13379-1 고장모드 매트릭스(1.2~2.1절).
- 독창 설계: 형식 누수 제거, 세션 교란 측정, 수집 조건 흔들림 시험, 인공 주입·성분 절제, 파형 확인으로 풀리는 경보 유지 규칙.
- 불균형은 정상만 학습으로 회피, 앙상블은 사후 보완 LSTM의 seed 3개 평균뿐이다. 핵심 규칙 두 개는 사후 착안이라 표본 밖 근거가 없다.

## 6. 코드·재현성
- 실행 진입점: 한 명령 `python run_all.py`(약 46분) 또는 `--quick`(약 14분). 해시 확인→진단→학습→검증 선택·잠금→test 채점→예측 파일→확률→사후 분석→37항목 대조(`code/run_all.py` 33–60, 98–189).
- 의존성·경로·시드 등: 판 고정(파이썬 3.13), 상대 경로, 원본 SHA-256 확인, seed 고정, 데이터·예측 파일 포함. 단위 테스트 대신 기대값 대조.
- 정적 점검 문제: ① 보고서 표 산출물이 없어 대부분 실행해야 확인 가능. ② 최종 스크립트가 `sys.path`로 이전 모듈 3개를 불러 쓰는 다세대 구조(`tvt/lib.py` 47–60)이고 옛 실행 안내가 남아 혼동 여지. ③ 외부 UCI 실험·콘솔 화면은 재생성되지 않고 보완 LSTM은 별도 8시간 실험. ④ 검증 실험 기준을 미리 고정했다는 계획 문서(`tvt/04_validation.py` 3행)가 자료에 없음. ⑤ macOS·Linux 미확인.

## 7. 강점 3가지 / 약점 3가지
- 강점 1: 형식 누수(재계산 확인)·기록 구조·세션 교란·단일 사건 진단이 기록 단위 시간순 분할, 정상 검증분 conformal 문턱, 검증 선택 해시 잠금으로 이어진다.
- 강점 2: 베이스라인 5종을 포함한 여러 모델을 같은 분할·같은 α로 비교했고, 문턱 무관 AUROC·부트스트랩·성분 절제·인공 주입·교란 대조를 더했다.
- 강점 3: FN 위치와 FP 운전 상태를 정량으로 보이고 경보 단계·점검 순서·재보정 절차로 이었다. 한 명령 실행과 37항목 대조로 재현성이 높다.
- 약점 1: 공식 1.000은 대부분 규칙 1의 경보 유지 효과이고 test가 같은 사건 뒷부분이라 모델 우열을 가르지 못한다(보고서 인정).
- 약점 2: 기반 모델 설계와 규칙·상수를 test 행의 오답을 본 뒤 정했고 2단계 규칙은 test 뒤 더했다. 해시 잠금은 후보 선택만 통제해 test 재사용 위험이 구조적으로 남는다.
- 약점 3: 다세대 모듈 의존, 산출물 미포함, 많은 단서와 사후 분석 때문에 선택 경로를 따라가기 어렵다. 정상 test가 짧고 조용해 오경보 추정이 낙관적이고, 진동 단독 고장은 감시 범위 밖이다.

## 8. 치명적 문제 (있으면)
- 코드 수준의 누수(무작위 창 분할, test로 학습·문턱 결정)는 확인되지 않았다. 다만 공식 test 수치는 단일 사건 뒷부분이고 설계 단계에서 이미 본 행이라 일반화 성능으로 읽을 수 없다(보고서도 같은 결론).
