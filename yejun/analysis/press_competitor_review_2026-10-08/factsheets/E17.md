## 2. 모델
- 베이스라인: AI0 진동 표준편차 단일 특징 문턱(repo/src/models.py:12-24).
- 비교한 모델(모두 정상만 학습하는 비지도): 마할라노비스, Isolation Forest, MLP 오토인코더, PCA 재구성, GMM(k=5, 학습 BIC로 선택), 원시 창 1D CNN 오토인코더(증강 유무). 특징 세트 3종(전체 15, 평균류 제외 12, 원시 30값)과 조합해 13개 후보(repo/results/selection_pool.csv). 순위평균 앙상블, 오프셋·이득·잡음 증강 학습 3종, 스펙트럼 특징 실험도 같은 관문에 적용했으나 최종 선택은 바뀌지 않음.
- 최종 모델과 근거: 전체 15특징 Isolation Forest(repo/results/final_summary.json). 관문은 순서대로 스트레스 최악 창 오경보 ≤0.10, 정상 조각 오경보 ≤0.08, 부트스트랩 재현율 5% 하한 최대(동률 폭 0.02), 이상 조각 탐지율 최대, 단순성(repo/src/selection.py:13-46, repo/src/config.py:25-27). 시험 F1이 더 높은 GMM(0.974)·마할라노비스(0.953)는 스트레스 최악 오경보 1.0으로 탈락했다.
- 검증 설계: 정상 조각을 시간 순서대로 학습/검증/시험으로 나눔(repo/src/data.py:28-34). 같은 조각은 한 분할에만 들어가고, 창은 조각 안에서만 겹친다. 이상 파일은 학습에 쓰지 않는다. 문턱은 검증 정상 점수 99백분위(repo/src/pipeline.py:34). 그러나 선정 관문 1·2단계는 정상 시험 분할(repo/src/stress.py:33-36, repo/src/pipeline.py:42-57)에서, 3·4단계는 유일한 평가용 이상 자료인 이상 파일(repo/src/bootstrap.py:16-35)에서 계산한다. 최종 모델과 경보 방식 조합은 시험 자료를 보고 고른 것이며 별도 선정용 자료가 없다.
- 보고 성능(노트북 출력·결과 파일): 창 단위 F1 0.898, 정밀도 0.988, 재현율 0.823, AUROC 0.997, 정상 창 오경보 0.15%. 조각 단위로 이상 16/17, 정상 1/109(repo/results/model_comparison.csv). 예측 파일(test_predictions_window.csv)로 다시 계산해 일치를 확인했다(TP 79, FN 17, FP 1, TN 669). 3단계 조각 경보는 관찰 탐지 100%·정상 오경보 11.9%, 주의 94.1%·0.9%, 경고 82.4%·0%(repo/results/hybrid_tier_cascade_summary.csv, test_predictions_segment.csv와 일치).
- 이상 확률 산출: 직접 확률은 없다. 검증 정상 점수 대비 창 p-값(repo/src/alarm.py:19-22), 조각 결합 p-값, e-값 순차검정(repo/src/seqtest.py:28-40)을 낸다.
- 누수·과대평가 위험:
  - 시험 자료로 모델을 고름(위). 관문 상수가 결과를 보기 전에 정해졌는지 확인할 기록이 없다.
  - 이상 21조각 중 10샘플 미만 4조각은 창이 없어 평가에서 빠진다(repo/src/eda.py:75). 가장 짧아 놓치기 쉬운 조각이 분모에서 제외된다.
  - 평가 이상 17조각은 한 사건에서 나왔다. 창 단위 지표는 반쯤 겹치는 창의 집계다.
  - 최종 모델은 평균류 특징을 포함한다. 평균류만으로 세션 구분이 됐으므로(AUROC 0.944) 탐지 일부가 세션 차이에 기댈 수 있다. 평균류를 뺀 IF는 재현율 0.69로 낮다.

## 3. 영향요인·오류분석
- 영향변수 분석: 오경보 창의 특징별 기여(특징을 학습 중앙값으로 바꿨을 때 점수 감소, repo/src/explain.py:5-12). 오경보 창이 1개뿐이라 진동 상관·평균류 순이라는 사례 수준이다. 미탐 창 17개의 강건 z-점수(repo/results/explain_missed_z.csv)와 판별 분류기의 단변수 AUROC(repo/results/adversarial_univariate.csv: 진동 비·상관·전류 표준편차 상위)도 있다.
- 변수 간 상호작용: 미탐 여부를 깊이 3 결정나무로 설명(repo/results/interaction_fn_tree.txt). AI0 진동 표준편차 ≤0.11 분기가 중요도 0.71이고 AI1 파고율·AI0 첨도와 결합한다. 오경보는 1개라 나무를 만들지 못했다.
- FN 조건(정량): 미탐 창 17개 모두 점수가 문턱의 0.89~1.00배로 경계 근처이고, 진동 표준편차가 낮은 창이다(위 결정나무). 합성 이상 주입으로 50%/90% 탐지에 필요한 진폭이 정상 표준편차의 3.1배/5.3배라고 측정했다(repo/results/injection_summary.csv).
- FP 조건: 정상 시험 오경보가 창 1개뿐이라 조건 정량이 불가하다. 대신 오프셋·이득 시나리오별 오경보를 정량화했다. 최종 모델 최악 창 오경보 6%, 주의 단계 조각 오경보 최악 17.4%(repo/results/stress_test_detail.csv, operating_scenario_table.csv).

## 4. 현장 활용
- 경보 단계: 관찰(유의수준 0.20, 고정 격자 규칙)·주의(0.05)·경고(0.01, 둘 다 e-값)(repo/src/tier_mix.py:8). 유의수준을 미리 고정하고 정상 시험에서 Clopper-Pearson 구간으로 보정 여부를 확인했다(repo/results/alarm_calibration.csv, evalue_calibration.csv).
- 점검 우선순위·작업자 행동: 단계별 조치(자동 기록 / 다음 정지 주기 점검 / 즉시 정지), 승격 규칙(같은 교대 2회 반복 시 승격), 담당(repo/src/scenario.py:17-31). 코드 주석이 "정성 규칙, 정량 검증 안 함"이라고 밝힌다.
- 실시간 적용: 조각 단위 순차 판정(지연 중앙값 1.0~1.5초)과 시간당·8시간 교대당 오경보 수(관찰 48.5회/시간, 주의 3.7회/시간). 약 16분 길이의 정상 시험 구간에서 환산한 값이다. 스트리밍 실행 코드는 없다.
- 재보정·운영 절차: 학습 정상 오염 민감도 실험(repo/results/contamination_sensitivity.csv)은 있으나 재보정 주기·절차는 없다.

## 5. 창의성·차별성
- 세션(날짜) 차이 대응: 판별 분류기 진단 → 오프셋·이득 스트레스 관문 → 평균류 제외 특징·증강 학습 비교로 이어진다.
- 확률적 경보: 검증 분포 기반 경험적 p-값, e-값(Ville 부등식) 순차검정, 단계별 오경보 보정 점검.
- 조각 단위 부트스트랩 재현율 하한, 합성 이상 주입으로 탐지 진폭 측정, 학습 오염 민감도.
- 순위평균 앙상블도 시험했으나 관문에서 탈락했다. 설비 물리 지식 결합은 없다.

## 6. 코드·재현성
- 실행 진입점: 한 명령 `python run_all.py`(README 기준 CPU 약 8분) 또는 노트북 Run All. run_all.py:38-241이 데이터 적재→특징→후보 학습→선정→경보→예측 파일→운영표 순서로 실행한다.
- 의존성 정확히 고정(repo/requirements.txt), 프로젝트 루트 기준 경로(환경변수로 데이터 위치 변경 가능), 시드 42 고정(numpy·torch·각 모델), 데이터·예측결과 포함. 테스트 코드는 없다.
- 정적 점검 문제: repo/src/error_analysis.py는 run_all.py에서 호출되지 않는 미사용 모듈이다. 그 밖의 하드코딩 경로나 없는 파일 참조는 보이지 않았다.

## 7. 강점 3가지 / 약점 3가지
- 강점 1: 날짜·세션 차이를 판별 분류기와 스트레스 시험으로 직접 진단하고, 그 결과를 모델 선정 기준에 넣었다.
- 강점 2: 시간순 조각 분할, 검증 정상만으로 정한 문턱, 학습에서 뺀 이상 자료. 결과 파일과 예측 파일이 서로 일치한다.
- 강점 3: p-값·e-값 기반 3단계 경보와 단계별 조치·승격·담당 표, 한 명령 재현(버전·시드 고정, 데이터 포함).
- 약점 1: 선정 관문이 모두 정상 시험 분할과 이상 파일에서 계산되어, 시험 자료로 모델과 경보 방식을 골랐다.
- 약점 2: 평가 이상이 한 사건의 17조각(짧은 4조각 제외)뿐인데 이 한계를 서술하지 않았다.
- 약점 3: 서술형 보고서가 없고 README에 수치·해석이 없다. FP 분석은 오경보 1개에 그치고, 변수 의미와 정밀도·양자화 진단이 없다.
