## 2. 모델
- 베이스라인: 가이드북 LSTM-AE 재현(PyTorch 시험 F1 0.705, TF 0.755, 가이드 0.748; [가이드재현]·branches/guide_*-reproduction/experiments/reproduce/tensorflow_reproduction.ipynb 셀 21), 행 단위 절댓값 규칙(F1 0.481; [초기분석] §5), 구간 분할 위 기본 LSTM-AE.
- 비교한 모델(모두 정상 전용 비지도): 구간 분할 위 LSTM-AE·ModernTCN(원신호/특징), 센서별 인코더(LSTM·ModernTCN·MLP)+FFT·P2P·RMS, 전류만·진동만, 부호 보존 MinMax, Optuna 조정 7개(branches/experiment_phm_base/phm_base/notebooks/). 초기 분석의 Isolation Forest.
- 최종 모델과 선정 근거: 없음(0절).
- 검증 설계: 구간 분할 실험([센서LSTM] 셀 21·25·39)은 정상을 구간 경계에서 시간순 70/10/20, 이상을 앞 1/3 Valid·나머지 Test로 나누고 창은 구간 안 stride 1. 같은 조각 공유 없음. 가중치는 정상 Valid loss, 문턱은 정상 Valid Q99(기본) 또는 Valid 최대 F1(이상 Valid 사용), Optuna 후보는 Valid AP로 선택(branches/experiment_phm_base/phm_base/notebooks/tuning/H04_sensor_lstm_all_features_optuna.ipynb 셀 41), Test는 선택 고정 후 평가. 가이드 분할 계열은 창을 만든 뒤 나눠 Valid/Test 경계 19행이 겹치고([가이드재현] 셀 14; [가설설정] §3) 공백을 넘는 창을 쓰며 문턱을 이상 Valid로 정함(창 길이 비교만 경계 49개 제거, [창보고서] §2).
- 보고 성능(창 단위; 구간 분할 Test 정상 1,988·이상 174창=이상 9구간; Q99/최대 F1 문턱): 기본 LSTM-AE 0.915/0.936(AP 0.977; [기본LSTM] 셀 39), ModernTCN 원신호 0.969/0.985, 센서 LSTM+특징 0.969/0.979(AP 1.000), 센서 MLP+특징 0.983/0.945, 전류만 0.781/0.878, 진동만 0.757/0.808 — 노트북 출력에서 확인. [건강점수] 수치는 branches/experiment_phm_base/phm_base/notebooks/analysis/96_saved_threshold_health_scores.ipynb 셀 10·14 출력과 일치. 가이드 분할 계열: 창 10/20/30 Test F1 0.721/0.594/0.497(branches/experiment_window-size-comparison/results/window_compare_02/summary.csv와 일치), 부호 보존 0.760 대 절댓값 0.693, P2P 결합 0.820(branches/report_hypothesis-validation/*-validation-total/results/h1_signed_input/ablation_comparison.csv, branches/report_hypothesis-validation/*-validation-total/results/h2_p2p_fusion/abc_test_comparison.csv와 일치), 행 위치 분할 Colab LSTM-AE 0.793.
- 이상 확률 산출: 없음. 확률 보정은 별도 노트북에서 한다고 적었으나 파일 없음([센서LSTM] 셀 38). 건강점수(0~100)는 로그 오차의 선형 변환이며 확률이 아니라고 명시([건강점수] §1, §4).
- 누수·과대평가 위험: (1) 이상 Valid·Test가 같은 사건의 인접 구간이고 문턱·후보 선택에 이상 Valid를 씀. (2) 특징 모델 Test AP 1.000과 단일 전류 주파수 변수 AUC 1.000은 날짜·파일 차이 학습 가능성을 시사하나 미점검. (3) 같은 Test로 20여 개 실행을 평가했고 Colab 선택 기록에 test_previously_seen=true(branches/experiment_phm_base/ipynb_experiments/KAMP_LSTM_AE_v4_Colab.ipynb 셀 40), [건강점수] §9도 Test 반영을 인정. (4) 가이드 분할 계열은 경계 겹침·공백 넘는 창(작가도 "누수 방지 재설계가 아님"이라 명시).

## 3. 영향요인·오류분석
- 영향변수 분석: 파생변수 62개 Valid AUC 순위(전류 고주파 대역·자기상관 AUC 1.000), VIF로 대표 변수 10개([변수분석] §5-6), 전류 RMS–P2P 정상 띠 이탈 AUC 0.92, 센서 단독 모델 비교.
- 변수 간 상호작용: 정상·이상에서 상관이 뒤집히는 쌍 정량(AI0–AI1 +0.39→−0.44, AI1/AI2 비율–전류 차분 RMS 0.89→−0.43; [변수분석] §1, §6).
- FN 조건 [정량]: 전류 P2P 기반 "저부하/가동" 대리 상태별 재현율 — 기본 LSTM-AE Test(최대 F1) 저부하 0.849(73/86) 대 가동 1.000(88/88)([기본LSTM] 셀 42). 구간 단위로는 Test 이상 9구간 모두 경보.
- FP 조건 [정량]: 행 위치 분할에서 정상 오탐 전부가 공백을 넘는 창([분할비교] §3), 정상 Test 구간 경보 4/90(최대 F1)·12/90(Q99)([기본LSTM] 셀 42), 관찰 부담(Q95에서 정상 Test 구간 49/90; [건강점수] §5.2).

## 4. 현장 활용
- 경보 단계: 건강점수 3단계(정상 50~100·관찰 45~49·이상 0~44), 경계는 Valid P=R 문턱과 정상 Valid 분위수로 설정([건강점수] §1-5). 급하락 경보: 최근 1초 Theil–Sen 기울기가 정상 기준 꼬리 1%를 2회 연속 넘으면 새 경보, 유지·해제 규칙, 사용자 문구 9종(§7-8). 점검 우선순위: 관찰마다 조사할지에 따라 Q95/Q98 선택 안내. 운영 규칙: 기록 재시작 후 20행이 모일 때까지 판정 보류([판단근거] §11). 재보정: 불필요 경보 빈도·선행시간·분포 변화 점검 항목([건강점수] §9). 실시간: 창당 추론 지연 측정(Colab 노트북).

## 7. 강점 3가지 / 약점 3가지
- 강점 1: 공백·구간 처리를 통계로 진단해 구간 경계 시간순 분할·고정 manifest로 연결했고 이후 실험이 채택.
- 강점 2: 같은 분할·같은 문턱 정책에서 여러 재구성 모델과 센서 단독 실험을 하고, 문턱을 Valid로만 정하며 Test 사용을 기록.
- 강점 3: 건강점수·급하락 경보 등 운영안이 구체적이고 운전상태·구간·공백별 오류를 정량화.
- 약점 1: 최종 모델·성능·통합 보고서·예측결과 파일이 없고 브랜치마다 분할이 달라 결론이 흩어짐.
- 약점 2: 이상 Valid·Test가 같은 사건이고 날짜·저장 방식 교란을 점검하지 않아 AP 1.0 수준 성능이 과대평가됐을 가능성.
