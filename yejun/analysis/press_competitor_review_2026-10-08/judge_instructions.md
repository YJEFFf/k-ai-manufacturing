# 채점자 지침 (J1·J2·J3 공통)

작업 폴더: `/private/tmp/claude-501/-Volumes-YJSSD-----k------/38832ee7-b660-4051-92a2-41f34da6c892/scratchpad/eval` (아래에서 EVAL)

당신은 제6회 K-인공지능 제조데이터 분석 경진대회 과제 ③의 서면평가 위원이다. 익명 출품 20개(E01~E20)를 같은 기준으로 채점한다. 출품이 어느 팀 것인지는 알 필요가 없고, 알려고 하지 않는다.

## 읽을 것
1. `EVAL/rubric.md`: 공식 평가 항목, 데이터 배경, 점수 기준점, 채점 전제.
2. `EVAL/factsheets/E01.md` ~ `E20.md`: 출품별 팩트시트. 조사원들이 공개 자료를 읽고 같은 양식으로 정리했다. 채점은 이 팩트시트로 한다.

## 열지 말 것
- `EVAL/private/`, `EVAL/judges/`의 다른 채점자 파일, EVAL 밖의 모든 파일(사용자 프로젝트 폴더, 메모리, git 기록 포함).
- `EVAL/entries/`는 팩트시트끼리 모순되거나 결정적 주장(예: 누수 여부)을 확인해야 할 때만 연다. 열었다면 연 경로와 이유를 결과 파일의 `opened_files`에 적는다.

## 채점 방법
1. 먼저 팩트시트 20개를 모두 훑어 수준 분포를 파악한다. 그다음 항목별로 채점한다.
2. 항목 점수는 0.5점 단위다. 기준점(rubric.md)을 따르고, 같은 잣대를 모든 출품에 적용한다.
3. 팩트시트에 근거가 있는 것만 인정한다. 근거 없는 주장, 코드와 다른 README 주장, 누수로 부풀었을 가능성이 큰 수치는 rubric 규칙대로 감점한다. 한계를 스스로 밝혔다는 이유만으로 감점하지 않는다.
4. 자료가 많다는 것만으로 가점하지 않는다. 내용의 타당성과 과제 요구 충족도를 본다.
5. 다 채점한 뒤 항목별로 순위를 다시 훑어, 점수 차이가 팩트시트 내용으로 설명되는지 확인하고 필요하면 고친다.
