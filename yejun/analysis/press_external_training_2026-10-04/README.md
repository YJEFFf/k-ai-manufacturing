# 외부 데이터의 학습량 증가 효과 비교 — 2026-10-04

사용자 요청은 **UCI·SKAB·Beihang·ESPset을 학습에 추가했을 때 대회 데이터의 예측이 좋아지는지**다. 외부 데이터에서 모델 성능을 평가하는 작업은 하지 않았다. 대회 보고서나 최종 모델 선정 문서가 아닌 구현·실험 기록이다.

**네 자료 모두 공통 진동 표현을 통해 학습 입력으로 연결하고 실제로 학습했다. 그러나 이번 두 학습 경로에서 원자료만 사용하는 3센서 기준 모델을 넘어선 설정은 없었다. 네 자료를 섞어 쓰는 효과도 입증되지 않았다.** 이는 아래 표현·모델·학습 예산에서의 결과이며 모든 전이학습 방법의 불가능성을 뜻하지 않는다.

## 비교 조건

- 원자료의 완전 중복 한 행을 제거한 정상 599기록·이상 21기록을 사용했다. 기존 분할 P0/P1/P2를 동일 적용하고 양쪽 라벨에 입력 정밀도 보정을 똑같이 적용했다.
- 정상의 시간순 fit/cal/evaluation은 각각 0–10/10–20/20–40분, 0–20/20–40/40–60분, 0–40/40–60/60분 이후다. 경계를 가로지르는 기록은 해당 역할에서 제외한다.
- 세 분할의 정상 평가 기록은 157/156/126개다. 이상 21기록은 모든 분할에서 같은 한 수집 에피소드를 사용한다. 이미 살펴본 자료에 대한 탐색 비교이며 새 독립 시험이 아니다.
- 문턱은 **대회 정상 cal만**으로 정했다. 외부 자료를 cal이나 평가 분모에 넣지 않았다. 주 α는 5%, 보조 α는 1·3%다. P0는 정상 cal 77개로 최소 순위 p=1/78이라 α1% 경보를 낼 수 없다. 이 보조 결과를 모델의 탐지 실패로 해석하지 않는다.
- 평가는 기록 종료 후의 기록 단위다. 과거 행 단위 F1 0.96–1.0이나 조기탐지 지연과 직접 비교하지 않는다.
- 각 외부 자료와 네 자료의 균등 혼합을 각각 시험했다. 요청 추가량은 target 진동 학습 예제 수의 1배·4배, 난수 seed는 11·29·47이다. 부족한 자료를 복제해 수를 채우지 않았다.

## 입력을 맞춘 방법과 범위

상부·하부 진동과 전류를 그대로 갖춘 동일 센서 자료가 네 개 생긴 것은 아니다. **전력이나 속도를 전류로 대체하지 않았다.** 외부 자료의 역할은 공유 진동 학습기다.

각 진동 채널의 양의 주파수 에너지를 상대 주파수 16구간으로 요약하고, 전체 에너지로 나눈 뒤 제곱근을 취했다. 원시 시계열은 구간 평균을 빼고 FFT를 계산한다. ESPset은 배포된 스펙트럼을 직접 사용하며 없는 위상이나 시계열을 만들지 않는다. 물리적 Hz·센서 단위·회전수·장착 위치가 같아졌다는 뜻은 아니다. 진동 진폭과 전류 정보는 target 3센서 기준 모델이 계속 처리한다.

학습 효과를 두 관점으로 남겼다.

1. **진동 학습기 단독:** 외부 학습이 실제로 해당 학습기에 미친 영향을 본다. 4표본 미만 target 기록도 분모에 남기고 미지원·무경보로 처리한다.
2. **3센서 결합:** 같은 분할로 다시 학습한 Press Guard v2 점수와 진동 학습기의 fit-only 꼬리 점수 중 큰 값을 사용하고, 동일 target cal로 보정한다. 짧은 기록은 기준 모델 판정을 사용한다. 여기서 v2는 효과 분리를 위한 고정 대조이며 새 최종 모델 선택은 아니다.

| 외부 자료 | 만든 진동 학습 예제 | 정상 혼합학습에 사용 가능한 예제 | 실제 수집 단위와 한계 |
|---|---:|---:|---|
| UCI | 2,205 | 10 | 60초 사이클당 VS1 앞 32표본. 정상은 네 부품 모두 정상이고 안정 상태인 경우로 제한. 누설 없음만으로 다른 고장 상태를 정상으로 붙이지 않음 |
| SKAB | 4,890 | 3,426 | 30수집 그룹의 RMS 진동 채널. 겹친 관측 중복 제거, 237주석 충돌은 정상 혼합학습에서 제외. 공백을 잇지 않음 |
| Beihang | 8,448 | 1,536 | 11파일·정상 2파일. 축별 시간축을 따로 처리하고 파일·축당 최대 256창. 예제 수가 독립 시험대·고장 수는 아님 |
| ESPset | 6,032 | 4,801 | 11개 펌프의 스펙트럼. ID와 스펙트럼 행 대응 확인. 기존 회전수 정규화·속도 스펙트럼이며 원시 3센서 파형과 다름 |

네 자료의 단위가 다른 만큼 위 수를 합쳐 독립 프레스 학습 기록 수로 주장하지 않는다. source별 수집 그룹을 돌아가며 비복원 추출했다. 혼합군은 source별 균등 할당이며 UCI 정상 예제 부족분을 다른 자료로 채우지 않는다. 실제 투입 수와 사용 그룹은 [학습 기록](evidence/training_ledger.json)에 있다.

## 두 학습 경로와 대조군

**정상 혼합학습:** target 정상 진동 예제에 외부 정상 예제를 추가한 kNN(k=5)이다. 비교군은 같은 target 예제만 사용한다. target 예제를 다섯 번 반복한 대조에서는 동일 ID를 제거하여 점수·지표가 정확히 같음을 확인했다. fit 꼬리 점수를 구할 때는 질의의 같은 기록에 속한 두 진동 채널을 모두 이웃에서 제외했다.

**사전학습:** 16→12→4→12→16 오토인코더(SiLU, MSE)를 외부 진동으로 300회 학습하고 target 정상 진동으로 300회 추가 학습했다. 외부의 고장 라벨을 target 정답으로 사용하지 않는 자기지도 학습이다. 같은 초기값·학습률·배치 크기·업데이트 횟수의 target-only 300+300 대조를 두었다. 각 단계에서 optimizer를 동일하게 초기화했다. 사전학습 없이 target만 300회 학습한 참고군도 함께 계산했다.

외부의 예전 fit/dev/cal/test 예약은 이번 별도 실험에서는 모두 **학습 자료** 역할이다. 과거 외부 평가 결과는 보존하며, 이 자료를 향후 새 미열람 시험이라고 부를 수 없다.

## 결과

아래는 **추가량 1배, α5%, 3시간분할×3seed의 3센서 결합 F1 평균**이다. 같은 이상 에피소드를 반복 사용한 단순 평균이며 독립 고장 9회 시험의 평균이 아니다. ‘우리 데이터만’은 해당 진동 학습기를 붙인 방식별 대조다.

| 학습 자료 | 정상 혼합 kNN | 오토인코더 사전학습 |
|---|---:|---:|
| 우리 데이터만 | 0.889610 | 0.881087 |
| + UCI | 0.889610 | 0.876900 |
| + SKAB | 0.895563 | 0.881087 |
| + Beihang | 0.891595 | 0.879257 |
| + ESPset | 0.889610 | 0.877352 |
| + 네 자료 | 0.895563 | 0.878730 |

**진동 학습기를 추가하기 전의 target-only 3센서 기준 모델은 평균 F1 0.895563**이었다. P0/P1/P2의 F1은 0.875000/0.857143/0.954545, FP는 6/7/2, FN은 모두 0이다. 주 α에서 외부 자료를 추가한 180개 분할·seed·방법·추가량 조합 중 같은 분할의 기준 모델을 넘어선 것은 **0개**다. 4배 추가에서도 이 결론은 같았다.

SKAB 혼합군의 작은 이익은 P0에서 진동 학습기를 추가하며 생긴 정상 오경보 1건을 되돌린 것이다(7→6). 기준 모델 자체의 오경보보다 줄어든 것은 아니다. 나머지 두 분할은 같은 결과다. 이를 새 고장 탐지나 기준 모델을 넘어선 향상으로 표현하지 않는다.

진동 학습기만 보면 차이가 더 뚜렷하다. 표의 범위는 요청 추가량 1배·4배 각각의 평균이다.

| 학습 자료 | 진동 kNN F1 | 진동 오토인코더 F1 |
|---|---:|---:|
| 우리 데이터만 | 0.709892 | 0.347230(300+300회) |
| + UCI | 0.687413 | 0.442577–0.445099 |
| + SKAB | 0.148902–0.323041 | 0.433817–0.439834 |
| + Beihang | 0.026667–0.251056 | 0.408639–0.417299 |
| + ESPset | 0.642410–0.657543 | 0.459733–0.465190 |
| + 네 자료 | 0.104312–0.467631 | 0.380065–0.381506 |

정상 혼합은 모든 source와 두 추가량에서 평균 성능을 낮췄다. 사전학습은 같은 학습 횟수의 대조보다 평균이 높은 경우가 있지만 seed·분할별 악화도 있었다. **target만 300회 학습한 오토인코더의 진동 F1은 0.535340**으로 위 사전학습 평균보다 높았다. 따라서 외부 데이터가 있어야 얻을 수 있는 실용적 향상은 확인되지 않았다. 학습 횟수에 따른 차이를 자료의 효용으로 바꾸어 말하지 않는다.

## 검증과 재실행

10개 계산·누수 경계 시험이 통과했다. 216개 학습 모델을 저장하고 재로딩한 예측이 동일했다. 별도 집계기는 저장된 cal/evaluation 점수에서 문턱을 직접 다시 계산하여 1,305개 지표 행을 검증했으며, target 반복 대조의 전체 점수도 일치했다. 이것은 현재 macOS/Python 3.12.2 CPU 환경에서의 검증이며 새로운 운영체제 재현을 주장하지 않는다.

source 검사 중 SKAB의 연속 구간이 처음 제안한 32표본보다 짧고 Beihang 한 파일은 중국어 열 이름을 쓰는 것을 발견했다. 모델 결과 계산 전에 부분 구간(4표본 이상)과 명시적 열 별칭 처리를 확정했다. [초기 명세](evidence/protocol_before_source_inspection.json)와 [수정 기록](evidence/pre_model_corrections.json)을 보존했다. [실행 동결](evidence/freeze.json), [검증 결과](evidence/verification.json).

원자료는 기존 위치에 필요하다. `yejun/`에서 실행하며 원자료 취득·출처는 [기존 취득 명세](../../plans/press_master_2026-10-03/03_data_sources.md)를 따른다. 데이터와 학습 상태·개별 기록 점수는 Git에서 제외했다. `basis.py`는 저장소의 `press_guard/`, `press_submission/`, master core를 읽기 전용으로 재사용한다. 다른 환경에서는 기록된 의존성을 별도 환경에 설치한다.

```bash
python -m pip install -r analysis/press_external_training_2026-10-04/requirements-runtime-lock.txt
python analysis/press_external_training_2026-10-04/run_all.py
python -m pytest -q analysis/press_external_training_2026-10-04/test_training.py
```

이 실험을 근거로 네 자료를 그대로 학습에 편입하는 것은 권하지 않는다. 공통 진동 표현의 직접 혼합과 고정 예산의 사전학습을 검사한 결과이며, 다른 표현·네트워크·정상만의 사전학습·지도 전이학습 등까지 실패했다고 일반화하지 않는다. 원자료의 한 이상 에피소드라는 한계도 그대로다.
