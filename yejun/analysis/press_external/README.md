# UCI 유압 자료 확보·별도 검증

[UCI Condition monitoring of hydraulic systems](https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems), Helwig·Pignanelli·Schuetze (2015), DOI 10.24432/C5CW21, CC BY 4.0. 공식 ZIP 76,601,704바이트를 확보하고 전체 CRC를 확인했다. SHA-256과 파일 목록은 [acquisition.json](acquisition.json)에 있다. 원본 ZIP은 `data/hydraulic.zip`이며 Git 제외다.

총 2,205개의 60초 시험대 사이클. 안정 상태 1,449개 중 누설 없음 489개, 약한 누설 480개, 심한 누설 480개. 압력 PS1·전력 EPS1·유량 FS1·진동 VS1을 실제로 읽어 각 센서의 5초 평균 12개, 총 48개 특징을 산출했다. 이 특징의 결측과 완전 중복 사이클은 없었다.

대회 센서는 전류·진동 10 Hz인 반면 이 자료는 전력 100 Hz·진동 1 Hz 등을 사용한다. **대회 모델 가중치를 전이하거나 대회 학습 자료에 합치지 않았다.** 같은 프레스의 추가 날짜·정비 이력·새 고장 사례도 아니다.

## 고정한 검증

모델 점수를 보기 전에 [protocol.json](protocol.json)을 기록했다. 정상 학습 분포만 쓰는 세 후보(센서 평균 최대 z, 정상 공분산 기반 운전 형태, 수력 대비 전력 비율)를 모두 공개한다. 각 냉각·밸브·축압 조건의 정상 사이클을 원래 순서로 60/20/20 분할하고 누설 사이클은 평가에만 쓴다. α=5%, 후보별 정상 보정 순위로 문턱을 정한다. 최소 p값 때문에 대회와 같은 α=1%를 적용하지 않았다.

`local_normal_reference`는 해당 냉각 조건의 정상 자료를 쓰고, `unseen_cooler`는 다른 두 냉각 조건으로 적합·보정한 뒤 보지 않은 조건 전체를 평가한다. 조건 라벨은 분할·집계에만 쓴다. 사이클 간 시간 의존성을 제거한 독립 실고장 시험은 아니다.

| 정상 공분산 모델 | 냉각 조건 | F1 | 정상 오경보율 | 누설 재현율 |
|---|---:|---:|---:|---:|
| 해당 환경 정상 기준 | 3 | 0.5161 | 2/32 | 35.0% |
| 해당 환경 정상 기준 | 20 | 0.9984 | 1/32 | 100% |
| 해당 환경 정상 기준 | 100 | 1.0000 | 0/34 | 100% |
| 다른 환경 기준 | 3 | 0.8000 | 160/160 | 100% |
| 다른 환경 기준 | 20 | 0.6708 | 1/160 | 50.6% |
| 다른 환경 기준 | 100 | 0.8432 | 119/169 | 100% |

조건 간 무보정 전이 성능 주장은 지지되지 않는다. 해당 환경 정상 기준도 냉각 효율 3 조건에서는 누설을 많이 놓친다. 성능 좋은 조건만 골라 보편적인 높은 성능으로 표현하면 안 된다. 이 결과를 대회 v2 F1과 합산하거나 직접 비교하지 않는다.

전체 18개 결과는 [metrics.csv](metrics.csv), 누설 강도별 결과는 [strata.csv](strata.csv), 재현 가능한 사이클 분할은 [partitions.csv](partitions.csv), 환경·특징 감사·해시는 [manifest.json](manifest.json)에 있다. 원행 센서와 개별 사이클 예측은 Git 제외다.

```bash
OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 /opt/anaconda3/bin/python yejun/analysis/press_external/evaluate.py
```

정상 기준과 학습 센서가 달라지면 재검증이 필요하다는 반례를 얻었다. 외부 검증 코드에 대한 별도의 후속 코드 리뷰와 독립 집계 테스트는 아직 수행하지 않았다.
