# 프레스 핵심 가설 재현과 개선안 검증

2026년 10월 3일. [통합 계획](../../plans/press_master_2026-10-03/README.md)의 조건부 모델 가설을 구현하고, Claude의 간이 평가와 차이를 확인한 실험 기록이다. **기존 명세 7설정과 후속 개선안 6개를 평가했지만, 등록한 정상 부담·민감도·손실 제한을 함께 통과한 새 후보는 없다.** C1의 우선 개발 가설을 보류하고 [수정 실행 계획](../../plans/press_master_2026-10-03/07_validation_revision.md)에 우선순위를 반영했다.

이 폴더는 검증용 구현과 실험 근거다. `press_v3` 제품 전체, 외부 모델 시험, 확률 헤드, 학습 증강, 운영 화면, 대회 보고서의 완료를 의미하지 않는다. 하위 `v1`과 `v2`는 이 검증 실험의 차수이며 과거 제품 버전과 다르다.

## 무엇을 고정하고 실행했는가

기준은 커밋 `d772d8e`의 [protocol.json](../../plans/press_master_2026-10-03/protocol.json)이다. 원본 해시, 정확한 중복 제거, 정상 599기록·이상 21기록, 완성 기록 시점, 순방향 분할, fit 전용 스케일·회귀, 정상 cal 전용 순위, 동일 알림 단위를 구현했다. 원기록의 날짜·파일·라벨·ID는 수치 특징에서 제외했다. kNN의 부모 제외용 식별자는 수집 자료별 이름 공간을 갖는다.

원계획에서 미정이던 진동 주입 채널, 잡음 대역, 충격 감쇠, 손실 셀 집계를 첫 성능 실행 전에 [1차 구현 결정](design_v1.json)으로 고정했다. 진동 두 채널을 따로 주입하고 계열 POD에서 동일 비중으로 합친다. 길이 척도는 유한 fit 값이 구간 안에 30개 이상일 때 사용한다. 따라서 “미기재 선택이 전혀 없는 완전한 동일 구현”이라고 표현하지 않는다.

P0/P1 정상 평가 부모는 각각 157·156개로 합계 313개다. 개발 주입은 D1 진동 대역 잡음, D2 감쇠 충격, D3 전류 잔차 증가이며 seed 11·29·47을 전부 썼다. 감소 및 전류 무효와 진동 변화의 복합 시험도 실행했다. 부모의 조건화 가능 여부는 주입 전에 고정한다. 비영 변화가 사라진 짧은 기록은 생성 실패로 표시하고 전체 부모 분모에서 탐지 0으로 처리한 보수적 POD를 채택에 쓴다. 지원 표본만의 POD도 별도 열에 남겼다.

P2 정상 126기록과 제공 이상은 선택 파일 생성 후 별도 감사 명령으로 평가했다. **P2와 제공 자료는 이미 탐색된 자료**다. 실행 순서가 새로운 맹검을 만들지 않는다. 후속 개선안은 1차 P2 결과까지 보고 설계했으며 그 이력은 [2차 설계](design_v2.json)에 명시했다. 외부 test의 모델 성능과 H1/H2 보류 변화는 이번에 열지 않았다.

## 확인한 실패 원인

**길이별 중심·척도는 정상 보정 분포와 짧은 이상 판정을 함께 바꾼다.** P2 B1에서 길이별 기준을 제거하면 정상 요청 33→10, 제공 이상 TP 18→21이다. 이 대조는 P2를 본 뒤의 진단이며 전역 기준을 새 독립 승자로 선정한 실험이 아니다. 작은 구간의 추정 불안정을 완화한 S4도 개발에서는 요청을 줄이지만 후반 36건과 손실 시험 실패를 남긴다. 길이별 처리 자체가 좋다고 선결하지 않는다.

**전류 조건화 이후에도 후반 진동 하락이 남는다.** 60~70분, 20표본 이상 기록에서 C1의 상·하부 표준화 잔차 중앙값은 약 −2.13/−1.85다. 속도·압력·운전 상태 라벨이 없으므로 이를 무해한 저부하나 실제 결함으로 확정할 수 없다. 정상 파일 라벨은 그대로 유지한다. 전류만으로 설명되지 않는 상태 변화가 정상 부담의 원인이라는 범위까지 확인했다. [시간대별 중앙값](evidence/diagnosis/normal_state_shift.csv)

**전역 경로로 돌아가는 코드가 같아도 문턱이 같지는 않다.** P0 B1 문턱은 약 3.152, C1은 3.624다. 전류 조건 불가 때 두 모델의 점수가 같은지 검사하는 테스트는 통과하지만, 전체 보정 점수의 분포가 달라 전류 감소·복합 변화의 탐지율이 떨어진다. C1에서 seed 평균으로 15개 고유 손실 셀이 −5%p 제한을 넘었다. seed별 검사까지 합친 59행을 독립 고장 59건으로 세지 않는다. [손실 셀](evidence/v1/loss_cells.csv), [성분별 문턱 초과](evidence/diagnosis/threshold_components.csv)

정상 요청을 줄인 S4·S5와 민감도를 올린 S3 모두 이 상충을 해결하지 못했다. 기준을 낮추거나 감소형 시험을 삭제하지 않았고, 요청을 계측·상태 변경이라는 이름으로 옮겨 전체 부담에서 빼지도 않았다. 현재는 개선 가능한 가설의 범위가 좁아진 결과다.

## 재현과 검수

저장소 루트에서 Python 3.12와 [고정 환경](../../plans/press_master_2026-10-03/requirements-audit-lock.txt)을 사용한다. 원자료는 공용 읽기 전용 경로에 있어야 한다.

```sh
python3.12 -m venv /tmp/press-master-validation
/tmp/press-master-validation/bin/python -m pip install -r yejun/plans/press_master_2026-10-03/requirements-audit-lock.txt
PYTHONDONTWRITEBYTECODE=1 /tmp/press-master-validation/bin/python yejun/analysis/press_master_validation_2026-10-03/reproduce.py
PYTHONDONTWRITEBYTECODE=1 /tmp/press-master-validation/bin/python yejun/analysis/press_master_validation_2026-10-03/verify_results.py
```

`reproduce.py`는 임시 출력 경로에서 24개 계산 계약, 원명세 실험, 진단, 후속 실험, 집계를 새로 실행해 저장 결과와 대조한다. 원래 실험 날짜와 결과는 덮어쓰지 않는다. 계약에는 원행 보존, 미래 정보·메타데이터 배제, ridge 목적함수의 독립 최적화 대조, 순위 동률, 짧은 기록, 주입 강도 0·에너지·비변경 채널, 수집 그룹 간 부모 ID 충돌 방지가 포함된다. [재현 결과](evidence/reproduction.json)와 [집계 검수](evidence/verification.json)는 성능 채택 성공과 별개다.

수집 자료 사이에 같은 정수 기록 ID가 있어 kNN이 외부 관측의 정상 참조 하나를 잘못 제외할 수 있는 구현 결함을 자체 검수에서 발견했다. 자료별 이름 공간을 추가하고 전체 실험을 재실행했다. 이번 집계 TP 수는 바뀌지 않았으며, 수정 전 영수증과 이상 집계를 [수정 이력](evidence/history/implementation_correction.json)에 보존했다. 결과를 본 뒤 새 모델을 추가한 이력과 구현 오류 수정 이력을 혼동하지 않는다.

원행 대응·특징·기록별 예측과 합성 자식별 판정은 Git 제외 `cache/`에 있다. Git에는 코드, 고정 설정, 집계, 해시, 실행·검수 기록만 포함한다. 저장된 합성 점수 행 수나 반복 시드는 독립 표본 수가 아니다.

캐시 성분 열의 해석은 모델별로 다르다. B1/C1/C2의 `component_v0/v1/i_raw/i_residual`은 실제 최대 점수의 성분이다. B3의 같은 열은 함께 계산한 전역 기준의 보조 진단이며 kNN 점수의 분해가 아니다. S5의 첫 성분 열은 두 진동 채널을 함께 쓴 kNN 거리다. 공통 `score`와 `p`가 해당 모델의 판정 기준이며, 성분별 문턱 표는 B1/C1/C2에만 생성했다. `model_parameters.json`도 요약용이고 저장 모델 체크포인트가 아니므로 실행에는 원자료 재적합이 필요하다.

## 아직 계산하지 않은 항목

B2의 공통 입력 재적합, 가이드북 LSTM-AE 완전 재현, A1 반복·A2 crop·A3 잔차의 학습 효용, O1 합성 노출, H1/H2 보류 변화, T1 지속 변화, 순차 운영 정책, 확률 헤드, 외부 자료의 모델 성능은 이 패키지에서 계산하지 않았다. 외부 자료의 취득과 구조 감사는 [기존 확보 기록](../../plans/press_master_2026-10-03/03_data_sources.md)을 유지한다. 다음 순서와 통과 조건은 수정 실행 계획에서 정한다.
