# LSTM 오토인코더 보완 실험 — 사전 등록

작성: 2026-10-07, Claude Code (예준 지시)
상태: 실행 전 고정. 이 문서를 커밋한 뒤에 변형 성능(valid·test)을 처음 연다. 아래 "변경 기록"에 독립 검토 반영 내용을 적었다.

## 0. 목적과 전제

- **목적:** 가이드북 모델인 LSTM 오토인코더를 보고서와 같은 조건에서 최대한 보완했을 때 성능이 어디까지 오르는지 잰다. 그 결과를 우리 모델(v2, v2+R1, v2+R1+R2)과 같은 기준으로 비교한다.
- **전제:** 처음에는 "가이드북 모델을 먼저 보완해 봤다"는 이야기의 재료로 시작했다. 다만 결과가 좋으면 모델을 바꿀 수도 있다(예준, 2026-10-07). 그래서 어느 쪽이 낫다는 가정 없이 진행한다.
- **고정한 것:** 결론 방향이 끼어들지 않도록 아래를 실행 전에 고정한다.
  - 변형 격자
  - 선택 규칙
  - 비교 짝
  - 교체 검토 조건
  - 해석 기준

  - 실시간 행 채점과 R1
- **재현 확인 (`00_reproduce.py`, 완료):**

  - 기록 번호가 일치한다.
  - 분할 A·B × 시드 0·1·2가 모두 있다.

## 2. 비교 대상

- **출발점:** lstm20. 가이드북 구조, 20행 창, 창 마지막 시점의 복원 오차다. 이 PC에서 시드 0·1·2로 다시 학습한 단일·앙상블 값과 보고서 값을 함께 적는다.
- **우리 모델:** v2, v2+R1(잠금 규칙의 선택), v2+R1+R2(최종).
- **참고:** 보고서 2.4절의 다른 베이스라인.

## 3. 보완 범위: LSTM 오토인코더 틀 안

- **고정한다:**
  - 입력: 3채널(진동 2·전류 1)의 v2 표준화 값
  - 학습 자료: 정상 학습 기록만
  - 구조: LSTM 인코더 → 마지막 은닉 상태 반복 → LSTM 디코더
  - 보정 방식과 α
- **바꾼다:**

  | 차원 | 선택지 |
  |---|---|
  | 창 길이 W | 5 · 10 · 20 · 30 |
  | 기록 앞부분 처리 | none(창이 다 찬 행만, 가이드북) · edge(첫 행 반복으로 채움) · var(채우지 않고 실제 길이의 창, 길이별 배치) |
  | 채점 방식 | 시간 요약 × 채널 처리(4절) |
  | 용량 | 기본 64-32. 짧은 창은 병목을 창 크기보다 작게(W5 16-4, W10 32-8) |
  | 학습 예산 | 300/30, 1000/100 |
  | 학습 자료 위치 | early80(공통 프로토콜) · late80(앞 20%로 조기 종료, valid에 가까운 뒤 80%로 적합) |
  | 시드 앙상블 | 시드 3개의 행 점수를 보정 전에 평균 |

- **넣지 않는다:** v2 성분(전류 사인 적합 R², AR(2) 예측 오차, max|z|)과 R2(크기 단독 경보 보류).
  - 이것들은 "자체 특징·규칙" 단계다.
  - R2는 성분 구조에 묶여 있고 test를 본 뒤 정한 규칙이라 LSTM에 붙이지 않는다.
- **R1:** 트랙 L+R1에서 보고서 2.4절 † 표와 같은 계산으로 붙인다.
  - R1의 해제 조건은 전류 사인 R², 곧 우리 특징을 쓴다. 이 점을 결과에 함께 적는다.

## 4. 1단계 격자 (`01_train.py --stage 1`)

| 앞부분 처리 | W (용량 64-32) | 짧은 창 병목 맞춤 |
|---|---|---|
| none | 5 · 10 · 20 | W5 16-4, W10 32-8 |
| edge | 5 · 10 · 20 · 30 | W5 16-4, W10 32-8 |
| var | 5 · 10 · 20 · 30 | W5 16-4, W10 32-8 |

- **(30, none)은 뺀다.** 기록마다 29행이 점수 없이 처음부터 미탐이 된다. 20행 창에서도 이미 test 이상 행의 54.6%가 이렇게 빠진다.
- **학습 설정:** 300에폭, 인내 30, early80(lstm20과 같음). 시드 0·1·2, 분할 A·B. 설정 17개로 모두 102회 학습한다.
- **채점 방식 (`lx_scoring.py`):** 이름은 `채널 처리-시간 요약`이다. none은 15종, edge·var는 21종이다.

  | 구분 | 종류 | 계산 |
  |---|---|---|
  | 시간 요약 | last | 창 마지막 시점(가이드북) |
  | 시간 요약 | mean | 창 전체 평균 |
  | 시간 요약 | max | 시점별 최댓값 |
  | 채널 처리 | raw | 세 채널 평균(가이드북) |
  | 채널 처리 | cn | 채널별 참조 평균으로 나눈 뒤 최댓값 |
  | 채널 처리 | cq | 채널별 참조 99% 분위로 나눈 뒤 최댓값 |
  | 채널 처리 | ct | 채널별 꼬리 변환(예준 ExpTail, v2가 성분을 합치는 척도) 뒤 최댓값 |
  | 채널 처리 | md | 채널별 오차 벡터의 마할라노비스 거리(EncDec-AD 근사) |
  | 채널 처리 | cpn (edge·var) | 기록 안 위치별·채널별 참조 평균으로 나눈 뒤 최댓값 |
  | 채널 처리 | cpt (edge·var) | cpn처럼 나눈 값에 채널별 꼬리 변환 뒤 최댓값 |

  - 참조는 조기 종료 구간 창의 오차다. 가중치 적합에는 쓰지 않았고 valid·test를 보지 않는다.

## 5. 선택 규칙 (valid만)

- **선택 단위:** 시드 0·1·2 앙상블(e012)이다.
- **지표:** valid 실시간 행 F1(α 1%)의 분할 A·B 평균이다.
- **동률 폭:** max(0.002, 그 변형의 단일 시드 지표 표준편차/√3).
- **동률일 때 고르는 순서:**
  1. 가이드북 lstm20에서 바꾼 차원 수가 적은 쪽. 차원은 W, 앞부분 처리, 시간 요약, 채널 처리, 용량, 예산, 학습 자료, 앙상블이다.
  2. W가 작은 쪽
  3. 이름순
- **1단계:** 격자 전체 중 트랙 L(규칙 없음) 승자와, 상위 3개의 (W, 앞부분 처리, 용량) 조합을 고른다. 조합마다 가장 좋은 채점 방식 기준이다.
- **2a:** 상위 3개 조합마다 용량 32-16·128-64를 추가한다. 그 (W, 앞부분 처리)들의 모든 용량·채점 방식 중 같은 규칙으로 고른다.
- **2b:** 2a에서 고른 조합에 세 가지를 추가한다.
  - 학습 예산 1000/100
  - late80
  - late80 + 1000/100
- **최종:** 1·2a·2b의 모든 변형 중 같은 규칙으로 트랙 L을 고른다.
- **트랙 L+R1:**
  - 주 결과는 트랙 L 최종 변형에 R1을 붙인 것이다. v2 → v2+R1과 같은 짝이다.
  - R1을 붙인 모든 변형 중 최고는 탐색 결과(낙관)로만 적는다.
- **잠금:** 단계별 선택 파일(`02_stage1_selection`, `02_stage2a_selection`, `02_selection`)은 sha256으로 잠근다. 다음 단계와 test는 잠금이 맞을 때만 읽는다.
- **새 시드 확인:** 잠근 최종 설정을 시드 3·4·5로 다시 학습한다(`--stage confirm`). 그 앙상블(e345)의 valid·test가 비교의 주 값이다. 선택에 쓴 시드의 운(승자의 저주)을 빼기 위해서다.

## 6. test와 보고 항목

- **test 공개:** 모든 변형의 test는 사후 자료로 공개한다. 다만 "선택된 LSTM"의 결과는 잠긴 선택과 새 시드 앙상블로만 말한다.
- **사후 낙관 상한:** test에서 가장 좋은 LSTM 변형도 참고로 적는다.
  - 이유: v2의 설계와 R1·R2는 전체 이상 데이터를 본 뒤 정했다(보고서 2.3절 경위). 이 비대칭이 있으니 LSTM 쪽 상한도 보인다.
- **주 표 (α 1%, α 3·5% 민감도 포함):**
  - valid 실시간 F1(A·B)
  - test 실시간 F1(A/B)
  - test 미탐·오경보 행
  - 기록 판정 F1(행 가중)
  - R1 행에는 "이상 흐름을 test 기록부터 따로 돌린 값"(준용 07의 test_only)
- **오류 조건:**
  - 미탐의 기록 안 위치
  - 오경보가 난 운전 상태: 분할 B의 valid+test 정상 300기록에서, 경보가 1행이라도 난 기록 수를 α 1·3·5%로 센다. 보고서 3.2절 표와 같은 정의이고, 상태는 준용 `06_operating_regime_records.csv`를 쓴다.
  - 첫 경보 지연
- **강건성:** 새 시드 앙상블, 그것의 +R1, 출발점, v2, v2+R1, v2+R1+R2를 같은 주입으로 잰다. 생성기와 시드(11·29·47)는 준용 `04_validation`과 같다.

  | 시험 | 내용 | 조건 |
  |---|---|---|
  | V1 | 전류 잔차 주입 | 강도 0.5·1 |
  | V1b | 진동 단독 주입 | 대역 잡음 0.5·1, 감쇠 충격 2·4 |
  | V2 | 진폭 감소 | 0.75~0배 |
  | V5 | 전류 이동 | +81.4·+272.4 |
  | V5 | 시각 흔들림 | 0.1ms, 60.6Hz |
  | V5 | 이상 기록 평균 제거 | |

  - V5 평균 제거는 주 표 옆에 둔다. 이상 기록은 기록마다 전류 평균이 크게 다르다. 긴 창 오토인코더는 이 평균 이동이라는 지름길만으로 이상을 잡을 수 있어서다.
- **비용:** 학습 시간, 시드 간 변동.

## 7. 비교 짝, 교체 검토 조건, 해석 기준 (실행 전 고정)

- **비교 짝:**
  - 트랙 L(새 시드 앙상블) ↔ v2
  - 트랙 L+R1(새 시드 앙상블 + R1) ↔ v2+R1(잠금 선택)
  - v2+R1+R2는 test를 본 뒤 정한 모델이라 참고로만 둔다.
- **같은 수준의 기준:** valid 평균 F1 차이가 0.002 이내면 "같은 수준"이다(보고서 동률 폭). 넘으면 높은 쪽·낮은 쪽으로 말한다.
- **교체를 검토할 만한 조건:** 트랙 L 새 시드 앙상블이 아래를 모두 만족하면 "교체를 검토할 만하다"고 적는다. 판단은 예준이 한다.
  1. valid 평균 F1 ≥ v2 − 0.002
  2. test 실시간 F1이 A·B 모두 v2 − 0.01 이상
  3. 분할 B valid+test 정상 300기록 중 α 5% 경보 기록 수 ≤ v2(보고서 3.2절 13기록)
  4. V1 전류 잔차 주입 탐지율이 v2보다 5%p 넘게 낮지 않음
  5. V5에서 두 가지를 모두 만족함
     - 이상 기록 평균을 지워도 이상 20기록 이상 탐지
     - 0.1ms 흔들림 정상 경보율 ≤ v2
- **트랙 L+R1:** 같은 항목을 v2+R1과 견준다.
- **test의 위치:** test는 이상 사건 1건(11기록·324행)이고, R1을 붙이면 대부분 포화된다. 그래서 단독 결론 근거로 쓰지 않고 valid와 함께 읽는다.
- **그 밖의 축:** 해석 가능성, 비용 같은 나머지 축은 수치를 나란히 적기만 한다.

## 8. 사전 공개: 실행 전 예상

- **기존 결과로 계산한 상한:** 기존 lstm20 결과에서, 기록 앞 19행을 오경보 없이 모두 맞혀도 test F1 상한은 0.833·0.810이다. 점수를 낸 147행 중 92·103행을 놓치기 때문이다.
- **상한의 범위:** 이 상한은 앞부분 채우기에만 해당한다. 창 길이·채점 방식·용량을 바꾼 변형에는 적용되지 않는다.
- 이 예상이 해석에 끼어들지 않도록 선택은 5절 규칙만 따른다.

  - **검사 추가:**
