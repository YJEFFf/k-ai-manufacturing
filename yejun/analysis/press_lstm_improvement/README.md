## 결과 요약

1. **α 1%(운영 기준)에서는 이번 고장 사건 탐지가 v2와 같은 수준까지 올랐다.**
   - 가이드북 LSTM 출발점: valid 0.363, test 0.317·0.239
   - 보완 LSTM(새 시드 앙상블): valid 0.968, test 0.975·0.972
   - v2: valid 0.963, test 0.965·0.970
   - 다만 차이는 시드 잡음 범위 안이다.
     - 단일 시드 test는 0.964~0.976이라 v2(평균 0.967)를 사이에 둔다.
     - 행으로는 A 6행, B 1행 차이다.
2. **α를 느슨하게 하면 v2보다 나빠진다.**
   - α 3%: valid는 0.972(v2 0.965)지만 test는 0.969·0.961(v2 0.973·0.964)이다.
   - α 5%: valid 0.925, test 0.958·0.948로 v2(0.957, 0.973·0.958)보다 낮다.
   - 이유: LSTM 오경보는 정상 기록 한두 개에 몰려 행 수가 빠르게 는다. B test 오경보 행이 α 1·3·5%에서 3·11·20이다(v2 3·7·11).
3. **R1을 붙이면 v2+R1이 낫다.**
   - 한 기록에 몰린 LSTM 오경보를 R1이 다음 기록으로 이어 붙여, B test 오경보가 3행에서 10행이 된다(v2+R1 3행).
   - 실제 최종 모델 v2+R1+R2와 견주면, 분할 B α 5% 정상 300기록 중 경보 기록이 15 대 4다.
4. **인공 주입·교락 시험에서 전류 파형 세부에 둔하다.**
   - 전류 파형 잔차 주입 탐지가 사실상 0이다. B 0.6%는 주입 없는 대조의 경보율과 같다. v2는 2.5~66%다.
   - 표본 시각 흔들림 0.1ms에 오경보가 거의 없다(0~0.7%, v2 8~31%). 이것도 같은 둔감함의 다른 얼굴이다. 흔들림 시험은 전류 파형만 바꾼다.
   - 전류 수준이 +81.4 움직이면 정상 기록 96%에서 경보가 난다(v2 0~4%).
   - 진동 단독 주입은 v2보다 잘 잡지만 수준은 낮다. 최대 47%이고, 16칸 중 11칸은 25% 미만이다.
5. **사전 등록한 교체 검토 조건은 5개 중 4개 충족했다.** 전류 잔차 주입 조건이 미충족이라 "교체를 검토할 만하다"에 해당하지 않는다.

  - 이상 기록 평균을 지워도 21/21을 잡으므로, 이번 사건을 전류 평균 차이만으로 잡은 것은 아니다.
- **진폭 감소:** 분할마다 결과가 크게 다르다. 전류를 0배로 줄였을 때 B는 94%를 잡고 A는 1.7%만 잡는다. 학습에 없던 입력에 대한 반응이 분할에 따라 불안정하다는 신호다.
- **진동 단독 주입:** v2보다는 잘 잡는다. 그래도 최대 47%이고 16칸 중 11칸은 25% 미만이라, 보고서 3.6절이 말한 "별도 진동 모델"의 공백을 메운다고 보기는 어렵다.

## 사전 등록 교체 검토 조건 (PROTOCOL.md 7절)

| 조건 | 보완 LSTM e345 ↔ v2 | 보완 LSTM+R1 e345 ↔ v2+R1 |
|---|---|---|
| 1. valid 평균 ≥ 기준 − 0.002 | 충족 (0.968 ↔ 0.963) | 미충족 (0.990 ↔ 0.997) |
| 2. test A·B 각각 ≥ 기준 − 0.01 | 충족 (0.975·0.972 ↔ 0.965·0.970) | 미충족 (B 0.985 ↔ 0.995) |
| 3. B 정상 300기록 α 5% 경보 기록 ≤ 기준 | 충족 (8 ↔ 13) | 충족 (15 ↔ 17) |
| 4. V1 전류 잔차 주입 탐지율이 5%p 넘게 낮지 않음 | **미충족 (최대 −65.7%p)** | **미충족 (최대 −65.2%p)** |
| 5. V5 평균 제거 탐지 ≥ 20, 0.1ms 흔들림 경보율 ≤ 기준 | 충족 | 충족 |
| 모두 충족 | 아니오 | 아니오 |

- 조건은 운영 기준 α 1%로 판정했다. α 5%였다면 트랙 L의 조건 1·2도 미충족이다.
- 전류 수준 이동(+81.4) 민감도는 사전 조건에 없어서 판정에 넣지 않았다. 넣었어도 판정은 같다.

## 해석과 한계

- **모델 선택에 대해:**
  - 사전 기준으로는 교체 조건을 채우지 못했다.
  - 보완 LSTM은 운영 기준(α 1%)에서 이번 사건을 v2만큼 잡는다. 그러나 차이는 시드 잡음 안이다.
  - α를 느슨하게 하거나 R1을 붙이면 오경보가 v2보다 빨리 는다. 전류 파형 이상에는 둔하고 전류 수준에는 과민하다.
  - 확인된 강점은 두 가지다.
    - 진동 단독 주입을 v2보다 잘 잡는다(그래도 대부분 25% 미만).
    - 정상 고부하 기록의 오경보 기록 수가 적다.
  - 두 모델을 합친 시험은 하지 않았으므로 "함께 쓰면 낫다"는 이 결과로 말할 수 없다. 교체·병행 여부는 예준이 판단한다.
- **"가이드북 모델을 먼저 보완해 봤다"는 이야기에 대해:**
  - 실험 결과는 "보완해도 이번 사건을 못 잡았다"가 아니다.
  - 실험이 말하는 것은 이렇다. "제대로 보완하면 운영 기준에서 이번 사건은 v2 수준으로 잡는다. 하지만 전류 파형에 주입한 이상을 놓치고, 전류 수준 변화에 과민하고, 문턱을 느슨하게 하면 오경보가 빨리 는다."
  - 다만 이 실험은 보고서 test 채점 이후에 한 것이다. 보고서에 쓴다면 사후(†) 비교로 밝혀야 한다.
- **한계:**
  - 이상은 약 3분짜리 사건 하나다. valid·test 차이는 몇 행 수준이다.
  - 변형 516개(설정 26개 × 채점 방식) 가운데 골랐다. 새 시드 확인으로 시드 운은 줄였지만, 같은 valid 사건에 맞춘 낙관은 남는다.
  - 비대칭이 양쪽에 있다.
    - v2의 설계와 R1·R2는 전체 이상 데이터를 본 뒤 정해졌다. LSTM은 valid만 보고 골랐다.
    - 반대로 이 격자도 보고서 test에서 나온 사실을 보고 설계했다(20행 창이면 test 이상 행 54.6%가 점수 없음).
  - 최종 설정은 학습 12번 모두 1000에폭을 다 써서 예산에 묶였다. 더 학습하면 달라질 수 있다.
  - R1의 해제 조건은 전류 사인 R², 곧 우리 특징을 쓴다.
- **비용·재현성:**
  - 최종 LSTM은 모델 3개 앙상블이다. 모델 하나 학습에 이 PC CPU로 약 1시간(동시 6개 실행 기준)이 걸린다. v2는 몇 초면 맞춰진다.
  - LSTM 학습 결과는 PC마다 다르다(lstm20이 준용 PC와 이 PC에서 달랐다). 같은 PC·같은 시드면 비트 단위로 같다(출발점 6개 재학습으로 확인). 보고서 6장처럼 예측 파일을 바이트 단위로 재현하려면 학습 환경까지 고정해야 한다.
