# 스토리라인 수정안: 가이드북 LSTM 보완 실험을 반영한 2.3~2.4절 흐름

2026-10-07, 예준 검토. 근거 수치는 [README.md](README.md), [outputs/06_summary.md](outputs/06_summary.md)(주 비교·α 민감도·강건성), [outputs/07_summary.md](outputs/07_summary.md)(R2 대응 규칙)에서 가져왔다.

## 출발점: 예준 코멘트 (결과보고서 v1, 2.3절 앞)

> 가이드북에 나온 모델을 단순히 f1 score가 낮다는 이유로 우리의 자체 모델로 가는게 아니라 기존 모델을 먼저 개선해봤는데도 특정 오류가 남아서 자체 특징이나 규칙을 추가해서 새로운 모델을 개발했다 라는 스토리라인으로 가면 우리 모델에 대한 신뢰가 더 생길거 같아

이 흐름을 실험으로 확인했다. 뼈대는 실험 결과와 맞는다. 다만 "특정 오류"를 실험에서 나온 구체적인 오류로 바꾸고, 각 오류를 우리 모델의 구성 요소에 짝지어야 사실과 맞는다.

## 실험 요약

- **조건:** 준용 tvt 틀을 그대로 썼다(분할 A·B, 형식 누수 제거, valid 정상 conformal 보정, 실시간 행 채점, R1).
- **보완 범위:** LSTM 오토인코더 틀 안에서만 바꿨다.
  - 기록 앞부분 처리
  - 채점 방식
  - 용량·학습량
  - 시드 앙상블
- **선택:** 변형 516개 중 valid로만 골라 잠그고, 새 시드로 다시 학습한 값을 썼다.
- **최종 LSTM:** 10행 가변 길이 창(앞부분을 채우지 않고 실제 길이만큼 넣음), 채널별 꼬리 점수의 창 평균, 용량 128-64, 시드 3개 앙상블.
- **R2 대응 규칙:** 최종 모델과 견줄 때는 LSTM에도 R2를 옮긴 규칙("전류 파형이 정상이면 경보 보류")을 붙여 규칙 수를 맞췄다.

| 모델 (α 1%) | test 실시간 F1 A / B | test 오경보 행 A / B |
|---|---:|---:|
| 가이드북 LSTM (보고서 lstm20, 준용 PC) | 0.289 / 0.238 | 1 / 1 |
| 보완 LSTM | 0.975 / 0.972 | 0 / 3 |
| v2 | 0.965 / 0.970 | 0 / 3 |
| 보완 LSTM + R1 + R2 대응 | 1.000 / 1.000 | 0 / 0 |
| 최종 v2 + R1 + R2 | 1.000 / 1.000 | 0 / 0 |

| ② 보완 | 기존 모델을 먼저 개선해 봤다 | LSTM 틀 안에서 보완했다: 기록 앞부분 처리, 채점 방식, 용량 |

| ⑥ 마무리 | (없음) | LSTM이 나은 점(진동형 고장, 시각 흔들림)은 3.6절 한계를 보완할 후보로 남긴다 |

## 남은 오류와 우리 구성 요소의 짝

| 남은 오류 | 보완 LSTM | 해결하는 우리 구성 요소 | 해결 결과 |
|---|---|---|---|
| A. 기록 시작 직후 미탐 (v2와 공통) | test 미탐 31행이 모두 기록 0~7행 | R1 사건 지속 | LSTM에 붙여도 미탐 0 |
| B. 오경보가 한 기록에 몰림 (v2와 공통) | α 5% B test 오경보 20행(v2 11행) | R2 교차 확인 | LSTM에 붙이면 최종 모델과 같은 test 1.000 |
| C. 전류 파형 이상 미탐 (LSTM에만) | 인공 주입 탐지 사실상 0% | 파형 성분(사인 적합) | v2는 2.5~66% 탐지 |
| D. 전류 수준 변화에 과민 (LSTM에만) | 전류 +81.4 이동 시 정상 기록 88~96% 경보 | v2 구조(표준화 크기, 절편 있는 사인 적합) | v2는 0~4% |

- **A·B:** 모델과 무관한 데이터 구조(기록이 5초 이하로 끊김, 부하 변화)의 문제다. 그래서 우리 규칙은 어느 모델에 붙여도 통한다. 보고서의 기존 서술(R1·R2를 v2의 오류에서 착안)과도 맞는다.
- **C·D:** 규칙으로 해결되지 않는다. 이 설비의 고장 서명(전류 파형 붕괴, 보고서 2.2절 특징 AUROC 1.000)을 직접 보는 성분이 있어야 한다. 이것이 v2를 기반 모델로 둔 이유가 된다.

## 문단 예시 (보고서 문체)

> 가이드북 LSTM 오토인코더는 같은 조건에서 test 실시간 F1이 0.289·0.238이었다. 낮은 F1이 모델 능력 때문인지 이 데이터에 맞지 않는 설계 때문인지 가리려고, LSTM 오토인코더 틀 안에서 기록 앞부분 처리(가변 길이 창), 채점(채널별 꼬리 점수의 창 평균), 용량을 보완했고 valid만으로 골랐다. 보완한 LSTM은 이번 사건에서 0.975·0.972로 v2 수준까지 올랐다. 따라서 F1만으로는 자체 모델을 택할 근거가 되지 않는다.
>
> 그러나 오류 네 가지가 남았다. 미탐은 기록 시작 직후에 몰렸고(0~7행 31행), 오경보는 한 기록 안에 몰려 문턱을 느슨하게 하면 빠르게 늘었다. 이 둘은 v2에서도 나타난 오류이며, R1·R2를 붙이면 보완 LSTM도 최종 모델과 같은 test 1.000이 된다. 나머지 둘은 규칙으로 해결되지 않았다. 인공 고장 시험에서 전류 파형 이상을 잡지 못했고(v2 2.5~66%), 전류 수준이 바뀌면 정상 기록 대부분에서 경보를 냈다.
>
> 이 설비의 고장 서명은 전류 파형 붕괴이므로, 파형을 직접 보는 성분을 가진 v2를 기반 모델로 두고 R1·R2를 더했다. 반대로 보완 LSTM은 진동만 바뀌는 고장과 표본 시각 흔들림에 강해, 3.6절의 진동형 고장 감시 후보로 남긴다.

## 넣을 때 정할 것 (준용과 협의)

1. **위치:** 2.3절(모델 구성) 앞의 도입 문단으로 넣거나, 2.4절(같은 조건의 모델 비교) 안에 문단과 표 한 개로 넣는다. 2.4절 표에는 이미 가이드북 방식 LSTM 행이 있어 "보완 LSTM" 행을 더하기 쉽다.
2. **† 표기:** 보고서는 "test 채점 이후 추가한 행·열"에 †를 붙인다. 이 비교 행에 † 규칙을 적용할지 정한다.
3. **숫자 출처:** 위 수치는 이 PC에서 다시 돈 결과다. 보고서의 lstm20 값(0.289·0.238)은 준용 PC 값이다. 이 PC의 lstm20은 0.285·0.215로 학습이 PC마다 조금 다르다.
4. **분량:** 문단 3개와 표 1개(가이드북 LSTM → 보완 LSTM → +R1·R2 → v2 → 최종)가 적당하다. 강건성 수치는 3.3절 실패 조건 표나 3.6절 적용 조건에 한 줄씩 넣을 수 있다.
