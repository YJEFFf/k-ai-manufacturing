# 최종모델 선정근거·사후 민감도 (2026-09-27)

최종 모델 선정 근거와 같은 특징 대안·결합 규칙·오경보 대응의 사후 비교다. **대회 보고서가 아니다.**

- 주 모델(v2 `early6_ar2`)·문턱·분할은 바꾸지 않는다. 동결 `press_guard/artifacts/guard_{A,B}.json`의 성분을 그대로 쓴다.
- 여기 대안은 모두 **사후 민감도**다. 이상 21구간을 이미 본 뒤의 비교다. v2보다 좋아 보여도 채택하지 않는다. 채택하면 같은 이상 자료에 대한 사후 선택이 한 번 더 늘기 때문이다.
- 대안마다 결합 점수 하나를 정상 보정 기록구간 최대 점수로 conformal 재보정한다(v2와 같은 규칙). α는 1·3·5%다. 아래 표는 α=1%이고, 나머지 α는 CSV에 있다.
- **fmax의 위치.** 성분 점수 g는 −log10(정상 꼬리 확률)이다. 그래서 fmax(g)는 정상 꼬리 확률에 대한 Tippett 최소 p 결합이다.
- **fmax를 유지하는 이유는 두 가지다.**
  1. **사전 선택을 유지한다.** 결합 규칙은 v1 계획부터 쓴 fmax다. 이상 21구간을 본 뒤 대안으로 바꾸면 사후 선택이 한 번 더 는다. 같은 특징 대안(Fisher·합·5NN)이 대회 F1과 주입 탐지에서 같거나 나은 경우가 있다는 사실은 아래(§1·§2)에 그대로 공개한다.
  2. **경보마다 단독 근거 성분이 있다.** 그래서 근거→조치 판단표(`press_guard/model.py`의 `DECISION_TABLE`)가 모든 경보에서 성립한다. 대안은 어느 성분도 단독으로 문턱을 넘지 않은 경보를 낸다.
- **유지 이유가 아닌 것.**
  - "결합 점수 하나를 한 번만 재보정해 다중검정이 없다"는 성분별 문턱을 OR로 묶는 규칙보다 나은 점일 뿐이다. Fisher·합·5NN도 결합 점수 하나를 한 번 재보정하므로 이들과의 차이가 아니다.
  - "라벨에 없는 고장 모양으로 전이된다"는 라벨 지도학습과 비교할 때의 근거다([press_supervised](../press_supervised/README.md)). 같은 특징 대안과의 비교에서는 근거가 되지 못한다(§2의 주입 전이 표).

## 1. 같은 특징 대안(M3) — [same_feature_alternatives.csv](same_feature_alternatives.csv)

v2의 세 변환 성분(크기, 초반 6→8 사인 1−R², AR(2) 전류 잔차)을 입력으로 그대로 넣었다. 비교표 `press_guard/outputs/model_comparison_v2.md`의 IF·5NN은 한 행의 z 3개만 입력으로 받는다. 여기서는 입력을 v2와 맞췄다. 결측 성분은 0으로 둔다.

- **같은 입력이면 5NN이 미탐을 조금 줄인다**(A 44→36, B 31→29, 정상 알림 같음). 숨기지 않는다. α=1%의 주입 전이에서도 A는 모든 족에서 fmax와 같거나 높다(§2 아래 표). 대신 어느 성분도 단독으로 문턱을 넘지 않은 경보가 A 8행·B 2행 생긴다. 그런 경보에는 확인할 센서·성분을 가리킬 수 없다.

- AR 차수는 1·3·4 모두 AR(2)보다 미탐이 많다. 일반 구현으로 다시 적합한 AR(2)는 동결 v2와 계수·경보가 같다(`manifest.json` checks).

## 2. 결합 규칙(O3) — [combination_rules.csv](combination_rules.csv)

같은 세 성분을 다섯 규칙으로 묶고 각각 재보정했다. 칸 = TP/FP/FN · 정상 알림 · 미탐(위치 0·1 + 위치 2 이상) · 근거 성분 없는 경보(이상/정상)

| 규칙 | A | B |
|---|---|---|
| **Tippett = fmax (v2)** | 556/0/44 · 0 · 26+18 · 0/0 | 569/3/31 · 3 · 20+11 · 0/0 |
| Fisher | 568/0/32 · 0 · 20+12 · **12**/0 | 569/1/31 · 1 · 20+11 · **1**/0 |
| Stouffer | 561/0/39 · 0 · 20+19 · 10/0 | 561/0/39 · 0 · 20+19 · 1/0 |
| 합 | 560/0/40 · 0 · 26+14 · 4/0 | 561/2/39 · 2 · 26+13 · 1/0 |
| 평균 | 558/0/42 · 0 · 20+22 · 8/0 | 558/0/42 · 0 · 20+22 · 0/0 |

- 사후 비교로는 **Fisher가 fmax보다 낫다.** A 미탐이 44→32로 줄고 B 정상 알림이 3→1로 준다.
- 대신 Fisher 경보 중 어느 성분도 단독으로 문턱을 넘지 않은 행이 A 12·B 1이다. 이런 경보에는 판단표의 조치를 붙일 수 없다.
- 이것은 사후 비교이고 채택 근거가 아니다. fmax를 유지하는 이유는 위 두 가지다. 표의 `remark` 열에도 같은 내용이 있다.
- α 3·5%에서는 차이가 줄어든다. Fisher의 미탐이 0~1행 적고 정상 경보 행이 0~5행 적다(CSV).

## 3. 오경보 대응 시험(E7) — [fp_mitigation_v2.csv](fp_mitigation_v2.csv)

v1에서 오경보를 줄이려고 시험한 두 대응을 v2 성분에 옮겨 한 번 평가했다.
- **지속성:** 크기 성분만 같은 기록구간 최근 3행 중 2번째 큰 값을 쓴다.
- **진폭 조건부 진동 잔차:** v1 `LoadNormalizer`를 그대로 쓴다. 정상 학습 앞 80% 기록에서 AI0 trailing-17 표준편차 ~ 전류 trailing-17 진폭을 선형 적합하고, 그 잔차의 정상 꼬리로 크기 성분을 대체한다.

칸 = 미탐(위치 0·1 + 2 이상) · 정상 알림 · 오경보 구간 번호(정상 전체 기준) · α=1% 문턱

| 변형 | A | B |
|---|---|---|
| **v2** | 44 (26+18) · 0/120 · — · 4.418 | 31 (20+11) · 3/180 · 423 461 570 · 3.520 |
| 크기 지속성 2/3(위치 0·1 미판정) | 52 (42+10) · 0/120 · — · 3.504 | 52 (42+10) · 1/180 · 446 · 3.113 |
| 크기 지속성 2/3(위치 0·1은 원래 크기) | **30** (20+10) · 0/120 · — · 3.504 | **30** (20+10) · **1/180** · 446 · 3.113 |
| 진폭 조건부 진동 잔차(v1 방식) | 31 (20+11) · 1/120 · 570 · 3.504 | 31 (20+11) · 1/180 · 570 · 3.520 |
| (참고) v1 진폭 정규화, 커밋 결과 | v1 99→84 · 0→1/120 | v1 86→84 · 3→1/180 |

- 모든 변형이 이상 21/21을 탐지하고, 첫 경보 최대 지연은 0.5초로 v2와 같다. 중앙 지연은 위치 0·1을 미판정으로 둔 지속성만 0.2초로 늦다(v2는 A 0.1초·B 0.0초).
- **v1 결과는 같은 방향으로 옮겨진다.** 진폭 조건부 잔차는 B 오경보 3→1(구간 423·461 제거)이고, A에서 정상 알림 0→1(구간 570)이 생긴다. v1에서도 B 3→1, A 0→1이었다.
- **크기 지속성(위치 0·1은 원래 크기)은 사후로는 두 분할·모든 α에서 v2보다 정상 알림과 미탐이 같거나 적다.** 주의할 점이 셋 있다.
  1. **원인은 문턱이다.** v2의 보정 기록구간 최대 점수를 만든 것은 위치 2 이후의 단발(1행) 크기 급등이다(A 4.418·4.049, B 3.520·3.510). 지속성은 이를 지워 conformal 문턱을 낮춘다(A 4.418→3.504, B 3.520→3.113). 새 오경보 446은 예측 오차 성분(3.43)이 낮아진 문턱을 넘은 것이다.
  2. **대가가 크다.** 아래 주입 시험에서 단발 진동 충격과 약한 진동 잡음을 거의 또는 크게 놓친다.
  3. **채택하지 않는다.** 이유는 아래 표 뒤에 수치로 적었다.
- 위치 0·1을 미판정으로 두면 그 위치 미탐이 42행으로 늘어 쓸 수 없다.

### 지속성 변형의 비용 — 주입 시험 [fp_mitigation_injection_v2.csv](fp_mitigation_injection_v2.csv)

**방식**
- 주입 함수는 `press_guard/recalibrate.py`의 `inject`·`unit_layout`을 그대로 썼다. 수락 검사 (b)와 같은 방식이다.
- 대상: 정상 평가 단위 중 30행 이상인 것(A 75개, B 111개)
- 주입: 10행째부터 계단형. 탐지 = 2초(20행) 안 경보.
- 단발 진동 충격: 10행째 한 행에만 진동 두 센서에 ±kσ를 더했다(부호는 난수).
- 잡음·충격 족은 5회 반복했다(`np.random.default_rng(rep)`, rep=0~4).
- 문턱은 각 모델 자기 보정값이다(v2 동결, 변형은 자기 보정 최대).
- 사후 비용 측정이다.

α=1%, 칸 = 2초 안 탐지율 v2 → 지속성 변형(위치 0·1은 원래 크기)

| 주입 | A | B |
|---|---|---|
| 없음(오경보 기준선) | 0.0% → 0.0% | 0.9% → 0.0% |
| **단발 진동 충격 4σ** | 29.3% → **1.1%** | 87.0% → **0.7%** |
| **단발 진동 충격 6σ** | 99.5% → **1.3%** | 99.6% → **0.9%** |
| **단발 진동 충격 8σ** | 100% → **1.3%** | 100% → **0.9%** |
| **진동 잡음 2σ** | 76.5% → **41.3%** | 95.0% → **64.0%** |
| 진동 잡음 4σ | 99.7% → 100% | 100% → 100% |
| 전류 잡음 0.1σ | 96.8% → 98.7% | 96.9% → 98.6% |
| 전류 잡음 0.2σ | 100% → 100% | 100% → 100% |
| 전류 오프셋 0.2×진폭 | 40.0% → 56.0% | 52.3% → 64.9% |
| 전류 오프셋 0.4×진폭 | 100% → 100% | 100% → 100% |

- **단발 진동 충격은 사실상 못 잡는다.** 6σ에서 v2는 99.5%·99.6%를 잡지만, 변형은 1.3%·0.9%로 주입 없음 수준까지 떨어진다. α 3·5%에서도 변형은 5.4% 이하다.
- **약한 진동 잡음도 크게 놓친다.** 2σ 탐지율이 A −35.2%p, B −31.0%p다. 탐지 지연 중앙값도 늦어진다(A 0.7→0.9초, B 0.3→0.7초). 진동 4σ에서도 지연이 0.0→0.2초로 늘어난다.
- 변형이 나은 곳은 전류 오프셋 0.2(+16.0·+12.6%p)와 전류 잡음 0.1σ(+1.9·+1.6%p)뿐이다. 이는 문턱이 낮아진 효과다. 크기 성분 자체가 좋아진 것이 아니다.
- 주입 표의 v2 값은 보완 실험 E1(`analysis/press_supplement/e1_summary.csv`)과 난수만 달라 거의 같다. 예를 들어 진동 잡음 2σ는 여기 76.5·95.0%, E1 74·94%다.

**지속성 변형을 채택하지 않는 이유**
1. **사후 선택이다.**
   - 탐색 장부 65개 뒤에, 이미 본 이상 21구간으로 고른 후보다.
   - 대회 자료의 이득은 작다. 미탐은 A 44→30·B 31→30행이고, B 정상 알림은 3→1이다.
   - 이 이득은 보정 최대 점수를 만든 단발 크기 급등(A 2건, B 3건)을 지운 문턱 효과다.
2. **단발 충격 비용이 크다.**
   - 가이드북 7쪽이 기어 마모의 신호로 드는 진동·소음 증가가 짧은 충격으로 먼저 나타날 수 있다.
   - 변형은 그 모양을 구조적으로 못 본다(6σ 충격 탐지 99.5%→1.3%).
   - 약한 진동 잡음도 3분의 1가량 더 놓친다.
3. **대안이 있다.** 오경보 업무량은 점수를 바꾸지 않는 운영 규칙으로 다룬다.
   - 예: `press_guard`의 2단계 경보(건 안의 경보 행 2개 이상이면 점검 요청)
   - 이 규칙은 1단계 경보를 그대로 남기므로 단발 충격도 기록된다.

## 5. 통합 비교표(M5) — [unified_comparison.md](unified_comparison.md) · [CSV](unified_comparison.csv)

한 표에 다음 모델을 모았다. 열은 입력 조건, 이상 라벨 사용 여부, 행 F1·정밀도·재현율, 사후 최적 F1, 전체 행 AUROC·AP, 정상 알림, 이상 탐지, 지연, 기록구간 F1·AUROC다.
- 가이드북 LSTM-AE: 별도 프로토콜이다. 창 단위로 계산했고 문턱을 고를 때 이상 라벨을 쓴다.
- v1
- 지도학습 로지스틱·부스팅 × 창 특징·창+v2 성분: 21겹 conformal이다. 커밋 `press_supervised/run.py`를 다시 실행했고, 건수가 커밋 표와 같다.
- 같은 특징 대안: 5NN·합·Fisher
- v2

| 분할 | v2 행 AUROC / AP | v1 행 AUROC / AP | v2 F1 α=1% / 사후 최적 | 기록구간 F1 (v1 = v2) |
|---|---|---|---|---|
| A | 0.978 / 0.970 | 0.939 / 0.913 | 0.962 / 0.973 | 1.000 |
| B | 0.976 / 0.966 | 0.934 / 0.902 | 0.971 / 0.971 | 0.933 |

- 기록구간 AUROC는 v1·v2 모두 1.0이다. 구간 단위로는 포화라서 구간 차이는 정상 알림 수로만 드러난다.
- v2의 α=1% F1은 평가 라벨로 고른 사후 최적 F1과 거의 같다. 정상 자료만으로 정한 문턱이 거의 최적이라는 뜻이다.
- 같은 입력·같은 문턱 규칙에서 지도학습(창+v2 성분)의 F1은 v2와 비슷하다(A 0.915~0.973, B 0.972~0.974). v2 방식(정상 자료만 쓰는 이상 탐지)을 라벨 지도학습보다 고른 이유는 F1 우위가 아니다. 이상 라벨이 필요 없고, 라벨에 없는 고장 모양으로 전이되며, 정상 자료만으로 다시 보정할 수 있기 때문이다([press_supervised](../press_supervised/README.md)). 같은 특징 대안과 비교할 때 전이는 근거가 아니다(§2).

## 한계

- **L1 독립 검증 없음.** 이상 21구간은 07-17의 3분 연속 기록 하나이고 A·B가 공유한다. 정상과 이상은 다른 날이다. 이 폴더의 어떤 비교도 대회 자료 밖으로 일반화할 근거가 아니다.
- **L2 설계의 사후성.** 초반 창과 AR(2)는 같은 이상 자료에서 v1 미탐을 본 뒤 설계했다. 중첩 선택은 후보 사이의 선택 편향만 잰다. 설계 자체의 사후성은 지울 수 없다.
- 지속성·Fisher·5NN이 사후로 v2보다 나아 보이는 결과(대회 F1, A의 주입 전이)도 같은 한계 안에 있다. 새 날짜 자료 없이 결론을 바꾸지 않는다.
