관측 이상에 대한 확인 순서입니다. 고장 원인 확정이나 자동 정지 명령이 아닙니다.

경보 기준 읽는 법정상 보정 구간의 최대 점수와 비교합니다. α는 시간 비율이 아니라 기록구간(최대 50행, 5초) 단위 비율입니다. 같은 날 기록 밀도(경과 1시간에 약 450구간)라면 α 1%는 교대 8시간에 약 30~36건 규모입니다. 끊김 없는 연속 입력은 50행 단위로 나눠 알리고, 이어지는 이상은 한 건으로 묶습니다. p값은 고장 확률이 아니며, α는 다른 날짜·설비의 실제 오경보율을 보장하지 않습니다. 수집 오류 행은 판정을 보류합니다.

행 단위 F1

남아 있는 미탐

α 1% · 원본과 같은 정밀도 맞춤 전처리

A/B는 이상 600행·21구간을 공유하며 정상 평가 구간도 일부 겹칩니다. 첫 경보 지연은 기록 시작부터 측정했으며 실제 고장 발생 시각은 제공되지 않았습니다.

어디서 놓치고 어디서 잘못 울리는가 · α 1%

기록구간 안의 위치(0.1초 간격 관측 번호)별 이상 행 미탐과 정상 행 오경보. 위치 0·1에는 센서 크기 성분만 있어 v1과 v2가 같다. v2의 미탐 감소는 주로 위치 2~6(A 49행·B 51행)이고, 위치 10 이후에서도 A 6행·B 4행 줄었다.

정상 알림 업무량 · 교대 8시간(경과시간) 환산

α는 기록구간(최대 50행)당 비율입니다. 명목은 보정 120구간이 허용하는 비율(⌊α·121⌋/121), 관측은 정상 평가 구간의 알림 수, 상한은 관측 비율의 이항 단측 95% 상한입니다. A 평가 구간은 보정보다 조용한 시간대라 관측 0건은 유리한 조건의 값입니다. 같은 날 간헐 수집 밀도를 가정한 환산입니다.

경보 근거별 확인 순서

확인 대상은 센서·성분에서 나온 가설입니다. 정비 결과로 검증하지 않았습니다. 크기 성분은 최대 편차가 진동 센서인지 전류 센서인지까지 구분합니다.

입력 정밀도가 바뀌면 · 재학습 없이 평가 입력만 교체

matched로 적합·보정한 상태를 고정하고 raw(원본 정밀도)·coarse(4배 거친 정밀도) 입력으로 평가했다. coarse B에서는 v2의 정상 알림이 v1보다 많다. 모든 정밀도에서 오경보가 같다고 말하지 않는다.

정상 규칙을 세 가지 관점에서 확인

  1. 즉시진동·전류 크기가 정상 범위를 벗어나는지 확인
  2. 0.2초부터앞선 두 전류 관측으로 예측한 값과 실제 값의 차이 확인
  3. 0.5초부터짧은 파형 6개 관측을 확인하고, 8개부터 더 긴 창으로 전환

실행 검증

입력 묶음 크기가 바뀌어도 경보와 점수가 같아야 합니다. 구간 경계·잘못된 값 이후에는 과거 창을 이어 쓰지 않습니다.
