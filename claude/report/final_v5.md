# 표지

- 부문: 일반국민/대학(원)생 부문
- 프로젝트명: 설비 물리·데이터 결함 진단에 기반한 프레스 유압펌프 이상 조기 경보와 오경보 발생조건 분석
- 팀명: 북적북적 (팀장 허예준, 팀원 장준용)

## 내용요약

◦ 핵심: 고장의 흔적은 전류 파형에 남고 오경보는 진동에서 생긴다는 진단에서 출발함. 전류 파형으로 고장을 잡고 파형이 정상인데 진동만 큰 경보는 점검 요청으로 올리지 않는 두 단계 경보를 만듦(과제 ③: 이상 조기탐지, 오경보 억제와 발생조건 분석).
◦ 데이터 진단: 저장 형식만 보고도 행 F1 0.992가 나오는 누수, 최대 50행(5초)씩 끊긴 기록, 정상·이상 자료의 날짜 차이부터 걷어내거나 설계에 반영함. 그러고도 남은 차이는 진동보다 전류 파형의 붕괴였음(정상 전류는 사인에 맞지만 이상 기록은 R² 최대 0.561).
◦ 탐지(과업 ①): 정상 자료로만 학습한 기반 모델 v2는 사건 지속 규칙(R1)을 빼도 두 분할의 test 행 F1이 0.965·0.970이라 베이스라인 5종 중 최고인 0.498을 크게 앞섬. 같은 전류 파형·동역학 특징을 5NN에 넣어도 0.970·0.972로 같은 수준이니 성능은 모델이 아니라 전류 파형이라는 신호에서 나옴(특징은 이상 자료를 본 뒤 정함). test 전에 잠근 v2+R1(1단계 "주의")의 공식 성능은 test 1.000·0.995, 미탐 0행임.
◦ 오경보 억제(과업 ②): 오경보는 학습에 없던 정숙 구간에서가 아니라 고부하 정상 운전 중 진동만 커질 때 몰림. 전류 파형이 정상이면 2단계로 올리지 않는 교차 확인 규칙(R2)을 두어 고부하 오경보 기록을 9/53→1/53로 줄임. 그 대가로 진동만 커지는 주입 고장에서는 2단계 탐지율이 최대 23.7%p 낮음.
◦ 현장 활용: 센서를 더 달지 않고 진동 2·전류 1채널만으로 "주의"·"점검 요청" 두 단계 경보와 경보 근거별 점검 순서·품질 조치를 정함(4장). 합성 열화에서는 전류 파형 열화의 95.8~100%가 최대 강도에 이르기 전에 2단계 경보를 냄.
◦ 재현성: run_all.py 명령 하나로 전처리부터 test 예측 파일·보고서 수치 대조까지 끝나며 새 가상환경에서 돌려도 보고서 수치 43개가 모두 일치함(6장).
◦ 한계: 이상 구간은 약 3분짜리 사건 하나뿐이라 1.000을 일반화 근거로 볼 수 없음. 모델 설계와 R1·R2는 이상 자료를 보고 나서 정했으며 R2는 test 결과를 확인한 뒤에 추가함(2.3·2.5절).

# □ 제1장. 데이터 이해 및 진단〔15점〕

◦ 주요 결과(test, 같은 시간순 분할·같은 보정 α 1%, 행 단위. '사후'는 test 채점 뒤 분석, 2.4절)

| 모델 | 실시간 행 F1 A / B | 행 AUROC A / B(문턱 무관, 사후) | 미탐 행 A / B | 오경보 행 A / B |
|---|---:|---:|---:|---:|
| MLP 오토인코더(베이스라인 F1 최고) | 0.498 / 0.498 | 0.801 / 0.770 | 216 / 216 | 2 / 2 |
| 5NN 거리(베이스라인 AUROC 최고) | 0.474 / 0.487 | 0.895 / 0.862 | 223 / 218 | 1 / 5 |
| max\|z\|(크기 성분만) | 0.404 / 0.428 | 0.862 / 0.818 | 242 / 235 | 0 / 3 |
| v1(크기 + 전류 파형) | 0.904 / 0.912 | 0.932 / 0.927 | 57 / 50 | 0 / 3 |
| 기반 모델 v2 | 0.965 / 0.970 | 0.975 / 0.974 | 22 / 16 | 0 / 3 |
| **v2 + R1 (잠금 모델, 공식 성능 = 1단계 "주의")** | **1.000 / 0.995** | 규칙(해당 없음) | **0 / 0** | **0 / 3** |
| v2 + R1 + R2 (2단계 "점검 요청", test 확인 후 추가) | 1.000 / 1.000 | 규칙(해당 없음) | 0 / 0 | 0 / 0 |

  - 크기 성분만 쓴 max|z|에 전류 파형 성분을 더한 v1에서 F1이 가장 크게 오른다. 같은 특징을 넣은 5NN도 v2와 같은 수준이니(사후, 2.7절) 고장을 가르는 힘은 전류 파형이라는 신호에서 나온다.
  - 오경보는 고부하 정상에서 진동만 커질 때 생긴다. v2만 쓰면 오경보가 베이스라인보다 적지 않지만(분할 B α 5% 9/53) 전류 파형이 정상이면 2단계로 올리지 않는 R2가 이를 1/53으로 줄였다(3.2절).
  - 공식 성능으로는 test 전에 잠근 v2+R1의 값을 쓴다. 단일 사건이라 1.000은 일반화 근거가 되지 못하니 모델의 우열은 R1 없는 F1·AUROC 열로 읽는다(1.7절).

## ◦ 1.1 과제와 출제 의도

- 이 보고서의 주장은 과제 ③(프레스 유압펌프 이상 조기탐지 및 오경보 분석)의 두 과업에 맞춰 둘로 나뉜다. 과업 ① 이상 조기탐지는 전류 파형으로 푼다. 과업 ② 정상 운전변화의 오경보 억제와 미탐·오경보 발생조건 분석에는 진동만 큰 경보를 거르는 규칙으로 답한다. ②는 가이드북(LSTM 오토인코더 실습)에 없던 요구다.
- 가이드북[27]에 따르면 이 펌프가 고장 나면 수리·부품 수급으로 공정이 최대 2~3일 멈춘다. 지금은 숙련 작업자가 소음을 듣고 판단한다.
- 용어
  - 조기 탐지: 이상 상태에 들어선 뒤 첫 경보까지 걸린 시간(행·초). 고장 직전 구간이 없어 고장 전 선행 시간은 검증할 수 없다(2.1절).
  - 오경보: 정상 기록에서 울린 경보. 행·기록 수와 시간당 경보 사건 수로 센다(2.5절).
  - 정상 운전변화: 부하(전류 크기)와 진동 수준이 바뀌는 정상 운전. 고·중·저부하와 정숙 구간으로 나눴다(3.2절).

## ◦ 1.2 설비 구조: 파인블랭킹 프레스와 유압 계통

- 전류와 진동 신호를 읽으려면 먼저 설비가 어떻게 힘을 내고 센서가 어디에 달렸는지 알아야 한다.
- 파인블랭킹은 판재를 V링으로 눌러 고정하고(V링력) 아래에서 역압으로 받친 채 펀치로 절단하며 V링력과 역압은 유압 실린더로 건다[12]. 가이드북에 따르면 이 설비는 유압펌프로 약 1000톤의 힘을 낸다.
- 한 행정에서 고압·저속으로 움직이는 구간은 블랭킹뿐이다[13]. 12,000kN급 유사 프레스에서는 모터-펌프가 어큐뮬레이터를 채우다가 설정압에 이르면 기름을 탱크로 돌려보낸다(언로딩)[13]. 이 설비도 같은 방식이라면 모터 부하는 수 초 단위로 오르내린다(추정).
- 가이드북의 구조 그림(맞물린 두 기어)과 "기어 마모" 서술로 미루어 이 펌프는 외접 기어펌프로 보인다. 고압 기어펌프의 잇수는 보통 9~12개다[14].
- 센서는 모터-펌프 유닛 상부·하부의 진동센서 2개와 펌프 모터 전력선의 전류센서 1개다. PLC가 이 신호를 초당 10회 수집한다.

## ◦ 1.3 기어펌프 고장의 물리와 센서 서명

- 문헌을 보면 기어펌프 고장은 진동뿐 아니라 모터 전류에도 흔적을 남긴다(아래 표). 전류로 고장을 잡는다는 주장은 이 사실을 물리적 근거로 삼는다.
- 가이드북은 노후화에 따른 기어 마모를 고장 원인으로 든다(진동·소음 증가, 유압 약화, 불량품). 마모는 주로 기어 끝면과 측판(플로팅 부싱)에서 생기며 가속수명시험에서는 체적효율이 70%로 떨어지기까지 960~982시간이 걸렸다[15]. 마모가 수백 시간 단위로 진행되는 만큼 2분 46초 안의 급변은 진행 중인 마모보다 이미 이상 상태인 펌프의 증상에 가깝다(추정).

| 고장 모드 | 진동·압력·유량 서명(문헌) | 모터 전류 서명(문헌) |
|---|---|---|
| 측판·끝면 마모(내부 누설) | 내부 누설·체적효율 저하, 압력 맥동 증가(압력 측정)[15] | 유압 일이 줄어 전류 감소(새것일 때 대비)[16] |
| 치면 마모·피팅 | 맞물림 주파수 주변 측대역(기어박스 연구, 적용은 가설)[17] | 부하 토크 변동 → 전류 위상 변조[18] |

- 표의 서명은 대부분 수십 Hz~kHz 대역에 있다. 10Hz로 볼 수 있는 것은 1.5절에서 다룬다.

## ◦ 1.4 변수 정의와 물리 해석

- 변수를 다시 읽어 보면 전류 채널은 교류 순시값이라 파형 모양을 볼 수 있다. 고장 신호도 이 파형에 담긴다. 정상 하부 진동은 부하를 따라 커지며 이것이 고부하 오경보의 바탕이 된다(3.2절).

| 변수 | 의미(가이드북 정의) | 정상 | 이상 |
|---|---|---|---|
| TimeStamp | 수집시간(초당 10회 수집) | 2022-07-12(화) 00:00~01:17 | 2022-07-17(일) 10:51~10:53 |
| AI0_Vibration | 유압펌프 상부진동 | 표준편차 0.071 | 0.448 |
| AI1_Vibration | 유압펌프 하부진동 | 표준편차 0.119 | 0.241 |
| AI2_Current | 유압펌프 전류 | 평균 1.4(음수 49.5%) | 평균 57.3 |
| Equipment_state | 장비 고장 여부(정상 0, 고장 1) | 20,000행 모두 0 | 600행 모두 1 |

- AI2_Current는 값의 절반이 음수이므로 실효값이 아닌 펌프 모터 전류의 교류 순시값이다. 정상 전류는 기록마다 겉보기 0.600Hz 사인에 맞는다(30행 이상 360기록, R² 0.9941~0.9996).
- 0.600Hz는 60Hz 계열 파형이 10Hz 표본으로 접힌 결과로 보인다. 잔차에는 홀수 고조파만 정확히 3·5·7배 위치에 있어 교류 전류의 반파 대칭과 맞는다. 다만 실제 0.6Hz 신호와는 구별할 수 없으므로 가설로만 둔다.
- 표본 간격이 정확히 100ms라면 전류는 59.4 또는 60.6Hz여야 하므로 한국 계통 허용 범위(60±0.2Hz)[21]를 벗어난다. 계통이 60Hz라면 실제 간격은 101.0ms 또는 99.0ms여야 한다. 그런데 타임스탬프 간격이 모두 정확히 100ms여서 시각은 계산값으로 보인다. 인버터로 구동했을 가능성도 있어 이 판단은 추정으로 두고 확정하지 않는다.
- 접힘 가설이 맞다면 적어도 전류 채널에는 충분한 안티앨리어싱 필터가 없다. 진동 채널은 필터가 있는지 알 수 없어 기록 안 표준편차(SD)를 상대 변동 지표로만 쓴다. 단위도 공개되지 않아 ISO 20816 구역 판정 대신 정상 대비 상대 판정만 한다[22].
- 정상 하부 진동은 백색 잡음이 아니다. 에너지의 71%가 1~2Hz 대역의 1.79Hz 톤에 몰려 있으며 이 톤의 진폭은 부하를 따라 오르내린다(전류 진폭과 Spearman 0.874).
- 데이터는 최대 50행(5초)짜리 "기록"으로 끊겨 들어온다. 기록 시작은 약 8.02초, 끝은 약 6.78초 주기에 묶여 있어 PLC가 표본을 최대 50개씩 모아 올리는 구조로 추정한다. 분석은 이 기록 단위로 하며 정상은 600기록, 이상은 21기록이다.

## ◦ 1.5 센서 관측 가능성: 초당 10회로 볼 수 있는 것

- 초당 10회 표본으로는 기어 맞물림 같은 표준 진단 서명을 볼 수 없다. 남는 세 정보 가운데 고장을 가르는 신호는 전류 파형이다(2.2·2.4절).
- 나이퀴스트 주파수가 5Hz여서 1.3절 서명은 대부분 직접 볼 수 없다. 4극 모터라면 회전 1X가 약 29Hz, 맞물림이 약 260~350Hz이고 캐비테이션은 고주파다. 극수·잇수는 가정값이다(3.5절 한계 표).
- 10Hz에서도 남는 정보는 다음 세 가지다. 이 정보가 기반 모델 특징과 어떻게 대응하는지는 설계 뒤에 점검한다(2.3절).
  - 관측 진폭의 크기: 진동 크기(기록 안 SD, 상대 변동 지표)

## ◦ 1.7 전처리와 검증 전략

- 이 절에서는 공식 성능을 어떻게 읽을지 정한다. 이상은 약 3분짜리 한 사건뿐이고 잠금 선택(valid)과 채점(test)이 그 사건을 앞뒤로 나눠 가지므로 test 1.000이 새 고장에도 일반화된다는 근거는 되지 못한다. R1을 붙이면 어느 모델이든 1.000 근처가 되기 때문에 기반 모델의 우열은 R1을 뺀 행 F1·AUROC로 가린다.
- 전처리: 두 파일의 진동은 1e-4, 전류는 1.1920929 간격으로 똑같이 반올림해 형식 누수를 없앤다. 이웃한 두 행의 간격이 0.1초를 벗어나면 거기서 새 기록이 시작된다고 보고 창 계산은 모두 기록 안에서만 한다. 표준화와 성분 분포는 정상 train으로 정한다. 라벨·날짜·파일명은 입력에서 뺀다.
- 검증 전략: train/valid/test를 시간순으로 나눈다.

| 구분 | 정상 분할 A | 정상 분할 B | 이상 21기록 | 쓰임 |
|---|---|---|---|---|
| train | 기록 0~359 | 0~299 | 사용 안 함 | 모델 학습 |
| valid | 360~479 | 300~419 | 앞 10기록 | 정상: 문턱 보정 / 이상: 모델 선택·확률 보정 |
| test | 480~599 | 420~599 | 뒤 11기록 | 최종 채점 |

  - 채점과 지표: 행 단위로 채점했다. 구간에서 한 점만 맞혀도 전체를 맞힌 것으로 치는 point-adjust는 쓰지 않았다[2]. 주 지표는 실시간 행 F1(valid A·B 평균, α 1%)이며 실시간 잠금 선택(v2+R1)도 이 값을 기준으로 했다. 기록 판정 F1(2.4절)은 정상·이상 기록에 같은 규칙을 적용하는 기록 분류 지표다. 이 값은 기록 단위 잠금 선택(v3 kNN)에만 썼고 보고에는 두 지표를 함께 싣는다.
  - valid의 한계: valid 정상 오경보는 그 기록을 뺀 나머지로 문턱을 정해 재므로(α 1%·120기록이면 '다른 119기록의 최댓값') 점수 모델의 valid 오경보는 구조상 1기록이 된다(α 3%는 3, 5%는 6). 그래서 잠금 선택의 모델 차이는 주로 사건 앞부분인 이상 앞 10기록의 미탐에서 나온다. 오경보는 test와 3.2절에서 비교한다.
  - R1의 효과: R1(2.3절)은 확인된 이상 기록에 이어지는 기록을 첫 행부터 경보로 채우므로 사건이 하나로 이어진 이 데이터에서는 point-adjust와 비슷한 이득을 본다. valid부터 이어 돌리면 R1을 붙인 모델은 모두 0.982~1.000이 된다. test 기록부터 따로 돌려야 IsolationForest+R1 0.612·0.609와 v2+R1 1.000·0.995로 갈린다. point-adjust와 달리 R1은 미래 행을 쓰지 않으며 전류 파형이 정상으로 확인되면 풀린다(2.6절 E1a′).
  - 해시 잠금: valid에서 고른 결과와 test 판정 기준은 해시로 잠갔다. test는 잠금이 맞을 때만 채점했다. 이 장치는 선택 과정을 통제할 뿐이다. 설계 경위는 2.3절, 일반화 시험은 2.6절에서 다룬다.
  - 두 분할: A·B는 이상 기록이 같고 A test 정상이 B test 정상에 포함되므로 서로 독립된 두 확인으로 볼 수 없다. A test 정상은 120기록 중 83기록이 정숙 구간이어서 고부하 오경보는 B test와 valid에서 본다.

- 기동 과도 가설: 이상 파일은 일요일 오전 기록이어서 주말 정지 뒤의 냉간 기동일 수 있다. 그렇다면 시간이 지날수록 이탈이 줄어야 하는데 13개 특징 가운데 줄어든 것은 없었다(보정 전 p<0.05 기준 0개). 작동유 점도(ISO VG 46, 20~25°C 가정 약 100~135cSt)[23]도 기어펌프 계열의 냉간 기동 최대 점도 2000mm²/s보다 훨씬 낮지만[24] 본 설비의 유온·흡입 조건 자료가 없어 판단에는 쓰지 않는다. 다만 2분 46초는 짧아서 검정력이 낮고(검정력 80%에 잡음 SD의 2.3배 변화가 필요) 공기 혼입·빈 어큐뮬레이터 충전 같은 기동 과도 요인도 배제하지 못했다.
- 전류 계열에는 증가 경향이 있었다(전류 실효값, 17기록 ρ 0.79. 연속 기록의 자기상관을 보정하면 유의하지 않음). 후반의 기록 19·20은 진동이 정숙 구간보다도 작은데 전류는 크다. 이 모습은 램이 멈춘 채 펌프가 고압에서 부하를 받는 상황과도, 전류센서 영점 이동·포화와도 맞는다. 압력 채널이 없어 둘을 가를 수 없다.

## ◦ 2.3 모델 구성

- 기반 모델 v2에는 고장을 가른 전류 파형을 직접 보는 성분이 있다. 두 경보 규칙 가운데 R1은 수집 공백을, R2는 고부하 정상 오경보를 다룬다. 모델 계열 v1(크기+파형), v2(v1에 초반 6행 파형 창과 동역학 성분을 더한 Press Guard), v3(기록 단위로 판정하는 기본형 B1·kNN과 부하 조건부 진동 성분)는 이 과제를 위해 먼저 만들었다. 그중 v1·v3는 2.4절의 같은 조건 비교와 2.6절의 검증 틀에 쓴다.
- 기반 모델 v2(Press Guard)는 정상 학습 자료만으로 0.1초마다 세 성분을 계산한다. 세 성분은 1.5절의 세 정보인 관측 진폭의 크기, 채널 관계를 뺀 저주파 구조, 전류 파형과 하나씩 대응한다. 이 대응은 설계를 마친 뒤에 점검했다.
  - 크기: 세 센서의 표준화 값 중 최댓값 → 관측 진폭의 크기. 행마다 표준화한 순간 편차로, 1.5절의 기록 안 진동 SD와는 다른 양이다.
  - 파형: 최근 6~8행 전류의 사인 적합 1−R² → 부하 토크 변동에 따른 전류 일그러짐
  - 동역학: 정상 전류로 학습한 AR(2)의 예측 오차 → 겉보기 0.6Hz 전류의 시간 구조
  - 각 성분을 정상 꼬리 확률의 −log10 척도로 바꾸면 가장 드문 성분이 최댓값이 되는데, 이 최댓값을 점수로 쓴다. conformal 문턱은 valid 정상 기록의 최대 점수로 정한다[4].
- 사건 지속 규칙 R1에서는 끝난 지 60초가 안 된 직전 기록이 확인된 이상이면 새 기록이 첫 행부터 경보를 이어받는다. 확인된 이상이란 자기 경보가 2행 이상 나왔거나 이어받은 경보가 기록 끝까지 풀리지 않은 기록을 말한다. 새 기록이 8행 이상이고 사인 적합 R²가 정상 학습 기준 이상이어서 전류 파형이 정상으로 확인되면 경보를 해제한다. 8행이 안 되는 기록에서는 해제하지 않는다.
  * 고장은 수 초짜리 수집 공백 사이에 사라지지 않고 v2의 미탐은 기록 시작 직후에 몰려 있어서 이렇게 정했다. 산업 경보 관리의 OFF-delay·래치 계열[5]에 속하지만 운전원 리셋 대신 전류 파형의 정상 확인으로 자동 해제한다.
- 교차 확인 규칙 R2는 크기 성분만 문턱을 넘고 그 시점 전류 파형이 정상이면 2단계 경보를 보류한다. 이 경보는 1단계 "주의"로 남는다(4.2절). 파형을 판단할 행이 아직 8행에 못 미치면 경보를 그대로 둔다.
  * 고부하 정상 구간에서는 크기만 커지고 전류 파형은 정상이다. 그래서 진동 크기와 전류 파형이라는 두 물리 채널이 함께 이상을 가리킬 때만 크기 경보를 올려 과업 ②의 정상 운전변화 오경보를 줄이려 했다.
- 설정은 아래 표에, 전체 구조는 그림 8에 모았다. R1·R2에서 쓰는 R²는 기록 첫 행부터 해당 행까지 들어온 전류로 구한 사인 적합 R²다.

[그림 8: 두 단계 경보 구조]

- 경위도 밝혀 둔다. 이 구성은 이상 자료를 본 뒤에 정했다. 기반 모델 v2의 설계인 초반 창·AR(2)와 2행 기준은 v2를 만들 때, 규칙 R1·R2와 그 상수는 초기 탐색에서 정했다. 둘 다 전체 이상 데이터를 열람한 뒤였다. 이후 시간순 train/valid/test로 다시 평가하면서 valid에서 고른 결과를 해시로 잠갔고 그 선택을 바꾸지 않은 채 test를 채점했다. 재실행해도 결과는 같았다. R2를 더한 2단계 승격 규칙은 그 뒤 test를 보고 정했다. 공식 성능은 잠금 모델로 둔다(2.5절).

## ◦ 2.4 같은 조건의 모델 비교

- 같은 분할·같은 보정에서 견주면 전류 파형 성분을 가진 v2가 R1 없이도 원신호 베이스라인을 크게 앞선다(test 행 F1 0.965·0.970, 베이스라인 최고 0.498).
- '사후'로 표시한 행·열·문단은 test 채점 뒤에 추가했으므로 선택·잠금·2단계 규칙 추가에는 쓰지 않았다. 사후 대조는 2.7절에 자세히 모았다.
- 모든 모델은 형식 누수를 지운 입력(1.6절)에서 같은 분할, 같은 valid 보정(α 1%)으로 채점했다. 실시간 판정은 행이 들어오는 순간, 기록 단위 판정은 기록이 끝난 뒤에 내린다. 기록 판정 F1은 그 판정을 기록의 모든 행에 펼쳐 센 값이다(1.7절). 기록 하나를 1개로 센 F1은 사후 열에 따로 적었다. 견준 모델은 거리(5NN)·트리(IsolationForest)·복원(MLP·LSTM 오토인코더)·예측(Ridge)·관리도(PCA·CUSUM·EWMA)·특징 기반(max|z|·v1·v2·v3)의 여섯 계열이다(일부 사후). 남은 차이가 고장에서 왔는지 수집 조건에서 왔는지는 2.6절 E5에서 따진다.
- R1을 붙이면 어느 모델이든 1.000 근처라(1.7절) 이 사건만으로는 모델을 가를 수 없다. 그래서 잠금 전에 정한 기반 모델 v2(2.3절)를 test에서 ① R1 없는 탐지(실시간 행 F1, 문턱과 무관한 행 AUROC·PR-AUC), ② 인공 주입 탐지력(성분 절제), ③ 정상 오경보(운전 상태별, 3.2절)의 세 기준으로 사후 점검했다. 보완 LSTM과 Ridge 예측 오차도 같은 기준으로 견줬다(2.7절). 보완 LSTM은 가이드북 LSTM의 기록 앞부분 처리·점수 방식을 고친 516개 변형 가운데 valid로 골랐다. - 한 행만 보는 모델(max|z|, 5NN, IsolationForest)과 가이드북 설정의 오토인코더는 실시간 판정에서 이상 행 대부분을 놓친다(행 F1 0.094~0.498, 그림 9). 기록 판정으로 모으면 행 가중 0.672~0.960, 기록 수 0.625~0.900까지 올라 v2와 격차가 좁아진다.

- v3의 조건부 진동 성분(전류 크기에 따라 진동 정상 범위를 바꿈)은 A에서 조금 오르고 B에서 내려 잠근 판정 기준(test A·B 평균 F1이 v2보다 높음)을 충족하지 못했다. 기록 단위 모델 가운데 valid로 고른 v3 kNN(0.993)도 test에서는 0.889~0.954로 떨어졌다.

- 딥러닝은 데이터 조건과 해석 가능성을 따져 기반 모델로 고르지 않았다. 고장은 한 사건뿐이고 기록이 최대 50행(5초)으로 끊겨 긴 시계열을 학습할 연속 구간이 없다. 표본도 초당 10회라 빠른 진동 정보가 담기지 않는다(1.5절). 다변량 시계열 이상탐지 연구에서도 단순한 방법이 딥러닝과 비슷하거나 낫다는 결과가 있다[9][10]. 가이드북 방식의 낮은 F1은 근거로 삼지 않았다. 20행 창이 기록 앞 19행을 판정하지 못해 test 이상 324행 중 177행(54.6%)을 처음부터 미탐으로 센 탓이 컸기 때문이다. 이를 보완한 LSTM은 v2와 같은 수준이었지만 전류 파형 주입을 거의 놓쳤다(사후, 2.7절).

## ◦ 2.5 제출 모델: 1단계 잠금 모델과 2단계 경보

- 제출 모델의 경보는 두 단계다. 전류 파형으로 고장을 잡는 잠금 모델(v2+R1)이 1단계 "주의"를 내고 여기에 R2를 더한 2단계가 "점검 요청"을 낸다. R2는 전류 파형이 정상이면 진동만 큰 경보를 올리지 않는다.
- 선정 근거는 세 가지다.
  - 기반 모델 v2: R1 없이 잰 test 행 F1(0.965·0.970)과 문턱에 좌우되지 않는 행 AUROC(0.975·0.974)가 모두 베이스라인 5종·v1보다 높다(2.4절, 사후 점검).
  - R1 사건 지속: test에서 A 22·B 16행이던 미탐을 0으로 줄였다(3.4절).
  - R2 교차 확인: 분할 B α 5% 기준으로 고부하 정상 오경보 기록을 9/53에서 1/53으로 줄였다. 대신 2단계의 진동 단독 주입 탐지율이 최대 23.7%p 떨어졌는데, 이 경보도 1단계에는 그대로 남는다(2.6절).
- 제출 구조: 공식 성능은 잠금 규칙이 고른 v2+R1(test 1.000·0.995, 미탐 0행)로 잰다. 2단계 모델(v2+R1+R2)은 test를 본 뒤 더한 운영 권고안으로, v2 경보에 R2를 먼저 적용한 다음 R1을 붙인다. R2는 경보를 빼기만 하고 R1은 전류 R²만 보고 해제되므로 2단계 경보는 늘 1단계 경보에 포함된다. 제출 예측 파일에서도 2단계에만 울린 행은 0이다.
- 기반 모델 근거: v2는 잠금 전에 정해 둔 기반 모델이다(2.3절). 잠금 후보 가운데 R1 없이 잰 valid 실시간 F1도 v2 계열이 가장 높았다(0.963, 베이스라인 최고 0.644). R1·R2를 붙이면 max|z|도 2단계 모델과 비슷해지므로 v2 성분의 몫은 세 곳에서 드러난다. R1 없는 탐지, 사건 첫 기록 안의 미탐(valid A에서 max|z|+R1 2행 대 v2+R1 1행), 약한 전류 파형 왜곡이다(모두 사후, 2.4·2.7절). 켜진 성분은 그대로 경보 근거가 되어 4.2절 점검 순서로 이어진다.
- 잠금 선택: 잠금 후보 가운데 valid 실시간 F1 0.998로 공동 1위에 오른 모델은 셋이었다. v2+R1+R2와, 여기에 v3 조건부 성분을 더한 두 변형이다. v2+R1(0.997)과는 valid에서 점수가 가장 높은 정상 기록(461)의 A 오경보 1행을 R2가 보류했느냐 하나로 갈렸다. 미리 정한 잠금 규칙("valid 차이 0.002 이내면 더 단순한 모델", 복잡도 = 성분 수 + 규칙 수, v2+R1 4·v2+R1+R2 5)대로 v2+R1을 골랐다. 공식 성능도 이 모델의 값(test F1 A 1.000·B 0.9954)으로 둔다.
- R2를 2단계에만 둔 이유: R2는 초기 탐색에서 v2의 정상 오경보가 고부하 정상의 크기 성분 단독 경보임을 보고 착안했다(2.3절). 과업 ②를 겨냥해 2단계 승격 규칙으로 더한 것은 test 결과를 확인한 뒤다. 사후 분석에서 탐지는 그대로였고(3.4절) 고부하 오경보는 9/53→1/53으로 줄었다(3.2절). 이 개선은 착안할 때 본 자료 안에서 확인한 결과라 통계적 우위로 볼 수 없고 R2를 더하는 판단에도 쓰지 않았다. 그래서 공식 성능에는 R2를 넣지 않고 출동할 경보를 골라내는 2단계에만 쓴다.
- 착안 기록을 뺀 재확인(준-표본 밖, 사후): 착안 때 본 기록(303·423·461·570)과 그 앞뒤 1기록을 빼고 2.6절 E3의 시간순 5창(평가 정상 288기록)으로 다시 셌다. α 5% 정상 오경보 기록은 v2 10 → v2+R2 2(차이의 블록 부트스트랩 95% 구간 1.4~4.2%p), 고부하 50기록에서는 7 → 0(7.5~21.0%p)이었다. α 3%에서는 4→1기록이었지만 구간이 0을 포함했다. 같은 날·같은 세션 안에서 한 재확인이므로 R2는 가설 규칙으로 두고 도입 첫 달에 표본 밖에서 잰다(4.3절).
- R1을 CUSUM·EWMA 대신 쓴 이유(사후): F1로는 셋이 갈리지 않고 차이는 해제에서 난다. 고장 뒤에 정상 기록을 이어 붙인 가상 흐름에서 R1은 7행(0.7초) 만에 풀렸지만 상태를 이어 가는 표준형 CUSUM은 11.4~12.2분 동안 경보가 계속됐다. EWMA는 0.2~0.3초로 더 빨리 풀렸지만 약한 이상이면 경보가 다음 기록까지 이어지지 않을 수 있다. R1은 고장 규모와 상관없이 전류 파형이 정상으로 확인되어야 풀린다.
- α 민감도(2단계 모델, test B): 오경보는 α 1%에서 0행(F1 1.000), 3%에서 1행(0.998), 5%에서 9행(0.986)이었다. A는 세 수준 모두 1.000이다. 운영 α는 1%로 둔다.
- 첫 경보 지연: test 이상 11기록 모두 기록 첫 행(0.0초)에서 경보가 났고 1·2단계 결과가 같았다. 이 결과는 R1이 직전 이상 기록의 판정을 이어받은 값이라 사건이 이어질 때만 성립한다. 기록마다 새로 판단하는 v2는 최대 3행(0.3초) 늦었다. 이상 파일의 첫 기록에서는 2단계 모델의 첫 경보가 valid A 1행(0.1초), B 0행이었다. 이상 흐름을 test 기록부터 따로 돌려도 F1은 같았다(사후, 2.7절).
- 불확실성: 2단계 모델은 정상 오경보 기록이 0/120(A)·0/180(B)이지만 Clopper-Pearson 단측 95% 상한[11]은 2.47%·1.65%로 설계값(1/121 = 0.83%)보다 크다. 1단계에서 B의 3/180은 α 1% 설계 기대(1.49기록)와 통계적으로 구별되지 않는다. 이상 기록은 11/11을 잡았지만 95% 하한으로 보면 76.2%다. conformal 문턱도 사후에 실측했다. E3 5창 정상 300기록에서 v2의 정상 오경보 기록 비율은 α 1·3·5·10%에서 0.67·2.67·4.67·9.33%로 명목값에 가까웠지만 R1을 붙이면 α 3% 이상에서 명목값을 넘었다(3.67·6.00·11.67%). R1이 경보를 보태므로 오경보율이 α 안에 머문다는 보장은 없다. 도입 뒤 실측이 α를 넘으면 재보정한다(4.3절).
- 경보 운영 지표: 정상 test 구간이 16.1분(A)·24.1분(B)뿐이라 2단계 경보 사건이 0건이어도 포아송 95% 상한은 시간당 11.2·7.5건이다. 1단계는 A 0건·B 3건(시간당 약 7.5건)으로 α 1% 설계치(시간당 약 3.7기록, 4.3절)와 구별되지 않는다. 산업 경보 관리 기준(운전원당 시간당 약 6건 이하)[5]은 대응을 요구하는 2단계에 적용한다. 다만 실제로 이 기준을 맞추는지 따지려면 정상 기록이 더 길어야 한다.
- 이상 확률: 경보와 별도로 v2의 확률 층이 이상 확률을 낸다. valid의 정상·이상 행에 단조 회귀(isotonic regression)로 맞춘 우도비를 사전 오즈에 곱하는 방식이며 test 행은 보정에 쓰지 않았다. 평가용 확률은 사전을 test 파일의 이상 행 비율(A 7.3%·B 5.0%)로 둔다. 행 단위 Brier는 A 0.0046·B 0.0038(비율만 쓴 예측 0.068·0.048), ECE는 0.007·0.006이다. 운영용으로 사전을 현장 가정 1%로 둔 확률은 우도비 표시 상한(보정 기록 120개 + 1)에 걸려 55%에서 멈춘다(그림 14의 55.0%). 이 확률로는 경보 행끼리 순위를 가를 수 없어 운영 판단은 conformal 경보로 내리고 확률은 기록·추세 관리에 쓴다. 두 확률은 제출 예측 파일의 v2_prob_site1pct, v2_prob_fileprior 열로 내며 test 행 AUROC는 둘 다 0.977·0.979다.

- 사후 대조로 지도학습도 시험했다. 1초 창 통계 또는 기록 특징 + HistGradientBoosting·RandomForest·LogisticRegression 조합을 기록 단위 그룹 5겹 교차검증으로 평가하면, 형식 누수를 지운 자료에서도 F1 0.793~0.970이 쉽게 나온다. 그런데 같은 날 정상 기록끼리도 약 1시간 떨어진 블록이면 ROC-AUC 중앙값 0.75~0.87로 갈라낸다. 인접 블록에서는 0.48~0.58에 그친다. 정상과 이상은 5일 떨어진 세션이라 이상-정상 분리(0.93~1.00)가 고장 때문인지 세션 차이 때문인지 가를 수 없다[1]. 그래서 가이드북처럼 정상만 학습했다. 우리 모델도 세션 차이를 완전히 배제하지는 못한다(E5).
- 정상 구간을 바꿔도 오경보는 나오지 않았다. 이상 탐지는 전류 평균 차이에 기대지 않았고(E5 ③) 규칙도 전류형 이상 탐지를 해치지 않았다(E1). 여기까지는 전류 파형으로 고장을 잡는다는 핵심 주장과 들어맞는다. 다만 정상 전류 수준이 이동하거나 표본 시각이 흔들리면 오경보가 늘어나므로(E5 ①②) 현장에 옮길 때는 재보정과 시각 동기화가 필요하다(약점 3.6절, 한계 3.5절).

## ◦ 2.7 사후 대조 상세

- 이 절의 비교는 모두 test 채점 뒤에 추가했으므로 선택·잠금이나 2단계 규칙 추가에는 쓰지 않았다(2.4절). 분할과 보정(α 1%)은 앞과 같고 지표 정의는 2.4절 표를 따랐다. 다른 스크립트로 낸 점수라 기록 수 F1 열은 없다.

- **표준 기법**: 공정 산업에서 표준으로 쓰는 PCA 관리도(Hotelling T²·SPE)[6]에 교과서의 99% 한계를 그대로 적용하면 valid 정상 기록의 49%(A)·45%(B)에서 한 행 이상이 한계를 넘었다. 그래서 기록 단위 운영에는 맞지 않았다(test 기록 판정 F1 0.163·0.127). 원인은 창이 겹치며 생기는 자기상관, 부하의 이봉 분포, 기록마다 수십 번 되풀이되는 검정이다. 같은 특징을 conformal로 보정하면(위 표) 고부하 정상 오경보는 0이 된다. 다만 기록 위치 0~1에는 점수가 없고 2~6행에서는 반응이 둔하다.
- 표준 순차 검출 기법인 CUSUM[7]·EWMA[8]도 기록 경계를 넘어 상태를 이어 가면 R1 수준에 이른다. 반대로 기록마다 0으로 되돌리면 v2보다 조금 오르는 데 그친다(CUSUM 0.978·0.975). 이득은 주로 수집 공백을 건너는 기억에서 나오며 차이는 해제에서 난다(2.5절). 단, 상태를 이어 가는 CUSUM에서 valid로 고른 k=5는 격자의 끝값이다. 이 값이 정상 점수 최댓값(A 4.42·B 3.52)보다 커서 α 보정이 퇴화했고 사실상 누적값이 0을 넘으면 경보가 난다. B test 1.000은 이 높은 문턱 덕분이다.
- **R1을 붙인 비교**: R1은 어떤 점수 모델에도 붙일 수 있으므로 베이스라인에도 붙였다(아래 표). test 이상 11기록은 60초 이내 간격으로 이어진 한 사건이다. 전류 파형도 끝까지 정상으로 돌아오지 않아서 경보가 한 번 켜지면 나머지 행은 앞단 모델이 무엇이든 맞는다(IsolationForest+R1도 1.000/1.000).
- R1은 첫 경보를 만들지 못하고 앞단 모델의 오경보까지 번지게 한다(B test 단독→+R1: 5NN 5→12행, MLP 오토인코더 2→9행, v2 3→3행). 그래서 차이는 사건 앞부분이 포함된 valid 실시간 F1과 test부터 돌린 결과에서 드러난다. 다만 max|z|(v2의 크기 성분과 같은 양)에 R1을 붙이면 세 곳 모두 v2+R1과 거의 같다(v1+R1도 같음). R2까지 붙이면 α 1%에서 2단계 모델(0.998·1.000·1.000)과 거의 차이가 없으며 α 5%의 test B 오경보는 0행이다(2단계 모델 9행). max|z|에서 R2는 '전류 파형이 정상이면 보류'라는 규칙이 되는데, 이때 파형을 판정하는 것은 v2 성분이 아니라 규칙용 R²다(2.3절). R1·R2를 붙이고 나면 이번 사건에서 v2 파형·동역학 성분의 몫은 보이지 않는다(그 몫이 드러나는 곳은 2.5절).

- **보완 LSTM: 가이드북 LSTM을 보완해도 남는 오류**
  - 가이드북 LSTM 오토인코더는 F1이 낮았다(test 0.289·0.238, 2.4절 주 비교표). 그 원인이 모델 능력인지 설계인지 가리려고 LSTM 오토인코더 틀 안에서 기록 앞부분 처리(가변 길이 창), 점수 방식, 용량·학습량을 바꾼 설정 26개를 학습했다(162회). 채점 방식과 조합한 변형 516개 가운데 valid만 보고 하나를 골라 잠근 뒤 새 seed 3개로 다시 학습한 앙상블을 썼다.
  - 결과는 valid 0.968, test 0.975·0.972로 v2(0.963, 0.965·0.970)보다 조금 높다. 그러나 단일 seed의 표준편차(0.005)와 test 범위(0.964~0.976) 안에 드는 차이라 같은 수준으로 본다. 가이드북 방식과 벌어진 F1 차이는 상당 부분 모델 능력보다 기록 앞부분 처리와 점수 방식에서 나왔다. R1을 붙이면 valid 0.990·test B 0.985로 v2+R1(0.997·0.995)에 못 미친다(위 표).
  - 남은 오류는 분할 이름 A·B와 헷갈리지 않게 가~마로 적는다(따로 적지 않으면 α 1%). 가·나는 두 모델에 공통이고 R1·R2가 줄인다. 다·라는 LSTM에만, 마는 v2에만 있어 규칙을 붙여도 남는다.

  - 가·나는 기록이 5초 이하로 끊기는 수집 구조와 부하 변화에서 생긴다. R1은 보완 LSTM의 미탐을 없앴지만 오경보까지 이어 붙여 분할 B test 오경보가 3행에서 10행으로 늘었다. R2를 원래 뜻대로 옮겨 진동 채널만 넘은 경보를 보류하게 하면 오경보가 줄지 않았다. '전류 파형이 정상이면 LSTM 경보를 모두 보류'하도록 넓혀야 0행이 되었다(분할 B 정상 300기록으로 넓히면 α 5% 경보 행 34행, 2단계 모델 11행). 넓힌 R2와 R1의 해제에서는 모두 규칙용 전류 파형 확인(2.3절)이 최종 판정을 내리므로 이 0행은 LSTM이 아니라 규칙의 효과다.
  - 다·라는 규칙으로 풀리지 않으므로 전류 파형 이상을 놓치지 않으려면 파형 성분이 필요하다는 근거가 된다. 다만 단서가 붙는다. 파형 붕괴가 고장 탓인지는 가를 수 없고 v2는 시각 흔들림에 더 민감하다(2.1절·E5 ②). 오류 다는 결과를 열기 전에 정한 교체 검토 조건 5개 가운데 보완 LSTM이 유일하게 채우지 못한 조건이다. 오류 라는 사후 관찰에서 나왔다.
  - 보완 LSTM이 나은 점도 있다. 진동 단독 주입(E1b)을 v2보다 잘 잡는다(최대 46.9%). 16칸 중 11칸은 25% 미만이라 별도 진동 모델을 대신하지는 못한다(3.6절). 분할 B 정상 300기록에서 오경보가 난 기록도 더 적다(α 1% 2 대 4, α 5% 8 대 13). 대신 학습이 무거워 최종 설정 하나에 CPU로 약 1시간이 걸린다(v2는 수 초).
  - 한계도 있다. 변형 516개를 같은 valid 사건으로 골랐으므로 낙관 편향이 남는다(새 seed 앙상블의 test 평균 0.973이 선택 seed 변형의 test 최고 0.971보다 높음). 최종 설정은 학습 12회 모두 1000에폭 예산을 다 썼다. 격자를 짤 때는 test에서 본 사실(20행 창이면 test 이상 행 54.6%가 점수 없음)도 반영했다. 거꾸로 v2·R1·R2는 이상 자료를 본 뒤 정했기 때문에(2.3절) v2 쪽에 유리한 비대칭도 있다.
- **성분 절제**: v2 안의 성분 조합마다 정상 valid로 문턱을 다시 잡은 뒤(α 1%) 2.6절 E1·E1b와 같은 주입을 test 정상 기록에 넣었다. 표의 '크기만' 행은 v2 크기 성분 하나로 잰 값이다. 이 성분은 max|z|와 같은 학습 표준화에 단조 꼬리 변환만 더한 양이어서 α 1% 경보가 max|z|와 같다.

| 크기+파형(v2의 파형 성분, v1과 다름) | 0.0 / 1.7% | 2.5 / 13.3% | 46.4 / 53.9% | 35.0% |
| v2(세 성분) | 0.0 / 1.7% | 2.5 / 15.2% | 48.6 / 66.3% | 35.0% |

  - 이 주입은 사인 성분과 직교하는 잡음(정상 잔차 RMS 중앙값의 0.5·1배)이어서 전류의 순간 크기를 거의 바꾸지 않는다. 파형·동역학 성분은 전류 채널만 보므로 성분 간 분담 자체는 설계로 정해져 있었다. 새로 얻은 정보는 탐지 수준과 문턱 비용이다. 강도 1에서 파형만 쓰면 68.3·60.6%를 잡았고 강도 0.5에서는 어느 조합도 3분의 1에 못 미쳤다. 세 성분을 합치면 조합 문턱이 함께 올라 A에서는 파형만 쓸 때보다 덜 잡고(48.6% 대 68.3%) B에서는 더 잡는다(66.3% 대 60.6%). 다만 α 1%·보정 120기록에서는 문턱이 보정 기록 하나로 정해지므로 이 차이는 그 기록에 민감하다. 주입 강도 1조차 실제 사건의 파형 붕괴(R² 중앙값 0.095)보다 훨씬 약하다.
- **Ridge 예측 오차**: 정상 train으로 각 센서의 현재 값을 같은 기록 안 과거 5행 × 3채널로 예측한 뒤 세 센서 표준화 잔차의 최댓값을 점수로 썼다(기록 첫 행은 점수 없음). R1을 붙이지 않은 F1·AUROC는 점 추정 기준으로 베이스라인 5종보다 높고 v2보다 낮았다. 전류 파형 주입은 대조 수준으로만 잡았지만 진동 단독 주입은 최대 95.7%(v2 35.0%)를 잡았다. 고부하 정상 오경보도 R2 없이 2/53이었다. 직전 값으로 예측하는 방식이라 갑자기 생긴 충격·잡음은 잘 잡지만 기록 전체의 진동 수준이 오르는 변화에는 둔할 수 있다(추정). R1을 붙이면 v2+R1과 거의 같다(B 오경보 1행 대 3행, test부터 0.998·0.997). 1단계에 함께 쓰는 구성은 4.3절에서 사후로 계산했다.
- **특징 맞춤 베이스라인과 기록 단위 AUROC**: 2.4절의 특징 맞춤 5NN(v2의 파형·동역학 성분 원값 + 세 센서 원값)은 R2 없이도 고부하 정상 오경보가 1/53이었다(정상 전체 16/300, v2 13/300). 같은 특징을 IsolationForest에 넣으면 F1 0.867·0.864가 나온다. v2가 앞서는 까닭은 주로 이 특징에 있으며 학습기를 바꿔도 효과가 유지된다. 이 특징은 이상 자료를 본 뒤 정한 전류 파형·동역학 성분이다(2.3절). 기록마다 최대 점수로 판정한 기록 단위 AUROC를 보면 기록 안 시간 구조를 쓰는 모델(v2·v1·Ridge·특징 맞춤 5NN·IsolationForest)은 0.999~1.000, 원신호 베이스라인은 0.676~0.984다. 기록이 묶음으로 올라온다면 이 데이터로는 기반 모델 사이의 우열을 가를 수 없다.
- **부트스트랩 세부**: 2.4절의 구간은 test 기록을 정상·이상 묶음 안에서 2,000회 복원 추출해 구했다. 기록을 하나씩 독립으로 뽑으면 이어진 기록끼리의 상관이 반영되지 않으므로 정상은 연속 10기록, 이상은 연속 3기록 블록으로 다시 뽑았다. 그래도 v2−v1 구간은 F1 A 0.030~0.096·B 0.027~0.092, AUROC A 0.020~0.070·B 0.019~0.075로 넓어지지 않았고 모두 0을 넘었다. 분할 A·B는 이상 test 11기록이 같고 A의 정상 test 120기록이 B의 test 180기록에 들어 있어 서로 독립된 반복도 아니다. 행 AUROC에서 창이 차지 않아 점수가 없는 행(MLP 오토인코더 기록 앞 4행, LSTM 오토인코더 앞 19행)은 가장 정상인 것으로 두었다. PR-AUC의 무작위 기준선은 이상 행 비율(A 0.073·B 0.050)이다.

# □ 제3장. 영향요인 및 오류분석〔15점〕

◦ 오경보는 진동이 만든다. v2의 미탐은 기록 시작 직후에 몰리고 오경보는 학습에 없던 정숙 구간이 아니라 고부하 정상에서 진동(크기 성분)만 커진 경보에 몰린다. 이 오경보는 그 순간의 전류 파형이 정상인지 확인하면(R2) 걸러진다.

## ◦ 3.1 주요 영향 변수와 상호작용

- 고장 여부는 전류 파형이 가른다. 반면 진동 크기는 고부하 정상과 이상을 헷갈리게 한다. 10행 이상 기록 전체에 겉보기 주파수의 사인을 맞추면 전류 R² 중앙값이 정상 0.995, 이상 0.095다.
- 이상이 생기면 진동의 크기와 시간 구조가 함께 바뀐다. 상부 진동 표준편차는 6.3배(전 행 합산 기준)로 커지고 자기상관(lag-1) 중앙값은 −0.031에서 0.686으로 오른다. 그런데 정상에서도 하부 진동은 전류 진폭(부하)을 따라 커진다. v2를 개발할 때 17행 이상 정상 469기록으로 분석한 SD-RMS 순위 상관이 0.865였다. 이상에서는 상·하부가 음의 상관을 보인다(상관 중앙 −0.36). 크기만 보면 고부하 정상과 이상이 섞이므로 R2는 전류 파형을 함께 본다.
- PCA 관리도에서도 이상 행의 T² 기여는 전류 사인 잔차 비율(A 26%·B 28%), 상부 진동 RMS(26%·25%) 순으로 크다.
- 모델에서도 전류 파형 성분이 가장 크게 기여한다. R1 없는 test 행 F1은 크기 성분만 0.404·0.428 → 전류 파형 추가(v1) 0.904·0.912 → 초반 파형 창·동역학 추가(v2) 0.965·0.970이다(2.4절).

## ◦ 3.2 정상 운전변화와 오경보 발생조건

- 오경보는 학습 분포의 아래쪽(정숙 구간)이 아니라 위쪽 꼬리(고부하 정상)에서 난다.
- 표의 각 칸은 분할 B(A 포함) 정상 valid+test 300기록 중 실시간 경보가 1행이라도 난 기록의 수다(사후, α 5%). 부하 등급은 전류 진폭 혼합분포 경계(127.2·225.1)로 나눴고 정숙 구간은 변화점 검출로 갈랐다. 단일 점수 모델은 보정 방식 때문에 valid 오경보가 모두 6기록으로 같다. 그래서 이 표는 오경보의 양보다 오경보가 몰리는 곳을 보여 준다.

| 운전 상태 | 기록 | max\|z\| | LSTM 오토인코더 | v2 | v2 + R2 | 2단계(v2+R1+R2) |
|---|---:|---:|---:|---:|---:|---:|
| 정숙 구간(연속 저부하) | 90 | 0 | 0 | 0 | 0 | 0 |
| 변동 구간·저부하 | 58 | 0 | 0 | 0 | 0 | 1 |
| 변동 구간·중부하 | 77 | 2 | 7 | 4 | 2 | 2 |
| 변동 구간·고부하 | 53 | 10 | 1 | 9 | 1 | 1 |
| 변동 구간·짧은 기록(8행 미만) | 22 | 0 | 0 | 0 | 0 | 0 |
| 전체 | 300 | 12 | 8 | 13 | 3 | 4 |

- 학습에 없던 정숙 구간에서는 오경보가 거의 나지 않았다. 학습의 연속 저부하는 최장 4기록인데 test에서는 정숙 구간을 포함한 저부하가 84·91기록(A·B) 이어졌다. 그래도 정숙 구간 오경보는 10개 모델 × α 1·3·5%를 합쳐 1행이었다. 진동이 작고 전류 파형이 정상이어서 이상 점수가 오히려 낮다.
- 반면 고부하에는 오경보가 몰린다. 분할 B, α 5%에서 단일 모델 7개(베이스라인 5종·v1·v2)가 낸 오경보 기록의 66%가 고부하였다. 고부하 기록의 오경보 비율은 평균 14.0%로 전체(3.8%)의 3.7배다. α 1%에서 v2가 낸 오경보 기록 4개는 모두 상부 진동 SD가 분할 B 학습 기록의 98.6~99.6% 분위였다.
- R2를 붙이면 분할 B 고부하 오경보 기록이 v2의 9/53에서 1/53으로 줄어들고(α 5%) test 미탐 행은 α 1·3·5% 모두 v2와 같다. 정상 기록에서 v2가 낸 경보는 대부분 크기 성분 단독이었고 파형 성분은 한 번도 켜지지 않았다. 남는 오경보는 파형을 판단하기 전(기록 앞 8행 미만)의 크기 경보와 중부하의 동역학 성분 경보다. 다만 R2는 이 오경보 유형을 보고 만든 규칙이라 이 결과는 착안 자료 안의 확인에 그친다(재확인 2.5절, 비용 2.6절 E1b).
- R1은 오경보도 퍼뜨린다. α 5%에서는 기록 446의 경보 2행이 다음 기록 447의 앞 7행으로 번졌다. 운영 α를 1%로 두는 근거 중 하나다.
- 기동·예열(2.2절), 금형 교체 뒤 시운전, 소재·두께·행정 속도·유온 변화는 기록에 표시되지 않아 도입 첫 달에 운전 일지로 센다.

## ◦ 3.3 잘 작동하는 조건과 실패하는 조건

- 고장이 전류 파형을 흐트러뜨리며 여러 기록에 걸쳐 이어지고 수집 조건이 학습 때와 같으면 모델은 잘 작동한다(2.6절 E3).
- 2단계 모델은 세 곳에서 실패한다. ① 기록 경계에서는 사건 첫 표본을 놓친다(미탐). 파형 판단 전(기록 앞 8행 미만)의 크기 경보와 중부하의 동역학 성분 경보, α를 느슨하게 했을 때 R1이 이어 붙인 경보도 여기서 생기는 오경보다(3.2절). ② 약한 전류 파형 이상, 진동만 바뀌는 고장, 진폭 감소·센서 끊김에는 모델이 둔하다(2.6절 E1·E1b·E2). ③ 학습 때와 다른 수집 조건에서도 실패한다(E5). 실제 오류는 아래 표와 그림 10에 모았다.

| 출처 | 오류 | 집중 조건 |
|---|---|---|
| v2, test | 미탐 A 22행·B 16행 | 기록 위치 0~1에 A 14행·B 12행. 과거 행이 없어 크기 성분만 계산되는데, 이상 기록 상당수는 진동이 오히려 작다 |
| v2, test | 오경보 B 3행 | 정상 기록 3개(고부하 2·중부하 1), 크기 성분 단독, 그 시점 전류 파형 R² 0.995~0.998 |

## ◦ 3.4 규칙별 효과 분해 (test, α 1%)

- R1은 기록 시작 직후의 미탐을, R2는 진동 크기만 넘은 오경보를 없앤다(그림 11).

| 모델 | 미탐 A / B | 오경보 A / B | F1 A / B |
|---|---:|---:|---:|
| v2 | 22 / 16 | 0 / 3 | 0.965 / 0.970 |
| v2 + R2 | 22 / 16 | 0 / 0 | 0.965 / 0.975 |
| v2 + R1 | 0 / 0 | 0 / 3 | 1.000 / 0.995 |
| v2 + R1 + R2 | 0 / 0 | 0 / 0 | 1.000 / 1.000 |

- 미탐 조건과 오경보 조건은 서로 맞물린다. 진동 크기만 보는 판정은 진동이 커진 정상(고부하)을 오경보로, 진동이 작아진 이상(기록 3·19·20)을 미탐으로 만든다. 그렇다고 "진동이 너무 작음"까지 경보로 바꾸면 학습에 없던 정숙 구간이 오경보가 된다. 정숙 구간 중 진동·부하가 학습 하위 1% 밖인 기록이 A 28·B 27이다. 그래서 R2는 진동을 절대 크기가 아니라 같은 순간의 전류 파형에 비춰 본다.

| 고장 정보 | 고장 판정 방법·시작 시각·유형, 정비 이력 | 라벨은 파일 단위 상수로만 사용 | 선행 시간·고장 종류 분류 불가 | 정비·고장 이력 |

| 표본 크기 | 이상 사건 1건(166초), 정상 test 달력 16~24분 | 이항·포아송 상한을 함께 보고 | 1.000(행 단위, α 1%)은 일반화 근거가 아님. valid부터 이어 돌리면 R1을 붙인 어느 모델이든 test F1 0.982~1.000이라 모델을 가르지 못함(2.7절) | 더 긴 운전, 다른 사건 |

## ◦ 3.6 적용 조건

- 이 체계가 겨냥하는 대상은 전류 파형이 흐트러지는 고장이다. 기어 마모가 파형을 흐트러뜨리는지는 아직 가설이고, 문헌 서명이 전류 감소인 측판·끝면 마모(1.3절)는 파형이 그대로면 R2에 막혀 1단계 경보로만 나간다. 수백 시간에 걸쳐 진행되는 마모는 같은 운전 조건의 전류 진폭 기준선을 주·월마다 비교해 추세로 잡는다. 센서를 더하지 않는 방법이지만 검증하지 않은 제안이다.
- 세 성분은 값이 커지거나 흐트러지는 변화만 보므로 진폭 감소·센서 끊김(2.6절 E2, 탐지 0~2%)은 잡지 못한다. 그래서 센서 건전성 점검을 따로 둔다(4.4절).
- 베어링·커플링 같은 진동형 고장은 별도 진동 모델이 맡아야 한다. 1단계(v2+R1)도 진동 단독 주입은 기록 하나 기준 B 최대 35.0%만 잡는다. Ridge 예측 오차(사후, 2.7절)를 1단계에 함께 두는 구성은 4.3절에서 계산했다.
- 이 체계는 수집 조건에 민감해서(2.6절 E5) 현장에 옮길 때는 그 현장의 정상 데이터로 문턱을 다시 맞추고 표본화 시각을 동기화한다.

# □ 제4장. 현장 활용방안〔10점〕

◦ 두 단계 경보는 "전류 파형으로 고장을 잡고, 전류 파형이 정상이면 진동만 큰 경보로는 출동하지 않는다"를 현장 운영 규칙으로 옮겼다. 1단계 "주의"는 화면에만 띄우고 사람은 2단계 "점검 요청"에서만 점검·품질 조치에 나선다(4.2절).

## ◦ 4.1 상태감시 표준 구조에 맞춘 운영 흐름

- 두 단계 경보는 ISO 13374-1의 6개 처리 블록[26] 가운데 상태 감지에 해당한다. 대회 범위는 데이터 획득부터 상태 감지까지이며, 건강 평가는 진단 매트릭스 수준까지만 다룬다.

| 블록 | 이 시스템 | 비고 |
|---|---|---|
| 데이터 획득 | PLC 초당 10회, 진동 2·전류 1 | 표본 시각 실측 권고(4.4절) |
| 데이터 처리 | 정밀도 맞춤, 기록 분할, 세 성분 계산 | 2.3절 |
| 상태 감지 | v2 conformal 문턱 + R1(1단계), R2 교차 확인(2단계) | 운영 α 1% |
| 건강 평가 | 경보 근거 → 진단 매트릭스로 점검 우선순위 | 2.1절 |
| 예지 | 하지 않음 | 고장 사건 1건으로는 잔여 수명 추정 불가 |
| 조언 생성 | 경보 단계별 점검·품질 조치 | 4.2절 |

## ◦ 4.2 경보에서 조치까지

- 출동 여부는 경보 단계가, 점검 순서는 경보 근거가 정한다. 1단계 "주의"는 사전 잠금 모델 v2+R1이 내는 경보이며, 공식 성능(test 행 F1 1.000·0.995)은 이 단계에서 잰 값이다. 2단계 "점검 요청"은 R2 교차 확인을 통과한 v2 경보에 R1을 붙인 경보(v2+R1+R2, 1.000·1.000)여서 늘 1단계 경보 안에 든다. 이 단계는 test를 확인한 뒤 더한 운영 권고안이다(2.5절). 60초 안에 이어지는 경보는 한 사건으로 묶는다. 담당 절차·점검 표·콘솔은 v2 기준 운영 문서·프로토타입에서 가져온 제안이다.
  - 1단계: 콘솔에 표시만 한다. R2가 거른 진동 크기 단독 경보는 고부하 정상과 진동형 고장이 섞인 채 여기 남는다. 같은 교대에 되풀이되면 품질 샘플 검사를 앞당기고 보전원이 다음 정지 때 진동 항목을 본다. 되풀이 기준은 도입 첫 달 경보량을 보고 정한다.
  - 2단계: 아래 경보 근거별 점검 표에서 운전 중 항목은 운전원이, [정지] 항목은 보전원이 그 교대 안에 본다. 계측·수집 이상을 배제할 수 없으므로(2.1절) 계측 항목을 먼저 본다.
  - 종료: R1의 자동 해제는 화면 표시만 끈다. 사건은 점검자가 콘솔 양식에 확인 시각·담당·결과(정상 확인·이상 확인·보류)·조치를 적어야 닫히며, 보류로 적은 사건은 열어 둔다. 정상 확인 구간은 재보정 자료로, 이상 확인 사건은 고장 라벨로 쌓는다(3.5절).
- 두 단계 경보는 제출 예측 파일의 `locked_v2_R1_realtime`(1단계)·`final_v2_R1_R2_realtime`(2단계) 열에 행마다 기록된다. 분할 B test 정상 180기록 가운데 1단계가 울린 기록은 3개, 2단계가 울린 기록은 0개였고, 이상 11기록에서는 모두 두 단계가 함께 울렸다(그림 12, 행 단위는 그림 13).

## ◦ 4.3 경보 운영 기준

- R1은 수집이 끊겨도 경보를 이어 가다가 전류 파형이 정상으로 확인되어야 푼다(2.3절). 정상 기록으로 번진 경보는 대부분 8행 안에 풀렸으며 이 해제는 화면 표시에만 적용한다(4.2절).
- 첫 경보 0.0초(2.5절)는 데이터 시각으로 잰 값이다. 기록이 최대 50행(5초)씩 묶여 올라온다면(1.4절, 추정) 경보는 화면에 최대 약 5초 늦게 닿는다. 사건이 수집 공백(중앙값 4.2초, 90% 분위 8.4초) 중에 시작되면 다음 기록이 올라올 때까지 밀린다. 이 지연은 수집 설정(4.4절 ①)을 바꿔 줄인다.
- 합성 열화 조기경보(사후)에서 전류 파형 열화는 최대 강도에 이르기 전에 거의 모두 2단계 경보를 냈다. 실제 이상은 처음부터 이상 상태여서 고장 전 경보를 잴 수 없다(2.1절). 대신 test 정상 흐름에 2.6절 주입(E1·E1b)을 2·5·10분에 걸쳐 0에서 최대 강도까지 키우며 첫 경보를 쟀다(α 1%).

| 합성 열화(열화 시작 → 최대 강도) | 2분 | 5분 | 10분 |
|---|---|---|---|
| 전류 파형(2단계): 완성 전 경보 비율 · 완성까지 남은 시간 중앙값 | 95.8% · 0.49분 | 100% · 2.02분 | 100% · 4.50분 |
| 전류 파형(2단계): 첫 경보 때 강도(최대 대비) | 0.74 | 0.59 | 0.55 |
| 진동 단독: 완성 전 경보 비율(2단계 / 1단계) | 14.6% / 30.2% | 20.8% / 45.8% | 20.8% / 69.8% |
| 대조(주입 없음): 같은 구간 경보 비율(2단계 / 1단계) | 0% / 12.5% | 0% / 25.0% | 0% / 37.5% |

  - 전류 파형은 강도가 최대의 55~74%일 때 첫 경보를 냈다. 여러 기록 가운데 하나만 울려도 잡은 것으로 세기 때문에 기록 하나 기준 탐지율(최대 강도 48.6·65.2%, 2.6절)보다 높게 나온다.
  - 진동 단독은 R2 때문에 2단계가 14.6~20.8%에 그쳤다(2.6절 E1b와 같은 비용). 1단계로는 30.2~69.8%가 알려졌지만 주입 없는 대조에서도 12.5~37.5%가 울려 우연 경보가 섞여 있다.
  - 주입 강도와 열화 속도는 가정한 값이어서 실제로 몇 분 전에 알릴지는 이 데이터로 알 수 없다.
- 1단계 병행 진동 감시(권고, 사후)는 R2 때문에 출동이 늦어질 수 있는 진동형 고장에 대비한다. 이 고장의 대책은 별도 진동 모델에서 다룬다(3.6절). 잠금 모델 v2+R1에 Ridge 예측 오차(사후, 2.7절) 경보를 행 단위 OR로 더하자 진동 단독 주입의 기록 탐지가 28.3~96.1%로 올랐다. 같은 주입에서 v2+R1만으로는 2.5~35.0%였다. 전류 파형 주입 탐지와 α 1% test 오경보(B 3행)는 그대로였는데, Ridge의 오경보 1행이 우연히 v2+R1과 겹쳐 오경보가 늘지 않았다. 대가도 있다. α 5%에서는 분할 B 정상 오경보 기록이 17에서 24/300으로 늘어난다. α 1%에서도 두 경보를 OR로 묶은 탓에 1단계 설계 오경보가 시간당 최대 약 7.4기록이 된다. 그래서 도입 첫 달에는 1단계 병행으로만 시험하고 2단계 규칙은 바꾸지 않는다.
- α 1% 기록 단위 보정을 연속 운전에 옮기면 1단계 설계 오경보는 시간당 약 3.7기록이다(교환 가능성 가정, R2 보류·R1 번짐·60초 묶음 전). 경보량 목표로 삼는 운전원 경보 예산(시간당 약 6건)[5]은 출동하는 2단계에 적용한다. test 정상 구간이 16~24분뿐이므로 도입 첫 달에는 단계별 경보를 기록한다. 경보가 넘치거나 실측 오경보율이 α를 넘으면 α를 낮추거나 다시 보정하는데, 1%보다 낮추려면 보정용 정상 기록이 120기록보다 많아야 한다.
- 진동 2·전류 1채널만 쓰므로 추가 센서 없이 인프라가 약한 중소기업 공정에도 옮길 수 있다. 옮길 때는 그 설비의 정상 데이터로 표준화·문턱을 다시 맞추고(정상 학습 → valid 보정 → α 1%) 운전 상태를 확인한다. 다만 짧은 창의 과도 변화를 보는 구조여서 느린 펌프 누설(UCI 유압 시험대)에는 옮겨 쓰지 못했다(2.6절).

# □ 제5장. 창의성 및 차별성〔10점〕

◦ 성과로 이어진 기여 세 가지: 고장을 가르는 신호를 찾아 오경보를 거르는 데 썼고 그 신호가 수집 조건 탓이 아닌지도 시험했다.
  - 전류 파형 신호: 전류 파형 성분을 더하자 R1 없는 test 행 F1이 크기 성분만 쓸 때의 0.404·0.428에서 v1 0.904·0.912로 올랐다. 크기 성분으로는 구조상 볼 수 없는 약한 전류 파형 왜곡(강도 1)도 v2는 48.6·66.3% 잡는다(사후, 2.4절). 같은 특징을 5NN에 넣어도 같은 수준이 나오니 성능을 가른 것은 모델이 아니라 신호다. 특징은 이상 자료를 본 뒤에 정했다(2.3절).
  - 진동 단독 경보 거르기(R2): 고부하 정상 상태에서 나온 크기 단독 경보는 전류 파형이 정상이면 2단계로 올리지 않는다. 이 규칙으로 분할 B α 5% 고부하 오경보 기록을 9/53에서 1/53으로 줄였다(착안 자료 안). 착안 기록을 빼고 다시 학습해도 α 5% 정상 오경보 기록은 10/288에서 2/288로 줄었다(사후). 다만 효과 크기는 도입 첫 달에 표본 밖에서 잰다. 걸러진 경보는 1단계로 남는다(2.5·4.2절).
  - 수집 조건 흔들림 시험(E5): 모델이 무너지는 조건을 찾아 현장에 옮겨 쓸 때의 조건(재보정, 표본 시각 동기화)을 정했다(2.6·3.6절).

◦ 가이드북 기본 틀과의 대조: 가이드북 LSTM 오토인코더 실습(정상만 학습)과는 조건이 달라 점수 대신 방법만 견준다(2.4절).

| 항목 | 가이드북 기본 틀 | 이 보고서 | 절 |
|---|---|---|---|
| 분할 | 정상 앞부분으로 학습, 나머지를 임곗값용·평가용 창으로 나눔 | 정상 기록을 시간순 train/valid/test로 나누고 valid 선택을 해시로 잠근 뒤 test 채점 | 1.7·2.5절 |
| 평가 단위 | 20행 창이 수집 공백을 가로지르고 창 단위로 판정 | 누수를 지운 입력에서 행마다 실시간 판정. point-adjust 안 씀(R1의 비슷한 이득은 1.7절) | 1.6·1.7·2.4절 |
| 모델 점수 | LSTM 오토인코더 복원 오차 | 크기·파형·동역학 세 성분의 꼬리 점수 최댓값(켜진 성분이 경보 근거) | 2.3·4.2절 |
| 문턱 | 이상 라벨이 든 검증 창으로 임곗값 선택 | 정상 valid 기록만으로 conformal 문턱(α 1%), α 1·3·5% 민감도 보고 | 2.3·2.5절 |
| 경보 규칙 | 창마다 임곗값 판정 | R1 사건 지속(수집 공백을 넘어 경보 유지)·R2 교차 확인(크기 단독 경보를 2단계에서 뺌) | 2.3·3.4절 |
| 오경보 분석 | 혼동행렬의 오경보 수까지 | 운전 상태(정숙 구간, 부하 등급)별 오경보와 원인(크기 성분 단독 경보)을 R2·운영 α로 이음 | 3.2~3.4절 |
| 검증 | 평가 구간 한 번의 채점 | 베이스라인·표준 기법·보완 LSTM·Ridge 대조, 인공 고장 주입·진폭 감소·분할 변경·수집 조건 시험, 오경보 상한 | 2.4~2.7절 |
| 재현 | 초기 가중치 탓에 결과가 소폭 다를 수 있음 | 명령 하나로 전처리부터 수치 대조까지. 새 가상환경에서 수치 43개 일치, 예측 파일 바이트 동일 | 6장 |

◦ 선택 과정의 감사 가능성(해시 잠금): 잠금 규칙이 고른 공식 성능 v2+R1(test B 0.995)과 test를 확인한 뒤 더한 2단계(v2+R1+R2)를 따로 적었다. 그래서 수치마다 어느 단계에서 고른 것인지 드러난다. 2단계를 더해도 잠금 모델의 경보는 바뀌지 않는다(2.5절).
◦ 수집 조건 흔들림 시험: 이상 기록의 전류 평균을 지워도 21/21을 탐지했으니 모델은 전류 수준에 기대지 않았다. 표본 시각이 0.1ms 흔들리자 정상 기록 경보율이 B 35.2%까지 올라 시각 차이가 섞였을 가능성은 남는다. 그러나 흔들림이 정상 기록을 이상일 만큼 무너뜨린 것은 5ms에 이르러서였고 치우침은 만들지 못했다(2.6절 E5).
◦ 신호 물리로 표본 간격 역산: 전류 고조파의 0.600Hz는 60Hz 계열이 접힌 것이라는 가설과 맞는다. 계통 직결이라면 표본 간격은 약 99·101ms로 역산된다. 이 역산을 근거로 실측 타임스탬프를 수집 개선 첫 단계에 넣었다(1.4·4.4절).
◦ 세션 교락의 크기 측정: 라벨 지도학습은 누수를 지운 자료에서도 F1 0.793~0.970을 냈다. 하지만 고장 없는 같은 날의 정상 기록끼리도 약 1시간 떨어지면 ROC-AUC 중앙값 0.75~0.87로 갈라냈다. 그래서 지도학습은 성능 비교에서 빼고 사후 대조로만 적었다(2.6절).
◦ 오경보 상한을 운영 단위로 환산: 정상 오경보 0/120·0/180에서 구한 이항 95% 상한(2.47%·1.65%)과 시간당 포아송 95% 상한(11.2·7.5건)을 산업 경보 관리 기준인 운전원당 시간당 약 6건과 견줬다(참고값, 2.5절).
◦ 설비 물리 진단 매트릭스: 고장 서명 가운데 초당 10회로 남는 정보(관측 진폭의 크기, 저주파 구조, 전류 파형)를 가려낸 뒤 ISO 13379-1 방식으로 이 데이터가 가를 수 있는 것과 없는 것을 나눴다. 이 구분이 경보 근거별 점검 순서가 됐다(1.3~1.5·2.1·4.2절).
◦ 표준 기법 대조와 R1의 해제 동작(사후): CUSUM·EWMA도 기록 경계에서 상태를 이어 가면 R1 수준까지 오른다. 이득은 수집 공백을 넘어 상태를 기억하는 데서 나온다. 차이는 해제에서 났다(R1 0.7초, 상태를 이어 가는 CUSUM 11.4~12.2분, 2.5·2.7절).
◦ 오류 조건을 원인과 운영 규칙까지 이음: 위험한 쪽은 학습에 없던 정숙 구간이 아니라 학습 분포의 위쪽 꼬리인 고부하 구간이었다. 기록 시작 직후에 나던 v2의 미탐은 R1로, 크기 성분 단독 경보에서 오던 오경보는 R2로 줄였다(test 미탐 A 22→0·B 16→0, 오경보 B 3→0). R2의 비용도 쟀는데, 2단계에서 진동 단독 주입의 탐지율이 최대 23.7%p 떨어진다(3.2~3.4절, 착안 경위 2.3절).

# □ 제6장. 코드 구성 및 재현성〔10점〕

◦ 실행: 패키지를 설치한 뒤 명령 하나로 전처리부터 학습·추론·test 예측 파일·보고서 수치 대조까지 끝난다.
  * `pip install -r requirements.txt`
  * conda를 쓰면 `conda env create -f environment.yml`
  * `python run_all.py` (전체) 또는 `python run_all.py --quick` (진단·모델·예측·2.4·2.7·4.3절 사후 계산·대조, 약 13분)
◦ 환경: 파이썬 3.13, CPU. 패키지 판은 v1·v2·v3 모듈의 예전 환경 파일을 빼고 결과를 만든 환경 그대로 하나로 고정했다. 설치 뒤에는 인터넷이 필요 없다. 설치 없이 제출 예측 파일만으로 F1을 확인하는 방법(약 5분)은 README 0절에 있다.
◦ 재현 확인
  - 새 가상환경에서 `run_all.py` 전체를 실행하니 보고서 수치 대조 43개가 모두 일치했다(약 55분, Windows 11·CPU 16코어).

  - 원본 CSV 2개는 시작할 때 해시로 확인하고 난수를 쓰는 곳은 seed를 고정했다.
  - 개발 때 쓰던 다른 채점 방식으로 잰 v2 원래 평가 F1 A 0.961938·B 0.970990이 같은 코드로 그대로 나온다. train·valid·test 사이 시각 겹침은 0이다.
