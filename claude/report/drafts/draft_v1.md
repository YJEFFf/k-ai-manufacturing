# 표지

- 부문: 일반국민/대학(원)생 부문
- 프로젝트명: 데이터 결함 진단과 고장 지속성 규칙에 기반한 프레스 유압펌프 실시간 이상 경보
- 팀명: 북적북적 (팀장 허예준, 팀원 장준용)

## 내용요약

◦ 파인블랭킹 프레스 유압펌프의 진동·전류 데이터를 분석하기 전에 설비 구조와 데이터부터 점검했다. 측정은 전체 시간의 43%뿐이고 최대 50행 단위로 끊겨 있으며, 정상·이상 파일은 날짜·요일·저장 형식이 모두 달랐다.
◦ 구조에서 출발해 고장 경우(case)를 나누고, 현재 데이터로 가능한 분석과 불가능한 분석(고장 직전 패턴, 고장 종류 구분)을 구분했다. 문제를 "정상 운전과 다른 상태의 실시간 경보"로 다시 정의했다.
◦ 팀원이 만든 정상 학습 모델(크기·파형·동역학 3성분, conformal 문턱)의 오류를 분석해 두 규칙을 더했다. R1 사건 지속은 기록 시작 직후 미탐을, R2 교차 확인은 고부하 정상의 오경보를 겨냥한다.
◦ 시간순 train/valid/test 평가에서 최종 모델의 시험 F1은 1.000(행 단위, α 1%, 두 분할 모두)이다. 베이스라인 5종과 팀원 모델 v1·v2·v3를 같은 조건에서 비교했다.
◦ 이상 데이터가 약 3분짜리 단일 사건이라 이 결과를 의심했다. 인공 고장 주입·손실·교락·분할 시험으로 어디까지 믿을 수 있는지 범위를 정했다.

# □ 제1장. 데이터 이해 및 진단〔15점〕

## ◦ 1.1 주제 선정

- 다섯 과제 중 ③ 프레스 유압펌프 이상탐지를 골랐다. 가이드북에 따르면 이 펌프가 고장 나면 수리비와 부품 수급 때문에 최대 2~3일 동안 공정이 멈춘다. 지금은 숙련 작업자가 작동 소음을 듣고 판단할 뿐 데이터 기반 감시가 없다.
- 고장 전에 이상을 알려 주면 정지 손실을 줄일 수 있다. 그래서 목표를 "정상 운전 데이터만으로 학습해 이상 상태를 실시간으로 경보하는 모델"로 잡았다.

## ◦ 1.2 본격 분석에 앞서: 프레스 구조 확인

- 파인블랭킹은 판재를 V링으로 눌러 고정하고(V링 힘), 아래에서 역압으로 받친 상태에서(역압), 펀치로 절단한다(블랭킹 힘). 세 힘을 따로 제어해야 해서 주로 유압 프레스를 쓴다. 이 설비는 유압펌프로 약 1000톤의 힘을 낸다.
- 유압은 기어형 펌프가 만든다. 맞물린 두 기어가 돌며 작동유를 밀어낸다. 가이드북이 지목한 고장 원인은 노후화에 따른 기어 마모다. 마모되면 진동·소음이 커지고 출력 유압이 약해져 불량품이 나온다.
- 센서는 세 개다. 수직으로 선 모터-펌프 유닛의 상부·하부에 진동센서가 있고, 펌프 전력선에 전류센서가 있다(가이드북 그림 3).

| 변수 | 의미 | 정상 | 이상 |

| TimeStamp | 수집 시각(0.1초 간격) | 2022-07-12(화) 00:00~01:17 | 2022-07-17(일) 10:51~10:53 |
| AI0_Vibration | 상부 진동 | 표준편차 0.071 | 0.448 |

- 전류는 실효값이 아니라 교류 순시값이다. 그래서 정상 전류의 평균은 0 근처이고 값의 절반이 음수다. 60Hz 교류를 약 0.1초 간격으로 찍어서 겉보기로 0.60Hz짜리 느린 사인파가 된다.
- 행은 최대 50행(5초) 길이의 "기록"으로 끊겨 들어온다. 정상은 600기록이고, 이상은 21기록이다.

## ◦ 1.4 데이터 결함 진단

| 결함 | 근거 | 분석에 주는 영향 |
|---|---|---|
| 측정이 띄엄띄엄이다 | 정상 77분 중 실제 측정 33분(43.3%). 50행을 넘는 기록 0개, 정확히 50행인 기록 202개 | 기록마다 과거 정보 없이 시작한다. 기록 시작 직후 판단이 어렵다 |
| 저장 형식이 파일마다 다르다 | 이상 파일만 진동 소수 8자리(정상 6자리), 전류가 1.192 간격 격자. "자릿수 > 6" 규칙만으로 행 F1 0.992 | 형식으로 정답을 맞히는 누수. 두 파일을 같은 정밀도로 맞춘 뒤 분석한다 |
| 날짜·요일·시간대가 다르다 | 정상 화요일 자정, 이상 일요일 오전 | 고장과 운전 조건 차이가 섞인다(교락) |
| 고장은 한 사건뿐이다 | 이상 600행 = 2분 46초짜리 한 사건이 21조각으로 나뉨 | 이상 21기록은 독립된 21건이 아니다 |
| 전류 모양이 정상과 다르다 | 사인 적합 겉보기 주파수 정상 0.60Hz, 이상 중앙 0.22Hz. 10행 이상 기록 중 \|평균\| > 표준편차: 정상 0/530, 이상 9/17 | 전력망 주파수는 고장으로 바뀌지 않는다. 계측·수집 조건 차이일 가능성을 배제할 수 없다 |
| 라벨이 파일 단위다 | 정상 파일 전체 0, 이상 파일 전체 1 | 고장 시작 시점이 없다 |
| 중복 행 | 정상에 시각·센서값이 같은 행 1개 | 제거 후 사용 |

- 상부·하부 진동의 관계도 달라진다. 20행 이상 기록에서 상부/하부 표준편차 비의 중앙값은 정상 0.72, 이상 1.55다. 상·하부 상관의 중앙값은 정상 0.28, 이상 −0.36이고, 이상 기록의 92%가 음수다. 수직 유닛이 아래쪽 고정점을 축으로 흔들리는 모양과 맞는다.

## ◦ 1.5 전처리와 검증 전략

- 전처리
  - 정밀도 맞춤: 두 파일의 진동을 1e-4, 전류를 1.1920929 간격으로 같게 반올림해 형식 누수를 지운다.
  - 기록 분할: 이웃 행 간격이 0.1초를 벗어나면 새 기록으로 본다. 모든 창 계산은 기록 안에서만 한다.
  - 표준화와 문턱은 정상 학습 자료로만 정한다. 라벨·날짜·파일명은 입력에서 뺀다.
- 검증 전략: 시간순 train/valid/test
  | 구분 | 정상 분할 A | 정상 분할 B | 이상 21기록 | 쓰임 |
  |---|---|---|---|---|
  | train | 기록 0~359 | 0~299 | 사용 안 함 | 모델 학습 |
  | valid | 360~479 | 300~419 | 앞 10기록 | 문턱 보정, 모델 선택 |
  | test | 480~599 | 420~599 | 뒤 11기록 | 최종 채점 |
  - valid 정상 기록의 오경보는 그 기록을 뺀 나머지로 문턱을 정해 잰다(leave-one-record-out).
  - valid에서 고른 결과를 해시로 잠그고, 잠금이 맞을 때만 test를 채점하도록 코드를 짰다.

# □ 제2장. AI 예측모델 개발 및 성능평가〔40점〕

## ◦ 2.1 구조에서 출발한 고장 case 분류

- 기어 마모 하나만 보지 않고, 모터-펌프 구조에서 생길 수 있는 고장을 여섯 경우로 나눠 센서 세 개로 무엇을 볼 수 있는지 따졌다.

| case | 고장 | 센서에 나타날 모양 | 이 데이터로 구분 |
|---|---|---|---|
| FM1 | 베어링 손상 | 진동 크기 증가 | 불가: 결함 주파수(수십 Hz~kHz)가 10Hz 측정으로 안 보임 |
| FM2 | 캐비테이션·흡입 공기 | 진동 증가, 전류 불규칙 | 불가: 흡입 압력 없음 |
| FM3 | 체결·정렬(커플링) 불량 | 진동 크기·상하부 관계 변화 | 일부: 이상 파일의 상·하부 역방향 흔들림과 맞지만 단정 불가 |
| FM4 | 내부 누설·기어 마모 | 진동 증가, 전류 수준·진폭 변화 | 불가: 출력 압력·유량 없음 |
| FM5 | 전기·전원 이상 | 전류 파형 왜곡 | 불가: 전압·상별 전류 없음 |
| FM6 | 계측·배선·수집 이상 | 형식 변화, 영점 이동, 시각 흔들림 | 1.4절 정황이 가장 많이 걸림 |

- 현재 데이터로 불가능한 분석
  - 고장 직전 패턴: 정상(7/12)과 이상(7/17) 사이 5일이 비어 있고, 이상 파일은 첫 기록부터 이미 이상이다.
  - 서서히 진행되는 열화: 정상 77분 안에 추세가 없고, 연속 측정이 아니다.
  - 고장 종류 구분: 위 표처럼 세 센서로는 case를 가를 수 없다.
- 그래서 문제를 다시 정의했다. 목표는 "고장 종류를 맞히는 모델"이 아니라 "정상 운전과 다른 상태를 실시간으로 알리는 경보 모델"이다.

## ◦ 2.2 사고 전 패턴 확인: 기록(case) 단위 특징

- 기록 하나를 다변량 시계열 하나로 보고 특징을 뽑아 정상·이상을 비교했다(10행 이상 기록: 정상 530, 이상 17).

| 특징 | 기록 단위 AUROC | 이상 중 정상 범위 밖 |
|---|---:|---:|
| 전류 사인 적합 R² | 1.000 | 17/17 |
| 전류 사인 적합 잔차 비율 | 1.000 | 17/17 |
| 상부 진동 자기상관(lag-1) | 0.945 | 11/17 |
| 하부 진동 자기상관(lag-1) | 0.923 | 14/17 |
| 상·하부 진동 상관 | 0.859 | 6/17 |
| 상부 진동 표준편차 | 0.825 | 15/17 |

- 정상 날 안에서 전조를 찾았다. 이상 서명(파형·상관·자기상관) 2개 이상을 가진 정상 기록은 3개뿐이었고, 그 R²도 0.982~0.986으로 이상(0.617 이하)과 거리가 멀었다. 정상 날에는 전조가 없었다.
- 결론: 데이터 구조상 "사고 전" 구간은 관찰할 수 없다. 대신 기록 단위에서 이상 상태가 뚜렷이 갈리고, 특히 전류 파형이 가장 강한 신호다.

## ◦ 2.3 모델 구성

- 기반 모델(팀원 v2, Press Guard): 정상 학습 자료만으로 0.1초마다 세 성분을 계산한다.
  - 크기: 세 센서의 표준화 값 중 최댓값
  - 파형: 최근 6~8행 전류의 사인 적합 1−R²
  - 동역학: 정상 전류로 학습한 AR(2)의 예측 오차
  - 각 성분을 정상 꼬리 확률로 바꿔 최댓값을 점수로 쓰고, valid 정상 기록의 최대 점수로 conformal 문턱을 정한다.
- 규칙 R1 사건 지속: 직전 기록(끝난 지 60초 안)이 확인된 이상(경보 2행 이상)이면, 새 기록은 첫 행부터 경보를 이어받는다. 새 기록의 전류 파형이 정상으로 확인되면(8행 이상, 사인 적합 R²가 정상 학습 기준 이상) 해제한다.
  - 근거: 고장은 수집 공백(수 초) 사이에 사라지지 않는다. v2의 미탐은 기록 시작 직후(위치 0~6)에 몰려 있다.
- 규칙 R2 교차 확인: 진동 크기 성분만 문턱을 넘고 그 시점 전류 파형이 정상이면 경보를 보류한다(경보 없음). 파형을 판단할 행(8행)이 아직 없으면 경보를 그대로 둔다.
  - 근거: 고부하 정상 구간에서는 진동만 커지고 전류 파형은 정상이다.
- 규칙 상수는 새로 맞추지 않았다. 60초·2행은 v2의 사건·2단계 경보 규칙 값이고, R² 기준은 정상 학습 자료의 0.5% 분위다.
- 경위
  - 규칙 R1·R2와 그 상수는 전체 데이터를 열람한 초기 탐색에서 착안해 정했다.
  - 이후 시간순 train/valid/test로 다시 평가했으며, valid에서 선택 결과를 해시로 잠근 뒤 그 선택을 바꾸지 않고 test를 채점했다(재실행 결과 동일).

## ◦ 2.4 같은 조건의 모델 비교

- 모든 모델을 같은 분할, 같은 valid 보정(α 1%)으로 채점했다. 실시간은 행이 들어오는 순간 판정하고, 기록 단위는 기록이 끝난 뒤 판정한다.

| 모델 | valid 실시간 F1(평균) | test 실시간 F1 A / B | test 기록 단위 F1 A / B |
|---|---:|---:|---:|
| IsolationForest | 0.028 | 0.133 / 0.094 | 0.672 / 0.672 |
| LSTM 오토인코더(20행 창) | 0.339 | 0.289 / 0.238 | 0.864 / 0.864 |
| max\|z\|(한 행) | 0.526 | 0.404 / 0.428 | 0.960 / 0.780 |
| 5NN 거리 | 0.629 | 0.474 / 0.487 | 0.897 / 0.756 |
| MLP 오토인코더(5행 창) | 0.644 | 0.498 / 0.498 | 0.890 / 0.890 |
| 팀원 v1(크기+파형) | 0.922 | 0.904 / 0.912 | 1.000 / 0.818 |
| 팀원 v2(크기+파형+동역학) | 0.963 | 0.965 / 0.970 | 1.000 / 0.818 |
| v2 + 팀원 v3 조건부 진동 성분 | 0.963 | 0.968 / 0.955 | 1.000 / 0.736 |
| 팀원 v3 kNN(기록 단위) | — | — | 0.889 / 0.954 |
| 팀원 v3 조건부(기록 단위, 단측) | — | — | 0.934 / 0.934 |
| v2 + R1 (잠금 규칙의 선택) | 0.997 | 1.000 / 0.995 | 1.000 / 0.818 |
| **v2 + R1 + R2 (최종)** | **0.998** | **1.000 / 1.000** | **1.000 / 1.000** |

- v2는 베이스라인보다 크게 앞선다. 한 행만 보는 모델(max|z|, 5NN, IsolationForest)은 이상 기록의 상당수를 놓친다.
- 팀원 v3의 조건부 진동 성분(전류 크기에 따라 진동 정상 범위를 바꿈)은 A에서 조금 오르고 B에서 내렸다. v3 kNN은 valid에서 0.993이었지만 test에서 0.889~0.954로 내려갔다.

## ◦ 2.5 최종 모델 선정

- valid 실시간 F1은 v2+R1+R2와 v3 조건부 성분을 더한 두 변형이 0.998로 공동 1위였고, v2+R1과의 차이는 A 오경보 1행이었다.
- 잠금 규칙이 고른 모델은 v2+R1(test F1 A 1.000·B 0.9954)이며, 최종 모델 v2+R1+R2는 test 결과를 확인한 뒤 정했다.
- v2+R1+R2를 최종으로 둔 이유
  - 공동 1위 세 모델 중 가장 단순하다(v3 성분 없음).
  - R2는 현장에서 가장 비용이 큰 고부하 정상 오경보를 직접 줄인다.
- R2가 test에서 줄인 오경보 3행은 초기 탐색에서 이미 본 행이다.
- α 민감도(최종 모델, test B): α 1% 오경보 0행(F1 1.000), 3% 1행(0.998), 5% 9행(0.986). A는 세 수준 모두 1.000이다. 운영 α는 1%로 둔다.
- 이상 확률: 경보와 별도로 팀원 v2의 확률 층이 등방 회귀로 우도비를 구해 이상 확률을 낸다. v2 점수 기준 교차 평가 Brier는 A 0.0072·B 0.0056이다.
- 첫 경보 지연(최종 모델): test 이상 11기록 모두 기록 첫 행(0.0초)에서 경보가 났다. 직전 기록이 이미 확인된 이상이라 R1이 경보를 이어받았기 때문이며, 사건이 이어지는 구조에서만 성립하는 값이다.

## ◦ 2.6 "다 맞았지만 의심했다": 검증

- 이상 데이터는 약 3분(2분 46초)짜리 단일 고장 사건이라, 1.000은 이 사건에 대한 결과다.
- 그래서 1.000이 무엇을 뜻하는지 확인하려고, 팀원 v3의 시험 틀(인공 고장 주입, 손실, 분할 변경)을 가져와 의심마다 실험을 붙였다. 판정 기준은 실험 전에 정해 두었다. 모든 실험은 test 채점 이후, 같은 test 정상 기록에 대해 했다.

# □ 제3장. 영향요인 및 오류분석〔15점〕

## ◦ 3.1 주요 영향 변수와 상호작용

- 가장 강한 변수는 전류 파형이다. 정상 전류는 기록마다 사인파에 거의 그대로 맞지만(R² 중앙 0.995), 이상 기록은 맞지 않는다(R² 중앙 0.095).
- 진동은 크기와 시간 구조가 함께 바뀐다. 상부 진동 표준편차는 6.3배가 되고, 자기상관(lag-1) 중앙값이 −0.031에서 0.686으로 올라 느린 흔들림이 된다.
- 상호작용
  - 정상에서는 하부 진동이 전류 진폭(부하)을 따라 움직인다. 부하가 크면 진동도 커지는 정상 관계다.
  - 이상에서는 상·하부가 반대 방향으로 움직인다(상관 중앙 −0.36).
  - 그래서 진동 크기만 보면 고부하 정상과 이상을 헷갈린다. R2가 전류 파형을 함께 보는 이유다.

## ◦ 3.2 잘 작동하지 않는 조건 (FN·FP 집중 조건)

| 출처 | 오류 | 집중 조건 |
|---|---|---|
| v2, test | 미탐 A 22행·B 16행 | 기록 위치 0~1에 A 14행·B 12행. 과거 행이 없어 크기 성분만 계산되는데, 이상 기록 상당수는 진동이 오히려 작다 |
| v2, test | 오경보 B 3행 | 고부하 정상 기록 3개(위치 41·40·11), 크기 성분 단독, 그 시점 전류 파형 R² 0.995~0.998 |
| 최종 모델 | α 3·5%에서 오경보 B 1·9행 | 문턱을 낮추면 고부하 정상의 동역학·파형 성분 경보가 늘어난다 |
| 팀원 v3 kNN | valid 0.993 → test 0.889~0.954 | 기록 단위 특징이 valid 시간대에 맞춰짐 |
| 검증 실험 | [V1b·V2·V5 결과 대기] | |

## ◦ 3.3 규칙별 효과 분해 (test, α 1%)

| 모델 | 미탐 A / B | 오경보 A / B | F1 A / B |
|---|---:|---:|---:|
| v2 | 22 / 16 | 0 / 3 | 0.965 / 0.970 |
| v2 + R2 | 22 / 16 | 0 / 0 | 0.965 / 0.975 |
| v2 + R1 | 0 / 0 | 0 / 3 | 1.000 / 0.995 |
| v2 + R1 + R2 | 0 / 0 | 0 / 0 | 1.000 / 1.000 |

- R1은 미탐을, R2는 오경보를 없앤다. 두 규칙은 서로 다른 오류를 맡는다.

## ◦ 3.4 적용 조건

- 1.000은 단일 고장 사건, 행 단위, α 1%에서의 결과다.

# □ 제4장. 현장 활용방안〔10점〕

## ◦ 4.1 경보에서 조치까지

- 경보는 두 단계다. 사건의 첫 경보는 1단계 "주의", 사건 안 경보가 2행에 이르면 2단계 "점검 요청"이다. 60초 안에 이어지는 경보는 한 사건으로 묶어, 작업자에게는 사건마다 두 번만 알린다.
- 경보마다 어떤 성분이 문턱을 넘었는지 근거가 남고, 근거별 점검 항목이 정해져 있다(팀원 v2 조치표).

| 경보 근거 | 확인 대상 | 점검 순서 |
|---|---|---|
| 진동 크기 | 기어 마모·체결·베어링·부하 변화, 센서 부착 | 센서 부착·케이블 → 체결 볼트·커플링 정렬 → 베어링 온도·소음 → 작동유 레벨·온도 |
| 전류 파형·예측 오차 | 모터·전원·계측·출력 유압 불안정 | 전류센서 영점·접지·표본화 시각 → 출력 압력 안정성 → 릴리프 밸브 |
| 진동 + 전류 함께 | 기어 마모로 출력 유압 약화 가능성 | 위 항목 전부 + 출력 유압 저하 + 필터 차압·오염 |

- 품질 조치: 1단계면 다음 샘플 검사를 앞당기고, 2단계면 의심 시간대 가공품을 보류해 전단면·버·치수를 확인한다.

## ◦ 4.2 규칙의 운영 의미

- R1은 경보 래치다. 고장이 확인되면 수집이 잠시 끊겨도 경보를 유지하고, 전류 파형이 정상으로 돌아온 것이 확인될 때만 해제한다.
- R2는 오경보 억제다. 진동만 크고 전류 파형이 정상이면 경보를 내지 않고 기록만 남긴다. 고부하 작업 때 울리는 경보를 줄여 작업자가 경보를 무시하게 되는 것을 막는다.
- [V1b 결과에 따른 R2 적용 범위]

## ◦ 4.3 데이터 수집 개선 권고

- 연속 수집: 지금은 측정이 43%뿐이고 5초마다 끊긴다.
- 표본화 시각 동기화: 교류 순시값은 수집 타이밍에 민감하다.
- 저장 형식 통일: 정상·이상 파일의 형식 차이는 누수를 만든다.
- 센서 추가: 출력 압력·작동유 온도가 있으면 기어 마모(FM4)를 직접 확인할 수 있다.

# □ 제5장. 창의성 및 차별성〔10점〕

◦ 결함부터 진단: 형식 누수(자릿수 규칙만으로 F1 0.992)를 먼저 찾아 정밀도를 맞췄다. 이 처리 없이는 어떤 모델의 점수도 믿을 수 없다(1.4절).
◦ 제조 구조 지식 결합: 수직 모터-펌프 구조와 고장 case로 센서 관측 가능성을 따져 문제를 다시 정의했고, 전류 파형을 교차 확인 근거로 썼다(2.1, 2.3절).
◦ 오류 원인별 규칙: 평균 성능이 아니라 오류가 몰리는 조건(기록 시작 직후, 고부하 정상)을 찾아 각각에 규칙을 붙였다. 미탐 A 22→0·B 16→0, 오경보 B 3→0(3.3절).
◦ 자기 의심 검증: 1.000을 그대로 믿지 않고 주입·손실·교락·분할 시험으로 범위를 정했다(2.6절).
◦ 잠금 절차: valid 선택을 해시로 잠그고 잠금이 맞을 때만 test를 채점하게 해, 선택과 채점을 코드로 분리했다(6장).
◦ 불확실성·확률: conformal 문턱으로 정상 오경보율을 α로 묶고, 별도 확률 층으로 이상 확률을 낸다(2.5절).
