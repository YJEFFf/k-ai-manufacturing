# 계획 v5

## 목표
- 지금 보고서(report/drafts/final.md, 18쪽)는 검증은 강하지만 도메인이 얕아 "데이터만 만진 분석"으로 읽힌다
- v5는 출제 의도 → 설비·고장 물리 → 센서 관측 가능성 → 진단 매트릭스 → 모델 → 검증 → 현장 순서로 다시 세운다
- 데이터로 확인할 수 없는 것은 "한계·가정" 표로 명시한다(왜 못 하나, 둔 가정, 영향, 필요한 데이터)

## 불변 조건
- 기존 수치(test F1, 검증 V0~V5)와 공개 문장 P1~P5는 바꾸지 않는다. 금지어("사전 등록", "독립 검증", "보지 않고", "처음 보는 시험") 0건
- 새 분석은 모두 test 채점 이후 추가한 것이다. 잠금 선택에 영향을 주지 않으며 보고서에도 그렇게 적는다
- 도메인 서술은 출처가 있는 것만. 모르는 사양(모터 극수·펌프 잇수·행정 속도 등)은 "가정"으로 표시
