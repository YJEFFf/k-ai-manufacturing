## 확인 질문 (PDF를 읽어야 답할 수 있음)

1. 2.4절 † 표에서 IsolationForest에 R1만 붙이면 test 실시간 F1이 얼마인가? 그런데도 v2를 기반 모델로 둔 근거를 보고서는 어디서 찾나? (쪽 번호)
2. 2.5절: 최종 모델 v2+R1+R2를 둔 이유는 통계 근거인가 설계 판단인가? 잠금 규칙이 실제로 고른 모델과 그 test F1은? (쪽 번호)
3. 4.2절 '이상 양상별로 먼저 볼 곳' 표(네가 낸 유형 나누기 의견을 넣은 곳): 상부 진동만 큰 기록은 몇 개이고 어디부터 점검하나? 이 표에 붙은 단서(한 사건이라는 점)는 무엇인가? (쪽 번호)
4. 2.5절: 이상 확률은 어떤 자료로만 보정했고, test Brier(파일 비율 사전)는 얼마인가? 확률이 55%를 넘지 않는 이유는? (쪽 번호)
5. 6장: 전체 실행에서 대조하는 항목은 몇 개이고, `run_all.py`가 다시 만들지 않는 수치는 무엇인가? (쪽 번호)
