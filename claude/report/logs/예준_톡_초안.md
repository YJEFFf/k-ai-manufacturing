# 예준에게 보낼 톡 (두 가지 어조 — 골라 쓰기)

## A. 솔직한 버전

예준아, 솔직하게 말할게. 지금까지 보고서, 코드, 재현 패키지는 거의 내가 했다고 느껴. 제출까지 이틀 남았으니 남은 건 같이 해 줬으면 해.

어제 말한 이상 유형 나누기는 좋은 의견이라 바로 넣었어. 4.2절 '이상 양상별로 먼저 볼 곳' 표에 들어가 있어. 이런 게 필요해. AI 돌려서 나온 검토 말고, 네가 직접 읽고 느낀 걸로 고칠 곳을 짚어 줘.

최신 보고서는 깃헙에 올렸어.
- 보고서: claude/press-cases 브랜치 claude/report/결과보고서_북적북적.pdf
- 확인 질문: claude/report/logs/검토요청_예준.md
- PR #3 댓글에 질문 8개 그대로 올려 둠: https://github.com/YJEFFf/k-ai-manufacturing/pull/3#issuecomment-5998000904

PDF 직접 읽고 질문 1~8에 PR #3 댓글로 답해 줘. 답마다 PDF 쪽 번호 꼭 적고. 쪽 번호 없으면 안 읽은 걸로 볼게. 마감은 10/7(수) 12시야. 그리고 발표자료 초안은 네가 맡아 줘.

## B. 조금 부드러운 버전

예준아, 어제 이상 유형 나눠 보자는 의견 고마워. 4.2절에 '이상 양상별로 먼저 볼 곳' 표로 넣었어.

솔직히 지금까지는 내가 거의 혼자 끌고 온 느낌이라, 남은 이틀은 같이 마무리했으면 해. 특히 AI 검토 말고 네가 직접 읽고 느낀 걸로 고칠 곳이 필요해.

최신 보고서랑 확인 질문 올려 놨어.
- 보고서: claude/press-cases 브랜치 claude/report/결과보고서_북적북적.pdf
- 질문: claude/report/logs/검토요청_예준.md
- PR #3 댓글에 질문 8개 그대로 올려 둠: https://github.com/YJEFFf/k-ai-manufacturing/pull/3#issuecomment-5998000904

PDF 보고 PR #3 댓글로 답해 줘. 답마다 쪽 번호 적어 주고, 10/7(수) 12시까지 부탁해. 발표자료 초안도 맡아 줄 수 있을까?

## 메모
- 읽게 하는 장치: 확인 질문 5개는 PDF를 직접 읽어야만 답할 수 있게 만들었고, 답마다 쪽 번호를 요구함(AI 요약으로는 쪽 번호를 맞히기 어려움). 직접 고칠 곳 3군데·심사위원 질문 1개는 본인 판단을 요구함
- 깃헙 PR 댓글에서 예준 계정을 불러 알림이 가게 했다(10/6, 커밋 74e6be3)
- 이 초안 파일은 팀 레포에 올리지 않았다(볼트에만 있음)
- 발표자료를 맡기는 줄은 준용이 정할 일이라 필요 없으면 지운다
