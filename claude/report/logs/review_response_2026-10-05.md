# 결과보고서 검수 회신

검수 12개 항목을 원자료(코드·예측 파일·공고·문헌 원문)로 하나씩 다시 확인했다. 확인 과정은 계획 → Architect·Critic 교차 검토 3회 → 반영 순서로 진행했다. 사실로 확인된 것만 고쳤고, 고치지 않은 것도 이유를 적었다. 결과 수치(test F1 1.000 등)와 잠금 절차는 바뀌지 않았다.

| # | 지적 | 판정 | 반영 내용 / 이유 |
|---|---|---|---|
| 01 | 기록 단위 F1의 분모가 행 | 채택 | 맞는 지적이다(lib.py record_flags를 행에 펼친 뒤 행 F1). 잠금·선택에 쓴 정의라 숫자는 그대로 두고 이름을 "기록 판정 F1(행 가중)"으로 바꿨다. 기록 하나를 1개로 센 F1은 새 스크립트 `tvt/06_record_count.py`로 계산해 2.4절 표에 † 열로 붙였다(사후, 선택에 쓰지 않음). B에서 v2(0.818 → 0.880)와 v3 kNN(0.954 → 0.857)의 순서가 바뀌는 것도 적었다 |
| 02 | 앨리어싱·RMS 단정 | 부분 채택 | "확인했다" → "가설과 맞는다", 짝수 고조파 배제 문장 삭제, 필터 문장은 "접힘 가설이 맞다면"으로, 진동 SD는 "상대 변동 지표"로 바꿨다. max\|z\|는 "에너지"가 아니라 "크기(표준화한 순간 진폭 편차)"로. 그림 2 라벨도 맞췄다. 99·101ms 문장은 원래 조건부라 그대로 |
| 03 | 부하 원인 배제 단정 | 채택 | "부하가 커져서 생긴 것이 아니다" → "정상 관계의 부하로는 설명하기 어렵다. 이상 상태의 전류 부하 대리성은 확인 못 해 실제 부하 변화를 원인에서 뺄 수는 없다" |
| 04 | 문헌 적용 범위 | 부분 채택 | [4] 압력 맥동은 "압력 측정"으로 구분, [5]는 측판 행에서 빼고 치면 행에 "기어박스 연구, 적용은 가설", kHz 광대역은 "고주파 광대역(추정)", "반대 방향으로 흔들린다"는 "음의 상관"으로. [9] 180° 행은 문헌 서명 소개라 그대로 |
| 05 | 재현 자료 미완 | 채택 | 공고가 요구한 "테스트데이터 예측결과 파일"이 zip에 없었다. `predictions/`를 zip에 넣었고, 새 가상환경에서 전체를 다시 돌려 확인했다(결과는 아래) |
| 06 | [6] 저자, [18] 출처, 60% 표현 | 채택 | [6] Smiley, A.(Noria 발행), [18]에 exida 백서(Stauffer·Sands·Dunn, Table 1) 서지와 URL, 60%는 "참고치"로 |
| 07 | 냉간 기동 점도 비교 | 채택 | 특정 펌프 계열의 허용값이라 이 비교만으로 캐비테이션 가능성을 판단할 수 없다고 썼다 |
| 08 | 압력·유온으로 체적효율 "직접 확인" | 채택 | 유량·회전수·펌프 사양, 흡입측 압력이 함께 필요하다고 고쳤다 |
