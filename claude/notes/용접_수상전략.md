# ② 용접 — 수상 전략

> 2026-09-21 팀 결정: **② 용접기 AI 데이터셋으로 확정.** 상위: [[제조데이터 경진대회 MOC]] · 데이터: [[데이터셋_구성]] · 선정 당시 비교: [[주제추천_수상가능성]]

## 1. 오늘 새로 확인한 데이터 사실 (진단 15점의 핵심 재료)

> 재현: `python code/01_diagnose_welding.py` → `code/outputs/diagnosis/diagnosis_report.md`
>
> **핵심: 원본으로 볼 수 있는 행은 2,177개(18.2%)뿐이다. 3/24 전체 1,200행과 3/25 앞부분 977행이 원본이고, 나머지 7일은 전부 이 원본 구간을 이어 붙인 것이다.** 반면 불량 라벨은 9일 모두 따로 있다 → 같은 센서 구간이 날마다 다른 불량 수를 갖는다. 센서 → 불량 관계를 학습할 근거가 원천적으로 약하다는 뜻이며, 이것 자체가 보고서의 가장 강한 진단 결과다.

| # | 사실 | 수치 |
|---|---|---|
| D1 | **블록 복사로 짜깁기한 데이터** | 11,939행 중 **97.9%**가 다른 곳에 똑같이 있는 27행 연속 구간에 속함. 고유 센서값 조합은 1,574개뿐 |
| D2 | **고가압력 243행 블록이 4일에 똑같이 붙어 있음** | 가압력 5.01~10.54bar(정상 중앙값 2.34). 3/25·3/27·3/31·4/3에 **완전히 같은 값·같은 순서**로 존재 |
| D3 | 통전시간이 소수(72.18 등)인 행 | 297행, 하루 27행 또는 54행 단위 → 27행 블록 단위로 삽입된 흔적 |
| D4 | 라벨은 일별 집계뿐 | `result` 23행 = 날짜 × 유형(파임·용접부족·크랙) × 개수. 9일간 총 39건. `result.idx`는 행 번호일 뿐 Raw `idx`와 연결되지 않음 |
| D5 | 3/27은 라벨 없음 | Raw 1,648행이 있는데 result에 행이 없음 → 라벨 있는 날은 8일 |
| D6 | 3/25 순번 오류 | idx=1 중복 1건, 1350→1650 사이 순번이 비어 있음(n=1,352인데 idx 최대 1,650) |
| D7 | 고정 변수 | 설비 1대, 품목 1개, 두께 0.7/0.7mm 고정 → 두께 영향 분석 불가 |
| D8 | `scaled_data.csv` | **Raw를 스케일링한 파일이 아님** — 행 단위 상관이 가압력 0.31, 전류·전압·통전시간 약 0. 결측 15~23개(Raw에는 결측 0) |
| D9 | 날짜 신호가 약함 | 일별 불량 수와 일별 센서 통계의 순위상관 최대 0.62, 표본 8개 → 우연 수준 |

→ 대부분의 팀은 D1·D2를 모른 채 이상탐지를 돌릴 것이다. **"이 데이터는 짜깁기됐고, 그래서 검증은 이렇게 설계했다"**를 가장 먼저 보여주는 것 자체가 차별화 포인트다.

## 2. 프레임

**"건별 정답이 없는 현장에서, 일별 불량 집계만으로 용접 한 건 한 건의 불량 위험을 추정하고 검사 우선순위와 안정 공정조건을 제시하는 약지도(weakly-supervised) 용접품질 AI"**

- 현실 논리: 중소기업 대부분이 건별 검사 기록 없이 일별 불량 집계만 갖고 있다 → 이 제약이 곧 현장 문제다
- 가이드북(2020) 방식은 오토인코더 + 일별 개수 비교라 오차 약 2개. 이것이 공개된 기준선이다. 우리는 이를 넘어서는 방법과 검증 틀을 제시한다

## 3. 평가항목별 설계

| 항목(점) | 할 일 |
|---|---|
| 진단 15 | 위 D1~D9. 복사 블록 탐지 알고리즘(n-gram 해시)과 중복 제거 전후 분포 비교 |
| 모델 40 | 베이스라인 ① SPC 관리한계(판정범위·3σ) ② Isolation Forest ③ 오토인코더(가이드북 재현) → 제안 ④ **LLP(라벨 비율 학습)**: 일별 불량 수를 bag 라벨로 삼아 건별 확률 학습 ⑤ 물리 특징 결합(입열량 Q=V·I·t, 동저항 R=V/I) |
| 검증 (40점 방어) | (a) **leave-one-day-out 일별 불량 수 예측** MAE (8일) — 실제 라벨로 한 유일한 정량 평가 (b) **가상 불량 주입 벤치마크**: 용접 물리에 맞춘 결함 패턴(전류 저하·가압력 과다/부족·통전시간 이탈 → 용접부족·파임·크랙)을 알려진 위치에 주입해 건별 F1·FN·FP 계산. 시뮬레이션임을 명시 |
| 오류 15 | 주입 벤치마크에서 FN·FP가 몰리는 조건(편차 크기, 센서 조합, 결함유형), 복사 블록 안 vs 밖 성능 차이 |
| 현장 10 | 일별 상위 k개 우선검사: 같은 검사량으로 잡히는 불량 수(recall@k). 경보 → 공정점검 규칙, 센서별 안정 운전 범위 표 |
| 창의 10 | LLP 약지도 + 물리 특징 + 순응 예측(conformal) 기반 경보 임계값 |
| 재현 10 | `python run.py` 한 번으로 전처리 → 학습 → 테스트 예측 파일 생성. 테스트 = 마지막 날(4/7) 또는 LODO 결과 |

## 4. 위험과 대응

- **정량 평가 표본 8개(일)** → 주입 벤치마크를 "보조 검증"으로 분명히 구분한다. 실제 라벨 평가(LODO)를 절대 부풀리지 않는다
- **고가압력 블록(D2)을 불량으로 단정하는 함정** → 243행 × 4일인데 해당 날짜의 실제 불량은 4~8건이다. 불량 신호가 아니라 복사된 운전 구간일 수 있다는 점을 진단에서 먼저 짚는다
- "안정 공정조건 범위"는 인과가 아닌 관측 기반임을 명시한다. 두께가 고정이라 두께별 조건은 범위 밖임을 밝힌다
