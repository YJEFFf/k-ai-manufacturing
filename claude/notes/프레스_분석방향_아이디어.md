## 0. 예준 작업 재현 결과

- `press_policy_audit.py`, `sensor_relation_audit.py`를 로컬 원본 CSV로 다시 돌림 → **수치가 레포 보고서와 일치** [확인]
- 예준의 결론: 단순 max-z도 이상 기록구간 18/21을 잡는다. 5NN은 행 예산 3·5%에서 19/21(한 구간 더), RMS는 준비구간 때문에 15/21. "복잡한 모델의 우위"는 아직 입증되지 않았다
- 즉 **성능 경쟁으로는 차이가 안 난다** → 점수는 진단 15, 오류분석 15, 창의 10에서 벌려야 한다

## 1. 이번에 새로 찾은 것 (예준 분석에 없음)

| # | 발견 | 수치 | 의미 |
|---|---|---|---|
| N1 | **이상 파일의 전류값은 100% 격자 위에 있다** (간격 1.1920929 = 2⁻²³×10⁷) | 이상 600/600, 정상 0.2% | `전류 mod 1.192 ≈ 0` 한 줄 규칙으로 **F1 0.972** [확인]. 두 날의 수집·저장 설정이 달랐다는 증거 [추정] |

| N3 | 상부 진동(AI0) 자기상관이 완전히 다르다 | lag-1 상관 정상 0.03, 이상 0.72 | 고장 신호일 수도, 샘플링·필터 차이일 수도 있음 — 분리 필요 |
| N4 | **전류 앨리어싱 주파수**: 60Hz 전류를 10Hz로 찍어 생긴 저주파 | 정상 구간 0.61±0.05Hz(매우 안정), 이상 구간 0.14~4.4Hz(흩어짐) | 전원·모터 주파수 안정성 지표가 될 수 있음. 손으로 하는 MCSA [추정] |
| N5 | 20,000행이 1시간 17분에 걸쳐 있다 | 10Hz면 33분 분량 | 기록 공백이 많다는 것. 예준의 "기록구간 600개"와 같은 이야기 |

→ N1·N2는 **데이터 진단 15점의 핵심 소재**다. 경쟁팀 대부분은 이걸 모른 채 날짜 차이를 학습한 F1≈1.0을 낼 것이다 [추정].

## 3. 수상작에서 뽑은 패턴

**국내 (K-AI 제조 1~5회, LG Aimers, 데이콘, HAICon)**
- 3회 대상: XAI 기반 실시간 이상탐지 — 심사평 "독창성·현장 적용성·확장성" [1차, KAIST]
- 2회 대상: 준지도 불량탐지 — "다양한 분석모델, 분석 타당성, 결과 해석" [2차]
- 5회 대상: 물리식 기반 시계열 회귀. 최우수 팀명도 PhysicsAI [1차, KAIST]
- 4회 본선: 10팀 중 6팀이 "예측 → 의사결정/최적화"로 연결
- HAICon(국정원 주최 이상탐지): 점 F1이 아니라 **구간 지표(eTaPR)**로 채점

**해외 (PHM Society, DCASE, HUMS, ESA)**
- PHM 2022 1위(서울대, 유압 락드릴): 개체마다 다른 domain shift를 **그 조건의 정상 기준 신호와 비교**해서 해결
- PHM 2023: 보지 못한 조건을 흉내 낸 검증셋으로 모델 선택
- HUMS 2023: 전통 신호처리가 딥러닝을 이김 — **오경보율을 명확히 정의한 임계값**이 결정적
- DCASE Task 2(기계음 이상탐지, 2020~2025): 정상 데이터에 감마분포를 피팅해 임계값 결정, **평가셋 보고 임계값 튜닝 금지**. 상위권은 보조분류(운전조건 맞히기) + kNN 점수 + 앙상블
- ESA-ADB: 구간을 이벤트로 세는 event-wise F0.5, 오경보 이벤트에 페널티

**논문 (핵심 인용 무기)**
- Wu & Keogh, TKDE 2021 — "한 줄 코드로 풀리는 벤치마크는 진전의 착시" → 우리 max-z 18/21, 격자 규칙 F1 0.97이 바로 이 사례
- Kim et al., AAAI 2022 — point-adjust를 쓰면 무작위 점수도 SOTA처럼 보인다
- Sarfraz et al., ICML 2024 / Audibert et al., PR 2022 — 단순 베이스라인이 딥모델과 비슷하거나 낫다
- Bates, Candès et al., Annals of Statistics 2023 — conformal p-value로 오경보율 상한 보장
- Geirhos 2020, Kauffmann et al. Nature MI 2025 — 지름길 학습, 비지도 모델의 Clever Hans. XAI로 지름길을 잡아낸 절차
- Hendriks et al., MSSP 2022 — CWRU 베어링 데이터 누수 비판(같은 개체가 학습·평가에 섞임) ↔ 우리의 "날짜 = 라벨" 교란과 같은 구조
- Helwig et al., I2MTC 2015 — 1~100Hz 저속 센서로 유압 시스템 진단(UCI 데이터). "10Hz로도 된다"의 근거

## 5. 분석 방향 — B. 창의적 아이디어 (카테고리별)

### B1. 데이터 신뢰성 감사 — "지름길을 먼저 잡는 팀" ★ 1순위
- 격자 규칙 하나로 F1 0.972를 보여주고 "이게 모델 성능이 아님"을 선언 (Wu & Keogh 인용)
- **불변화 전처리**: 두 날짜를 같은 해상도로 재양자화(또는 디더링)한 뒤에도 성능이 유지되는지 → 유지되는 부분만 "진짜 신호"로 주장
- 누수 탐지기(날짜 판별기)를 따로 만들고, 제안 모델 점수와 날짜 판별 점수의 상관을 보고
- XAI로 모델이 격자·해상도에 기대지 않는지 확인 (Kauffmann 2025)
- 왜 이기나: 진단 15 + 창의 10을 동시에 가져가고, 발표에서 "다른 팀 F1 1.0은 왜 틀렸나"를 보여줄 수 있다. 수상작 공통점인 "분석 타당성"에 정면으로 맞음

### B2. 물리 기반 특징 — "10Hz 전류에서 모터 상태를 읽는다"
- **앨리어싱 주파수 안정성**(N4): 구간별 주파수·진폭 추정 → 전원·부하 안정성 지표. 단, 샘플링 타이밍 차이로 생긴 것인지 먼저 검증
- 전류 포락선 진폭(구간 내 max-min, RMS) = 부하 대리 지표
- 상·하부 진동비, 전류 대비 진동 전달비 → 관계가 깨지는 것을 이상으로 (예준 실험은 단순 공분산이라 효과 약했음 — 물리 관계식 잔차로 다시 시도)
- 5회 대상·PhysicsAI 계열과 맞고, 해석 가능해서 현장 조치문으로 이어짐

### B3. 조건 정규화 (domain shift) — PHM 2022 1위식
- 정상일 운전 상태를 전류 진폭 등으로 클러스터링 → 상태별 기준으로 점수를 정규화
- "정상적인 운전변화를 이상으로 오인"(과제문 문구)에 정면으로 대응: 정상 내 운전 전환 구간의 오경보 감소를 보여줌
- 검증은 정상일 시간 블록 forward-chaining (PHM 2023식 "보지 못한 조건" 흉내)

### B4. 오경보 통제 — conformal + 지속성 규칙
- 정상 보정 구간으로 conformal p-value → **오경보율 상한을 수식으로 보장** (Bates 2023). 평가표 창의성 예시 "불확실성 추정·확률보정"과 정확히 일치
- 경보 정책: "k개 연속 초과" 또는 CUSUM, 짧은 구간에는 즉시 판정 점수(max-z)를 쓰는 **결합 정책** (예준이 가설로 남긴 것 — RMS 준비구간 문제 해결)
- 이상 확률 출력: 정상 점수 ECDF 기반 보정 → 과제 "이상 확률 예측" 문구 충족

### B5. 평가 설계 자체를 기여로 — "조기탐지를 수치로"
- 점 F1(point-adjust 없이) + 구간 탐지율 21개 중 몇 개 + 구간 첫 경보 지연(초) + 정상 알림 구간 수를 한 표로
- VUS-PR 또는 range-based F1 병기 (HAICon·ESA 관행)
- "관측 시작 후 몇 초 안에 잡나"로 조기탐지를 정직하게 정의 (고장 전 선행시간은 주장하지 않음)

### B6. 현장 연결 — XAI 3단 출력
- 경보 → 원인 센서 기여도 → 점검 조치문 (예: 하부 진동 → 커플링·베어링, 전류 진폭 → 릴리프밸브·부하)
- 오경보 예산 슬라이더가 있는 간단한 대시보드(발표용)
- 3회 대상(XAI 실시간)과 LG Aimers 1위(현장 적용성) 패턴

### 보류·비추천
- 큰 딥모델(LSTM-AE, Transformer) 중심 — 모두가 할 것이고 단순 기준을 못 이긴다는 실험·논문 근거가 있음. 베이스라인으로만 둔다
- 합성 이상 주입 — 용접에서 한 번 했지만 여기선 실제 이상 600행이 있으니 보조로만
- RUL·고장 N분 전 예측 — 고장 시각이 없어 주장 불가

## 6. 추천 조합과 스토리

**B1 + B4 + B2 (+ B5는 평가표로 자연스럽게 포함)**

> "날짜가 곧 라벨인 데이터에서, 지름길을 걷어낸 뒤에도 남는 이상 신호만으로 오경보율을 보장하는 유압펌프 경보"

1. 진단: 격자 규칙 F1 0.97 → 이 데이터는 한 줄로 풀린다 → 불변화 전처리
2. 모델: max-z / IF / AE / 5NN / 제안(물리 특징 + 조건 정규화 + 결합 정책)을 같은 예산으로 비교
3. 오류: 놓친 구간과 정상 알림의 조건 (+ 불변화 전후 무엇이 사라졌나)
4. 현장: conformal로 "하루 N회 이하" 보장하는 운영점 + 원인 센서 조치문
5. 창의: 지름길 감사 + conformal 보장 + 앨리어싱 물리 특징

## 7. 재양자화 검증 결과 (2026-09-23) [확인]

코드 `code/press/05_requantize_audit.py` → 결과 `code/press/outputs/requantize/`. 예준 `press_policy_audit.py`(분할·예산·분모 고정)를 변환본마다 그대로 돌림.

**지름길은 두 개였다**

| 형식 규칙 | 원본 F1 | 재양자화 후 |
|---|---:|---:|
| 전류가 1.192 격자 위 | 0.972 | 0.057 (전부 격자 위 → 구분 불가) |
| 진동에 소수 6자리보다 세밀한 값 | **1.000** | 0.000 |

- 진동: 정상은 소수 6자리로 저장, 이상은 8~10자리 → 자릿수만 세도 완벽 분리
- 변환: matched = 진동 1e-4, 전류 1.192 격자로 두 날 모두 반올림 / coarse = 진동 1e-3, 전류 4.77 격자

**모델 성능은 거의 그대로다**

- max-z, 5NN, RMS5 × 두 분할 × 행/구간 보정 × 1·3·5% 예산 36개 설정 모두 raw ≈ matched ≈ coarse
- F1 차이 최대 0.005, 이상 탐지 구간 수(18·19·15/21)는 전부 같고, 정상 알림 구간 수는 ±1
- 예: 60/20/20, 행 1%에서 5NN F1 0.602 → 0.602 → 0.601, 18/21 · 3/120 유지

**해석**
- 크기 기반 모델(max-z·kNN·RMS)은 이 형식 지름길을 쓰지 않는다 → 예준 결과는 형식 누수로 부풀려진 것이 아님
- 따라서 B1은 "성능이 무너진다" 스토리가 아니라 **"형식 누수 2개를 찾아 제거했고, 우리 모델이 거기 기대지 않음을 증명했다"**는 강건성 검증이 된다. 진단 15점 소재로는 여전히 강함 (F1 1.0 규칙은 인상적)
- 재양자화로는 날짜·운전조건 교란이 해결되지 않는다. 남은 차이(진폭·자기상관·앨리어싱 주파수)가 고장인지 날짜인지는 여전히 분리 불가
- 원자료 값을 직접 읽는 모델(문자열·소수부 특징, 일부 딥모델)은 지름길을 탈 수 있다 → 경쟁팀 F1 1.0의 원인 설명 재료 [추정]

## 7-2. B2 앨리어싱 주파수 검증 결과 (2026-09-23) [확인]

코드 `code/press/06_alias_frequency_audit.py` → `code/press/outputs/alias/`. 구간마다 전류에 단일 사인파(0~5Hz 격자 최소제곱)를 피팅.

**1) 앨리어싱 주파수 자체는 샘플링 간격으로 검증 불가**
- 타임스탬프 간격은 두 파일 모두 정확히 100ms(정상 표준편차 0.7ms, 이상 0) → 소프트웨어가 찍은 명목 시각으로 보임. 실제 ADC 간격이 0.101초면 60Hz가 정확히 0.6Hz로 보이는데, 이를 확인할 방법이 없음

**2) 핵심은 주파수가 아니라 "사인파가 깨졌는가"다**

| | 정상 530구간 | 이상 17구간 (길이 ≥10) |
|---|---|---|
| 사인 R² | 0.993~1.000 (중앙 0.996) | **0.29~0.78** (중앙 0.45) |
| 앨리어싱 주파수 | 0.600 ± 0.002Hz (시간 드리프트 없음) | 0.005~4.44Hz |

- 정상 전류는 완벽한 사인파, 이상 전류는 17구간 전부 사인파가 아님. 겹치는 구간이 없음
- 이상 전류는 5초 동안 양(+) 쪽에 머무는 구간도 있음(평균 155~272) → 정상적인 AC 샘플이 아님

**3) max-z가 놓치는 3구간을 정확히 잡는다**
- 예준 분할(60/20/20)에서 max-z가 놓친 이상 구간 = 0부터 셀 때 3·19·20번(길이 31·10·15) = **진동이 정상 수준인 구간**(진동 표준편차 0.02~0.07)
- 사인 R² 규칙은 이 3개를 모두 잡음

**4) 조기판정 — 구간 첫 k관측만 보고 판정** (문턱 = 정상 보정 구간 R²의 1% 분위)

| k (초) | 정상 알림 | 이상 탐지 |
|---|---|---|
| 5 (0.5s) | 0/116 | 10/18 |
| 6 (0.6s) | 0/115 | 14/18 |
| **8 (0.8s)** | **2/113** | **18/18** |
| 10 (1.0s) | 1/108 | 17/17 |

- 8관측 미만인 이상 구간 3개(길이 4·3·4)는 판정 불가 → 이 3개는 max-z가 첫 관측에서 잡음

**5) 결합: max-z(짧은 구간·진동 이상) + 사인 R²(k=8, 전류 파형 이상)**

| max-z 구간 예산 | max-z 단독 | 사인 단독 | **합집합** |
|---|---|---|---|
| 1% | 18/21 · 정상 0/120 | 18/21 · 2/120 | **21/21 · 2/120** |
| 3% | 18/21 · 1/120 | 18/21 · 2/120 | 21/21 · 3/120 |
| 5% | 18/21 · 2/120 | 18/21 · 2/120 | 21/21 · 4/120 |

→ 예준 36개 설정 어디에서도 못 넘은 18~19/21을 **21/21로, 정상 알림 2/120**에서 달성

**반드시 같이 쓸 한계**
- 탐색 결과다. 분할 하나(60/20/20), 이상 21구간을 이미 본 상태에서 만든 규칙. 50/20/30 분할과 예산 합산(두 규칙 문턱을 합쳐 전체 오경보 예산 맞추기)으로 재확인 필요
- **파형 붕괴가 고장인지 수집 설정 차이인지 분리 불가.** 이상일은 저장 형식(전류 격자·진동 자릿수)도 달랐다(7절). 샘플링 클록이나 채널 설정이 달라도 사인파가 깨질 수 있다. 보고서 표현은 "정상일 전류는 정현파 R² 0.99 이상을 유지했고, 이상 구간은 모두 이를 벗어났다"까지만
- 물리적 해석(부하 변동·전원 불안정·모터 이상)은 가설. 10Hz라 고조파·측대파 분석(MCSA 본래 방식)은 불가
