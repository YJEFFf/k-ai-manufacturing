## 1. 이번에 확정된 것

- **최종 모델 = 4성분 극값꼬리 p값 ACAT 융합 + conformal** (`code/press/pipeline/`)
  - 성분: max-z · 5NN · 창 AE · 전류 사인 적합도(w=8). 각 성분을 정상 학습 분포 + GPD 꼬리로 p값화(로그 영역, 포화 없음) → ACAT 결합 → 보정 구간 기록구간 최댓값으로 conformal 문턱
  - 창 w=8은 **정상 데이터만으로** 선택(백색잡음 99% 기각 최소 창, 두 분할 모두 8, 반주기 8.3관측과 일치)
  - 결과(conformal, 기록구간 1%): 60/20/20 **21/21 · 정상 0/120 · F1 0.936**, 50/20/30 **21/21 · 3/180 · 0.937**
  - ablation: 사인 성분 빼면 18/21, 나머지 성분은 빼도 탐지 불변 → 파형 성분이 추가 3구간 담당. 단독으로는 사인 18/21, max-z 18/21(서로 보완)
  - 비교: 가이드북 LSTM-AE 재현 17/21·F1 0.40(2분 예산, 과소학습), 기록구간 준수판 8~10/21, IF 7/21
- **검증에서 고친 결함**: 점수 포화(tail_logp 상한, 1e-300 언더플로) → 로그 영역, 경보 규칙 이중(예준 문턱식 vs conformal) → conformal 주, 창 규칙 결함 → 폐기·교체, 보고서 과대 문장 목록(계획 파일 "깨지는 것" 6번)
- **가이드북 원문 확보** → [[가이드북_소성가공_원문확인]]: 기어형 유압펌프, 고장 모드 기어 마모, 전류센서는 펌프 전력선, PLC 10Hz, "변수 간 상호성 → 복합 감지 모델" 요구
- **외부 데이터 1단계** → [[외부데이터_NLN-EMP_1단계]]: CC0, healthy 세션 날짜가 다름(대리 교차일 검증 가능). 2단계(부분 해제 0.7~1.5GB)는 **사용자 결정 대기**
- **핵심 한계(보고서에 반드시)**: 전류 파형 성분은 샘플링 지터에 극도로 민감 — 60±f_a Hz 앨리어싱 가정 아래 σ 0.05~0.1ms에서 정상 알림이 예산을 넘음(`perturb_curve.csv`). 이상일 파형 붕괴는 지터 2~3ms로도 재현 → **고장인지 계측·운전 조건 차이인지 분리 불가**. 현장 적용 조건: 하드웨어 클록 동기 샘플링
