## 1. 데이터 이해·진단 (15) — `diagnosis.md`, `fig_current_waveform.png`, `fig_segment_length.png`

- 정상 20,000행(07-12, 77분), 이상 600행(07-17, 2분 46초). 10Hz라면 33분 분량 → 기록 공백이 많아 **0.1초가 아닌 간격에서 기록구간을 끊는다**: 정상 600구간, 이상 21구간(길이 3~50)
- 중복 타임스탬프 1건, 결측 0
- **저장 형식 차이 2개**: 진동은 정상 소수 6자리 / 이상 8자리(1e-6보다 세밀한 값 0% vs 98.7~99.2%), 전류는 이상 100%가 1.1920929 격자 위(정상 0.2%). 형식만 보는 규칙으로 F1 0.972 / **1.000**. 두 날짜를 같은 양자화로 맞추면 규칙은 무너지고, 크기 기반 모델 36설정의 F1 변화는 최대 0.005
- **전류 파형**: 10Hz로 찍힌 60Hz 교류가 정상 530구간에서 사인 R² 0.993~1.000(앨리어싱 0.600Hz), 이상 17구간은 0.291~0.783
- 한계: 정상·이상이 서로 다른 하루 → 날짜·운전조건과 고장을 분리할 수 없다. 이상 21구간은 독립 고장 21회가 아니다
- 검증 전략: 정상만 학습·보정(시간순 60/20/20, 민감도 50/20/30), 이상은 평가에만. 문턱은 정상 보정 구간의 오경보 예산(1·3·5%)으로

## 2. AI 예측모델 (40) — `model_comparison.md`

기록구간 보정 1% 예산. 셀 = 이상 탐지 구간 · 정상 알림 구간 · 전체 행 F1

| 모델 | 60/20/20 | 50/20/30 |
|---|---|---|
| max-z (베이스라인) | 18/21 · 0/120 · 0.460 | 18/21 · 3/180 · 0.491 |
| Isolation Forest | 7/21 · 0/120 · 0.101 | 7/21 · 3/180 · 0.113 |
| AutoEncoder (5관측 창) | 15/21 · 1/120 · 0.589 | 15/21 · 5/180 · 0.585 |
| 5NN 거리 | 18/21 · 1/120 · 0.554 | 18/21 · 4/180 · 0.563 |
| RMS5 | 15/21 · 1/120 · 0.556 | 15/21 · 4/180 · 0.556 |
| 사인 1−R² 단독 (w=8) | 18/21 · 0/120 · 0.867 | 18/21 · 3/180 · 0.864 |
| **결합 max-z + 사인, w 규칙** | **21/21 · 0/120 · 0.759** (w=5) | **21/21 · 1/180 · 0.894** (w=10) |
| 결합, w=8 (탐색값) | 21/21 · 0/120 · 0.915 | 21/21 · 6/180 · 0.918 |

- **최종 모델 선정 근거**: 결합 모델만 두 분할·세 예산·두 보정단위 모두에서 21/21. 기존 모델은 최대 19/21
- 창 길이는 **정상 데이터만으로** 고른다(`w_selection.csv`): 60/20/20 → w=5 (5·6·8 동률, 작은 값), 50/20/30 → w=10. 라벨 없는 규칙이라 검출력은 보지 못한다 — w=5는 행 F1이 w=8보다 낮다(0.759 vs 0.915). 두 값 모두 보고
- 이상 점수는 **정상 이탈 p값**(구간 단위 conformal)으로 낸다. 사후확률이 아니다. 결합 모델에서 `p ≤ 1%` 경보와 예준 문턱 경보가 같은 구간을 고른다
- 탐지 지연(탐지된 구간의 첫 경보까지, 중앙값): 0~0.1초
- 한계: 결합 구조는 이상 데이터를 본 뒤 떠올렸다. 두 분할은 같은 이상 600행을 공유한다

## 3. 영향요인·오류분석 (15) — `influence.csv`, `error_conditions.csv`, `fig_recall_by_position.png`, `fig_vibration_vs_sineR2.png`

- **영향요인**: 구간 단위 단변량 AUROC — max-z 최댓값 0.96~0.98, 전류 사인 이탈 0.91~0.94, 하부 진동 0.90~0.93, 상부 진동 0.86, 전류 진폭 0.70~0.75, 구간 길이 0.41
- max-z 경보의 **94%가 상부 진동(AI0)**에서 나온다. 이상 경보 사유는 사인 52~64%, max-z 12~31%, 둘 다 18~25%
- **상호작용**: 진동이 정상 수준인 이상 구간 3개(max-z 미탐)는 전류 파형으로만 잡힌다 (그림: 진동 × 사인 R²)
- **FN 조건**: 50/20/30(w=10)에서 놓친 이상 행 114개가 **전부 구간 시작 9관측 안** — 사인 창이 차기 전. 10번째 관측부터 재현율 100%. w=5에서는 창이 짧아 깨진 파형도 사인으로 맞춰져 구간 중간에서도 놓친다(233행 중 185행이 창 밖)
- **FP 조건**: 정상 알림 구간은 **전류 진폭 250(정상 중앙 123), 상부 진동 표준편차 0.117(0.049)** — 고부하 운전 구간. 과제문이 말한 "정상적인 운전변화를 이상으로 오인"이 바로 이것. 5% 예산 알림 15행 중 9행이 max-z에서 발화

## 4. 현장 활용 (10)

- 운영점: 기록구간 1% 예산 → 정상 알림 0~1구간/120~180구간, 이상 21/21, 첫 경보 0~0.1초
- 경보마다 사유(max-z 센서 / 전류 파형)를 붙인다 → 점검 대상 안내: 상부 진동 → 펌프 상부·커플링, 전류 파형 붕괴 → 모터·전원·부하 계통 [현장 매핑은 가설]
- 고부하 구간 오경보는 운전 조건(전류 진폭)으로 구분 가능 → 다음 개선 후보: 부하 조건별 문턱
- 구간 시작 1초 안은 max-z만 판정 → 운영 문서에 "기동 직후 1초는 진동 기준만 적용"으로 명시

## 5. 창의성 (10)

- 형식 누수 감사: F1 1.0을 내는 지름길을 찾아 제거하고, 모델이 그것을 쓰지 않음을 증명
- 제조 지식 결합: 10Hz 전류의 앨리어싱을 이용한 사인 파형 적합도 (저속 샘플링에서의 전류 파형 진단)
- 불확실성·보정: 정상 이탈 conformal p값으로 오경보 상한, 오경보 예산별 운영점
- 라벨 없는 창 길이 선택 규칙 + 민감도(5~10 전부 21/21) 공개
