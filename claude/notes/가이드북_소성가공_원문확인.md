## 가이드에 없는 것
- 전류센서 종류(CT/홀), PLC 모델·스캔 주기·아날로그 입력 분해능
- 모터 구동 방식(직입/인버터) — 인버터 언급 없음
- 두 날짜의 운전 상태(생산 중/대기), 고장 판정 방법, 정비 이력
- 이상 데이터를 합성했다는 서술 없음 (실측 고장일로 제시)

## 우리 분석에 주는 의미
1. **전류 파형 붕괴의 물리 경로가 생긴다.** 기어 마모는 기어 맞물림 주파수(수백 Hz)에서 부하 토크를 흔들고, 이는 모터 전류를 변조한다(전류 신호 분석 MCSA로 기어 결함을 찾는 근거). 안티앨리어싱 없이 10Hz로 점샘플하면 이 고주파 변조가 잡음처럼 접혀 들어와 60Hz 기본파의 앨리어스(0.6Hz) 사인 적합도를 떨어뜨린다 → "기어 마모 → 전류 파형 정합성 저하"는 물리적으로 그럴듯한 **가설**
2. **대안 설명도 유지해야 한다.** PLC 스캔 기반 샘플링은 타이밍 지터가 흔하다(2~3ms 지터로 R² 붕괴 재현됨). 정상일(자정 직후)과 이상일(오전) 운전 상태 차이도 있다. 둘 다 이 데이터로는 배제 불가
3. **"복합 감지" 요구 → 다성분 융합 모델의 근거.** 진동 크기·다변량 관계·시계열 재구성·전류 파형을 결합하는 최종 모델 설계가 가이드의 분석 목표 문장과 직접 맞는다
4. 가이드의 진동 절댓값 변환·20행 슬라이딩 창(기록 공백 무시)은 비교 베이스라인으로 재현한다
