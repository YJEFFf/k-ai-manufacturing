# train / valid / test 분석

> 상위: [[제조데이터 경진대회 MOC]] · 이전 사후 분석: `code/press/cases/README.md`

## 절차 (실행 전 고정)

| 구분 | 정상 A / B (예준 v2와 같은 기록 번호) | 이상 21기록 (시간순) | 쓰임 |
|---|---|---|---|
| train | 0~359 / 0~299 | 안 씀 | 모든 모델 학습, 교차 확인 R² 기준 |
| valid | 360~479 / 300~419 | 앞 10기록 (276행) | 문턱 보정, 모델 선택, test 판정 기준 기록 |
| test | 480~599 / 420~599 | 뒤 11기록 (324행) | 잠근 선택으로 채점 |

- valid 정상 행의 오경보는 그 기록을 뺀 보정으로 잰다(leave-one-record-out). α 1%가 주 기준이다
- 선택 규칙: valid 실시간 행 F1(A·B 평균) 최고. 0.002 이내면 단순한 모델을 고른다
- `02`가 선택과 판정 기준을 `tvt_selection.json`에 쓰고 해시로 잠근다. `03`은 해시가 맞을 때만 test를 채점한다

## 경위

1. 규칙 R1·R2와 그 상수는 전체 데이터를 열람한 초기 탐색(`code/press/cases/`)에서 착안해 정했다
   - 60초·2행: 예준 v2 사건·2단계 규칙 값
   - R² 0.5% 분위·8행: 정상 학습 자료
2. 이후 이 폴더에서 시간순 train/valid/test로 다시 평가했다. valid에서 선택 결과를 해시로 잠근 뒤 그 선택을 바꾸지 않고 test를 채점했다(재실행 결과 동일)
3. 잠금 규칙이 고른 모델은 v2+R1(test F1 A 1.000·B 0.9954)이다. 최종 모델 v2+R1+R2는 test 결과를 확인한 뒤 정했다
4. R2가 test에서 줄인 오경보 3행은 초기 탐색에서 이미 본 행이다
5. 이상 데이터는 약 3분(2분 46초)짜리 단일 고장 사건이라, 1.000은 이 사건에 대한 결과다

## 규칙과 판정 (판정 기준은 valid 단계에서 `tvt_selection.json`에 기록)

| 보고서 이름 | 코드 이름 | 내용 | test 판정 |
|---|---|---|---|
| R1 사건 지속 | H1 | 고장 상태는 수집 공백을 넘어 이어진다. 직전 기록이 확인된 이상이면 새 기록 첫 행부터 경보 유지 | 기준 충족 (미탐 A 22→0, B 16→0, 오경보 증가 없음) |
| R2 교차 확인 | H2 | 고부하 정상의 진동 크기 단독 초과는 전류 파형이 정상이다. 그런 경보는 보류(경보 없음) | 기준 충족 (B 오경보 3→0, 탐지 그대로) |
| 조건부 성분 | H3 | 예준 v3의 전류 조건부 진동 성분을 v2에 더하면 성능이 오른다 | 기준 미충족 (A 0.965→0.968, B 0.970→0.955) |
| 형식 누수 점검 | H4 | 진동 소수 자릿수만으로 이상을 가를 수 있다 → 정밀도 맞춤 필요 | 확인 (규칙 F1 0.994) |

## 결과 (α 1%)

| 모델 | valid F1 (A·B 평균) | test 실시간 F1 A / B | test 기록 판정 F1 A / B(행 가중) |
|---|---:|---:|---:|
| **v2 + R1 + R2** (최종, valid 공동 1위 3개 중 가장 단순) | 0.9982 | **1.000 / 1.000** | **1.000 / 1.000** |
| v2 + R1 (잠금 규칙의 선택) | 0.9973 | 1.000 / 0.9954 | 1.000 / 0.818 |
| 예준 v2 | 0.9635 | 0.965 / 0.970 | 1.000 / 0.818 |
| 예준 v1 | 0.9221 | 0.904 / 0.912 | 1.000 / 0.818 |
| v2 + v3 조건부 성분(C1) | 0.9635 | 0.968 / 0.955 | 1.000 / 0.736 |
| 예준 v3 B3k10 (기록 단위 트랙 선택) | 0.9928 | — | 0.889 / 0.954 |
| 예준 v3 C2d1 | 0.9211 | — | 0.934 / 0.934 |
| 예준 v3 B1 | 0.8978 | — | 0.796 / 0.701 |
| MLP-AE / 5NN / max\|z\| | 0.64 / 0.63 / 0.53 | 0.50 / 0.48 / 0.42 (평균) | — |
| 가이드북형 LSTM-AE / IsolationForest | 0.34 / 0.03 | 0.26 / 0.11 (평균) | — |

- valid 실시간 F1은 v2+R1+R2, v2+C1d1+R1+R2, v2+C2d1+R1+R2가 0.9982로 공동 1위다. v2+R1과의 valid 차이는 A 오경보 1행이다
- 선택 규칙(0.002 동률 → 단순한 쪽)은 v2+R1을 골랐다. 최종 모델 v2+R1+R2는 test 결과를 확인한 뒤 정했다
- v2 + R1이 B에서 1.000이 안 된 이유는 B test 오경보 3행(고부하 정상, 크기 단독, 파형 R² 0.995~0.998) 때문이다. 이 3행은 초기 탐색에서 이미 본 행이고, R2가 겨냥한 오류다
- 최종 모델의 α 민감도: B α 3% 오경보 1행(F1 0.9985), α 5% 9행(0.986)
- 예준 v3 기록 단위 모델은 valid에서 높았지만(B3k10 0.993) test에서 0.889~0.954로 내려갔다
