# 지도학습 재현과 세션 교락 시험

> 상위: [[제조데이터 경진대회 MOC]] · 코드 `code/press/domain/05_supervised_confound.py` · 수치 `outputs/05_supervised_confound.json`·`.csv`

**한 줄 결론**: 형식 누수를 지운 자료로도 라벨로 학습하면 F1 0.79~0.97이 쉽게 나온다(경쟁팀 0.944와 같은 수준). 그런데 같은 파이프라인이 **고장이 전혀 없는 같은 날 정상 구간끼리도** 간격이 1시간쯤 벌어지면 ROC-AUC 중앙값 0.75~0.87로 가른다. 이상-정상 분리(0.93~1.00)는 이보다 크고 한결같지만, 정상과 이상은 5일 떨어진 다른 세션이다. 따라서 지도학습 고득점으로는 '고장 탐지 능력'과 '세션(날짜·운전 조건·수집 설정) 구분 능력'을 가를 수 없다.

## 실행

```bash
cd code/press/domain
PYTHONIOENCODING=utf-8 python 05_supervised_confound.py            # 전체 (약 8분, 10프로세스 병렬)
PYTHONIOENCODING=utf-8 python 05_supervised_confound.py --md-only  # 이 문서만 다시 쓰기
```

- 모델: catboost가 설치돼 있지 않아 CatBoost 대신 **sklearn HistGradientBoosting**(HGB)을 썼다. RandomForest(RF)·LogisticRegression(LR)도 함께 돌렸다. 셋 다 class_weight=balanced, 문턱 0.5
- 검증: StratifiedGroupKFold 5겹(그룹 = 기록) × seed 10개(0~9). seed마다 OOF 확률을 모아 지표를 계산하고 평균 ± 표준편차를 냈다
- 표현: window = 기록 안 비중첩 1초(10행) 창의 센서별 mean/std/RMS/min/max 15개(정상 1820창/530기록, 이상 53창/17기록. 10행 미만 기록은 창이 없다). case = `common.case_table` 기록 특징 10개(n·t0 제외, 정상 600·이상 21기록)

- 형식 누수를 지운 matched 자료에서 window F1 0.793~0.924(PR-AUC 0.900~0.978), case F1 0.944~0.970이다. 경쟁팀 F1 0.944와 같은 수준이다
- 원본 그대로(raw)의 창 통계도 F1 0.790~0.921로 matched와 거의 같다. 창 통계를 받는 트리·선형 모델은 값의 크기로만 나누므로 자릿수 정보를 쓰지 못한다. **경쟁팀식 창 통계 점수는 자릿수 누수 때문이 아니다**
- 자릿수 특징을 넣으면 1.000에 붙는다. 자릿수 2개만으로도 F1 0.991~1.000이다. 원본 이상 파일 상부 진동은 98.7%가 7자리 이상이고, 정상은 0.005%다
- 형식 누수 통로가 하나 더 있다. **원본 이상 파일 전류는 100%가 1.1920929 격자 위**에 있고, 정상은 0.18%만 그렇다. matched에서는 둘 다 격자로 맞춰 지워진다

### 2a′. 블록 쌍 분리도 지도 — 시간 간격이 벌어지면 얼마나 갈리나

정상 기록 0~587을 21기록 블록 28개로 나누고, 모든 쌍 378개를 같은 파이프라인(seed 0)으로 분류했다. 같은 방식으로 이상 21기록 vs 각 정상 블록 28쌍도 분류했다.

| 표현 | 모델 | 정상 블록 쌍 AUC 중앙값 [10%, 90%] | 정상 쌍 AUC ≥ 0.9 비율 | 간격별 중앙값 (1 / 2-4 / 5-9 / 10-19 / 20-27 블록) | 이상 vs 정상 블록 AUC 중앙값 (최소) |
|---|---|---|---|---|---|

- 같은 날 정상끼리도 **간격이 벌어질수록 잘 갈린다**. 인접 블록은 중앙값 0.48~0.58(우연 수준)이다. 20~27블록(약 59분) 떨어지면 0.75~0.87까지 오른다. 정상 블록 쌍의 16%~20%가 AUC 0.9 이상이다
- 이상 vs 정상 블록은 중앙값 0.93~1.00이다. 정상끼리 분포의 84%~100% 분위로 상단에 있다. 약 1시간 떨어진 정상 쌍은 31%~44%가 AUC 0.9 이상이고, 그 상위 25% 경계는 0.91~0.99이다. 값의 크기만 보면 이상-정상 분리와 겹친다
- 차이도 있다. 이상은 정상 28블록 **모두**와 일관되게 갈린다(최소 0.912~0.998). 정상끼리는 같은 1시간 간격에서도 최소 0.22~0.32까지 내려가 들쭉날쭉하다. 즉 이상-정상 차이는 '같은 날 안의 표류'보다 크고 한결같다. 그 원인이 고장인지, 5일 간격 세션 차이인지는 이 비교로 가를 수 없다
- 정상과 이상은 **5일**(약 7,200분) 떨어져 있다. 이 데이터 안에서 볼 수 있는 최대 간격은 약 75분이고, 그 안에서 이미 분리도가 간격과 함께 커진다. 5일 간격의 세션 차이만으로 얼마가 나오는지는 이 데이터로 잴 수 없다. 이것이 교락의 핵심이다

### 2b. 고장과 무관해야 할 특징만으로 정상/이상 분류

근거(상세는 스크립트 docstring):

- **Tier 0 — 정의상 고장 무관(로거가 정하는 수집 메타데이터)**: 기록 길이 n, 직전 기록과의 공백 gap_prev, 기록 시작 시각의 0.1초 격자 위상(clock), 시작 시각을 0.6064 Hz 시계로 본 위상(tphase)
- **Tier 1 — 조건부 고장 무관(가정: 모터가 60 Hz 계통에 직결)**: 전류 절편/진폭 비, 전류 겉보기 주파수, 0.6 Hz 사인의 기록 시작 위상
  - 교류 전류는 물리적으로 평균이 0이다. 절편이 0에서 벗어나는 건 겉보기 주파수와 기록 길이가 맞지 않거나 센서에 DC 편차가 있을 때다
  - 겉보기 주파수는 60 Hz를 10 Hz로 찍은 앨리어스라서 전원 주파수와 표본화 간격이 정한다
  - 단, 인버터 고장처럼 실제 DC 성분을 만드는 고장도 있다. 또 이상 파일 전류는 사인 꼴이 아니라서(R² 중앙값 약 0.1) 주파수 추정치에 파형 붕괴가 함께 섞인다

- matched window 모델(HGB)은 상부진동 묶음(0.60)과 전류 묶음(0.25)에 기댄다. 단일 특징 상위 둘은 `up_std`·`cur_min`이다. 창 안 전류 최솟값·최댓값에는 사인 진폭과 **DC 오프셋**이 함께 담긴다. 이상 파일의 큰 오프셋은 2b의 Tier 1(세션 단서일 수 있는 값)과 같은 정보다
- matched case 모델(HGB)은 전류 파형 묶음(R²·잔차·절편 비, 0.56)에 거의 전부 기댄다. 이 값도 겉보기 주파수가 바뀌면(측정 타이밍 가설) 그대로 재현된다
- raw+digits 모델(HGB)에서는 자릿수 묶음이 0.90이고, 나머지 센서는 0에 가깝다. 쉬운 누수가 있으면 모델은 물리 신호보다 그것을 먼저 쓴다
- 가짜 라벨(앞/뒤 절반) 모델은 전류·진동의 크기와 모양을 고루 쓴다. 같은 날 안의 시간 표류도 센서 하나가 아니라 운전 상태 전반에 퍼져 있다

### 2d. 수집 조건 이동 반응 — 보고서 V5와 같은 조작을 지도학습 모델에

matched 지도학습 모델을 5겹 학습 겹으로 적합했다. 평가 겹의 정상 기록(17행 이상)을 조작해 넣고, 이상으로 판정된 기록 비율을 쟀다(window = 창 하나라도 p ≥ 0.5, case = 기록 p ≥ 0.5, seed 10개 평균).

| 조작 (정상 평가 기록, 17행 이상) | window 경보율 (HGB / RF / LR) | case 경보율 (HGB / RF / LR) | 보고서 V5 (우리 정상 학습 모델) |
|---|---|---|---|
| none | 0.003 / 0.002 / 0.036 | 0.000 / 0.000 / 0.000 | — |
| cur_shift_+81.4 | 0.555 / 0.288 / 0.469 | 0.001 / 0.000 / 0.000 | A 0/120 (0%) · B 7/180 (3.9%) |
| cur_shift_+272.4 | 0.852 / 0.913 / 0.968 | 0.001 / 0.000 / 0.000 | A 118/120 · B 180/180 |
| jitter_0.1ms_60.6Hz | 0.004 / 0.002 / 0.036 | 0.000 / 0.000 / 0.000 | A 8.8% · B 35.2% |

- 경쟁팀식 창 통계 모델은 **전류를 +81.4 옮기기만 해도 정상 기록의 29%~56%를 이상으로 판정**한다. 이 조작은 센서 오프셋·영점 변화 같은 수집 조건 변화에 해당한다. 같은 이동에서 우리 정상 학습 모델은 A 0%·B 3.9%였다(보고서 V5)
- 반대로 0.1 ms 표본화 시각 흔들림에는 창 통계 모델이 둔감하다(0.2%~3.6%, 조작 없을 때와 같은 수준). 창 통계는 위상·파형 정보를 보지 않는다. 우리 모델은 이 조작에 민감했다(A 8.8%·B 35.2%)
- case 지도학습 모델은 두 조작 모두에 둔감했다(+81.4 이동 0.0%~0.1%, 흔들림 0%). 이 모델은 이동에 둔감한 전류 사인 R²에 기댄다(2c). 0.1 ms 흔들림으로는 R²가 이상 수준(≤0.62)까지 떨어지지 않는다
- 어느 방식이든 **어떤 수집 조건 변화에는 민감하다**. 지도학습이라고 수집 조건 문제에서 자유롭지 않다. 민감한 방향만 다르다
- 비교 주의: V5는 시간순 test 정상 기록(A 120, B 180)을 1단계 경보 기준으로 쟀고, 여기서는 5겹 평가 겹의 정상 기록 469개를 쟀다. 흔들림 생성도 기록별 적합 주파수 대신 고정 F0(0.6064 Hz)를 썼다

## 3. 해석 — 왜 정상만 학습 + 형식 누수 제거 + 시간순 분할인가

1. **지도학습 고득점은 이 데이터에서 '고장 탐지 능력'의 증거가 될 수 없다.** 라벨(정상/이상)이 날짜·요일·시각대·저장 형식, 그리고 아마도 운전 조건과 완전히 겹친다. 이상 사건이 하나뿐이라 세션을 그룹으로 두면 이상 그룹이 1개다. 그래서 세션 단위 교차검증(leave-one-session-out)이 원리적으로 불가능하다. 기록 단위 그룹 CV는 같은 사건의 이웃 조각을 학습·평가 양쪽에 넣으므로 세션 단서를 막지 못한다
2. 같은 파이프라인이 **고장 없는 같은 날 정상 구간끼리도** 1시간 간격이면 AUC 중앙값 최대 0.87로 가른다(2a′). 앞/뒤 절반도 최대 0.69이다(2a). 5일 떨어진 세션끼리라면 고장이 없어도 높은 점수가 나올 수 있다. 관측된 이상-정상 분리(AUC 0.93~1.00)는 같은 날 표류보다 크고 한결같다. 하지만 5일 간격 세션 차이의 범위를 넘는지는 이 데이터로 판정할 수 없다
3. 가장 강한 분리 특징(전류 오프셋·겉보기 주파수·파형 R²)은 수집 타이밍 가설로도 설명된다(2b). 지도학습 모델은 실제로 여기에 기댄다(2c)
4. 그래서 우리 파이프라인은 세 가지를 택했다
   - **정상만 학습**: 라벨을 학습에 쓰지 않는다. 그러면 이상 세션 고유의 특이점(오프셋 크기, 자릿수, 격자 등)을 외워 맞히는 경로가 막힌다. 경보 기준은 정상 분포만으로 정한다. 가이드북이 안내하는 방식과도 같다
   - **형식 누수 제거**(정밀도 맞춤): 자릿수 2개만으로 F1 0.991이고, 전류 격자 비율은 100% 대 0.18%다. 지우지 않으면 어떤 모델이든 이것부터 쓴다(2c)
   - **시간순 분할**: 같은 날 안에서도 간격이 벌어질수록 분포가 달라진다(2a′). 무작위 분할이나 기록 단위 분할은 평가를 낙관적으로 만든다. 시간순 분할은 미래 구간에 대한 일반화를 그대로 잰다

## 4. 한계

- **정상만 학습한 우리 모델도 세션 차이를 완전히 배제하지 못한다.** 이상 점수는 '학습한 정상 분포에서 얼마나 먼가'를 잰다. 날짜나 수집 설정이 바뀐 정상도 멀게 나타난다. 보고서 V5에서도 **수집 조건에 민감**했다(전류 수준 +81.4 이동에 B 3.9%, 0.1 ms 표본화 흔들림에 정상 기록 경보율 A 8.8%·B 35.2%). 이상 파일의 전류 파형 붕괴가 고장 때문인지 계측 때문인지는 여전히 분리되지 않는다. Tier 1 결과와 같은 문제다
- 이 시험이 보인 것은 '지도학습 점수로는 가를 수 없다'까지다. '정상 학습이 고장을 잡았다'는 적극적 증거는 아니다. 이를 가르려면 같은 날·같은 수집 설정의 정상-이상 자료나, 다른 날 정상 자료(세션 간 표류 측정)가 필요하다
- 블록 쌍 지도는 75분 안의 표류만 잰다. 5일 간격으로 외삽하는 것은 검증할 수 없다. 블록 쌍은 seed 0 하나로 쟀다(쌍 378개가 반복 역할을 한다)
- 경쟁팀 CatBoost를 sklearn HGB로 대체했다. 창은 기록 안 비중첩 10행으로 정했다(경쟁팀의 정확한 창 구성은 확인하지 않았다). 수치가 같은 수준이라는 것이지 정확히 재현했다는 뜻은 아니다
- Tier 분류는 '직결 구동' 가정에 기댄다. 인버터 구동이면 겉보기 주파수가 운전 지령(운전 조건)에 따라 바뀐다. 그 경우에도 고장 고유 신호는 아니다
- 이상은 단일 사건(21기록, 약 3분)이다. 모든 지도학습 수치는 이 사건 하나에 대한 것이다
