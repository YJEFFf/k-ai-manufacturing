# 순차 검출 비교 · 불확실성 · 경보 운영 지표 (사후 분석)

> 상위: `code/press/tvt/README.md` · 산출: `outputs/04_sequential_uncertainty.json`(전체), `.csv`(비교 표), `_grid.csv`(검증 격자), `_delays.csv`(첫 경보 지연), `_ops.csv`(운영 지표)

> **test 채점 이후에 추가한 사후 비교다.** 잠금 선택(v2+R1)과 최종 모델(v2+R1+R2) 결정에는 영향이 없다. tvt/ 산출물은 읽기만 했고(캐시·선택 파일 해시 확인), CUSUM·EWMA 파라미터는 valid로만 고른 뒤 test를 그 값으로 한 번 채점했다.

## 요약

- **이득의 핵심은 상태를 수집 공백 너머로 넘기는 것이다.** 표준 CUSUM·EWMA도 기록 경계에서 상태를 이어 가면(carry, R1과 같은 60초 규칙) test 실시간 F1이 R1 수준으로 오른다: CUSUM-carry(k=5) A/B 1.000 / 1.000, EWMA-carry(λ=0.5) 1.000 / 0.998 (v2+R1 1.000 / 0.995, 최종 1.000 / 1.000). 기록마다 리셋하면 CUSUM 0.978 / 0.975, EWMA 0.976 / 0.976로 v2(0.965 / 0.970)에서 조금 오르는 데 그친다. v2의 test 미탐은 기록 첫 0~6행에 몰려 있어서(A 22행 중 20행, B 16행 중 16행) 기록 안에서만 쌓는 통계량은 첫 행을 구하지 못한다
- **그래서 이 데이터의 F1만으로는 R1이 표준 기법보다 낫다고 말할 수 없다.** 차이는 경보를 푸는 방식에서 난다. 고장 직후 정상 기록을 5초 간격으로 붙인 가상 흐름에서 R1은 7행(0.7초) 만에 풀렸고, CUSUM-carry는 2,920~3,068행(11.4~12.2분, 정상 기록 86~91개) 동안 경보가 이어졌다. EWMA-carry(λ=0.5)는 2~3행이었다
- CUSUM-carry가 고른 k=5는 **격자 끝값이고 보정이 퇴화했다.** k가 검증 정상 점수 최댓값(A 4.42, B 3.52)보다 커서 검증 정상 기록 최댓값이 전부 0(비율 A 100% · B 100%)이고, 문턱은 'S>0이면 경보'가 된다. 이때 실질 문턱은 α가 아니라 원점수 k=5다. B test에서 v2·v2+R1의 오경보 3행(점수 3.97~4.59)을 피한 것도 이 높은 문턱 때문이다
- 최종 모델의 test 결과는 표본이 작아 구간이 넓다. 정상 오경보 기록 0/120(A)·0/180(B)의 Clopper–Pearson 단측 95% 상한은 2.5%·1.7%로 설계값 α_grid 0.83%(=1/121)보다 크다. 이상 시험 기록 탐지 11/11의 단측 95% 하한은 76.2%(양측 71.5%)다
- 기록 단위 부트스트랩(10,000회)에서 최종 모델 F1 구간은 [1.000, 1.000]으로 퇴화한다. 오류가 하나도 없어서 다시 뽑아도 오류가 생기지 않을 뿐, 불확실성이 없다는 뜻이 아니다. v2는 A [0.946, 0.977]·B [0.948, 0.983], 최종−v2 차이는 A [0.023, 0.054]·B [0.017, 0.052]로 이 사건 안에서는 개선이 기록 재추출에 흔들리지 않는다
- **이상 시험 11기록은 한 고장 사건(2022-07-17 10:51:07부터 166초)의 연속 구간이다. 사건 단위 표본은 1이다.** 위 구간들은 모두 '이 사건 안에서'의 변동만 반영한다
- 정상 시험 구간은 측정 409초(A)·610초(B), 달력 16.1분·24.1분뿐이다. 최종 모델 경보 사건 0건의 포아송 95% 상한은 시간당 11.2건(A)·7.5건(B, 달력 기준), 측정 시간 기준이면 26.4건·17.7건이다. α 1% 기록 단위 보정을 연속 운전(시간당 약 447기록)에 옮기면 설계 오경보율은 시간당 3.7기록(교환가능성 가정, R2 보류·60초 묶음 전)이다. 이 데이터로는 0과 3.7을 구별할 수 없다

## 1. 순차 검출 비교 (α 1%, 실시간 행 단위)

- 입력 점수는 v2 결합 점수(성분별 −log10 꼬리확률의 최댓값). 검증 정상 행 평균 μ0 = 0.839(A)·0.850(B)
- CUSUM S_t = max(0, S_{t−1} + s_t − k), S_0 = 0 · EWMA z_t = λ s_t + (1−λ) z_{t−1}, z_0 = μ0
- reset: 기록마다 초기값 · carry: 직전 기록이 끝난 지 60초 안이면 상태를 이어 감(정상·이상 흐름 모두 기록 간격 최대 17초라 사실상 항상 이어짐)
- 문턱: 검증 정상 기록별 통계량 최댓값으로 conformal p(검증 정상 행은 LOO), p ≤ 1%이면 경보. 흐름·채점 행은 evalcore와 같다
- 파라미터: valid 실시간 F1(A·B 평균) 최고, 0.002 안 동률이면 큰 k·큰 λ. test는 고른 값 1회

## 3. 경보 운영 지표 (정상 시험 구간)

- A: 정상 시험 120기록 · 4,090행 → 측정 409.0초(6.8분), 달력 965.8초(16.1분, 첫~끝 타임스탬프) · 달력 기준 시간당 447기록

## 4. 해석 — R1과 CUSUM·EWMA는 무엇이 같고 다른가

**같은 점**

- 셋 다 한 행만 보지 않고 앞의 증거를 기억한다. carry 방식 CUSUM·EWMA는 R1과 같은 60초 규칙으로 수집 공백을 넘는다
- 이번 데이터에서 v2의 미탐은 거의 모두 기록 첫 몇 행이다. 기록 첫 0~4행은 파형 성분, 0~1행은 동역학 성분이 아직 없어 크기 성분만으로 판정한다. 수집 공백을 넘는 기억이 있으면 어떤 형태든 이 미탐을 없앤다. reset 방식이 v2보다 조금밖에 나아지지 않는 것이 그 반증이다

**다른 점**

1. **넘기는 것**: CUSUM·EWMA는 점수의 크기를 누적·평활해서 넘긴다. R1은 '확인된 이상'(자기 경보 2행 이상 또는 이어받은 경보 미해제)이라는 이진 상태만 넘긴다. 정상 기록의 오경보 1행은 다음 기록으로 넘어가지 않는다
2. **푸는 조건**: CUSUM·EWMA는 통계량이 문턱 아래로 감쇠할 때 풀린다. 감쇠 시간은 쌓인 양과 기억 길이에 달려 있어서 큰 고장일수록 늦게 풀린다(가상 접합에서 CUSUM 11~12분). R1은 새 기록에서 전류 파형이 정상이라는 반대 증거(prefix R² ≥ 기준)가 나오면 풀린다. 해제 시간이 고장 규모와 무관하고 최소 0.7초(8행)다. EWMA λ=0.5는 기억이 짧아(반감기 1행) R1보다 빨리 풀렸다(0.2~0.3초). 대신 기록 경계를 넘겨 주는 힘도 고장 점수 크기에 달려 있어, 점수가 문턱 근처인 약한 이상이면 다음 기록 첫 행까지 상태가 남지 않을 수 있다
3. **기록 안 동작**: CUSUM·EWMA는 기록 안에서도 평활하므로 새 사건의 첫 반응이 늦어질 수 있다(작은 λ, 큰 k). R1은 기록 안에서는 v2 그대로이고 기록 경계에서만 기억을 쓴다
4. **보정**: CUSUM·EWMA는 통계량마다 다시 보정해야 하고, carry 방식에서는 보정 기록의 통계량이 앞 기록 상태에 좌우된다. CUSUM k=5처럼 k가 정상 점수보다 크면 보정이 퇴화해 α가 의미를 잃는다. R1은 v2의 보정 문턱을 그대로 쓰고 상수 두 개(60초, 2행)만 더한다
5. **CUSUM이 유리할 수 있는 곳**: 문턱 아래의 작은 이탈이 오래 이어지는 서서히 시작되는 이상. 이번 사건은 점수 중앙값이 약 25(문턱 3.5~4.4의 6배 이상)인 급격한 이상이라 이 장점이 드러날 여지가 없었다

**운영 판단**: 이 데이터에서는 F1로 R1과 carry 방식 표준 기법을 가를 수 없다. EWMA-carry는 성능이 거의 같고 해제도 빨랐다. R1에 남는 장점은 해제가 점수 크기와 무관하게 '정상 파형 확인'에 묶여 있다는 점(고장 규모에 따라 경보가 길게 끌리지 않음)과 v2 보정을 그대로 쓴다는 점이다. CUSUM을 쓴다면 상한이나 정상 확인 리셋을 붙여야 하고, 정상 확인 리셋을 붙이면 해제 부분은 R1과 같은 구조가 된다

## 5. 한계

- test를 본 뒤 추가한 분석이다. CUSUM·EWMA 격자와 동률 규칙은 이번에 정했고 test 이후 바꾸지 않았다. R1·R2 상수 자체는 전체 데이터를 본 초기 탐색에서 착안했다(tvt README 경위 1)
- 고장 사건이 하나(급격한 이상)다. 다른 형태의 이상에서 순위가 바뀔 수 있다
- 고장 뒤 정상 복귀 구간이 데이터에 없다. 해제 동작은 가상 접합으로만 봤고, 접합 흐름은 실제 시간 순서가 아니다
- 정상 시험 시간이 측정 7~10분, 달력 16~24분이라 시간당 경보율 상한이 넓다
- A 시험 정상 기록이 B 시험 정상 기록에 포함돼 A·B는 독립 반복이 아니다
- Clopper–Pearson·부트스트랩은 기록 독립을 가정한다. carry·R1에서는 이웃 기록이 상태를 공유한다
- carry 방식의 LOO 보정은 자기 기록 최댓값만 빼고, 그 기록이 다음 기록 초기 상태에 준 영향은 남는다. EWMA 초기값 μ0도 검증 정상 전체 평균이다
- CUSUM-carry k=5는 격자 끝값이다. 격자를 넓혔다면 다른 값이 뽑혔을 수 있다
