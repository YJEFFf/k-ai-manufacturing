# MSPC 기준선: 창 특징 PCA + Hotelling T² / SPE

> **사후 비교다.** test 채점(`tvt/03_score_test.py`) 뒤에 덧붙였다. 잠근 선택(`tvt_selection.json`)과 최종 모델 v2+R1+R2(코드 이름 v2+H1+H2)는 바뀌지 않는다. 분할·평가 함수(`tvt/evalcore.py`)는 그대로 썼다. `(사후 변형)` 표시 모델은 주 사양의 test 결과를 본 뒤 검증 A 진단을 근거로 추가했으므로 참고용이다.

## 설정

- 행마다 같은 기록 안 그 행까지의 최근 8행 창(고정). 창 3행 미만(기록 위치 0·1)은 점수 없음 → 경보 없음
- 특징 7개: 상·하부 진동 창 RMS(log), 전류 RMS(log, 고정 F0 사인 진폭/√2), 상·하부 진동 lag-1 자기상관, 상·하부 진동 상관, 전류 사인 적합 잔차 비율(log). 전류 RMS는 창 표준편차 대신 사인 진폭을 썼다(정상 학습 기록에서 기록 RMS와 상관 0.99 vs 0.71)
- 창 길이(3~8행)별로 정상 학습 행 평균·표준편차로 표준화 → PCA(누적 분산 90%) → T²·SPE
- PCA 성분 수 k = 5 (A·B 같음, 누적 94.8%). PC1(분산 52%)은 진동·전류 크기와 하부 진동 자기상관이 함께 움직이고 전류 잔차 비율이 반대로 움직이는 부하 축이다
- 고전 한계 99%: T² 15.10(F 분포, 새 관측용), SPE 1.90(Jackson–Mudholkar, h0 = 0.266). 두 관리도 OR
- conformal: T²·SPE를 정상 학습 꼬리 확률(예준 ExpTail 식)로 바꿔 최솟값 → 검증 정상 기록 최댓값으로 보정, 검증 정상은 LOO
- 부하 정규화(mspc_load): 창 길이별로 진동 RMS z를 전류 RMS z에 정상 학습 OLS 회귀한 잔차를 재표준화해 대신 쓴다

## 해석

### 1. 고전 관리 한계는 행 단위로는 잡지만 기록 단위 운영에는 못 쓴다

- 이상 시험 행은 창이 3행 이상이면 99% 한계를 100% 넘는다(A·B 모두 모든 이상 기록의 위치 2에서 첫 경보). 문제는 정상 쪽이다
- 정상 학습 행(표본 안)에서도 OR 초과율이 A 3.3% · B 3.2%로 명목치(약 2%)보다 높다(SPE 단독 2.0%, 명목 1%). 창이 겹쳐 행끼리 자기상관이 있고, 특징이 정규분포가 아니며, 부하가 두 상태로 갈리는 이봉 분포라 가우시안 PCA 한 개의 가정이 깨진다
- 기록 하나에 평균 30여 행이 있어 행 단위 1% 한계를 기록마다 수십 번 검정하는 셈이다. 검증 정상 기록의 49%(A)·45%(B), 시험 정상 기록의 75%·68%가 한 행 이상 한계를 넘는다 → 기록 단위 F1 0.163 / 0.127
- 시험 정상 행 초과율은 A 10.4% · B 7.4%로 검증(3.3% · 3.0%)의 2~3배다. 4절의 운전 조건 변화(저부하 기록 비중 증가, 저부하 상태 안의 이동) 때문이다
- R1(사건 지속)을 얹으면 오경보가 다음 정상 기록으로 번져 더 나빠진다(고전 + R1 test 실시간 F1 0.435 / 0.412). 검증 정상 기록 최댓값으로 보정하는 conformal은 이 다중 검정 문제를 구조적으로 막는다

### 2. conformal MSPC: B는 쓸 만하고, A는 짧은 창 하나가 문턱을 정해 민감도를 잃는다

- α 1%, 검증 정상 120기록이면 문턱은 검증 정상 기록 최댓값 중 가장 큰 값이다. A는 원 기록 443 (`valid:normal:83`) 13.3(2위 5.2), B는 원 기록 306 5.4
- A의 기록 443은 4행짜리이고 최댓값은 창 3행(위치 2)에서 나왔다. 짧은 창의 3점 사인 적합으로 추정한 전류 진폭이 거의 0이 돼 전류 RMS z = -6.9, SPE 30.6(99% 한계 1.9)이 됐다. 정상 학습에서도 짧은 창의 점수 꼬리가 두껍다(점수 99.9% 분위: 창 3행 9.3, 창 5행 4.2, 창 8행 3.1)
- 그래서 A는 이상 시험 행 중 창 8행이 찬 행도 122/250만 잡는다(B 237/250). 기록 443은 B에서는 시험 정상이라 B 주 사양의 유일한 오경보 1행이 된다
- 사후 변형 `mspc_nt`(꼬리 확률을 창 길이별 정상 학습 분포로 계산)는 이 문제를 없앤다. 검증 A 실시간 F1 0.590 → 0.918, test 0.917 / 0.920. A 보정 최댓값은 3.78로 내려간다. 배치 MSPC에서 시점별 관리 한계를 쓰는 것과 같은 처방이다

### 3. 기록 시작 직후가 MSPC의 가장 큰 약점이다

- 위치 0·1은 창이 없어 점수 자체가 없다. 이상 시험 324행 중 22행(11기록 × 2행)이 구조적으로 미탐이다. v2는 크기 성분으로 이 위치에서 A 8/22 · B 10/22를 잡는다
- 창 3~7행(위치 2~6) 이상 행 탐지: mspc A 3/52 · B 33/52, mspc_nt A 31/52 · B 30/52, v2 A 46/52 · B 48/52. 짧은 창은 RMS·상관·자기상관 추정이 흔들려 정상과 겹친다
- 이상 시험 기록별 첫 경보 위치(규칙 없음): mspc_nt A [None, 4, 3, 3, 4, 3, 4, 4, 6, 4, 4] · B [None, 4, 3, 3, 4, 3, 4, 4, 6, 5, 4], v2 A [0, 0, 1, 2, 0, 2, 0, 1, 3, 2, 3] (None = 그 기록 안에서 못 잡음)
- R1(사건 지속)을 얹으면 직전 기록 판정이 시작 직후 행을 덮어 test 실시간 F1이 mspc + R1 1.000 / 0.998, mspc_nt + R1 0.994 / 0.998까지 오른다. 이 이득은 이상 21기록이 한 사건이라서 생긴다

### 4. 고부하 정상에는 강하고, 저부하 정상(특히 시험 구간)에서 흔들린다 — v2와 반대

- 고전 한계의 시험 정상 오경보: 고부하 A 15/818행 · B 34/1963행, 저부하 A 361/3052행 · B 361/3812행. 오경보 대부분이 저부하 기록에서 난다
- 시험 구간에서 저부하 기록 비중이 크게 늘었다. 고/저부하 기록 수 A 학습 178/101, 검증 61/33, 시험 21/75. 시험 저부하 행은 학습 저부하보다 상부 진동 lag-1(평균 z -0.61 vs -0.01)과 상·하부 상관(-1.28 vs -0.39)이 낮다. 고전 99% 초과율은 학습 저부하 6.5% → 시험 저부하 12.4%(고부하 1.5% → 1.9%)
- v2의 B 시험 오경보 3행(고부하 정상, 진동 크기 단독)에서 conformal MSPC p는 0.4132, 0.9339, 0.1983로 경보가 아니다. 단일 표본 |z| 대신 8행 창 RMS를 보므로 한 표본 튐에 둔하다. conformal MSPC의 시험 고부하 정상 오경보는 A 0 · B 0행이다. 다만 고전 99% 한계로는 그 3행 중 2행이 한계를 넘는다(행 단위 한계는 여기서도 예민하다)
- 부하 정규화: 정상 학습에서 하부 진동 RMS는 부하로 잘 설명되고(창 8행 R² 0.84, 기울기 0.92) 상부는 약하다(R² 0.21). 정규화는 A 실시간을 올렸지만(검증 0.590 → 0.687, test 0.557 → 0.714) test B 기록 F1을 떨어뜨렸다(0.988 → 0.781). 하부 진동 잔차의 표준편차가 작아 시험 저부하 구간의 작은 관계 이동도 크게 보인다. 모델을 조일수록 느린 운전 조건 이동에 민감해지는 MSPC의 전형적인 맞교환이다

### 5. 무엇이 이상을 만드나 — 기여 분석 (이상 시험 행, 창 3행 이상)

- A: 평균 T² 95(정상 시험 7.8), 평균 SPE 23(정상 0.48). T² 기여 상위: 전류 사인 잔차 비율 26.6(26%), 상부 진동 RMS 25.3(26%), 하부 진동 lag-1 14.5(15%), 하부 진동 RMS 9.7(10%). SPE 기여 상위: 하부 진동 RMS 12.1(44%), 전류 사인 잔차 비율 8.1(39%), 전류 RMS(부하) 1.9(12%). 괄호는 행별 기여 비율의 평균
- B: 평균 T² 99(정상 시험 6.8), 평균 SPE 23(정상 0.45). T² 기여 상위: 전류 사인 잔차 비율 29.2(28%), 상부 진동 RMS 24.8(25%), 하부 진동 lag-1 16.2(16%), 전류 RMS(부하) 9.6(10%). SPE 기여 상위: 하부 진동 RMS 12.0(44%), 전류 사인 잔차 비율 7.7(38%), 전류 RMS(부하) 1.9(12%). 괄호는 행별 기여 비율의 평균
- 이탈 방향(A, 평균 z): 전류 사인 잔차 비율 +7.1, 전류 RMS -2.8, 상부 진동 RMS +1.6, 상·하부 상관 -1.4, 상부 lag-1 +1.2, 하부 진동 RMS -0.2
- 읽는 법: 전류 파형이 사인에서 크게 벗어나고 진폭이 줄었는데, 하부 진동은 부하를 따라 줄지 않았다. 정상에서는 하부 진동이 전류를 강하게 따르므로 이 관계 깨짐이 SPE의 하부 진동 RMS 기여로 나타난다. 부하 정규화 모델에서는 같은 신호가 하부 진동 잔차의 T² 기여 76(41%)로 바로 드러난다. 상부 진동은 커지고 상·하부 상관은 낮아졌다
- 가장 큰 기여(전류 파형)는 앞선 사후 분석에서 측정 타이밍 차이(이상 파일 전류 겉보기 주파수 0.19 Hz vs 정상 0.60 Hz)로도 설명됐다. MSPC도 고장과 계측 차이를 가려 주지는 못한다

### 6. 요약 판단

- MSPC 주 사양(conformal) test 실시간 F1 0.557 / 0.908: v2(0.965 / 0.970)보다 낮고 베이스라인 max|z|(0.404 / 0.428)보다 높다
- R1을 얹은 mspc + R1은 test 실시간 1.000 / 0.998로 최종 모델(1.000 / 1.000)에 가깝다. 그러나 valid (0.949 / 0.978 vs v2+R1+R2 0.998 / 0.998)와 α 5%에서 뒤처지고, test 성적의 대부분은 R1이 만든다
- 강점: 고부하 정상의 단일 표본 튐에 오경보가 없다. 그래서 B 기록 단위 F1은 MSPC conformal 0.988, v2 0.818로 MSPC가 높다(v2는 고부하 오경보 3행이 기록 3개를 통째로 오판). 창 8행이 찬 뒤 이상 행 탐지율이 높다(B mspc 237/250, mspc_nt A 247/250 · B 247/250). 기여 분석으로 어느 변수 관계가 깨졌는지 설명할 수 있다
- 약점: 기록 시작 0~1행은 점수가 없고 2~6행은 둔하다. 행 단위 고전 한계는 기록 단위 운영에 맞지 않는다. 운전 조건이 학습과 달라지면(시험 구간 저부하 증가) 오경보가 는다. R1은 기반 탐지기의 오경보가 많으면 오경보도 이어 붙인다(α 5% test A: mspc + R1 0.856 < mspc 0.905)
- 최종 모델 v2+R1+R2와 같은 방향의 결론: 시작 직후는 크기 성분과 사건 지속이 필요하고, 크기 단독 경보는 다른 축(파형·상관 구조)으로 확인해야 한다

## 한계

- test 채점 이후의 사후 비교다. 특히 `mspc_nt` 변형은 주 사양의 test 결과를 본 뒤 추가했다(근거는 검증 A 진단이지만 test 독립성은 없다)
- 이상 자료는 약 3분짜리 단일 사건(21기록)이다. 기여 순위와 F1은 이 사건에 대한 값이다
- 고전 한계의 가정(독립·정규·단일 운전 상태)은 겹치는 창과 이봉 부하 분포 때문에 성립하지 않는다. 결과는 가정이 깨졌을 때 교과서 한계가 실제로 어떻게 동작하는지로 읽어야 한다
- PCA와 꼬리 참조를 같은 정상 학습 행에서 만들었다(표본 안). 최종 문턱은 검증 정상 conformal 보정이 정한다
- R2(교차 확인)는 크기 성분 열이 필요해 MSPC에는 적용하지 않았다. 부하 상태(고/저)는 기록 전체 전류로 매긴 사후 진단값이라 실시간에는 쓸 수 없다
- 창 길이 w = 8는 고정값이다. 민감도 표처럼 A 결과가 w에 크게 흔들리는데, 원인은 2절의 짧은 창 꼬리 문제다
