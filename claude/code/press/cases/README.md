## 결과 (α = 1%, 예준과 같은 분할·평가 행)

| | A 행 F1 | B 행 F1 | 미탐 A/B | 오경보 A/B |
|---|---:|---:|---:|---:|
| 예준 v2 | 0.9619 | 0.9710 | 44 / 31 | 0 / 3 |
| + 교차 확인 | 0.9619 | 0.9735 | 44 / 31 | 0 / 0 |
| + 사건 지속 | 0.9992 | 0.9975 | 1 / 0 | 0 / 3 |
| **+ 둘 다 (실시간)** | **0.9992** | **1.0000** | 1 / 0 | 0 / 0 |
| **+ 둘 다 (기록 단위 판정)** | **1.0000** | **1.0000** | 0 / 0 | 0 / 0 |

- 실시간 A의 미탐 1행은 이상 사건의 맨 첫 표본(10:51:07.943)이다. 값 하나만으로는 정상과 구별되지 않는다(점수 4.19 < 문턱 4.68).
- α 3%: 실시간 A 0.9992 · B 0.9967, 기록 단위 둘 다 1.000. α 5%: 실시간 B 0.982, 기록 단위 B 0.927 (`outputs/metrics_fixed.csv`).

## v2가 틀린 이유

1. **미탐 = 기록 시작 직후.** 미탐 A 44행 중 26행, B 31행 중 20행이 기록 위치 0~1이다. 이 행들은 과거 행이 없어 파형·예측오차 성분이 계산되지 않고, 크기 성분만 남는다. 그런데 이상 기록 상당수(3·19·20 등)는 진동이 오히려 작다.
2. **v2는 기록마다 기억을 지운다.** 이상 21기록은 3분짜리 한 사건이 1.8~8.6초 수집 공백으로 잘린 조각이다. 바로 앞 기록이 이상이었다는 정보를 쓰지 않았다.
3. **오경보 = 고부하 정상에서 진동 크기 하나만 튐.** B 오경보 3행(기록 423·461·570)은 모두 크기 성분 단독이었고, 그 시점 전류 파형은 완전 정상(prefix R² 0.995~0.998)이었다.

## 수정 규칙

- **사건 지속**: 직전 기록(60초 안)이 '확인된 이상'(경보 2행 이상)이면 새 기록은 첫 행부터 경보를 유지한다. 직전 기록 판정만 쓰므로 실시간 가능. 새 기록의 전류 파형이 정상으로 확인되면(8행 이상, prefix R² ≥ 정상 학습 0.5% 분위) 해제한다.
- **교차 확인**: 크기 성분 단독 경보인데 전류 파형이 정상이면 경보를 보류한다. 파형을 볼 행(8행)이 아직 없으면 경보를 그대로 둔다.
- 60초·2행은 예준 v2의 사건·2단계 규칙 값을 그대로 썼다. 새로 맞춘 값은 R² 기준(정상 학습 자료로만 결정)뿐이다.

## 케이스 특징 (`01_case_features.py`)

- 10행 이상 기록에서 **전류 사인 R²·잔차 비율은 정상과 이상을 완전히 가른다**(AUROC 1.000, 이상 17/17이 정상 범위 밖). 진동 lag-1 0.95, 상·하부 상관 0.86, 진동 크기 0.83~0.84.
- **정상 날에 전조는 없다.** 이상 서명 2개 이상인 정상 기록 3개는 R² 0.982~0.986으로 경계값 바로 밑이고, 이상(≤0.62)과는 거리가 멀다.
- **고장 직전 자료는 이 데이터에 없다.** 정상(7/12)과 이상(7/17) 사이 5일이 비어 있고, 이상 파일 첫 기록부터 이미 이상 서명이 있다. 이상 3분 안에서는 진동이 작아지고 전류 반송파가 거의 사라지는 기록(11·12·19·20)이 섞여 있다.
- **저장 형식 누수**: 진동 소수 자릿수 > 6 규칙 하나로 행 F1 0.992 (`leak_demo.json`). 위 분석은 전부 matched 정밀도로 형식 차이를 지운 뒤 계산했다.

## 한계

- 두 수정 모두 v2의 오답을 본 뒤 만든 사후 규칙이다. 이상 사건은 하나뿐이라 새 고장에서 1.000이 나온다는 근거가 아니다.
- '사건 지속'의 이득은 이상 21기록이 한 사건이라서 생긴다. 고장이 짧게 한 번 나오는 현장에서는 이득이 작다.
- 가장 강한 분리 특징(전류 파형)은 측정 타이밍 차이로도 재현된다(이상 파일 전류 겉보기 주파수 0.19 Hz vs 정상 0.60 Hz). 고장인지 계측 차이인지는 여전히 분리되지 않는다.
