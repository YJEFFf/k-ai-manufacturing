# 데이터 진단 (자동 생성)

## 1. 구조

| 항목 | 정상 | 이상 |
|---|---|---|
| 행 | 20,000 | 600 |
| 기간 | 07-12 00:00:00 ~ 01:16:55 | 07-17 10:51:07 ~ 10:53:53 |
| 기록구간(0.1초 아닌 간격에서 끊음) | 600 | 21 |
| 구간 길이 최소/중앙/최대 | 1/37/50 | 3/28/50 |
| 중복 타임스탬프 | 1 | 0 |
| 결측 | 0 | 0 |
| `Equipment_state` | 전부 [0] | 전부 [1] |

- 10Hz라면 20,000행은 33분 분량인데 실제 기간은 77분 → 기록 공백이 많다. 연속 창은 기록구간 안에서만 만든다
- 정상·이상이 서로 다른 하루씩이라 **날짜·운전조건 차이와 고장 차이를 분리할 수 없다**. 모든 성능은 제공 라벨 기준이다

## 2. 저장 형식 차이 (지름길)

- 상부 진동: 저장 자릿수 최빈값 정상 6자리, 이상 8자리 · 1e-6보다 세밀한 값 비율 정상 0.0%, 이상 98.7%
- 하부 진동: 저장 자릿수 최빈값 정상 6자리, 이상 8자리 · 1e-6보다 세밀한 값 비율 정상 0.0%, 이상 99.2%
- 전류가 1.1920929 격자 위에 있는 비율: 정상 0.2%, 이상 100.0%
- 형식만 보는 규칙의 F1: 전류 격자 0.972, 진동 자릿수 1.000 → 두 날짜를 같은 양자화로 맞추면 0.057, 0.000
- 재양자화 후 max-z·5NN·RMS 36설정 F1 최대 변화 0.005 → 크기 기반 모델은 형식 지름길을 쓰지 않는다
- 원자료 문자열·소수부를 읽는 모델은 이 지름길로 F1≈1을 낼 수 있다 → 비교 시 주의

## 3. 전류 파형 (10Hz로 찍힌 60Hz 교류)

| | 구간 수(길이≥10) | 사인 R² 최소~최대 | 앨리어싱 주파수 중앙값(Hz) |
|---|---|---|---|
| 정상 | 530 | 0.993 ~ 1.000 | 0.600 |
| 이상 | 17 | 0.291 ~ 0.783 | 0.220 |

- 정상 전류는 거의 완벽한 사인파, 이상 구간은 모두 사인파에서 벗어난다. 고장 때문인지 이상일 수집 설정 차이 때문인지는 분리 불가
- 타임스탬프 간격은 두 파일 모두 명목 100ms라 실제 샘플링 간격으로 앨리어싱 주파수를 검증할 수 없다
