# 가상 불량 주입 벤치마크

> `code/04_injection_benchmark.py` 자동 생성. **시뮬레이션 기반 검증이며 실제 불량 탐지 성능이 아니다.**
> 원본 2,177행, 원본 구간 5겹 분할, 시드 5개. 임계값은 학습 구간에 따로 주입한 데이터에서 F1 최대로 정하고 평가 구간에 적용.

## 1. 결함 모델 (가정)

| 유형 | 조작 | small / medium / large |
|---|---|---|
| 용접부족 | 전류 감소, 통전시간 감소 | 전류 −[0.01, 0.025, 0.05], 시간 −[0, 1, 3] ms |
| 파임 | 가압력·전류 증가, 가압력 1bar당 저항 1% 감소 | 가압력 +[0.15, 0.4, 1.0] bar, 전류 +[0.005, 0.01, 0.02] |
| 크랙/날림 | 전류 급등 + 동저항 급락 | 전류 +[0.01, 0.025, 0.05], 저항 −[0.01, 0.02, 0.04] |

## 6. 해석 시 주의

- 결함 크기·형태는 가정이다. 결과는 '이런 종류의 이탈을 얼마나 잘 잡는가'이지 이 공장의 실제 불량 탐지율이 아니다.
- 결함 모델을 바꿔도 순위가 유지되는지(강건성)는 PARAMS를 바꿔 재실행해 확인한다.
