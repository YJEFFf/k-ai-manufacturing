## 최종 모델: v2 + R1 + R2

- **기반 모델 v2(Press Guard):** 정상 자료만으로 학습합니다. 0.1초마다 크기·파형·동역학 세 성분을 계산하고, conformal 문턱(α 1%)을 넘으면 경보합니다.
- **R1 사건 지속:** 켜진 경보를 이어 가서 기록 시작 직후의 미탐을 줄입니다(test 미탐 A 22행·B 16행 → 0행). 첫 경보를 만들지는 못하고, 앞단 모델의 오경보도 함께 이어 갑니다.
- **R2 교차 확인:** 고부하 정상에서 크기 성분만 커질 때 나는 경보를 전류 파형으로 한 번 더 거릅니다. 분할 B, α 5%에서 고부하 오경보 기록이 9/53에서 1/53으로 줄었습니다.
- valid에서 해시로 잠근 선택 규칙은 v2+R1을 골랐습니다. 최종 모델 v2+R1+R2는 test 결과를 확인한 뒤 정했습니다(보고서 2.5절).
- v1·v2·v3는 이 과제를 위해 먼저 만든 모델 계열입니다. 보고서는 v2를 기반 모델로 쓰고, v1·v3는 같은 조건의 비교(2.4절)와 검증 틀(2.6절)에 씁니다.
- 추가 센서 없이 진동 2채널과 전류 1채널로 동작합니다. 경보는 사건 단위 2단계(주의, 점검 요청)로 묶습니다. 경보 근거별 점검 순서, 품질 조치, 경보량 목표, 재보정 절차는 보고서 4장에 있습니다.

## 주요 결과

아래 표는 test 구간의 행 단위 결과입니다. 모든 모델을 같은 시간순 분할과 같은 보정(α 1%)으로 채점했습니다(보고서 2쪽 표).

| 모델 | 실시간 행 F1 A / B | 미탐 행 A / B | 오경보 행 A / B |
|---|---:|---:|---:|
| MLP 오토인코더(베이스라인 최고) | 0.498 / 0.498 | 216 / 216 | 2 / 2 |
| 기반 모델 v2 | 0.965 / 0.970 | 22 / 16 | 0 / 3 |
| v2 + R1 (잠금 규칙의 선택) | 1.000 / 0.995 | 0 / 0 | 0 / 3 |
| v2 + R1 + R2 (최종, test 확인 후 선정) | 1.000 / 1.000 | 0 / 0 | 0 / 0 |

결과를 읽을 때는 다음 조건을 함께 봐야 합니다.

- 1.000은 약 3분 동안 이어진 고장 사건 하나에서 나온 결과입니다. R1만 붙여도 베이스라인이 test 0.982~1.000에 이르므로, 베이스라인과 v2의 우열은 R1을 붙이지 않은 값으로 판단합니다(2.4절).
- R1·R2는 전체 데이터를 본 뒤 착안했고, 최종 모델은 test를 확인한 뒤 정했습니다(2.3·2.5절).
- 오경보 0/120·0/180의 95% 상한은 2.47%·1.65%입니다(참고값).
- R2를 쓰면 진동 단독 주입의 탐지율이 최대 23.7%p 낮아집니다. 진폭 감소나 수집 조건 변화에는 모델이 약합니다(2.6·3.6절).

## 재현

제출 코드 zip을 푼 폴더에서 실행합니다. 파이썬 3.13이 필요하며 GPU는 쓰지 않습니다.

```bash
python run_all.py            # 전체: 전처리 → 학습 → 추론 → test 예측 → 보고서 수치 대조 26개 (약 56분)
python run_all.py --quick    # 핵심만: 대조 19개 (약 13분)
```

- 새 가상환경에서 대조 26개가 모두 일치했습니다(Windows 11, 전체 55.7분). macOS와 Linux에서는 실행해 보지 않았습니다.
- zip은 레포 루트에서 `python claude/submission/make_package.py --repo .`로 다시 만듭니다. 그 전에 원본 CSV 2개를 `claude/data/3_소성가공_예지보전/`에 넣어 둡니다.
