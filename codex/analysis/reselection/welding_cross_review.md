# ② 용접 추가자료 51·52·57 독립 교차검토

2026-09-22. 실제 로컬 가이드 PDF의 본문·실습코드를 대조했다. 아래 원본 행 수·분포는 **가이드에 제시된 내용**이며, 이 문서를 작성한 검토자가 별도로 ZIP 전체를 읽어 재현한 결과는 아니다. PDF 쪽수는 뷰어 기준이다. 52번 PDF 24쪽은 이미지로 직접 렌더링해 표를 확인했다.

## 판단

**세 자료가 대회 ② 점용접 원본의 건별 불량 정답 부족을 해결한다는 근거는 없다.** 다른 공정에서 검증할 수 있는 사례와 기법이 추가된 것이다. 51·52는 강철 파이프 용접, 57은 배터리모듈 레이저 용접이다. 그 라벨을 대회 원본의 개별 행으로 옮길 연결키나 실측 대응관계가 확인되지 않았다.

## 1. 51번 용접 예지보전

### 확인된 문제

1. **공개된 정상/이상 분포는 5개 센서 모두 완전히 떨어져 있다.** PDF 9쪽 표를 옮기면 다음과 같다.

   | 센서 | 정상 최소~최대 | 이상 최소~최대 |
   |---|---:|---:|
   | DV_R | 308~323 | 250~260 |
   | DA_R | 7,934~8,653 | 6,800~7,300 |
   | AV_R | 357~370 | 250~304 |
   | AA_R | 5,948~50,000 | 3,800~4,500 |
   | PM_R | 9,270~10,710 | 4,700~5,200 |

   이 표가 배포 원본과 일치한다면 `DV_R<284` 같은 단일 임계값만으로 해당 전체 표본을 분리할 수 있다. **이는 표에서 도출한 결과이지 원본으로 실행한 성능이 아니다.** LSTM F1 1.0만으로 복잡한 시간 패턴을 학습했거나 초기 고장을 예측했다고 볼 수 없다. 최소한 단일 센서 규칙·단순 다변량 경계와 비교해야 한다.

2. **FIN_JGMT 의미가 실습 중 반전된다.** PDF 9–10쪽은 1=양품, 0=불량인데 PDF 25쪽은 정상 파일 전체를 0, 이상 파일 전체를 1로 덮어쓴다. 이 변환을 기록하면 이상검출 지표의 positive class를 1로 맞추는 정상적인 재부호화일 수 있다. 반전 자체가 오류는 아니다. 다만 원본 FIN_JGMT 값을 검사하지 않고 파일 구분으로 전체를 덮어쓰므로, 실제 파일 안에 다른 라벨이 섞여 있으면 이를 숨긴다. 파일 내용 대조가 필요하다.

3. **학습 목표와 이상 점수 비교 대상이 코드상 다르다.** PDF 30쪽에서 입력은 `[i:i+20]`, 학습 목표는 미래 `[i+40:i+60]`이고 PDF 34쪽은 `fit(X_train,Y_train)`이다. 그러나 PDF 36–37쪽 이상 점수는 예측 결과의 마지막 값과 **미래 Y가 아니라 입력 X의 마지막 값**을 비교한다. 따라서 제시된 점수는 미래 예측오차가 아니다. 재구성형으로 쓰려면 X→X로, 미래 예측형으로 쓰려면 예측→Y로 학습·평가 정의를 일치시켜야 한다.

4. **검증/테스트 윈도우가 겹친다.** PDF 30쪽에서 1행씩 이동하는 윈도우를 먼저 만들고 PDF 31쪽에서 앞 4,000개 정상 윈도우·1,200개 이상 윈도우를 검증, 나머지를 테스트로 나눈다. 경계의 인접 윈도우 두 개만 비교해도 입력 20개 중 19개, 목표 20개 중 19개가 같다. 검증에서 임계값을 정하므로 최종 테스트의 독립성이 약해진다.

5. **파일 연결 시 실제 시간·제품 경계가 보존되는지 코드에서 보장하지 않는다.** `normal_data`와 `outlier_data`를 각각 순서대로 윈도우화하며 `PIPE_NO`나 작업 중단 경계를 검사하지 않는다. 이상을 제거한 정상 파일의 연속 행이 실제로 연속 시간이라는 보장은 원본을 확인해야 한다. '불량 상태 관측 후 탐지'와 '발생 전 경보'도 구별해야 한다.

### 비판의 범위를 제한해야 하는 부분

- 학습/테스트 전체에 윈도우 중복이 있다고 단정하면 틀린다. PDF 29쪽은 정상 원시행의 60,000번째 경계를 먼저 나누고 각각 윈도우를 만든다. **확인된 경계 중복은 검증/테스트 쪽**이다.
- 정규화도 PDF 30쪽에서 학습 정상 자료에만 fit하고 평가에는 transform하므로, 이 단계에 전체 데이터 정규화 누수라는 비판을 붙이면 안 된다.
- PDF 36–37쪽 임계값은 별도 검증 자료에서 선택한다. 문제는 윈도우 경계 중복 및 학습 목표와 점수 정의의 불일치이지, 코드가 곧바로 최종 테스트 정답으로 임계값을 고른다는 것은 아니다.

## 2. 52번 용접 공정최적화

### 739,888행을 739,888개의 독립 검사 제품으로 볼 수 없다

- PDF 8쪽에서 공정을 **서브머지드 아크 용접**으로 설명한다. 대회 원본의 점용접과 다른 공정이다.
- PDF 9쪽: 739,888행×7열, `PIPE_NO`는 제품번호, `FIN_JGMT`는 1=양품·0=불량이다.
- **PDF 24쪽의 출력 이미지를 직접 확인했다. `PIPE_NO.value_counts()` 길이는 303이다.** 가장 많은 제품번호는 7,922행이며, 6,684·6,508·6,450·6,230행의 제품들도 보인다. 적은 예시도 24행이다. 따라서 가이드에서 이미 제품별 반복 측정이 확인된다.
- PDF 32쪽은 `train_test_split(...,shuffle=True)`로 행을 섞는다. 이 코드는 동일 파이프의 측정을 학습과 평가에 나누므로, 미관측 제품에 대한 성능과 구별해야 한다. 적절한 단위는 먼저 `PIPE_NO` 그룹이며, 공정 시간이나 생산일이 확인되면 미래 제품 평가를 추가한다.
- 제품번호별 라벨이 한 가지로 일정한지, 제품 전체 검사 결과를 모든 측정 행에 전파했는지, 구간별 결함을 독립 검사했는지는 가이드의 설명만으로 확정할 수 없다. **파이프 내 반복 측정은 확정, 라벨 전파 방식은 미확인**이다.

### 'F1 0.9753'은 불량 클래스 F1이 아니다

- PDF 37쪽의 `f1_score(y_test,dt_pred)`는 `pos_label`을 지정하지 않는다. FIN_JGMT=1이 양품이므로 이는 **양품 F1**이다.
- PDF 38쪽: 의사결정나무의 정답 양품 183,004개, 정답 불량 29,710개, F1 0.9753, 정확도 0.9583을 제시한다.
- 안내된 739,888행의 30% 테스트는 221,967행이다. 위 두 대각원소를 사용하면 오분류 합은 9,253개이므로 불량 클래스 F1은 `2×29,710/(2×29,710+9,253)≈0.8653`이다. 양품 F1은 같은 방식으로 약 0.9753이 되어 표기와 부합한다. **이는 가이드 숫자의 산술 대조이며 새 모델 실행 결과가 아니다.**
- PDF 28쪽은 전체 자료의 2~98백분위로 센서를 절삭한다. 분할 후 학습 자료에만 적용해야 하는 전처리와 구분해야 한다.
- PDF 37쪽의 `confusion_matrix(dt_pred,y_test)`는 일반적인 참값/예측값 순서와 반대이고 축 제목은 일반 순서다. 대각선 정답 수는 같지만 FP/FN을 읽을 때 방향이 바뀐다.
- PDF 40쪽 LightGBM 혼동행렬 시각화는 계산한 `lgbm_cm` 대신 `xgb_cm`을 그린다. 해당 그림을 새 분석의 독립적인 LightGBM 결과로 인용하면 안 된다.

### 품질 라벨의 실제 수집 근거

PDF 6쪽은 파괴검사의 제약을, PDF 47쪽은 비파괴검사를 일반적으로 설명하며, 제품 공정값과 라벨의 정확한 매핑이 필요하다고 말한다. 그러나 **이 파일의 FIN_JGMT가 어떤 검사 규격·검사 시점·매칭 절차로 만들어졌는지**를 확인하는 충분한 절차는 찾지 못했다. 따라서 '가이드상 품질 라벨 존재'는 확정할 수 있지만 '전 행마다 독립 실측 검사 정답 존재'는 주장할 수 없다.

## 3. 57번 전자부품(배터리팩) 예지보전

### 라벨의 출처는 대회 점용접과 연결되지 않는다

- PDF 8–11쪽: 배터리셀 단자와 센싱라인의 레이저 용접, 수집기간 2022-07~09, 약 3초 주기다.
- PDF 9쪽은 용접 완료 모듈 검사 결과의 날짜·시간과 설비 알람을 기록하고 공정값과 상관관계를 분석해 정상/이상을 구분한다고 설명한다.
- PDF 17쪽은 원 공정 데이터의 종속변수가 없다고 적으며, 후속 실습은 별도 `WeldingTest_03_NG_Label.csv`, `WeldingTest_04_NG_Label.csv`를 사용한다. 원 로그와 별도 평가 라벨이 있다는 구조는 모순이 아니다.
- PDF 70쪽은 03_NG를 고립된 시점에서 RealPower가 크게 벗어나는 이상으로 설명한다. 그러나 각 라벨의 판정자·검사기준·이상 주입 여부는 이 설명만으로 확정되지 않는다. 명시적 증거 없이 자연 발생 결함 또는 합성 이상이라고 단정하지 않는다.

### 테스트 전체 평균·표준편차 사용 문제는 N-HiTS 경로에 해당한다

- PDF 69·76쪽: `X_errors`를 `pred_score1`로 놓고 그 **테스트 오차 전체**의 평균과 표준편차로 Z-score를 계산한다. 실시간 평가라면 미래에 관측할 테스트 구간의 오차 분포가 현재 판정에 들어간다.
- PDF 87쪽 설명은 학습 오차의 표준편차를 사용한다고 하지만 위 실행 코드와 일치하지 않는다. 새 분석에서는 학습/검증으로 정한 척도를 고정하거나 과거 관측만 사용하는 갱신법으로 구현해야 한다.
- PDF 76쪽은 `nshift=12`로 예측 라벨을 이동한다. PDF 71쪽 테스트 윈도우 시작점 및 별도 라벨 파일의 실제 시각 대응관계를 재확인해야 한다. **수동 이동은 코드에서 확인했지만 오정렬이라고 확정하지는 않는다.**

반면 **두 모드 통계 baseline은 다른 방식이다.** PDF 80–84쪽은 `Training_Data_Real_Power.csv`의 두 출력 군집 평균·표준편차를 구한 다음 테스트에 고정 적용한다. 여기에 테스트 전체 분포를 썼다는 비판을 적용하면 부정확하다. 가이드 자체가 고립 이상에는 N-HiTS F1 0.8947, 연속 이상에는 두 모드 통계 F1 1.0을 제시하므로, 새로운 고급 모델을 도입하는 것 자체로 차별화되지는 않는다.

또한 PDF 89쪽은 제품 불량이 곧 설비 이상 때문이라고 보지 말라고 명시한다. 조립 문제와 설비 문제를 섞어 '설비 고장 예지 정답'으로 해석하면 안 된다.

## 4. 수상 전략에 미치는 영향

추가 자료는 **검증 설계를 개선하고 과장된 성능을 걸러내는 데 유용**하다. 하지만 대회 ② 원본의 건별 정답·반복 데이터 문제를 직접 치유하지 않는다.

- 51번 F1 1.0으로 원본 ②의 불량 검출 성능을 주장할 수 없다. 51번에서는 단순 임계값과 비교하고, 실제 이상 발생 전 평가가 가능한지부터 확인해야 한다.
- 52번은 제품 단위 품질 분류의 외부 사례가 될 수 있다. 다만 303개 제품 그룹의 정답과 분할을 확인해야 하며, 해당 성능은 파이프 공정에 대한 결과다.
- 57번은 다른 용접 방식의 센서 이상탐지 검증 사례가 될 수 있다. 고정 임계값·모드 조건부 통계와 비교해야 하고, 레이저 용접의 정답을 저항 점용접에 옮길 수는 없다.
- 51·52는 2022년 수집기간과 센서·제품번호 구조가 겹친다. 별도 두 현장 검증으로 세기 전에 같은 원천 행/제품의 겹침을 검사해야 한다. **원천 중복은 가능성이고 현재 원본 대조로 확정된 사실은 아니다.**

②로 출품한다면 가장 방어 가능한 주장은 **품질 확정 자동판정**보다 **반복을 제거한 공정 이상 경보와 검사 우선순위 제안**이다. 다만 일별 소수 집계만으로 실제 불량 검출 F1을 확정할 수 없으므로, 심사에서 성능 근거를 요구할 때 약점이 남는다. 주최 측이 추가자료 중심의 검증이나 집계 수준 평가를 명시적으로 인정하지 않는 한, 추가자료의 양만으로 이 위험을 낮게 평가해서는 안 된다.

결론적으로, 이번 교차검토는 **용접의 추가자료 확보가 곧 최우선 수상 후보로의 복귀를 의미하지 않는다**는 판단을 뒷받침한다. 다른 과제 원본에 신뢰할 수 있는 건별 정답과 독립 테스트가 있다면, 그 과제는 같은 노력으로 더 설득력 있는 심사 근거를 만들 수 있을 가능성이 있다. 실제 최종 순위는 다섯 원본을 동일 기준으로 검사한 뒤 정한다.
