## 20·21. 전해탈지와 도금욕

- 두 자료 모두 PDF 9~10쪽에서 2021-09-06~10-27, 5초 주기, 입력 50,094행과 일별 결과 33행을 설명한다. 전해탈지는 pH·온도·전류, 도금욕은 여기에 전압을 사용한다.
- **결과의 `LoT`/`LoT2`는 불량 개수가 아니라 해당 날짜의 불량 Lot 식별값으로 사용된다.** 전해탈지 PDF 31~32쪽, 도금욕 PDF 39~41쪽 코드가 이 의미를 구체화한다. 전해탈지는 `LoT` 또는 `LoT2`가 일치하면, 도금욕은 `LoT`가 일치하면 해당 날짜·Lot의 센서행을 `QC=0`, 목록에 없으면 `QC=1`로 만든다.
- 변수 정의표만 보면 Lot 추적번호라는 설명이 있어 종속변수 의미가 모호하지만, 실제 학습 코드는 Lot 번호 자체를 예측하는 회귀가 아니라 위 방식으로 품질 라벨을 생성한다.
- 이 라벨은 **불량 Lot 소속 여부를 시간별 센서행에 전파한 것**이다. 각 센서 시점마다 독립적으로 시행한 품질검사 결과라고 표현하면 안 된다. 불량 목록에 없는 Lot를 양품으로 처리하므로 기록이 완전한지도 중요하다.
- 전해탈지 PDF 34쪽, 도금욕 PDF 42쪽은 라벨 전파 후 행 무작위 80:20 분할이다. 독립 날짜·Lot 평가를 대체하지 못한다.
- 두 자료와 ID 19는 같은 업종·기간·입력 행수·Lot 구조를 제시한다. 같은 제조현장의 연속 공정일 가능성이 높지만, **원자료 연결을 확인하지 않았으므로 독립한 세 제조업체/세 외부 실증으로 세지도, 완전히 같은 데이터라고 단정하지도 않는다.**

판단: ② 용접의 일별 불량 개수와 달리 여기는 날짜+Lot 연결키가 있다. 이 사례를 따라 용접 센서행에 임의로 불량을 배정하는 것은 정당화되지 않는다. 공개 외부 데이터 허용 시 집단 라벨 방법의 별도 비교 실험 후보이며, 원 용접 데이터의 건별 정답 문제를 직접 해결하지 않는다.
