# 용접 데이터 진단과 무라벨 모델 시연

이 코드는 데이터 구조·품질·반복 구간을 확인하고 세 종류의 공정이탈 점수를 비교한다. **불량 정답을 생성하지 않으며 품질 F1·오경보율을 계산하지 않는다.** 연구 판단은 루트의 [로봇용접 심층분석](../../로봇용접_심층분석.md)을 참고한다.

## 실행

검증 환경: macOS, Python 3.14.6. 직접 사용한 패키지 버전은 `requirements.txt`에 고정했다. 다른 Python 버전에서의 설치 호환성은 검증하지 않았다.

```bash
python3.14 -m venv .venv
.venv/bin/python -m pip install -r analysis/welding/requirements.txt
.venv/bin/python analysis/welding/deep_dive.py --plots
```

이미 분석에 사용한 임시 환경이 남아 있다면 다음으로 실행할 수 있다.

```bash
/tmp/kamp_selection/venv/bin/python analysis/welding/deep_dive.py --plots
```

기본 입력은 저장소 아래의 `2.*.zip` 한 개 또는 추출된 `Welding Data Set_01.xlsx`와 같은 폴더의 `scaled_data.csv`다. ZIP이 있으면 내부 파일을 읽고, 없으면 추출본을 읽는다. 파일이 여러 개로 모호하면 중단한다. `--root`로 검색 루트, `--out`으로 출력 폴더를 지정할 수 있다. `--plots`를 생략하면 그래프를 만들지 않는다.

원본 데이터는 수정하지 않는다. 네트워크에 접근하지 않고 로컬 결과 파일을 생성한다. 결과 CSV에는 원본 센서값이 포함되므로 데이터를 업로드하기로 결정하기 전에는 생성 결과도 GitHub 업로드 대상에 넣지 않는다.

## 생성 파일

| 파일 | 내용 |
|---|---|
| `outputs/audit.json` | 입력 해시·버전·메타데이터·CSV 복원 후보·반복 구간·모델 비교 |
| `outputs/daily_audit.csv` | 날짜별 행 수·기록된 결함유형 값·기존 센서조합 수 |
| `outputs/repeated_sequences.csv` | 날짜 사이 100행 이상 연속 일치 구간과 위치 |
| `outputs/unlabelled_scores.csv` | 후일자 기록의 원값·추적용 엑셀 행 번호·이탈 점수·기준 초과 여부 |
| `outputs/reference_exceedance_by_date.csv` | 날짜별 기준 초과 비율. 실제 오경보율이 아님 |
| `outputs/welding_data_audit.png` | 관측 가압력·기존 조합 재등장·800행 반복 시각화 |

## 해석 제한

- 날짜와 idx를 모델 입력으로 넣지 않는다. 날짜의 의심되는 두 셀도 자동 정정하지 않는다.
- 첫 이틀 2,552행을 기준으로 학습했으나 정상으로 검증된 자료는 아니다.
- 이후 9,387행의 센서 조합이 전부 기준자료에 등장한다. 시연을 독립 미래 검증이라고 부르지 않는다.
- 각 모델의 기준자료 점수 99분위수는 경보량을 비교하기 위한 설정이다. 품질 오경보율 1% 보장이 아니다.
- 상위 5% 민감도 분석은 고유 센서조건 1,574종 중 79종에 관한 것이다. 생산건의 5% 검사예산과 다르다.
- CSV 역변환은 수치 대응을 확인한 후보식이다. 공식 scaler·가공 이력 또는 개별 용접 연결키를 복원한 것은 아니다.
- result의 값 합계 39는 불량제품 39개로 단정할 수 없다. 누락 유형·날짜를 0으로 채우지 않는다.

전체 실행, 핵심 수치 대조, 그래프 열람을 통해 결과를 확인했다. 실제 불량 예측모델 개발과 검증은 별도 품질 정의 확인 후 진행할 단계다.
